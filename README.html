大模型业界技术报告与论文研究笔记

一句话：把 2026 年这一代大模型的技术报告和论文，拆成不预设任何背景的中文笔记 —— 从"一张网页怎么变成训练数据"，一直讲到"模型训好了怎么服务几万个用户、怎么被榜单考核"。

174 篇笔记，11 个专题，全部小白向。 每个名词第一次出现都会给「英文全称 + 中文 + 一句话解释」再使用。

⚠️ 先说清楚四件事

① 这是学习笔记，不是论文复述。
每个专题的写法都是：先用生活类比讲清"这个问题为什么存在"，再上 ASCII 图讲结构，最后才挂回真实系统（Megatron-LM、vLLM、SGLang 的具体代码位置）。你可以只看类比和图，跳过所有公式，仍然能读懂后面的章节。

② 数字的可靠性是分级标注的。

标记 含义
✅ 从一手技术报告 PDF 正文提取核对过，能追到原文
⚠️ 我的推断、估算或二手来源，引用前请自行核实

尤其注意：多模态大模型/ 目录里的 arXiv 编号没有逐条验证（写作时访问 arXiv 被环境拦截），该目录 README 里有明确声明。相比之下 后训练/ 的 38 个编号是逐条验证过的。

③ 时效：主体写于 2026 年 8–9 月。
讲原理的章节（架构、并行、KV cache）过期最慢；讲"业界现状""开放问题"的章节过期最快。每个专题的最后一章通常就是最容易过期的那章。

④ 仓库里没有 PDF 原文和框架源码。
论文 PDF 和 Megatron-LM / vLLM / SGLang / veRL 等开源项目的完整拷贝都在本地、不进仓库（见 .gitignore）—— 前者是他人版权内容，后者没必要重复上传。需要核对数字时请从 arXiv / 官方渠道重新获取。

每个专题目录下都有 README.md（本专题导读）和 附-速查表.md（全部缩写的英文全称 + 中文 + 在哪章讲）。看到不认识的缩写，先去速查表查。

关于 .html 文件

每篇 .md 都有一个同名 .html，是为了在浏览器里读得舒服一点（ASCII 图不会错位、表格更好看）。内容完全一致，选一种读就行。 在 GitHub 上直接看 .md 即可；把仓库 clone 到本地的话，.html 双击就能打开。
