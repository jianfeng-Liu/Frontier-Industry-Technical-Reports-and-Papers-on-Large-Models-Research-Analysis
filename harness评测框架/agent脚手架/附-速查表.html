D. Claude Code 配置项速查（✅ 全部来自官方文档）

许可模式（permissions.defaultMode，或 --permission-mode）

值 不问就能干
default（界面名 Manual） 只读
acceptEdits 读 + 改文件 + 常见文件系统命令
plan 读（+ auto 可用时的分类器批准命令）
auto 全部，有后台安全检查
dontAsk 只有预先批准的工具
bypassPermissions ⚠️ 全部，无检查

⟹ ★★ 会话中切换：Shift+Tab。★★★ 任何模式都不放行 rm 关键路径。

沙箱

配置键 / 命令 作用
/sandbox 打开沙箱面板
sandbox.enabled 全局开启
sandbox.failIfUnavailable 沙箱起不来时硬失败
sandbox.allowUnsandboxedCommands: false ★★ 严格沙箱模式，关掉逃生舱
sandbox.filesystem.allowWrite / denyWrite / allowRead / denyRead 文件边界
sandbox.network.allowedDomains / deniedDomains / strictAllowlist 网络边界
sandbox.excludedCommands 完全排除在沙箱外的命令
dangerouslyDisableSandbox ★★ 单次逃生舱参数

⟹ ★ 默认边界：只能写当前工作目录 + 会话临时目录；★★★ 网络默认不放行任何域名。
⟹ ⚠️ 不支持原生 Windows，需 WSL2。依赖 bubblewrap + socat（+ 可选 seccomp）。

上下文 / 记忆

命令 / 路径 作用
/compact / /compact <重点> 手动压缩
/clear 清空重开
/context 看上下文占用
/memory 浏览编辑记忆文件

CLAUDE.md 位置（加载顺序：广 → 窄）

  1. 托管策略：macOS /Library/Application Support/ClaudeCode/CLAUDE.md；Linux/WSL /etc/claude-code/CLAUDE.md；Windows C:\Program Files\ClaudeCode\CLAUDE.md
  2. 用户：~/.claude/CLAUDE.md
  3. 项目：./CLAUDE.md 或 ./.claude/CLAUDE.md
  4. 本地：./CLAUDE.local.md

⟹ ★★ 引入其他文件：@path/to/file（最多 4 层）。兼容 AGENTS.md：@AGENTS.md 或 ln -s AGENTS.md CLAUDE.md。
⟹ ★ 建议每个文件 200 行内；超过 4 MiB 直接跳过。

配置键 取值

子 agent

配置键 作用

⟹ ★★ 定义位置：~/.codex/agents/（个人）或 .codex/agents/（项目），一个 agent 一个 TOML 文件。

AGENTS.md

  • 全局：~/.codex（或 CODEX_HOME）下先试 AGENTS.override.md，回退 AGENTS.md
  • 项目：从 Git 根逐级向下走到当前目录，每层先试 AGENTS.override.md 再试 AGENTS.md
  • 合并：从根往下拼接，★★ 越靠近当前目录的越晚出现，因而覆盖前面的
  • 上限：project_doc_max_bytes，默认 32 KiB
  • 备选文件名：project_doc_fallback_filenames

F. ⚠️⚠️ 四个容易踩的坑

① ★★★ 「harness」是同音异义词

   评测入门讲的 harness = 判卷程序
   本目录讲的 harness = agent 脚手架
   ⟹ ⚠️ DeepSeek-V4 报告里两个意思都出现了，要看上下文。

② ★★★ 坏工具比没工具更糟

   ✅ 不给搜索工具 = 15.7
   ✅ 给一个难用的迭代式搜索 = 12.0
   ⟹ 🔑 模型会去用坏工具，然后被带偏、被它填满上下文。

③ ★★★ 工具结果挂在哪个角色下，是有后果的

   ✅ DeepSeek-V4 报告：
      作为 tool result 回传 ⟹ 触发工具调用路径 ⟹ 思考轨迹保留
      伪装成 user message ⟹ 不触发 ⟹ 官方建议改用非思考模型
   ⟹ 🔑 ★★★ 同一个模型，脚手架写法不同 = 换一个档位。

④ ★★★ 榜单上没有"模型的分数"

   只有【模型 + 脚手架 + 子集 + 预算 + 口径】这一整套系统的分数。
   ⚠️ 评测框架能看到的只有一个 patch，它不知道脚手架长什么样。
