# 业界模型技术报告解析

> **一句话**：2026 年这一代国产旗舰大模型 —— DeepSeek-V4、Kimi K3、GLM-5.2/5.3、MiniMax M3、openPangu-2.0 —— **架构上到底各自改了什么、为什么这么改、谁抄了谁**。

**27 篇笔记** = 17 章架构入门（从零讲起）+ 6 份技术报告解析 + 1 份五家横向对照。

---

## ⚠️ 先说清楚三件事

**① 不懂架构？先读 [大模型架构入门/](大模型架构入门/README.md)，不要直接看报告解析。**
技术报告里全是 MLA、GQA、MoE、RoPE、MTP、Muon 这类缩写，不预先搞懂，报告解析会一个字都看不进去。架构入门那 17 章**不预设你懂任何架构知识**，从"一个词怎么变成一串数字"讲起。

**② 数字是从 PDF 正文核对的，不是二手解读。**
Kimi K3、openPangu-2.0、模型技术对比这几篇，架构、公式、超参、评测数字均从技术报告 PDF 正文提取核对（每篇开头都写了来源和日期）。标 ✅ 的能追到原文，标 ⚠️ 的是我的推断。

**③ GLM 有两代、MiniMax 含 M2 复盘 —— 不是重复文档。**
GLM-5.2 和 GLM-5.3 是两次发布、两套细节；MiniMax M3 那篇里带 M2 的复盘，因为这是五家里**唯一一个把三条路线都跑过、并且把失败原因写进正式论文的团队**。
