03 · 残差流：全教程最重要的一个直觉

这一章的目标：如果你只读一章，读这章。
读完你应该能回答：x = x + f(x) 这个"加号"为什么是深度学习最重要的发明？残差流为什么可以当成一条"总线"？DeepSeek-V4 和 openPangu 的 mHC、Kimi K3 的 AttnRes 到底在改什么？为什么 GLM 和 MiniMax 选择不改？
读法：本章有四组"拿计算器就能按完"的小例子——§3.1.2（$d=4$，一个加号）、§3.3.4–§3.3.5（$d=8$，叠加与干涉）、§3.5.4（$3\times3$ 的 Sinkhorn 迭代）、§3.6.4（$d=4$ 的深度注意力）。这四组按过一遍，本章就没有黑箱了。

本章关键词（每个缩写第一次出现都给中英文全称，后面直接用缩写）

残差连接（Residual Connection / Skip Connection，残差连接 / 跳跃连接）—— 就是那个 x = x + f(x) 的加号，2015 年 ResNet（Residual Network，残差网络）提出。

残差流（Residual Stream）—— 贯穿全模型的那条 $d$ 维"总线"。本章 §3.3 起的核心比喻。

增量（Increment / Update）—— 一层写到残差流上的那一份 $F_l(x_l)$。★ 全章最需要分清的一对概念：增量 $F_l(x_l)$ vs 累加值 $x_l$。

雅可比矩阵（Jacobian Matrix）—— 向量函数输出对输入的偏导表，形状 $[d, d]$。反向传播就是一串雅可比连乘。

Pre-Norm（Pre-Normalization，前置归一化）—— 归一化放在子层之前，详见 04 章 §4.3。本章的 $\sqrt{N}$ 增长是它的直接后果。

mHC（manifold-constrained Hyper-Connections，流形约束超连接）—— DeepSeek-V4 与 openPangu 的残差改造：把 1 条流变成 $n$ 条（§3.5）。

HC（Hyper-Connections，超连接）—— mHC 的前身，"把残差加宽成多条"这条技术线的源头。

双随机矩阵（Doubly Stochastic Matrix）—— 非负、每行和为 1、每列和为 1 的方阵。mHC 的核心约束（§3.5.3）。

Sinkhorn–Knopp（辛克霍恩–克诺普算法）—— 把任意正矩阵投影到双随机流形的交替归一化算法（§3.5.4）。

AttnRes（Attention Residuals，注意力残差）—— Kimi K3 的残差改造：在深度方向做一次 softmax 注意力（§3.6）。

JL 引理（Johnson–Lindenstrauss Lemma，约翰逊–林登施特劳斯引理）—— 高维空间里"近似正交的方向"数量随维度指数增长的理论依据（§3.3.5）。

MoE（Mixture of Experts，混合专家）／MTP（Multi-Token Prediction，多 token 预测）—— 本章只在提到五家配置时用到，详见 10 章 / 12 章。

本章会用到的五家层数（来自 01 章 §1.6）：DeepSeek-V4-Pro 61、Kimi K3 93、GLM-5.2 78、MiniMax M3 60、openPangu-2.0-Pro 50。

3.1 先看那个式子

回忆 01 章的主循环：

x = x + Attention( Norm(x) )
x = x + FFN( Norm(x) )

注意这不是 x = Attention(Norm(x))。 这个 x + 叫残差连接，2015 年 ResNet 提出。

它看起来只是一个加号。但没有它，超过 20 层的网络根本训不起来。

3.1.1 逐符号读一遍：每个记号是什么

本章公式不多但记号密，先把它们摊在一张表上。后面每一节都会回来查这张表。

记号 怎么读 是什么 形状
$d$ "残差流宽度" 每个 token 的向量维度。openPangu 5120、K3 7168 标量
$N$ "层数" openPangu 50、K3 93 标量
$l$ "第 $l$ 层" 从 1 数到 $N$ 标量
$x_l$ "第 $l$ 层的输入" 残差流在第 $l$ 层的累加值 $[d]$（单 token）／$[L, d]$（整条序列）
$F_l$ "第 $l$ 层的子层" Attention 或 FFN，连它前面那个 Norm 一起算进去 函数 $[d] \to [d]$
$F_l(x_l)$ "第 $l$ 层写出的增量" ★ 全章最重要的一个量。§3.6 会反复强调它和 $x_l$ 的区别 $[d]$
$\mathcal{L}$ "损失" 一个标量 标量
$\dfrac{\partial F_l}{\partial x_l}$ "$F_l$ 的雅可比" 子层输出的每一维对输入的每一维的偏导 $[d, d]$
$I$ "单位矩阵" 对角线全 1、其余全 0 $[d, d]$
$|x|$ "$x$ 的范数" 向量长度 $\sqrt{\sum x_i^2}$ 标量

📌 两个最容易混的记号，现在就分清：
```
x_l = 【累加值】。它是"到第 l 层为止，所有层写进去的东西的总和"。
F_l(x_l) = 【增量】。 它只是"第 l 层这一次写进去的那一份"。

标准残差： x_{l+1} = x_l + F_l(x_l)
=> x_N = x_0 + F_1(x_1) + F_2(x_2) + ... + F_{N-1}(x_{N-1})
=> 累加值 = 初始值 + 所有增量之和
```
§3.6 的 AttnRes 之所以容易被讲反，就是因为很多人把这两个搞混了。

3.1.2 ★ 一个 $d=4$ 的最小例子：这个加号到底做了什么

取 $d = 4$，设第 $l$ 层的输入和它的子层输出分别是

x_l        = [ 2.0,  0.0, -1.0,  1.0 ]        ||x_l|| = sqrt(6)    = 2.44949
F_l(x_l)   = [ 0.3, -0.2,  0.5,  0.1 ]        ||F_l|| = sqrt(0.39) = 0.62450

两种接法，逐元素算出来：

接法 式子 $x_{l+1}$ $|x_{l+1}|$ 和 $x_l$ 的夹角
无残差 $x_{l+1} = F_l(x_l)$ [ 0.3, -0.2, 0.5, 0.1] 0.62450 82.5°
有残差 $x_{l+1} = x_l + F_l(x_l)$ [ 2.3, -0.2, -0.5, 1.1] 2.60576 13.7°

那两个角度怎么来的（余弦定义 $\cos\theta = \dfrac{a\cdot b}{|a|\,|b|}$）：

有残差： x_l . x_{l+1} = 2.0x2.3 + 0.0x(-0.2) + (-1.0)x(-0.5) + 1.0x1.1
                       = 4.6 + 0 + 0.5 + 1.1 = 6.2
         cos = 6.2 / (2.44949 x 2.60576) = 6.2 / 6.38278 = 0.97136  ->  13.7 度

无残差： x_l . F_l    = 2.0x0.3 + 0 + (-1.0)x0.5 + 1.0x0.1 = 0.6 - 0.5 + 0.1 = 0.2
         cos = 0.2 / (2.44949 x 0.62450) = 0.2 / 1.52971 = 0.13074  ->  82.5 度

🔑 这两个角度就是残差连接的全部直觉：
```
无残差：新状态和旧状态几乎【正交】（82.5 度）。
每一层都在"换话题"——上一层辛苦算出来的方向，这一层基本不管。

有残差：新状态只比旧状态偏了【13.7 度】。
每一层都在"微调"——原来的内容基本保留，只加了一个小修正。
```
$|F_l| / |x_l| = 0.62450 / 2.44949 = 0.255$，也就是"这一层只改动了大约四分之一的幅度"。 这个比值会在 04 章 §4.3.5以 $1/\sqrt{l}$ 的形式再出现。

3.1.3 ★ 把子层"学废"：有加号和没加号的差别有多大

现在做一个思想实验：假设第 $l$ 层彻底没学会，它的子层输出恒为 0。

情形 无残差 $x_{l+1} = F_l(x_l)$ 有残差 $x_{l+1} = x_l + F_l(x_l)$
$F_l$ 输出恒为 0（这一层学废了） [0, 0, 0, 0] ❌ 信息全丢，它后面所有层都在处理零向量 [2, 0, -1, 1] $= x_l$ ✅ 恒等直通，等于这一层不存在
此时 $\dfrac{\partial x_{l+1}}{\partial x_l}$ $\mathbf{0}$ ❌ 梯度链在这里断掉 $I$ ✅ 梯度原封不动通过
$F_l$ 输出异常大（这一层炸了） 后面全被它主导，原始信息无从恢复 $x_l$ 还在里面，至少保住了一份原始信号
这一层的默认行为 "输出一个新东西"（默认值是零） "什么都不做"（默认值是恒等）

🔑 看最后一行。残差连接真正干的事，不是"加了一条捷径"，而是——

把每一层的默认行为从【替换】改成了【什么都不做】。

```
无残差：网络要学的是"这一层应该输出什么"。
想让这一层不起作用，必须精确地学出一个【恒等映射】—— 这非常难。

有残差：网络要学的是"这一层要在原来的基础上改一点什么"。
想让这一层不起作用，只要把输出学成 0 —— 这非常容易（权重归零即可）。
```

ResNet 论文里的原话就是这个意思：学"残差" $F(x) = H(x) - x$ 比直接学 $H(x)$ 容易。 因为在深层网络里，$H(x)$ 的最优解往往接近恒等，而"接近恒等"对应的残差 $F(x)$ 就接近 0，是个好起点。

3.2 为什么没有它就训不动：连乘 vs 连加

这一节是纯数学，但很短，而且是理解一切的基础。

3.2.1 没有残差：连乘

设第 $l$ 层是 $x_{l+1} = F_l(x_l)$，一共 $N$ 层。反向传播时，损失 $\mathcal{L}$ 对第 1 层输入的梯度是链式法则的连乘：

$$\frac{\partial \mathcal{L}}{\partial x_1} = \frac{\partial \mathcal{L}}{\partial x_N}\cdot\frac{\partial F_{N-1}}{\partial x_{N-1}}\cdot\frac{\partial F_{N-2}}{\partial x_{N-2}}\cdots\frac{\partial F_1}{\partial x_1}$$

$N-1$ 个雅可比矩阵连乘。 设每个雅可比的"典型放大倍数"（谱范数量级）是 $\rho$，那么整体就是 $\rho^{N-1}$。把这个数算出来：

层数 $N$ $\rho = 0.9$ $\rho = 0.95$ $\rho = 1.0$ $\rho = 1.05$ $\rho = 1.1$ 有残差的恒等项
10 0.387 0.630 1 1.55 2.36 1
25 0.0798 0.292 1 3.23 9.85 1
50（openPangu） 0.00573 0.0810 1 10.9 107 1
93（Kimi K3） $6.2\times10^{-5}$ 0.00892 1 89.0 6429 1

自己验算一行：$0.9^{49} = e^{49\ln 0.9} = e^{49\times(-0.105361)} = e^{-5.1627} = 0.00573$ ✓

rho = 0.9 ,  N = 93  ->  6.2e-5      梯度消失，浅层收到的信号只有万分之 0.6
rho = 1.1 ,  N = 93  ->  6429        梯度爆炸，训练直接发散
rho = 1.0            ->  刚好，但这是【测度为零】的巧合，不可能自然维持

🔑 这就是 2015 年之前深度网络的死穴：不是"深了学不到东西"，是梯度在传回去的路上就已经数值上死掉或炸掉了。而 $\rho$ 恰好等于 1 是不可能靠运气维持的——每一层的权重都在变。

注意 $\rho$ 只要偏离 1 一点点就够致命：$\rho = 0.95$（只小 5%）在 93 层上就衰减到 0.9%；$\rho = 1.05$（只大 5%）在 93 层上放大 89 倍。深度把任何微小偏差指数放大，这是连乘的本质。

3.2.2 有残差：连加

$x_{l+1} = x_l + F_l(x_l)$，雅可比变成：

$$\frac{\partial x_{l+1}}{\partial x_l} = \underbrace{I}_{\text{恒等}} + \frac{\partial F_l}{\partial x_l}$$

连乘展开：

$$\frac{\partial x_N}{\partial x_1} = \prod_{l=1}^{N-1}\left(I + \frac{\partial F_l}{\partial x_l}\right) = I + \sum_l \frac{\partial F_l}{\partial x_l} + \sum_{l<m}\frac{\partial F_m}{\partial x_m}\frac{\partial F_l}{\partial x_l} + \cdots$$

关键就在展开式的第一项 $I$。 把它画出来（以 $N=4$、三个子层为例）：

无残差：只有【一条】路径，长度 N-1 = 3，梯度必须走完全程

          x1 --[F1]--> x2 --[F2]--> x3 --[F3]--> x4


有残差：每个 F 都可以【走】或【不走】，于是 2^(N-1) = 8 条路径并存

  长度 0 :  x1 ------------------------ x4     <- 恒等路径，梯度原封不动直达
  长度 1 :  x1 --[F1]------------------ x4
  长度 1 :  x1 --------[F2]------------ x4
  长度 1 :  x1 ---------------[F3]----- x4
  长度 2 :  x1 --[F1]--[F2]------------ x4
  长度 2 :  x1 --[F1]--------[F3]------ x4
  长度 2 :  x1 --------[F2]--[F3]------ x4
  长度 3 :  x1 --[F1]--[F2]--[F3]------ x4     <- 唯一那条"和无残差一样"的路

$N = 93$ 时这个数是 $2^{92} \approx 5\times10^{27}$ 条路径，长度从 0 到 92 都有。梯度是这 $5\times10^{27}$ 条路径贡献之和，其中长度为 0 的那一条完全不衰减。

🔑 一句话：残差把连乘变成了连加。$\prod(1+a_i) \approx 1 + \sum a_i$（当 $a_i$ 小时）。加法不会指数衰减。

对照 §3.2.1 那张表最右边一列：无论 $N$ 是 10 还是 93，恒等项都是 1。这一列就是残差连接的全部价值。

📌 一个很有用的经验观察：残差网络在行为上更像"很多个浅网络的集成"，而不是"一个很深的网络"。实验上随机删掉训练好的 ResNet 的某一层，性能只掉一点点；而无残差的网络删一层就废了。从上面那张路径表就能看出为什么：删掉 $F_2$ 只是让 8 条路径里的 4 条失效，另外 4 条（包括恒等路径）照旧工作。这也解释了为什么这一代模型敢堆到 93 层（Kimi K3）。

3.3 核心比喻：残差流是一条总线

现在换一个视角，这个视角比上面的数学更重要。

不要把模型想成"数据从一层流到下一层"。要把它想成：有一条贯穿全模型的"传送带"，每一层从上面读一点、往上面写一点。

🔑 三个必须同时成立的性质，才让"总线"这个比喻站得住：
(1) 【共享】：所有层看的是同一条流，不是各层之间点对点传话。 (2) 【可寻址】：流的 d 个维度可以当 d 条"频道"用，谁想读哪条自己去读。 (3) 【只做加法】：写入是 x += delta，不是 x = delta。 ★ 这一条最关键：前面写的东西【不会被后面覆盖】。 所以第 3 层写的信息，第 90 层还能原样读到。

3.3.2 "读"和"写"具体是什么：逐层的操作表

这个视角能被落到具体的矩阵上，非常实在。一个 FFN 是 $W_{\text{down}}\big(\text{act}(W_{\text{gate}}x,\ W_{\text{up}}x)\big)$，一个 Attention 是四个投影，把它们按"读 / 写"分类：

子层 矩阵 形状 对残差流的动作 为什么
Attention $W_Q$ $[d,\ \cdot]$ 读 每一行对应流上的一个方向，决定"从哪些频道取 query"
Attention $W_K$ $[d,\ \cdot]$ 读 同上
Attention $W_V$ $[d,\ \cdot]$ 读 同上
Attention $W_O$ $[\cdot,\ d]$ 写 每一列对应流上的一个方向，决定"往哪些频道写"
FFN $W_{\text{gate}}$ $[d,\ d_{ff}]$ 读
FFN $W_{\text{up}}$ $[d,\ d_{ff}]$ 读
FFN $W_{\text{down}}$ $[d_{ff},\ d]$ 写

所以一层有 5 个"读取器"、2 个"写入器"；而对残差流本身，一层发生的是 2 次读 + 2 次写（Attention 前读一次、后写一次；FFN 前读一次、后写一次）。累积起来：

到第 $l$ 层为止 读取残差流的次数 写入残差流的次数 流上叠加的增量个数 对应模型
1 2 2 2 —
10 20 20 20 —
50 100 100 100 openPangu-2.0-Pro 全深度
61 122 122 122 DeepSeek-V4-Pro 全深度
93 186 186 186 Kimi K3 全深度

🔑 所以残差流的 $d=5120$ 个维度，可以理解成 5120 条"通信频道"。
- 某一层把"这个词是主语"写到第 37 号频道上
- 后面第 40 层的某个注意力头，用它的 $W_Q$ 专门去读第 37 号频道
- 两层之间不需要相邻，也不需要经过中间层的许可 —— 中间层只是往流上加东西，不会覆盖它

这就是残差流被称为"总线"的原因：它是一个共享的、可寻址的、只做加法的通信媒介。

3.3.3 ⚠️ 顺手算一笔账：残差相加本身是全模型算术强度最低的操作

"读一点、写一点"听起来很轻，但它在硬件上并不便宜。把那个 x += delta 的账算出来（BF16，每元素 2 字节）：

每个元素要搬的字节： 读 x (2) + 读 delta (2) + 写 x (2)  =  6 Byte
每个元素的计算量：   一次加法                            =  1 FLOP

算术强度 I = 1 / 6 = 0.167 FLOP/Byte
             ^^^^^  对比 H100 SXM5 的 BF16 屋脊点 295 —— 低了 1770 倍
屋顶线上界 P = 3350 GB/s x 0.167 = 0.56 TFLOPS  ← 只占 989 TFLOPS 峰值的 0.056%

代入 openPangu（$d = 5120$、50 层）、一条 4096 token 的序列：

每次残差相加的字节数 一层（2 次） 全模型（50 层 / 100 次）
字节 $3 \times 4096 \times 5120 \times 2 = $ 125.8 MB 251.7 MB 12.58 GB
按 3.35 TB/s 的最短时间 37.6 µs 75.1 µs 3.76 ms

⚠️ 口径与现实的差距，必须说清：
✅ 上表是【完全不融合】时的账：残差相加被写成一个独立 kernel， 从 HBM 读两份、写一份。3.76 ms 纯粹花在搬运上，一个浮点数都没多算。 ✅ 真实实现会把残差相加【融进上一个矩阵乘的 epilogue】（尾声阶段）： delta 本来就在寄存器里，只需要多读一次 x，字节数从 6d 降到 4d， 而且省掉一整次 kernel 启动。 -> 见 [../../大模型算子开发/05-算子融合.md] 与 [../../大模型算子开发/02-屋顶线与性能剖析.md] §2.5 盲区三 ⚠️ 上表【没算】L2 缓存命中。d=5120 的一行只有 10 KB， 连续两层之间 x 很可能还在 50 MB 的 L2 里，实际 HBM 流量小于这个数。

🔑 记住这个结论就够了：残差相加是典型的 Memory Bound 操作，它的成本【全在搬运，不在计算】。

3.5 改法一：mHC（DeepSeek-V4 / openPangu）

mHC = manifold-constrained Hyper-Connections（流形约束超连接），源自超连接（Hyper-Connections, HC）这条线。

3.5.1 它在改什么

标准残差是一条流。mHC 把它变成 n 条并行的流（V4 和 openPangu 都用 n=4）：

【标准残差】n = 1

   ----------------------------------------    唯一的那条流（宽度 d）
        |         ^
        |         |
        v         |
      [ F ] ------'                            读一次、写一次，都不带可学习权重


【mHC】n = 4

   ----------------------------------------    流 1
   ----------------------------------------    流 2
   ----------------------------------------    流 3
   ----------------------------------------    流 4
        |         ^         |
        A         C         B
        |         |         |
        v         |         v
      [ F ] ------'        (B 这一路不经过子层，流之间直接混合)

三个新矩阵各管一件事：

矩阵 形状 一句话作用 对应上图
$A_l$ $1\times n$ 读：把 $n$ 条流加权合成一条，喂给子层 左边那条下行的箭头
$C_l$ $n\times 1$ 写：把子层的单条输出分发回 $n$ 条流 中间那条上行的箭头
$B_l$ $n\times n$ 流间混合：$n$ 条流之间怎么交换，不经过子层 右边那条旁路

3.5.2 公式

$$x_{l+1} = B_l\,x_l + C_l\,F_l(A_l\,x_l)$$

其中 $x_l \in \mathbb{R}^{n\times d}$（n 条流，每条 d 维）。

注意 $A, B, C$ 都是可学习的、且是逐层不同的。标准残差是它的特例：$n=1,\ A=B=C=1$。

3.5.3 关键在于"manifold-constrained"这个前缀

如果 $B_l$ 自由学习，会立刻退化成一个 $n$ 层深的线性网络，重新引入 §3.2.1 的连乘爆炸问题（$B_N B_{N-1}\cdots B_1$ 的谱半径不受控）。§3.2.1 那张表就是它的下场：$\rho$ 只要偏离 1 百分之五，93 层就衰减到 0.9% 或放大 89 倍。

mHC 的做法：把 $B_l$ 约束在【双随机矩阵】流形上。

双随机矩阵（doubly stochastic）的三条定义：
    (1) 所有元素 >= 0
    (2) 每一行的和 = 1
    (3) 每一列的和 = 1

一个 $n=3$ 的例子（这就是原来那张容易渲染错位的方框图，改成表格）：

$B$ 列 1 列 2 列 3 行和
行 1 0.5 0.3 0.2 1.0 ✓
行 2 0.2 0.5 0.3 1.0 ✓
行 3 0.3 0.2 0.5 1.0 ✓
列和 1.0 ✓ 1.0 ✓ 1.0 ✓

为什么这个约束正好是对的——三条理由，第一条是关键：

(1) 双随机矩阵的谱半径【恰好等于 1】
    证明只要两行：
      · 全 1 向量是它的特征向量，特征值 1（因为每行和 = 1）  => 谱半径 >= 1
      · 非负矩阵的谱半径 <= 最大行和 = 1                      => 谱半径 <= 1
      => 谱半径 = 1，严格地
    -> 连乘 B_N...B_1 永远不会爆炸也不会消失，§3.2 的好性质被完整保留

(2) 它是【广义的置换 / 混合】：信息在 n 条流之间【重新分配】，总量守恒
    -> 不会凭空放大或丢失

(3) 所有 n x n 双随机矩阵构成【Birkhoff 多胞体】，它的顶点恰好是 n! 个置换矩阵
    （Birkhoff-von Neumann 定理）
    -> 所以 B 学到的是"n 条流之间的一种软置换"，语义非常清楚

3.5.4 ★ Sinkhorn–Knopp：$3\times3$ 手算走一遍

这是个漂亮的算法，而且你懂算法的话一眼就能看懂：

def sinkhorn(M, iters=20):
    P = np.exp(M)                              # 先取指数，保证严格正
    for _ in range(iters):
        P = P / P.sum(axis=1, keepdims=True)   # 归一化每一行 -> 行和 = 1
        P = P / P.sum(axis=0, keepdims=True)   # 归一化每一列 -> 列和 = 1（行和被破坏一点）
    return P                                   # 交替投影，几何速率收敛到双随机

✅ 翻 4 倍的只有【残差流那一份激活】：从 3.58 GB 涨到 14.33 GB。 ❌ 【不是】整机显存 ×4。模型权重、优化器状态（AdamW 的两份动量、Muon 的动量缓冲）、 注意力和 FFN 内部的中间激活，一个字节都没变。 一个 61 层 / 1.6T 参数的模型，权重本身就是 TB 量级，10.75 GB 的增量占比很小。 ⚠️ 上表按"每层都完整保存残差流"算，是【不做 activation checkpointing】的上界。 做了重计算之后实际驻留量更小。

🔑 把 §3.3.3 那笔账接上，这一节的结论就完整了：残差相加的算术强度只有 0.167，深陷 Memory Bound；mHC 把访存从 $2d$ 量级推到 $20d$ 量级，在一个本来就卡带宽的地方再乘 10 倍。⚠️ 这是我对"+6.7% 来自哪里"的归因，V4 报告只给了总数，没有分解。

3.6 改法二：AttnRes（Kimi K3）

AttnRes = Attention Residuals（注意力残差）。 它和 mHC 不是"改残差的两种做法"，而是在改两件完全不同的事：
mHC 改的是"残差流有几条"；AttnRes 改的是"这一层到底该读谁写进去的东西"。

📄 一手来源：Kimi K3 技术报告 §2.2（式 8 / 9 / 10）、§5.2 训练 infra、§5.4 推理 infra，均已核对正文。
独立论文《Attention Residuals》arXiv:2603.15031（Kimi Team，2026-03-16），比 K3 报告早四个多月。
⚠️ K3 报告的参考文献 [58] 只写了 "Kimi Team. Attention Residuals. Preprint. 2026."，并没有给 arXiv 编号——上面这个编号来自 arXiv 检索。

3.6.1 一句话框架：标准残差犯的是 RNN 犯过的错

报告原文的这句话，是整节最好的解释：

标准残差把所有历史信息压进深度方向上的单个状态 $h_l$ —— 这是一个瓶颈，让人想起 RNN 在时间方向上的问题。
（原文：a bottleneck reminiscent of RNNs over time）

RNN（Recurrent Neural Network，循环神经网络）把所有历史 token 压进一个固定状态；标准残差把所有历史层的输出压进一个 $x_l$。同一个病，只是换了一根轴。 而 Transformer 当年治 RNN 的药方就是注意力——让每个位置用随数据变化的权重去选读任意历史位置。

把这个类比摊成一张表，两行读完整节的思想：

病：把所有历史压进一个固定状态 药：换成注意力 在哪根轴上 什么时候
RNN → Transformer 所有历史 token 压进一个隐状态 每个位置用随数据变化的权重选读任意历史位置 序列方向 2017 年
标准残差 → AttnRes 所有历史 层 的输出压进一个 $x_l$ 每一层用随数据变化的权重选读任意历史层 深度方向 2026 年

🔑 记住这个类比。下面所有公式都只是它的技术实现。

3.6.2 第一步：可以读的"源"是什么（★ 最容易看错的地方）

📌 报告用 $h$ 表示残差流，就是本章 §3.1.1 那张表里的 $x$；$f_i(\cdot)$ 是第 $i$ 层的子层函数。

第 $l$ 层面前摆着 $l$ 个可选的源（报告式 8）：

$$k_i = v_i = \begin{cases} h_{-1}, & i=0 \quad(\text{token embedding})\[3pt] f_i(h_i), & 1\le i\le l-1 \quad(\text{第 }i\text{ 层【自己写出的那一份】}) \end{cases}$$

三个细节，每一个都必须点出来：

(a) k_i = v_i —— 没有 W_K，也没有 W_V
    层的输出【直接】既当 key 又当 value
    -> "我怎么介绍自己" 和 "我能给你什么" 是同一个东西
    -> 这是它比标准注意力便宜得多的原因之一

(b) ★★ 是 f_i(h_i)【增量】，不是 h_i【累加值】—— 全节最关键的一点
    回去看 §3.1.1 那张表最后两行的区分。
    拿累加值当源：每个源里都已经包含了它前面所有的源 -> 高度冗余，根本挑不出东西
    拿增量当源  ：l 个源才是 l 份【互相独立的贡献】，才构成一组值得挑的基

    ✅ 这一点在报告里是自洽的：Block 版把块内的源【求和】成 b_n = Sum_j f_j(h_j)
       —— 只有当 f_j(h_j) 是增量时，"把它们加起来"才讲得通

(c) i = 0 是 token embedding
    -> "直接回头看原始输入" 永远是一个可选项，不必让信息逐层传话

3.6.3 第二步：query —— 可学习，但不依赖输入

$$q_l = w_l \in \mathbb{R}^{d}$$

每一层拥有一个固定向量，含义是"我这一层想找什么样的东西"。训练时学出来，推理时冻结，不随 token 变化。

🔑 但注意力权重本身仍然随输入变——因为 key 是激活值 $f_i(h_i)$，逐 token 不同。
这正是它比 DenseFormer 强的地方：DenseFormer 的深度权重是可学习标量，对所有输入都一样（见 §3.6.9 的谱系）。

3.6.4 第三步：打分 —— ★ RMSNorm 在这里不是装饰（$d=4$ 手算）

$$\phi(q,k)=\exp!\big(q^{\top}\,\mathrm{RMSNorm}(k)\big),\qquad \alpha_{i\to l}=\frac{\phi(q_l,k_i)}{\sum_{j=0}^{l-1}\phi(q_l,k_j)}$$

✅ 报告明确写了 RMSNorm 的作用：防止某一层因为输出幅度大就霸占全部权重。

现在用 $d = 4$、$l = 4$ 个源把这件事算出来。 假设前面四层写出的增量是（故意让幅度差很大）：

源 是什么 $f_i$ $|f_i|$ $\mathrm{RMSNorm}(f_i)$ 范数
$f_0$ token embedding [1, 0, 0, 0] 1 [2, 0, 0, 0] 2
$f_1$ 第 1 层的增量 [0, 2, 0, 0] 2 [0, 2, 0, 0] 2
$f_2$ 第 2 层的增量 [0, 0, 1, 0] 1 [0, 0, 2, 0] 2
$f_3$ 第 3 层的增量 [0, 0, 0, 4] 4 [0, 0, 0, 2] 2

RMSNorm 把四个源的范数统统拉到 $\sqrt{d} = 2$（04 章 §4.1.1），幅度信息被彻底剥掉，只剩方向。

实验 A：$w_l = [1, 1, 1, 1]$（"我对四个频道一视同仁"）

🔑 实验 B 是整节最该按一遍的表。 注意这里的荒谬之处：
```
没有 RMSNorm 时，w = [0, 1, 2, 0] 明明说了"3 号频道我要两倍",
但因为 f_1 的幅度恰好是 f_2 的两倍，两个源的分数一模一样（都是 2），
结果打成 44% : 44% 的平手 —— 这一层的【意图被幅度抹掉了】。

加上 RMSNorm，幅度被剥掉只剩方向，f_2 拿到 85.3%。
★ 注意 f_2 是四个源里【最小】的那一个（||f_2|| = 1，而 ||f_3|| = 4）。
"最小的源赢了最大的源" —— 这才是"内容匹配"该有的样子。
```

一句话：RMSNorm 把打分从"谁嗓门大"变成了一次纯粹的内容匹配。

📌 顺带解释一个小疑问：这里没有 $1/\sqrt{d}$ 缩放（对比 05 章 §5.3 的 $QK^\top/\sqrt{d_h}$）。
因为 RMSNorm 已经把 $k$ 的尺度钉死了（范数恒为 $\sqrt{d}$），而 $w_l$ 本身可学，任何常数缩放都能被它自己吸收掉。

3.6.5 第四步：输出 —— ★ 它替换掉累加，不是加在累加之上

$$h_l=\sum_{i=0}^{l-1}\alpha_{i\to l}\,v_i$$

和标准残差并排放，差别只有一处：

标准残差:   x_l = Sum_i    1      x f_i(x_i)      权重恒为 1，不可选、不归一
AttnRes :   x_l = Sum_i  alpha_i  x f_i(x_i)      权重由 softmax 给出，和为 1
                         ^^^^^^^
                         唯一的差别

把 §3.6.4 实验 B 的 $\alpha$ 代进去，和标准残差对账：

3.6.6 形状：对每一个 token 都算一份

f_i(x_i)   [d]      每层写出的那一份                i = 0 ... l-1
w_l        [d]      第 l 层的伪 query（不依赖输入）
scores     [l]      w_l . RMSNorm(f_i)
alpha      [l]      ★ softmax 在【层】这个维度上做
x_l        [d]      Sum alpha_i x f_i

带上 batch 和序列：alpha 的形状是 [B, L_seq, l]
                   —— 每个 token 各有一份"我该读哪几层"的分布
                   ★ 显存问题就来自这里：
                     l 份 [B, L_seq, d] 的层输出必须【全部留着】

3.6.7 代价：算得起，但存不起（把两笔账都算出来）

算术开销 O(L^2 d)   ✅ 报告明说【负担得起】—— 因为深度 L < 100，L^2 才 ~10^4，
                     和序列方向上动辄 (10^6)^2 = 10^12 完全不是一个量级

内存开销 O(L d)     ❌ ★ 这才是真正的问题：所有层的输出要同时留在显存里
                     而且在【流水线并行】下这些输出要跨 stage 传输，
                     通信开销同样是 O(Ld)

算术那一笔，代入 K3 的 $L=93$、$d=7168$，验证"负担得起"这句话：

第 l 层的 AttnRes：l 个源，每个源要算一次 d 维内积（打分）+ 一次 d 维加权累加
                   约 4 x l x d FLOP
全模型：Sum_{l=1..93} 4 l d = 4d x 93x94/2 = 4 x 7168 x 4371 = 1.25e8 FLOP / token

对比全模型一次前向（§3.5.5 算过一层约 1.204e9）：
        1.204e9 x 93 = 1.120e11 FLOP / token

AttnRes 占比 = 1.25e8 / 1.120e11 = 0.11%          <- 千分之一，确实负担得起

内存那一笔，同样代入 K3（BF16，每个源每 token 是 $7168\times2 = 14{,}336$ 字节 = 14 KiB）：

版本 要同时留着的源个数 每 token 一个 4096 token 的 micro-batch
标准残差 1（只有累加值） 14 KiB 58.7 MB
完整 AttnRes 93 1.33 MB 5.46 GB
Block AttnRes（8 块 + embedding = 9 源） 9 126 KiB 528 MB

5.46 GB vs 58.7 MB —— 差 93 倍，而且这只是一个 micro-batch、一条 4K 序列。 K3 原生 1M 上下文，这条路走不通。

🔑 这是一个很好的例子：同一个 $O(n^2)$，在序列轴上是灾难，在深度轴上根本不算事。
复杂度符号本身不说明问题，要看 $n$ 到底多大。
但反过来也成立：同一个 $O(n)$ 的内存，在深度轴上（$n=93$，每份 14 KiB）就足以把显存吃穿。

3.6.8 Block AttnRes：K3 实际用的版本

⚠️ 这一段常被讲反，包括不少二手解读：

L 层切成 N 块，每块 S = L/N 层

  块【内】：层输出直接【求和】  b_n = Sum_{j in B_n} f_j(x_j)     <- 退化成普通残差
  块【间】：对 N 个块级表示做【全注意力】                          <- ★ AttnRes 在这里生效
  b_0 := token embedding，永远是一个可选源

❌ 不是"以 8 层为一块、只在块内做注意力"。
✅ 是"块内求和、块间做注意力"，而且 K3 的块是 12 层、一共 8 块。

报告式 10 还有一个细节，决定了"块内的近邻层不会丢"——块内第 $i$ 层看到的源是：

i = 1（块内第一层）:  V = [ b_0, b_1, ..., b_{n-1} ]
i >= 2             :  V = [ b_0, b_1, ..., b_{n-1}, b_n^{i-1} ]
                                                    ^^^^^^^^^
                                       本块内前 i-1 层的【部分和】

-> 每一层看到的是：
     已完成的各个块 —— 每块【单独占一个条目】，可以精确挑选
   + 自己块内已经走过的部分 —— 【合并成一个条目】
-> 近邻信息没丢，只是分辨率变粗了

✅ K3 的具体数字，逐项验算：

项 算式 结果
块数 $93 \div 12 = 7$ 个满块（84 层）+ 1 个 9 层的尾块 8 块
源的个数 8 块 + 1 个 token embedding 9 个源
内存开销 $O(Ld) \to O(Nd)$，即 $93 \to 9$ 约 10.3×
每 token 要留的字节 $1.33\ \text{MB} \to 9\times14\,\text{KiB}$ 1.33 MB → 126 KiB
算术开销 $4\times9\times d\times L = 4\times9\times7168\times93$ $2.4\times10^7$ FLOP/token，占全模型 0.021% 
报告说 N ~ 8 就能在各个模型规模上拿回大部分收益

⭐ 一个漂亮的跨章呼应：块结构让推理时的状态有界，于是"块间并行算出的结果"可以和"块内顺序累加的部分和"用 online softmax（在线 softmax）合并——
这和 05 章 §5.7.4 的 FlashAttention 是同一个算法，只不过一个用在序列轴上，一个用在深度轴上。那个递推式的 6 元素手算推演在 ../../大模型算子开发/04-FlashAttention全系.md §4.2，按一遍就能同时理解这两处。

📌 ✅ 两处工程细节，说明上面那个显存问题是怎么被真正解决的（报告 §5.2 / §5.4）：
```
训练：块表示在边界层【只生成一次】，之后所有层共享；整个 AttnRes 计算被
checkpointing（激活重计算）包起来
-> ★ 每层为反向保存的激活【与标准残差完全相同】
换句话说，上表那个 528 MB 在真实实现里也不驻留
流水线并行用 "cache-based pipeline communication"：只增量传输新生成的块，
micro-batch 一结束就释放 -> 报告称达到显存占用的理论下界

推理：两阶段调度 —— 批量的块间 pass 每块只读一次缓存的块表示，
之后每层用 online-softmax 把块内部分和折进去
⚠️ 报告明说这些 kernel 的成本【很大一部分是访存】
—— 和 §3.3.3、§3.5.5 的结论一致：残差这一带的瓶颈永远在带宽
所以 prefill 用序列并行让每个 token 的块表示只在一个 rank 上物化，
decode 把块间 kernel 放到 side stream 上和主流重叠
```

⭐ 它是三家残差改动里唯一一个已经长出独立后续研究线的：

Delta Attention Residuals (2605.18855, 2026-05, Luo / Cai / Hu)
   批评：AttnRes 在【累加隐状态】上做路由，这些状态高度冗余
        -> 深层出现"路由塌陷"，注意力分布趋于均匀（峰值权重仅 ~0.2）
   做法：改成在【相邻隐状态之差】（增量）上路由 -> 分布更锐（峰值 ~0.6）
   结果：220M-7.6B 上验证困惑度改善 1.7%-8.2%

Multi-Head Attention Residuals (2607.27230, 2026-07, 同一组作者)
   批评：读深度用的是【整个宽度共享的一个 query】，所有特征子空间被迫
        用同一个分布去读历史层；子空间之间越"意见不合"代价越大，
        而这种分歧随宽度增长
   做法：把路由 query 拆成 H 个子空间头，各自独立 softmax（块对角读取）
        零新增参数、计算可忽略；H=1 退化回原版 AttnRes，最优在 H ~ 4-8
   结果：100M / 350M / 1B 上验证损失 -0.061 / -0.149 / -0.140
        ⚠️ 但也暴露了成本：即使配上融合 Triton kernel，
           吞吐也只有 baseline 的 0.55-0.88x（不融合时只有 0.2-0.5x）

🔑 注意后续工作攻击的，正好是让 AttnRes 便宜的那两处简化：
"每层只有一个 query" 和 "源该怎么取"。
这是读技术报告很值得记的一课：一个设计的【简化点】，往往就是它的【下一个改进点】。

⚠️ 另外注意 Multi-Head AttnRes 那个"吞吐只有 baseline 的 0.55–0.88×"——换算成时间就是慢 1.14~1.82 倍（$1/0.88 = 1.14$，$1/0.55 = 1.82$）。"吞吐 0.55×"和"慢 45%"是两个不同的数，别混（慢的幅度是 82%，不是 45%）。

⚠️ 一处我没能核实的矛盾，如实标出：Delta AttnRes 说 AttnRes 是在"累加隐状态"上做路由，
但 K3 报告式 8 明确写的是 $f_i(h_i)$（增量），而且块内求和 $b_n=\sum_j f_j(h_j)$ 只有在增量语义下才讲得通（§3.6.2 细节 b）。二者对不上。
可能是两篇论文记号不同，也可能是独立论文原版与 K3 部署版有差异——仅凭摘要无法判断。
本节按 K3 报告正文讲，因为那是我核对过全文的一手来源。

3.6.10 ⚠️ 关于"代价"的一个说明

关于 AttnRes 的墙钟开销，需要说清楚一件事：

✅ K3 报告给出的： O(Ld) -> O(Nd) 的【渐近】开销降低（§3.6.8 算出是 10.3 倍），
                  以及 "checkpointing 后每层保存的激活与标准残差完全相同"
❌ K3 报告【没有】给出： 任何百分比形式的墙钟开销 —— 全文检索无此数字
⚠️ 独立论文摘要页也没有给百分比，只有定性的 "minimal overhead"

🔑 所以正确的说法是：AttnRes 的开销，在一手报告层面只有渐近界和工程手段，没有公开的墙钟百分比。
这和 mHC 形成对比——DeepSeek-V4 明确给了 +6.7% 这个实测数字（§3.5.5）。
⚠️ 网上流传的"训练 +4% / 推理 +2%"我无法回溯到一手来源，本教程不再采用。

3.7.1 怎么理解这个分歧

⚠️ 以下是我的分析，不是厂商的说法。

支持"改"的一方的逻辑：
    §3.4 的两个问题（深层被稀释、等效学习率失控）是真实的
    层数越多越严重 -> 看表最后一列：K3 的 10.4% 是五家最低，动机最强
    残差是【全模型每一层都经过】的位置，改这里的杠杆最大

支持"不改"的一方的逻辑：
    墙钟开销是【实打实的钱】（V4 实测 +6.7%；K3 未公开数字，
       但从它要专门写 checkpointing + cache-based 流水线通信 + 两阶段
       推理 kernel 来看，代价显然不是零）
    残差改动会让所有并行策略、算子融合、推理框架都要重写
       -> ★ 而且改的正好是 §3.3.3 那个算术强度只有 0.167 的地方，
          任何额外访存都会被 Memory Bound 直接放大成墙钟
    GLM-5.2 明确走的是"工程可落地优先"路线（9 个国产芯片平台适配）
       -> 一个需要在 9 个芯片平台上都重新实现的残差结构，收益比很差

🔑 一个更根本的观察：残差改造是这一代五家分歧最大的一项。 注意力大家都在改（只是路线不同）、MoE 大家都在用、Muon 四家都上了——只有残差这一项，是"改不改"的二分。这通常意味着收益还没有大到形成共识。

📌 对比 07 章 §7.6：MLA 已经形成共识（四家都用），残差改造还没有。"是不是所有人都在用"是判断一项技术成熟度的一个实用标尺。

3.8 numpy 走一遍

# ---------- 标准残差 ----------
def block_standard(x, attn, ffn, norm1, norm2):
    x = x + attn(norm1(x))         # 读一次、写一次；默认行为是"什么都不做"（§3.1.3）
    x = x + ffn(norm2(x))
    return x

# ---------- mHC（n 条流）----------
def block_mhc(X, F, A, B_raw, C, n=4):
    # X: [L, n, d]   A: [n]   B_raw: [n,n]   C: [n]
    B = sinkhorn(B_raw, iters=20)           # 投影到双随机流形，谱半径 = 1（§3.5.3）
    h = np.einsum('i,lid->ld', A, X)        # 读：n 条流 -> 1 条
    y = F(h)                                 # 子层照常算
    mixed = np.einsum('ij,ljd->lid', B, X)  # 流间混合（不经过子层）
    return mixed + np.einsum('i,ld->lid', C, y)   # 写：1 条 -> n 条

def sinkhorn(M, iters=20):
    P = np.exp(M)                                    # 保证严格正
    for _ in range(iters):                           # ★ 严格串行，这是墙钟开销的来源之一
        P = P / P.sum(axis=1, keepdims=True)         # 行和 -> 1
        P = P / P.sum(axis=0, keepdims=True)         # 列和 -> 1
    return P

# ---------- AttnRes（完整版）----------
def attn_res(srcs, w_l):
    # ★ srcs: [l, d] —— 前面每一层【写出的增量】f_i(x_i)，不是累加状态 x_i（§3.6.2b）
    #                    srcs[0] 是 token embedding
    #   w_l : [d]    —— 第 l 层的可学习伪 query（不依赖输入）
    #   ★ key 和 value 是【同一个东西】，没有 W_K / W_V
    scores = np.array([w_l @ rmsnorm(k) for k in srcs])   # [l]，无 1/sqrt(d) 缩放
    alpha  = softmax(scores)                              # ★ 在【层】维度上 softmax
    return alpha @ srcs        # [d]，★ 用【未归一化】的 srcs 当 value，这是【替换】掉累加

# ---------- Block AttnRes（K3 真正用的版本）----------
def block_attn_res(blocks, partial, w_l):
    # blocks : [n, d] —— 已完成的块表示 b_0...b_{n-1}，块【内】是直接求和
    # partial: [d] 或 None —— 本块内前 i-1 层的部分和 b_n^{i-1}（块内第一层为 None）
    srcs = blocks if partial is None else np.vstack([blocks, partial])
    return attn_res(srcs, w_l)      # ★ 注意力只在【块之间】做，源从 93 个降到 9 个

📌 注意 attn_res 里一个容易写错的地方：scores 用的是 rmsnorm(k)（归一化后的，只看方向），而最后 alpha @ srcs 用的是 srcs（未归一化的）。key 归一化、value 不归一化 —— §3.6.4 实验 B 的输出表就是这么算出来的。写成 alpha @ [rmsnorm(k) for k in srcs] 会得到完全不同的结果。

3.9 本章小结

(1) 残差把梯度的【连乘】变成【连加】，这是深层网络能训练的唯一原因
    §3.2.1：rho 只要偏离 1 百分之五，93 层就衰减到 0.9% 或放大 89 倍；
            而残差的恒等项无论多少层都恒等于 1
    §3.2.2：N 层展开出 2^(N-1) 条路径，其中长度 0 的那条完全不衰减
    ★ 更本质的说法（§3.1.3）：残差把每一层的【默认行为】从"替换"改成了"什么都不做"

(2) 更好的图景：残差流是一条【总线】，共享 + 可寻址 + 只做加法
    W_Q/W_K/W_V/W_gate/W_up 是【读】（5 个），W_O/W_down 是【写】（2 个）
    一层 = 2 次读 + 2 次写；50 层 = 100 个增量叠在同一条 5120 维的流上
    ⚠️ §3.3.3：残差相加本身的算术强度只有 1/6 = 0.167（屋脊点是 295），
       彻底 Memory Bound —— 它的成本全在搬运，不在计算。这一条是理解 mHC 代价的钥匙

(3) 叠加与干涉（§3.3.4 / §3.3.5，d=8 走一遍）
    严格正交的方向：三个概念叠在一个 8 维向量上，一个内积就能精确取回（误差 0）
    塞不下时：第 9 个概念和 e2 重叠 0.995 -> 读 e2 读到 5.975（本该 1）
    d=5120 里随手取两个方向，典型夹角 89.2 度（cos = 1/sqrt(d) = 0.014）
    -> 近似正交的方向数量指数级（JL 引理），叠加能工作的真正前提是【特征稀疏】

(4) 因为只加不覆盖，残差范数按 sqrt(N) 增长（§3.4）
    第 50 层的增量只占残差流 14.1%，第 93 层只占 10.4%
    ★ 注意问题不是"范数溢出"（sqrt(93) = 9.6 一点不大），而是【稀释】

(5) mHC（V4 / openPangu）：改成 n=4 条流，B 约束在双随机流形
    §3.5.3：双随机 => 谱半径【恰好】= 1（两行可证），连乘不爆不消
    §3.5.4：Sinkhorn 交替行/列归一化，每轮偏差乘约 0.27，20 轮到 1e-12
            收敛后实测特征值 |1.0000|, |0.5345|, |0.3882| ✅ 谱半径定理验证通过
    §3.5.5：⚠️ 代价【不在 FLOP】（只占一层的四千万分之一）：
            显存 —— 残差流激活 x4（61 层 3.58 GB -> 14.33 GB，不是整机 x4！）
            访存 —— (4n+4)d = 20d（V4.1-Flash 口径），在一个 Memory Bound 的地方 x10
            串行 —— 20 次 Sinkhorn 严格串行，4x4 矩阵打不满 GPU，纯延迟
            ✅ V4 实测训练墙钟 +6.7%（⚠️ 分解归因是我的推断）

(6) AttnRes（K3）：在【深度方向】做 softmax 注意力，每层自选该读哪几层
    ★ 源是每层写出的【增量】f_i(x_i)，不是累加状态；k = v，无 W_K / W_V
    ★ §3.6.4 实验 B：w=[0,1,2,0] 明说"3 号频道要两倍"，但没有 RMSNorm 时
      f_1 的两倍幅度把这个偏好抹平，两源 44%:44% 打平；
      加上 RMSNorm 后 f_2 拿到 85.3% —— 而它是四个源里【最小】的那个
    ★ 权重和为 1 => ||h|| <= max_i ||f_i||，【不随 l 增长】，sqrt(N) 增长被结构性消掉
      标准残差累加得 4.690，AttnRes 得 0.886，均匀平均得 1.173（= 4.690/4）
    ★ K3 用 Block 版：93 层切 8 块 x 12 层，【块内求和、块间注意力】
      （不是"块内做注意力"），加 embedding 共 9 个源
    代价：算术只占全模型 0.11%（报告说负担得起）；
          真正的问题是内存 —— 完整版每 token 1.33 MB（4K micro-batch 5.46 GB），
          Block 版降到 126 KiB（528 MB），10.3 倍
          ⚠️ K3 报告【没有】给出任何百分比墙钟开销

(7) GLM / M3 完全不改 —— 这是五家分歧最大的一项，说明收益尚未形成共识
    对比 MLA（四家都用）："是不是所有人都在用"是技术成熟度的实用标尺
