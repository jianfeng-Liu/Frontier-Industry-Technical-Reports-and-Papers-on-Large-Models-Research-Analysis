# 03 · 残差流：全教程最重要的一个直觉

> **这一章的目标**：如果你只读一章，读这章。
> 读完你应该能回答：`x = x + f(x)` 这个"加号"为什么是深度学习最重要的发明？残差流为什么可以当成一条"总线"？DeepSeek-V4 和 openPangu 的 **mHC**、Kimi K3 的 **AttnRes** 到底在改什么？为什么 GLM 和 MiniMax 选择不改？

---

## 3.1 先看那个式子

回忆 [01 章](01-鸟瞰全景.md)的主循环：

```
x = x + Attention( Norm(x) )
x = x + FFN( Norm(x) )
```

**注意这不是 `x = Attention(Norm(x))`。** 这个 `x +` 叫**残差连接**（residual connection / skip connection），2015 年 ResNet 提出。

它看起来只是一个加号。**但没有它，超过 20 层的网络根本训不起来。**

---

## 3.2 为什么没有它就训不动：连乘 vs 连加

这一节是纯数学，但很短，而且是理解一切的基础。

### 没有残差的情况

设第 $l$ 层是 $x_{l+1} = F_l(x_l)$，一共 $N$ 层。反向传播时，损失 $\mathcal{L}$ 对第 1 层输入的梯度是**链式法则的连乘**：

$$\frac{\partial \mathcal{L}}{\partial x_1} = \frac{\partial \mathcal{L}}{\partial x_N}\cdot\frac{\partial F_{N-1}}{\partial x_{N-1}}\cdot\frac{\partial F_{N-2}}{\partial x_{N-2}}\cdots\frac{\partial F_1}{\partial x_1}$$

**$N-1$ 个雅可比矩阵连乘。** 设每个雅可比的"典型放大倍数"是 $\rho$：

```
ρ = 0.9,  N = 50   →   0.9^49 ≈ 0.006      梯度消失，浅层几乎收不到信号
ρ = 1.1,  N = 50   →   1.1^49 ≈ 106        梯度爆炸，训练发散
ρ = 1.0            →   刚好，但这是【测度为零】的巧合，不可能自然维持
```

> 🔑 **这就是 2015 年之前深度网络的死穴**：不是"深了学不到东西"，是**梯度在传回去的路上就已经数值上死掉或炸掉了**。而 $\rho$ 恰好等于 1 是不可能靠运气维持的——每一层的权重都在变。

### 有残差的情况

$x_{l+1} = x_l + F_l(x_l)$，雅可比变成：

$$\frac{\partial x_{l+1}}{\partial x_l} = \underbrace{I}_{\text{恒等}} + \frac{\partial F_l}{\partial x_l}$$

连乘展开：

$$\frac{\partial x_N}{\partial x_1} = \prod_{l=1}^{N-1}\left(I + \frac{\partial F_l}{\partial x_l}\right) = I + \sum_l \frac{\partial F_l}{\partial x_l} + \sum_{l<m}\frac{\partial F_m}{\partial x_m}\frac{\partial F_l}{\partial x_l} + \cdots$$

**关键就在展开式的第一项 $I$**：

```
❌ 无残差：只有【一条】路径，长度 N，梯度必须走完全程
✅ 有残差：展开后有 2^(N-1) 条路径，长度从 0 到 N-1 都有
           其中【长度为 0 的那条恒等路径，梯度原封不动地传到底】
```

```
     无残差                        有残差
                                 ┌──────────────────────┐ 长度0：梯度直达
   x1 →F1→ x2 →F2→ x3           x1 ─┬──────┬──────┬──→ x4
        ↑一条路，49次连乘             ├→F1→─┤      │      短路径
                                    │      ├→F2→─┤
                                    └→F1→──┴→F2→─┘      长路径
```

> 🔑 **一句话**：残差把**连乘**变成了**连加**。$\prod(1+a_i) \approx 1 + \sum a_i$（当 $a_i$ 小时）。**加法不会指数衰减。**

> 📌 **一个很有用的经验观察**：残差网络在行为上更像"**很多个浅网络的集成**"，而不是"一个很深的网络"。实验上随机删掉训练好的 ResNet 的某一层，性能只掉一点点；而无残差的网络删一层就废了。这也解释了为什么这一代模型敢堆到 93 层（Kimi K3）。

## 3.3 核心比喻：残差流是一条总线

现在换一个视角，这个视角比上面的数学更重要。

**不要把模型想成"数据从一层流到下一层"。要把它想成：有一条贯穿全模型的"传送带"，每一层从上面读一点、往上面写一点。**

```
        Embedding 把初始内容放上传送带
              │
   ═══════════╪══════════════════════════════════════════════ 残差流（宽度 d=5120）
              │  ↑读            ↓写
        第1层  ├──[Attn]────────┤       读整条流，写回一个增量
              │  ↑读            ↓写
              ├──[FFN]─────────┤
              │
   ═══════════╪═══════════════════════════════════════════════
              │  ↑读            ↓写
        第2层  ├──[Attn]────────┤
              │  ↑读            ↓写
              ├──[FFN]─────────┤
              ⋮
   ═══════════╪═══════════════════════════════════════════════
              ▼
        LM Head 从传送带上读走最终内容
```

### "读"和"写"具体是什么

这个视角能被落到具体的矩阵上，非常实在：

```
一个 FFN 是   W_down( act( W_gate·x , W_up·x ) )

    W_gate, W_up : [d, d_ff]   ← 从残差流【读】。它的每一行对应流上的一个方向
    W_down       : [d_ff, d]   ← 往残差流【写】。它的每一列对应流上的一个方向

一个 Attention 是

    W_Q, W_K, W_V : [d, ...]   ← 【读】
    W_O           : [..., d]   ← 【写】
```

> 🔑 **所以残差流的 $d=5120$ 个维度，可以理解成 5120 条"通信频道"**。
> - 某一层把"这个词是主语"写到第 37 号频道上
> - 后面第 40 层的某个注意力头，用它的 $W_Q$ 专门去读第 37 号频道
> - **两层之间不需要相邻，也不需要经过中间层的许可** —— 中间层只是往流上加东西，不会覆盖它

**这就是残差流被称为"总线"的原因**：它是一个**共享的、可寻址的、只做加法的通信媒介**。

### 一个重要推论：残差流的"带宽"是有限的

$d = 5120$ 意味着最多只有 5120 个正交方向。但模型要表示的概念远不止 5120 个。

```
→ 所以模型必须【叠加】：不同的概念占用不完全正交的方向，靠近似正交勉强共存
→ 高维空间里"近似正交的方向"数量是【指数级】的（Johnson–Lindenstrauss）
   所以 5120 维能塞下的概念数量远大于 5120
→ 代价：概念之间有微弱的串扰
```

> 📌 这也是为什么 $d$ 不能太小。openPangu 选 5120（[02 章](02-Embedding与词表.md)）是在"省参数"和"总线带宽"之间做的权衡。

## 3.4 一个真实的副作用：残差范数会持续增长

这是理解 [04 归一化](04-归一化.md)和 mHC 的前提。

因为每层都在**往流上加东西**，而不是替换，所以 $\|x_l\|$ 会随层数单调增长。

假设每层写入的增量 $F_l(x_l)$ 与当前的 $x_l$ **大致独立**（实践中近似成立），那么方差相加：

$$\|x_{l+1}\|^2 \approx \|x_l\|^2 + \|F_l\|^2$$

如果每层写入的幅度相当（这正是 Pre-Norm 造成的，见 [04 章](04-归一化.md)），则

$$\|x_N\| \approx \sqrt{N}\cdot\|F\|$$

```
第 1 层：  ‖x‖ ≈ 1        新写入的增量占比 100%
第 25 层： ‖x‖ ≈ 5        新写入的增量占比 1/5
第 50 层： ‖x‖ ≈ 7.1      新写入的增量占比 1/7
```

> ⚠️ **这带来两个真实的问题**：
>
> **① 深层的"话语权"越来越小。** 第 50 层再怎么努力，它写的东西相对于已经积累的 $\sqrt{50}$ 倍背景来说，只是一个小扰动。**深层实际上被"稀释"了。**
>
> **② 每层的有效学习率被隐式改变。** 因为 Pre-Norm 会先把 $x$ 归一化再送进子层，所以子层看到的输入始终是单位尺度，但它的输出被加到一个越来越大的 $x$ 上 —— 相当于**深层的等效学习率被自动调小了**。这有稳定的好处，也有"深层学不动"的坏处。

**mHC 和 AttnRes 都是在动这个地方。** 现在可以看它们了。

## 3.5 改法一：mHC（DeepSeek-V4 / openPangu）

> mHC = **m**anifold-constrained **H**yper-**C**onnections，源自超连接（Hyper-Connections）这条线。

### 它在改什么

标准残差是**一条**流。mHC 把它变成 **n 条并行的流**（V4 和 openPangu 都用 **n=4**）：

```
标准残差：                        mHC（n=4）：

    ═══════ 一条流 ═══════          ═══════ 流 1 ═══════
        │  ↑   ↓                    ═══════ 流 2 ═══════
        └─[F]──┘                    ═══════ 流 3 ═══════
                                    ═══════ 流 4 ═══════
                                       ╲  ╲ ↑   ↓ ╱  ╱
                                        └──[F]────┘
                                     A: 从4条流【混合出】F的输入
                                     C: 把F的输出【分发到】4条流
                                     B: 4条流之间【互相混合】
```

### 公式

$$x_{l+1} = B_l\,x_l + C_l\,F_l(A_l\,x_l)$$

其中 $x_l \in \mathbb{R}^{n\times d}$（n 条流，每条 d 维），而

| 矩阵 | 形状 | 作用 |
|---|---|---|
| $A_l$ | $1\times n$ | **读**：把 n 条流加权合成一条，喂给子层 |
| $C_l$ | $n\times 1$ | **写**：把子层的单条输出分发回 n 条流 |
| $B_l$ | $n\times n$ | **流间混合**：n 条流之间怎么交换 |

**注意 $A, B, C$ 都是可学习的、且是逐层不同的。** 标准残差是它的特例：$n=1, A=B=C=1$。

### 关键在于"manifold-constrained"这个前缀

**如果 $B_l$ 自由学习，会立刻退化成一个 $n$ 层深的线性网络，重新引入 §3.2 的连乘爆炸问题**（$B_N B_{N-1}\cdots B_1$ 的谱半径不受控）。

**mHC 的做法：把 $B_l$ 约束在【双随机矩阵】流形上。**

```
双随机矩阵（doubly stochastic）：
    ① 所有元素 ≥ 0
    ② 每一行和 = 1
    ③ 每一列和 = 1

例（n=3）：  ┌ 0.5  0.3  0.2 ┐   行和 = 1 ✓
            │ 0.2  0.5  0.3 │   列和 = 1 ✓
            └ 0.3  0.2  0.5 ┘
```

**为什么这个约束是对的**：

```
① 双随机矩阵的谱半径【恰好等于 1】（Perron–Frobenius）
   → 连乘 B_N···B_1 永远不会爆炸也不会消失，§3.2 的性质被完整保留

② 它是【广义的置换/混合】：信息在 n 条流之间【重新分配】，总量守恒
   → 不会凭空放大或丢失

③ 所有 n×n 双随机矩阵构成【Birkhoff 多胞体】，它的顶点恰好是 n! 个置换矩阵
   → 所以 B 学到的是"n 条流之间的一种软置换"，语义非常清楚
```

### Sinkhorn–Knopp：怎么把任意矩阵投影到双随机

这是个漂亮的算法，而且你懂算法的话一眼就能看懂：

```python
def sinkhorn(M, iters=20):
    P = np.exp(M)                    # 先取指数，保证非负
    for _ in range(iters):
        P = P / P.sum(axis=1, keepdims=True)   # 归一化每一行 → 行和=1
        P = P / P.sum(axis=0, keepdims=True)   # 归一化每一列 → 列和=1（行和被破坏一点）
    return P                          # 交替投影，指数收敛到双随机
```

**交替把行和列各归一化一次，反复迭代。** 这是"交替投影法"，可以证明对严格正矩阵**线性收敛**（收敛速率由矩阵的 Hilbert 投影度量决定）。

> ✅ **DeepSeek-V4 和 openPangu 都是 n=4 条流、Sinkhorn 迭代 20 次。**（两家报告均明确给出）
>
> ⚠️ 两家用同一个技术且参数一致，我倾向认为是同一条公开工作的直接采用，但**两份报告都没有互相引用，这只是我的推测**。

### 代价

| | 代价 | 来源 |
|---|---|---|
| **显存** | 残差流从 $[B,L,d]$ 变成 $[B,L,n,d]$，**×4** | 结构直接决定 |
| **计算** | 每层多 3 个小矩阵 + 20 次 Sinkhorn 迭代 | 矩阵本身很小（4×4），但 Sinkhorn 是**串行**的 |
| **DeepSeek-V4 报告的实测** | **训练墙钟 +6.7%** | ✅ V4 报告明确给出 |

## 3.6 改法二：AttnRes（Kimi K3）

> **AttnRes = Attention Residuals。** 它和 mHC 不是"改残差的两种做法"，而是在**改两件完全不同的事**：
> **mHC 改的是"残差流有几条"；AttnRes 改的是"这一层到底该读谁写进去的东西"。**

> 📄 **一手来源**：Kimi K3 技术报告 §2.2（式 8 / 9 / 10）、§5.2 训练 infra、§5.4 推理 infra，均已核对正文。
> 独立论文《Attention Residuals》[arXiv:2603.15031](https://arxiv.org/abs/2603.15031)（Kimi Team，2026-03-16），比 K3 报告早四个多月。
> ⚠️ K3 报告的参考文献 [58] 只写了 "Kimi Team. *Attention Residuals*. Preprint. 2026."，**并没有给 arXiv 编号**——上面这个编号来自 arXiv 检索。

### 一句话框架：标准残差犯的是 RNN 犯过的错

**报告原文的这句话，是整节最好的解释**：

> 标准残差把所有历史信息压进深度方向上的**单个状态** $h_l$ —— 这是一个瓶颈，**让人想起 RNN 在时间方向上的问题**。
> （原文：*a bottleneck reminiscent of RNNs over time*）

RNN 把所有历史 token 压进一个固定状态；标准残差把所有历史层的输出压进一个 $x_l$。**同一个病，只是换了一根轴。**

而 Transformer 当年治 RNN 的药方就是**注意力**——让每个位置用**随数据变化的权重**去选读任意历史位置。

```
      RNN     ──换成注意力──▶  Transformer     在【序列】方向上，2017 年做过一次
   标准残差    ──换成注意力──▶    AttnRes       在【深度】方向上，2026 年再做一次
```

> 🔑 **记住这个类比。下面所有公式都只是它的技术实现。**

### 第一步：可以读的"源"是什么（★ 最容易看错的地方）

> 📌 报告用 $h$ 表示残差流，就是本章的 $x$；$f_i(\cdot)$ 是第 $i$ 层的**子层函数**。

**第 $l$ 层面前摆着 $l$ 个可选的源**（报告式 8）：

$$k_i = v_i = \begin{cases} h_{-1}, & i=0 \quad(\text{token embedding})\\[3pt] f_i(h_i), & 1\le i\le l-1 \quad(\text{第 }i\text{ 层【自己写出的那一份】}) \end{cases}$$

**三个细节，每一个都必须点出来：**

```
(a) k_i = v_i —— 没有 W_K，也没有 W_V
    层的输出【直接】既当 key 又当 value
    → "我怎么介绍自己" 和 "我能给你什么" 是同一个东西
    → 这是它比标准注意力便宜得多的原因之一

(b) ★★ 是 f_i(h_i)【增量】，不是 h_i【累加值】—— 全节最关键的一点
    拿累加值当源：每个源里都已经包含了它前面所有的源 → 高度冗余，根本挑不出东西
    拿增量当源  ：l 个源才是 l 份【互相独立的贡献】，才构成一组值得挑的基

    ✅ 这一点在报告里是自洽的：Block 版把块内的源【求和】成 b_n = Σ f_j(h_j)
       —— 只有当 f_j(h_j) 是增量时，"把它们加起来"才讲得通

(c) i = 0 是 token embedding
    → "直接回头看原始输入" 永远是一个可选项，不必让信息逐层传话
```

### 第二步：query —— 可学习，但**不依赖输入**

$$q_l = w_l \in \mathbb{R}^{d}$$

每一层拥有**一个固定向量**，含义是"我这一层想找什么样的东西"。训练时学出来，**推理时冻结，不随 token 变化**。

> 🔑 **但注意力权重本身仍然随输入变**——因为 **key 是激活值** $f_i(h_i)$，逐 token 不同。
> **这正是它比 DenseFormer 强的地方**：DenseFormer 的深度权重是可学习**标量**，对所有输入都一样（见本节末的谱系）。

### 第三步：打分 —— RMSNorm 在这里不是装饰

$$\phi(q,k)=\exp\!\big(q^{\top}\,\mathrm{RMSNorm}(k)\big),\qquad \alpha_{i\to l}=\frac{\phi(q_l,k_i)}{\sum_{j=0}^{l-1}\phi(q_l,k_j)}$$

**✅ 报告明确写了 RMSNorm 的作用**：防止某一层因为输出**幅度**大就霸占全部权重。

```
没有 RMSNorm： score = w·k ∝ ‖k‖  →  "嗓门大"的层无条件胜出，和内容无关
加上 RMSNorm： 幅度被剥掉，只剩【方向】 →  变成一次纯粹的【内容匹配】
```

> 📌 **顺带解释一个小疑问**：这里**没有 $1/\sqrt{d}$ 缩放**（对比 [05 章](05-注意力机制.md) 的 $QK^\top/\sqrt{d_h}$）。
> 因为 RMSNorm 已经把 $k$ 的尺度钉死了，而 $w_l$ 本身可学，**任何常数缩放都能被它自己吸收掉**。

### 第四步：输出 —— ★ 它**替换**掉累加，不是加在累加之上

$$h_l=\sum_{i=0}^{l-1}\alpha_{i\to l}\,v_i$$

**和标准残差并排放，差别只有一处：**

```
标准残差:   x_l = Σ_i    1     · f_i(x_i)      权重恒为 1，不可选、不归一
AttnRes :   x_l = Σ_i α_{i→l}  · f_i(x_i)      权重由 softmax 给出，和为 1
                       └───────┘
                        唯一的差别
```

> ⭐ **所以标准残差就是 $\alpha\equiv 1$ 的特例。** 两个直接后果：
>
> ```
> ✅ 权重和为 1 → §3.4 那个"残差范数按 √N 增长"的问题【自动消失】
>                 因为这是加权平均，不是累加
>    ★ 独立论文摘要给出的动机与此完全一致：标准 PreNorm 残差以【固定单位权重】
>      累加每层输出，导致"随深度不受控的隐状态增长，逐步稀释每一层的贡献"
>
> ⚠️ 代价（我的推断，报告没写）：平均是【压不出增长】的。
>    如果第 l 层真想要"把前面全部加起来"，它最多只能拿到均值，幅度被压掉约 1/l
>    —— 要靠可学的 w_l 和后面的 norm 补回来
> ```

**一次深度注意力长这样**（softmax 是对**层**做的）：

```
   源（每层写出的那一份）           第 l 层用一个 softmax 决定读谁

   f_0 = token embedding ──┐  α=0.05
   f_1 ────────────────────┤  α=0.02
   f_2 ────────────────────┤  α=0.40  ← 这一层特别有用，重点读
    ⋮                      ├──▶ 加权和 ──▶ 送进第 l 层的子层
   f_{l−1} ────────────────┘  α=0.31
                               └── Σα = 1，在【层】这个维度上归一
```

### 形状：对**每一个 token** 都算一份

```
f_i(x_i)   [d]      每层写出的那一份                i = 0 … l−1
w_l        [d]      第 l 层的伪 query
scores     [l]      w_l · RMSNorm(f_i)
α          [l]      ★ softmax 在【层】这个维度上做
x_l        [d]      Σ α_i · f_i

带上 batch 和序列：α 的形状是 [B, L_seq, l]
                    —— 每个 token 各有一份"我该读哪几层"的分布
                    ↑ ★ 显存问题就来自这里：
                      l 份 [B, L_seq, d] 的层输出必须【全部留着】
```

### 代价：**算得起，但存不起**

```
算术开销 O(L²d)   ✅ 报告明说【负担得起】—— 因为深度 L < 100，L² 才 ~10⁴，
                    和序列方向上动辄 (10⁶)² 完全不是一个量级

内存开销 O(Ld)    ❌ ★ 这才是真正的问题：所有层的输出要同时留在显存里
                    而且在【流水线并行】下这些输出要跨 stage 传输，
                    通信开销同样是 O(Ld)
```

> 🔑 **这是一个很好的例子**：**同一个 $O(n^2)$，在序列轴上是灾难，在深度轴上根本不算事。**
> **复杂度符号本身不说明问题，要看 $n$ 到底多大。**

### Block AttnRes：K3 实际用的版本

**⚠️ 这一段常被讲反**，包括不少二手解读：

```
L 层切成 N 块，每块 S = L/N 层

  块【内】：层输出直接【求和】  b_n = Σ_{j∈B_n} f_j(x_j)     ← 退化成普通残差
  块【间】：对 N 个块级表示做【全注意力】                       ← ★ AttnRes 在这里生效
  b_0 := token embedding，永远是一个可选源
```

> ❌ **不是**"以 8 层为一块、只在块内做注意力"。
> ✅ **是**"块内求和、**块间**做注意力"，而且 K3 的块是 **12 层**、一共 **8 块**。

**报告式 10 还有一个细节，决定了"块内的近邻层不会丢"**——块内第 $i$ 层看到的源是：

```
i = 1（块内第一层）:  V = [ b_0, b_1, …, b_{n−1} ]
i ≥ 2              :  V = [ b_0, b_1, …, b_{n−1}, b_n^{i−1} ]
                                                  └── 本块内前 i−1 层的【部分和】

→ 每一层看到的是：
     已完成的各个块 —— 每块【单独占一个条目】，可以精确挑选
   + 自己块内已经走过的部分 —— 【合并成一个条目】
→ 近邻信息没丢，只是分辨率变粗了
```

**✅ K3 的具体数字**：

```
93 层 ÷ 12 = 7 个满块 + 1 个不满的尾块 = 8 块
再加上 embedding                        = 9 个源
开销 O(Ld) → O(Nd)，即 93 → 9，约 10×
报告说 N ≈ 8 就能在各个模型规模上拿回大部分收益
```

> ⭐ **一个漂亮的跨章呼应**：块结构让推理时的状态**有界**，于是"块间并行算出的结果"可以和"块内顺序累加的部分和"用 **online softmax** 合并——
> **这和 [05 章 §5.7](05-注意力机制.md) 的 FlashAttention 是同一个算法**，只不过一个用在序列轴上，一个用在深度轴上。

> 📌 **✅ 两处工程细节，说明上面那个显存问题是怎么被真正解决的**（报告 §5.2 / §5.4）：
> ```
> 训练：块表示在边界层【只生成一次】，之后所有层共享；整个 AttnRes 计算被
>       checkpointing 包起来 → ★ 每层为反向保存的激活【与标准残差完全相同】
>       流水线并行用 "cache-based pipeline communication"：只增量传输新生成的块，
>       micro-batch 一结束就释放 → 报告称达到显存占用的理论下界
>
> 推理：两阶段调度 —— 批量的块间 pass 每块只读一次缓存的块表示，
>       之后每层用 online-softmax 把块内部分和折进去
>       ⚠️ 报告明说这些 kernel 的成本【很大一部分是访存】，所以
>          prefill 用序列并行让每个 token 的块表示只在一个 rank 上物化，
>          decode 把块间 kernel 放到 side stream 上和主流重叠
> ```

### 谱系：往前三步，往后两步

**✅ 以下 arXiv 编号、日期、方法描述均已逐条核对。**

```
DenseFormer (2402.02622, 2024-02, Pagliardini 等)
        每层后插入"深度加权平均"，权重是【可学习标量】，与输入无关
        ↓ 让权重依赖输入
DeepCrossAttention (2502.06785, 2025-02, Google, Heddes 等)
        用【可学习且输入相关】的权重动态组合各层输出，并加入深度方向的交叉注意力
        ↓ 把每个块的输入解耦
MUDDFormer
        解耦成 Q / K / V / 残差 四路
        ↓ 换成一次真正的 softmax 注意力
★ AttnRes (2603.15031, 2026-03-16, Kimi Team)
        单个伪 query 的深度 softmax 注意力（K3 用的是它的 Block 版）
```

**⭐ 它是三家残差改动里唯一一个已经长出独立后续研究线的**：

```
Delta Attention Residuals (2605.18855, 2026-05, Luo / Cai / Hu)
   批评：AttnRes 在【累加隐状态】上做路由，这些状态高度冗余
        → 深层出现"路由塌陷"，注意力分布趋于均匀（峰值权重仅 ≈ 0.2）
   做法：改成在【相邻隐状态之差】（增量）上路由 → 分布更锐（峰值 ≈ 0.6）
   结果：220M–7.6B 上验证困惑度改善 1.7%–8.2%

Multi-Head Attention Residuals (2607.27230, 2026-07, 同一组作者)
   批评：读深度用的是【整个宽度共享的一个 query】，所有特征子空间被迫
        用同一个分布去读历史层；子空间之间越"意见不合"代价越大，
        而这种分歧随宽度增长
   做法：把路由 query 拆成 H 个子空间头，各自独立 softmax（块对角读取）
        零新增参数、计算可忽略；H=1 退化回原版 AttnRes，最优在 H ≈ 4~8
   结果：100M / 350M / 1B 上验证损失 −0.061 / −0.149 / −0.140
        ⚠️ 但也暴露了成本：即使配上融合 Triton kernel，
           吞吐也只有 baseline 的 0.55~0.88×（不融合时只有 0.2~0.5×）
```

> 🔑 **注意后续工作攻击的，正好是让 AttnRes 便宜的那两处简化**：
> **"每层只有一个 query"** 和 **"源该怎么取"**。
> **这是读技术报告很值得记的一课：一个设计的【简化点】，往往就是它的【下一个改进点】。**

> ⚠️ **一处我没能核实的矛盾，如实标出**：Delta AttnRes 说 AttnRes 是在"**累加隐状态**"上做路由，
> 但 **K3 报告式 8 明确写的是 $f_i(h_i)$（增量）**，而且块内求和 $b_n=\sum_j f_j(h_j)$ 只有在增量语义下才讲得通。**二者对不上。**
> 可能是两篇论文记号不同，也可能是独立论文原版与 K3 部署版有差异——**仅凭摘要无法判断**。
> 本节按 **K3 报告正文**讲，因为那是我核对过全文的一手来源。

### ⚠️ 关于"代价"的一个说明

**关于 AttnRes 的墙钟开销，需要说清楚一件事：**

```
✅ K3 报告给出的： O(Ld) → O(Nd) 的【渐近】开销降低，
                  以及 "checkpointing 后每层保存的激活与标准残差完全相同"
❌ K3 报告【没有】给出： 任何百分比形式的墙钟开销 —— 全文检索无此数字
⚠️ 独立论文摘要页也没有给百分比，只有定性的 "minimal overhead"
```

> 🔑 **所以正确的说法是**：**AttnRes 的开销，在一手报告层面只有渐近界和工程手段，没有公开的墙钟百分比。**
> 这和 mHC 形成对比——**DeepSeek-V4 明确给了 +6.7% 这个实测数字**（§3.5）。
> **⚠️ 网上流传的"训练 +4% / 推理 +2%"我无法回溯到一手来源，本教程不再采用。**

## 3.7 三家改、两家不改：这个分歧本身很有信息量

| 模型 | 残差改动 | 代价（厂商实测） | 层数 |
|---|---|---|---|
| **DeepSeek-V4** | **mHC**（n=4, Sinkhorn 20） | 训练墙钟 **+6.7%** | 61 |
| **openPangu-2.0-Pro** | **mHC**（n=4, Sinkhorn 20）+ 门控塌陷修复 | 报告未给出墙钟数字 | 50 |
| **Kimi K3** | **AttnRes**（93 层 → **8 块 × 12 层**，块间注意力） | ⚠️ 报告只给了 O(Ld)→O(Nd)，**未给墙钟百分比** | **93** |
| **GLM-5.2** | **不改** | 0 | 78 |
| **MiniMax M3** | **不改** | 0 | 60 |

### 怎么理解这个分歧

**⚠️ 以下是我的分析，不是厂商的说法。**

```
支持"改"的一方的逻辑：
    §3.4 的两个问题（深层被稀释、等效学习率失控）是真实的
    层数越多越严重 → K3 有 93 层，是五家最深的，动机最强
    残差是【全模型每一层都经过】的位置，改这里的杠杆最大

支持"不改"的一方的逻辑：
    墙钟开销是【实打实的钱】（V4 实测 +6.7%；K3 未公开数字，
       但从它要专门写 checkpointing + cache-based 流水线通信 + 两阶段
       推理 kernel 来看，代价显然不是零）
    残差改动会让所有并行策略、算子融合、推理框架都要重写
    GLM-5.2 明确走的是"工程可落地优先"路线（9 个国产芯片平台适配）
       → 一个需要在 9 个芯片平台上都重新实现的残差结构，收益比很差
```

> 🔑 **一个更根本的观察**：**残差改造是这一代五家分歧最大的一项。** 注意力大家都在改（只是路线不同）、MoE 大家都在用、Muon 四家都上了——**只有残差这一项，是"改不改"的二分**。这通常意味着**收益还没有大到形成共识**。

## 3.8 numpy 走一遍

```python
# ---------- 标准残差 ----------
def block_standard(x, attn, ffn, norm1, norm2):
    x = x + attn(norm1(x))
    x = x + ffn(norm2(x))
    return x

# ---------- mHC（n 条流）----------
def block_mhc(X, F, A, B, C_raw, n=4):
    # X: [L, n, d]   A: [n]   B_raw: [n,n]   C: [n]
    B = sinkhorn(B_raw, iters=20)          # 投影到双随机流形
    h = np.einsum('i,lid->ld', A, X)       # 读：n 条流 → 1 条
    y = F(h)                                # 子层照常算
    mixed = np.einsum('ij,ljd->lid', B, X) # 流间混合
    return mixed + np.einsum('i,ld->lid', C_raw, y)   # 写：1 条 → n 条

# ---------- AttnRes（完整版）----------
def attn_res(srcs, w_l):
    # ★ srcs: [l, d] —— 前面每一层【写出的增量】f_i(x_i)，不是累加状态 x_i
    #                    srcs[0] 是 token embedding
    #   w_l : [d]    —— 第 l 层的可学习伪 query（不依赖输入）
    #   ★ key 和 value 是【同一个东西】，没有 W_K / W_V
    scores = np.array([w_l @ rmsnorm(k) for k in srcs])   # [l]，无 1/√d 缩放
    alpha  = softmax(scores)                              # ★ 在【层】维度上 softmax
    return alpha @ srcs                                   # [d]，★ 这是【替换】掉累加

# ---------- Block AttnRes（K3 真正用的版本）----------
def block_attn_res(blocks, partial, w_l):
    # blocks : [n, d] —— 已完成的块表示 b_0…b_{n−1}，块【内】是直接求和
    # partial: [d] 或 None —— 本块内前 i−1 层的部分和 b_n^{i−1}（块内第一层为 None）
    srcs = blocks if partial is None else np.vstack([blocks, partial])
    return attn_res(srcs, w_l)      # ★ 注意力只在【块之间】做，源从 93 个降到 9 个
```

## 3.9 本章小结

```
① 残差把梯度的【连乘】变成【连加】，这是深层网络能训练的唯一原因
② 更好的图景：残差流是一条【总线】，每层从上面读、往上面写
   W_Q/W_K/W_V/W_gate/W_up 是【读】，W_O/W_down 是【写】
③ 因为只加不覆盖，残差范数按 √N 增长 → 深层被稀释、等效学习率被隐式改变
④ mHC（V4/openPangu）：改成 n=4 条流，B 约束在双随机流形（谱半径=1）
   用 Sinkhorn 20 次迭代投影。代价：显存×4，V4 实测训练 +6.7%
⑤ AttnRes（K3）：在【深度方向】做 softmax 注意力，每层自选该读哪几层
   ★ 源是每层写出的【增量】f_i(x_i)，不是累加状态；k=v，无 W_K/W_V
   ★ 权重和为 1 → 它【替换】掉累加，标准残差 = α≡1 的特例，√N 增长消失
   ★ K3 用 Block 版：93 层切 8 块 × 12 层，【块内求和、块间注意力】
     （不是"块内做注意力"），加 embedding 共 9 个源，O(Ld)→O(Nd)
   代价：算术 O(L²d) 报告说负担得起，真正的问题是 O(Ld) 显存与跨 stage 通信
   ⚠️ K3 报告【没有】给出任何百分比开销数字
⑥ GLM/M3 完全不改 —— 这是五家分歧最大的一项，说明收益尚未形成共识
```
