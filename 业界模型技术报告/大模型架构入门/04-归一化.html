04 · 归一化：一个除法，和它放在哪

这一章的目标：讲清 Norm(x) 是什么、为什么必须有、放在残差前面还是后面为什么是个大问题。
读完你应该能回答：RMSNorm 的公式为什么长这样？Pre-Norm 和 Post-Norm 的分歧点在哪？openPangu 的"门控塌陷"是怎么回事？

4.1 先看公式：它就是一个除法

现在所有大模型用的是 RMSNorm（Root Mean Square Normalization）：

$$y_i = \frac{x_i}{\sqrt{\frac{1}{d}\sum_{j=1}^{d} x_j^2 + \varepsilon}}\cdot g_i$$

def rmsnorm(x, g, eps=1e-6):
    rms = np.sqrt(np.mean(x**2, axis=-1, keepdims=True) + eps)
    return x / rms * g        # g 是可学习的缩放，形状 [d]

拆开看只有三步：

① 算这个向量的"平均能量"          mean(x²)
② 开根号，得到一个标量 rms         √(mean(x²) + ε)     ← ε 防除零，通常 1e-5 或 1e-6
③ 整个向量除以它，再逐维乘 g       x / rms * g

做完之后，向量的长度被拉到固定值（不管 $g$ 的话，$|y| = \sqrt{d}$），但方向完全不变。

    归一化前              归一化后
        ↗ x                  ↗ y      方向一样
       ╱  长度=37           ╱   长度=√d，固定
      ╱                    ╱
     ●                    ●

🔑 一句话理解：RMSNorm 只管长度，不管方向。它是在说"我不关心这个向量有多大，我只关心它指向哪"。

和老的 LayerNorm 差在哪

$$\text{LayerNorm}:\quad y = \frac{x - \mu}{\sqrt{\sigma^2 + \varepsilon}}\cdot g + b,\qquad \mu = \tfrac{1}{d}\textstyle\sum x_j$$

LayerNorm   =  减均值 + 除标准差 + 缩放 g + 平移 b
RMSNorm     =           除 RMS   + 缩放 g          ← 去掉了减均值和平移

为什么可以去掉减均值：实验发现减均值这一步对 Transformer 的效果几乎没贡献，而它需要多一遍归约（先算均值、再算方差），在 GPU 上是实打实的开销。

✅ RMSNorm 比 LayerNorm 快 7~64%（论文报告的范围），效果持平
✅ 五家【全部】用 RMSNorm，无一例外。这个已经没有争议了

4.2 为什么必须有归一化

表面理由：防止数值失控

回忆 03 章 §3.4：残差流的范数会随层数增长。如果不归一化：

第 1 层输入 ‖x‖ ≈ 1
第 50 层输入 ‖x‖ ≈ 7    → 送进 softmax 之前 QK 内积会大 49 倍
                        → softmax 饱和（见 §4.5），梯度趋近 0

归一化保证每个子层看到的输入尺度是固定的，无论它在第 1 层还是第 50 层。这样：

① 每层可以用【同一套超参】（初始化、学习率）
② 激活值不会溢出低精度格式（BF16 的动态范围虽大，FP16/FP8 就很吃紧）
   → 直接关系到 [14 量化](14-量化.md)

更深的理由：它让损失曲面变平滑

早期的解释是"减少 internal covariate shift"（内部协变量偏移），这个解释后来被实验推翻了——人为往归一化后注入协变量偏移，训练依然稳定。

目前更被接受的解释（Santurkar et al. 2018）：归一化让损失曲面的 Lipschitz 常数变小，梯度更可预测。

无归一化的损失曲面：           有归一化：

     ╱╲    ╱╲                     ╱‾‾‾╲
    ╱  ╲__╱  ╲                   ╱     ╲
   ╱  陡峭、多尖峰                ╱  平滑、可用大学习率
   走一大步可能直接跳到           走一大步大概率还在下坡
   一个更糟的地方

一个直观的机制：归一化让权重的尺度变得无关紧要。

$$\text{RMSNorm}(\alpha \cdot x) = \text{RMSNorm}(x)\quad\text{对任意 } \alpha > 0$$

所以如果把某层权重整体乘 10，归一化会把它除回来 —— 模型只能通过改变"方向"来学习，不能靠"变大"来作弊。这消掉了一整个无用的自由度。

📌 副作用：这也意味着权重的模长会自由漂移（因为它不影响输出）。这正是权重衰减在有归一化的网络里仍然重要的原因——它把模长拉回来，从而间接控制有效学习率。这条线索会在 13 优化器里再出现。

4.3 放哪里：三种选择

这是本章真正有分量的部分。同一个 RMSNorm，放的位置不同，训练行为天差地别。

┌─── Post-Norm（原始 Transformer, 2017）──────────────────┐
│                                                          │
│     x ──┬─────────────────────┐                          │
│         └──[ 子层 F ]──────────┤                          │
│                              ( + )                       │
│                                │                         │
│                            [ Norm ]  ← 归一化在【残差相加之后】│
│                                │                         │
│                                ▼                         │
│     x_{l+1} = Norm( x_l + F(x_l) )                       │
└──────────────────────────────────────────────────────────┘

┌─── Pre-Norm（现在的主流）────────────────────────────────┐
│                                                          │
│     x ──┬────────────────────────────┐                   │
│         │                            │                   │
│     [ Norm ]  ← 归一化在【子层之前】   │                   │
│         │                            │                   │
│      [ 子层 F ]───────────────────────┤                   │
│                                    ( + )                 │
│                                      ▼                   │
│     x_{l+1} = x_l + F( Norm(x_l) )                       │
└──────────────────────────────────────────────────────────┘

┌─── Sandwich-Norm（两边都放）─────────────────────────────┐
│                                                          │
│     x_{l+1} = x_l + Norm₂( F( Norm₁(x_l) ) )             │
│                       ↑ 子层输出【也】归一化再写回残差流    │
└──────────────────────────────────────────────────────────┘

分歧的关键：那条恒等通路有没有被打断

回到 03 章 §3.2 的核心——梯度能不能沿一条"什么都不做"的路径直达浅层。

Post-Norm:  x_{l+1} = Norm(x_l + F(x_l))
            ↑ 恒等路径【经过了 Norm】，梯度被 1/rms 反复缩放 N 次
            → §3.2 的连乘问题【部分回来了】
            → 深层网络必须靠【warmup】才能训起来，超过 ~20 层非常难训

Pre-Norm:   x_{l+1} = x_l + F(Norm(x_l))
            ↑ 恒等路径【完全干净】，∂x_{l+1}/∂x_l = I + ...
            → 可以不用 warmup、可以堆到 100 层
Post-Norm Pre-Norm Sandwich
恒等通路 ❌ 被 Norm 打断 ✅ 干净 ✅ 干净
训练稳定性 差，需要 warmup + 小学习率 好 更好
深度上限 ~20 层就很吃力 100+ 层 OK 100+ 层 OK
最终效果 略好（如果训得起来） 略差 介于之间
残差范数 每层被压回固定值 按 √N 增长（§3.4） 增长被抑制
额外开销 0 0 多一次 Norm

🔑 Pre-Norm 用一点点最终效果，换到了"能训起来"。 这个交易在 100B+ 规模上根本没得选——一次训练几千万美元，训崩了就全没了。

五家【全部】是 Pre-Norm 基础（Sandwich 是在此之上的加固）。

Pre-Norm 的那个代价，具体是什么

$$x_{l+1} = x_l + F(\text{Norm}(x_l)),\qquad |x_l| \approx \sqrt{l}$$

因为 $F$ 的输入被归一化了，$|F(\cdot)|$ 大致是常数，而 $|x_l|$ 在长大：

$$\frac{|F_l|}{|x_l|} \approx \frac{1}{\sqrt{l}}$$

第 1 层：子层的贡献占残差流的 100%
第 50 层：子层的贡献占 1/7

→ 深层的子层【实际上在做很小的修正】，表达力被浪费了
→ 这就是 Pre-Norm "最终效果略差" 的机制性解释

📌 Sandwich-Norm 正是针对这一点的补丁：给子层输出也加一个 Norm，让每层写入的幅度受控且可比，缓解深层被稀释。

4.4 openPangu 的门控塌陷：一个真实的故障与修复

这是本章唯一一个五家里有明确一手记录的故障案例，值得完整看一遍，因为它把 03 章和本章连在了一起。

背景

openPangu-2.0-Pro 用了 mHC（§3.5）。mHC 引入了 $A_l$（读门控）和 $C_l$（写门控）。

故障

✅ 华为报告明确记录：训练早期，早期层的 mHC 门控出现塌陷——报告中记为 $H_{\text{pre}}$、$H_{\text{post}}$ 趋近于 0。

门控 → 0 意味着什么：

    x_{l+1} = B_l x_l + C_l F_l(A_l x_l)
                        ↑ 这一项被门控乘成了 0

    → 子层【完全不起作用】，那一层退化成纯粹的 B_l x_l（只是流间混合）
    → 参数白白浪费，而且是发生在【最该学基础特征的浅层】

为什么恰好在早期层

⚠️ 以下是我的推断，华为报告没有给出机制解释。

回忆 §4.3：Pre-Norm 下 ‖x_l‖ ≈ √l

    浅层 l 小  →  ‖x_l‖ 小  →  归一化的除数小  →  子层输出相对【偏大】
    → 早期层的子层输出更容易冲击残差流
    → 优化器为了稳定，最简单的办法就是【把门控关掉】

    这是一个【局部最优陷阱】：门控一旦接近 0，梯度也趋近 0，就再也出不来了

并且这和 01 章 §1.3 的分层现象一致：浅层做的事最简单，所以"关掉也不太掉 loss"，优化器就真的关掉了。

修复

✅ 华为报告给出的两条措施：

① Sandwich Norm —— 给子层输出也加归一化，控制它写回残差流的幅度
② 块级后归一化 —— 在第 1 层之后、以及每 5 层的块之后，各加一次归一化

    层 1  ──[Sandwich Norm 的 block]──  ← 后面加一次块级归一化 ★
    层 2~5 ─────────────────────────────  ← 第 5 层后加一次 ★
    层 6~10 ────────────────────────────  ← 第 10 层后加一次 ★
    ⋮
    层 46~50 ───────────────────────────  ← 第 50 层后 ★

为什么这管用：

Sandwich Norm 保证子层输出【尺度受控】
    → 它不会因为浅层 ‖x‖ 小就相对过大
    → 优化器不再有"必须关掉门控"的压力

块级后归一化【周期性地把残差流范数压回来】
    → 直接对治 §3.4 的 √N 增长
    → 深层的相对话语权被恢复

🔑 这个案例的价值：它说明 03 章那些"改残差"的方案不是免费午餐。mHC 带来的不只是 +6.7% 墙钟，还带来了新的、需要额外补丁才能压住的训练不稳定性。这是"三家改、两家不改"这个分歧的一条实证注脚。

4.5 另一个位置：QK-Norm

除了残差前后，还有第三个常放归一化的地方——注意力内部的 Q 和 K。

$$\text{score} = \frac{\text{RMSNorm}(q)\cdot \text{RMSNorm}(k)^\top}{\sqrt{d_h}}$$

动机：softmax 饱和

05 章会详讲 softmax，这里只需要知道结论：

如果 q·k 的数值变得很大（比如 200），softmax 会变成【近乎 one-hot】：

    softmax([200, 5, 3]) ≈ [1.0, 0.0, 0.0]

    → 梯度几乎全是 0（softmax 在饱和区导数趋近 0）
    → 这个注意力头【卡死了】，再也学不动
    → 训练日志上表现为【loss spike】或者干脆发散

而 $q\cdot k$ 变大是很容易发生的：$q$ 和 $k$ 都是无约束的线性投影输出，训练中它们的范数会自由漂移。

QK-Norm 的修复

先把 $q$ 和 $k$ 归一化到固定长度，再算内积。 这样内积被硬性限制在有界范围内，softmax 永远不会饱和。

✅ DeepSeek-V4 明确使用 QK-RMSNorm（报告有记）。
⚠️ 其他几家报告中我没有找到明确记载，不代表没用——这是个很常规的稳定化手段。

📌 这条"softmax 会饱和"的线索非常重要，它在教程里出现三次：
这里（§4.5） → 训练不稳定的一个来源，用 QK-Norm 治 [05 章 §5.x] → softmax 和必须为 1，模型没有"什么都不看"的选项 [14 章 §14.6] → 上一条导致模型自造巨大激活当泄压阀 = 离群值 这是低比特量化最大的敌人

归一化类型 位置 特别的地方
DeepSeek-V4 RMSNorm Pre-Norm ✅ QK-RMSNorm
Kimi K3 RMSNorm Pre-Norm AttnRes 内部对 $k_i$ 用 RMSNorm（§3.6）
GLM-5.2 RMSNorm Pre-Norm —

🔑 归一化这一格，是五家最一致的地方之一：全部 RMSNorm、全部 Pre-Norm。唯一的差异都是"因为改了别的东西，所以不得不在这里打补丁" —— openPangu 是因为 mHC，V4 的 QK-Norm 是因为要压 softmax。

这本身就是个有用的判断：归一化不是创新点，它是稳定器。谁在这里做了额外动作，说明谁在别处冒了额外的险。

4.7 本章小结

① RMSNorm = 除以 RMS 再乘可学习的 g。只改长度，不改方向
   比 LayerNorm 少了减均值和平移，快 7~64%，效果持平。五家全用
② 它有效的原因不是"减少协变量偏移"（已被推翻），
   而是【让损失曲面变平滑】+【消掉权重尺度这个无用自由度】
③ Pre-Norm vs Post-Norm 的分歧点只有一个：
   恒等通路有没有被 Norm 打断 → 决定了能不能堆到 100 层
   五家全部 Pre-Norm，用一点最终效果换"能训起来"
④ Pre-Norm 的代价：深层贡献被稀释成 1/√l → Sandwich Norm 是补丁
⑤ openPangu 的门控塌陷：mHC 的门控在早期层塌到 0
   修复 = Sandwich Norm + 第1层后及每5层的块级后归一化
   这是"改残差不是免费午餐"的实证
⑥ QK-Norm：防 softmax 饱和。这条"softmax 饱和"的线索会一路通到量化章
