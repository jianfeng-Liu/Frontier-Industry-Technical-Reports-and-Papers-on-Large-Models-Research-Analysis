# 04 · 归一化：一个除法，和它放在哪

> **这一章的目标**：讲清 `Norm(x)` 是什么、为什么必须有、放在残差前面还是后面为什么是个大问题。
> 读完你应该能回答：RMSNorm 的公式为什么长这样？Pre-Norm 和 Post-Norm 的分歧点在哪？openPangu 的"门控塌陷"是怎么回事？
> **读法**：本章有两张"同一组数值走一遍"的表（§4.1.2 和 §4.3.2），**都用同一个 4 维向量 `x = [1, 2, 3, 4]`**。把这两张表按一遍，归一化这一章就没有黑箱了。

---

**本章关键词**（每个缩写第一次出现都给中英文全称）

**LayerNorm / LN**（Layer Normalization，层归一化）—— 2016 年的原始版本：减均值、除标准差、再缩放平移。

**RMSNorm**（Root Mean Square Normalization，均方根归一化）—— 现在所有大模型用的简化版：**只除以均方根，不减均值**。本章主角。

**Pre-Norm / Post-Norm**（前置归一化 / 后置归一化）—— 归一化放在子层**之前**还是放在残差相加**之后**。§4.3 的全部内容。

**Sandwich-Norm**（三明治归一化）—— 子层前后**各放一个**归一化。openPangu 用它救了一个真实故障（§4.4）。

**QK-Norm**（Query-Key Normalization，查询-键归一化）—— 归一化的第三个位置：注意力内部的 $q$ 和 $k$（§4.5）。

**FLOP**（Floating-Point Operation，浮点运算次数）／**算术强度**（Arithmetic Intensity）—— 每搬 1 字节能算多少次浮点运算，$I = \text{FLOP} / \text{Byte}$。判断一个算子卡在算力还是卡在带宽，全靠它。

**Memory Bound**（带宽受限）—— 算术强度低于**屋脊点**（Ridge Point，算力屋顶与带宽斜线的交点）时，算力空转等数据。H100 SXM5 的 BF16 屋脊点是 **295 FLOP/Byte**，而归一化只有 1~2，深陷带宽受限区。

**BF16**（Brain Float 16，脑浮点 16 位）—— 2 字节的浮点格式，本章数字节都按它算。

**mHC**（manifold-constrained Hyper-Connections，流形约束超连接）—— [03 章 §3.5](03-残差流.md) 讲的残差改造，本章 §4.4 是它的一个副作用。

**H100 SXM5 关键数字**（本章所有屋顶线计算都用这一组）：BF16 稠密算力 **989 TFLOPS**、HBM3 显存 **80 GB / 3.35 TB/s**、屋脊点 **295 FLOP/Byte**。⚠️ 常见的 **1979 TFLOPS 是 2:4 结构化稀疏**的数字，不适用于这里的稠密算子。

---

## 4.1 先看公式：它就是一个除法

现在所有大模型用的是 **RMSNorm**：

$$y_i = \frac{x_i}{\sqrt{\frac{1}{d}\sum_{j=1}^{d} x_j^2 + \varepsilon}}\cdot g_i$$

```python
def rmsnorm(x, g, eps=1e-6):
    # 固定前面的维度，只在最后一个 axis（一般是 hidden dim）上取平均
    rms = np.sqrt(np.mean(x**2, axis=-1, keepdims=True) + eps)
    return x / rms * g        # g 是可学习的缩放，形状 [d]
```

### 4.1.1 拆开看只有三步

```
(1) 算这个向量的"平均能量"          mean(x^2)
(2) 开根号，得到一个标量 rms         sqrt(mean(x^2) + eps)   <- eps 防除零，通常 1e-5 或 1e-6
(3) 整个向量除以它，再逐维乘 g       x / rms * g
```

**做完之后，向量的长度被拉到固定值**（不管 $g$ 的话，$\|y\| = \sqrt{d}$），**但方向完全不变**。

```
    归一化前                   归一化后
      /  x                       /  y          方向一样
     /   长度 = 37              /   长度 = sqrt(d)，固定
    /                          /
   o                          o
```

> 🔑 **一句话理解**：RMSNorm **只管长度，不管方向**。它是在说"我不关心这个向量有多大，我只关心它指向哪"。
>
> **为什么 $\|y\| = \sqrt{d}$**：$\text{rms}(y) = 1$ 意味着 $\frac{1}{d}\sum y_i^2 = 1$，即 $\sum y_i^2 = d$，所以 $\|y\| = \sqrt{d}$。$d=5120$ 时 $\|y\| = 71.55$。**归一化后的向量长度不是 1，是 $\sqrt{d}$，这一点经常被记错。**

### 4.1.2 ★ 同一组数值走一遍：LayerNorm vs RMSNorm 到底差在哪

老的版本是 **LayerNorm**：

$$\text{LayerNorm}:\quad y = \frac{x - \mu}{\sqrt{\sigma^2 + \varepsilon}}\cdot g + b,\qquad \mu = \tfrac{1}{d}\textstyle\sum x_j,\quad \sigma^2 = \tfrac{1}{d}\textstyle\sum (x_j-\mu)^2$$

```
LayerNorm   =  减均值 + 除标准差 + 缩放 g + 平移 b
RMSNorm     =           除 RMS   + 缩放 g          <- 去掉了减均值和平移
```

**现在拿 $d = 4$、$x = [1, 2, 3, 4]$ 走一遍**（取 $g=1, b=0, \varepsilon\to 0$，好手算）：

```
共用的中间量：
  mean(x)   = (1+2+3+4)/4      = 2.5
  mean(x^2) = (1+4+9+16)/4     = 7.5        -> rms = sqrt(7.5) = 2.73861
  var(x)    = ((-1.5)^2 + (-0.5)^2 + 0.5^2 + 1.5^2)/4 = 5/4 = 1.25
                                             -> std = sqrt(1.25) = 1.11803
```

| | 公式 | 输出 $y$ | $\|y\|$ | 均值 | 保留了什么 |
|---|---|---|---|---|---|
| 原始 $x$ | — | `[1, 2, 3, 4]` | 5.47723 | 2.5 | — |
| **RMSNorm** | $x / 2.73861$ | `[0.36515, 0.73030, 1.09545, 1.46060]` | **2.00000** | 0.91287 | **方向完全不变**（每个分量同比缩小） |
| **LayerNorm** | $(x - 2.5)/1.11803$ | `[-1.34164, -0.44721, 0.44721, 1.34164]` | **2.00000** | **0** | 只保留"相对高低"，扔掉整体水平 |

**两个都把长度拉到 $\sqrt{d} = 2$，但 RMSNorm 的输出全是正数、LayerNorm 的输出均值是 0。差别就在"减均值"这一步上。**

**让差别更明显：把 $x$ 整体加 10，变成 $x' = [11, 12, 13, 14]$。**

```
  mean(x')   = 12.5
  mean(x'^2) = (121+144+169+196)/4 = 157.5   -> rms = sqrt(157.5) = 12.54990
  var(x')    = 1.25（和平移无关）              -> std = 1.11803
```

| | 输出 $y'$ | 和平移前比 |
|---|---|---|
| **RMSNorm** | `[0.87650, 0.95618, 1.03586, 1.11554]` | ❌ **完全变了**（四个分量被挤到 1 附近） |
| **LayerNorm** | `[-1.34164, -0.44721, 0.44721, 1.34164]` | ✅ **一个字没变** |

> 🔑 **这就是"减均值"的唯一功能：让归一化对【整体平移】免疫。** LayerNorm 是平移不变的，RMSNorm 不是。
>
> **那为什么 Transformer 不需要这个不变性？** 因为 $d$ 维残差流里的"整体平移"只占**一个方向**（全 1 方向），而残差流有 5120 个方向（[03 章 §3.3](03-残差流.md)）。这一个方向该留还是该扔，**下游那个线性层自己能学**——$W$ 的每一行减掉一个常数就等价于减均值。**实验发现的"减均值几乎没贡献"，机制上就是这个。**

### 4.1.3 ★ FLOP 与访存的账：RMSNorm 到底省在哪（⚠️ 不省带宽）

**把每个元素上发生的运算数出来**（$H$ 个元素一行，行级的 `rsqrt`、除法被 $H$ 摊薄，忽略）：

| 步骤 | LayerNorm 每元素 FLOP | RMSNorm 每元素 FLOP |
|---|---|---|
| 求均值 `sum += x` | 1（加） | — |
| 求平方和 `sum2 += x²` | — | 2（平方、加） |
| 求方差 `sum2 += (x-mean)²` | 3（减、乘、加） | — |
| 输出 | 4（减、乘、乘、加） | 2（乘 `inv_rms`、乘 `g`） |
| **合计** | **8** | **4** |

**字节呢？两者一模一样**：读 $x$ 一次（BF16，2 字节）+ 写 $y$ 一次（2 字节）= **每元素 4 字节**（$g$、$b$ 各只有 $H$ 个元素，被 $T$ 行摊薄，忽略）。

| | FLOP/元素 | Byte/元素 | **算术强度 $I$** | 屋顶线上界 $P = 3350\times I$ | 占 989 TFLOPS 峰值 | 归约遍数 |
|---|---|---|---|---|---|---|
| LayerNorm | 8 | 4 | **2.0** | 6.7 TFLOPS | 0.68% | **2**（先均值，再方差） |
| **RMSNorm** | 4 | 4 | **1.0** | 3.35 TFLOPS | 0.34% | **1**（只要平方和） |

> ⚠️ **这张表有一个非常反直觉的结论，是全章最该记住的一条**：
>
> ```
> RMSNorm 的算术强度【更低】（1.0 < 2.0），不是更高。
> 因为它省掉的是【分子】（FLOP 少一半），分母（字节数）一点没变。
>
> 两者都远低于 H100 的屋脊点 295，都深陷 Memory Bound。
> Memory Bound 区里性能只由【字节数】决定，而字节数完全相同
>     =>  屋顶线预测的【理论时间完全一样】。
> ```
>
> **所以"RMSNorm 省下的"不是带宽，具体是这三样：**
>
> ```
> (1) 少一遍【归约】。归约要跨线程同步（warp shuffle + 块内 barrier）。
>     H = 5120 时一行归约大约要 log2(5120) ≈ 13 轮 shuffle。
>     LayerNorm 要走两遍（或者用 Welford 单遍但每步更贵），RMSNorm 只走一遍。
>     -> 省的是【延迟与同步】，不是带宽。
>
> (2) 朴素（非融合）实现下，LayerNorm 要把 x 从 HBM 读【两次】：
>     一次求均值、一次求方差。
>     每元素 Byte 从 4 变成 6  ->  I 掉到 8/6 = 1.33，时间【多 50%】。
>     ★ 这一条才是真正能测出差别的地方。融合 kernel 把 x 留在寄存器里就没这问题了,
>       但这恰好说明"为什么融合重要"（见 [../../大模型算子开发/05-算子融合.md]）。
>
> (3) 少一个平移参数 b：少一份权重、一份梯度、一份优化器状态。量级很小，但不是零。
> ```

> ⚠️ **顺手改掉一个含糊的说法。** 常见的"RMSNorm 比 LayerNorm 快 7~64%"这个区间，来自 RMSNorm 原论文（Zhang & Sennrich, NeurIPS 2019）在**当时的 RNN 系 seq2seq 模型**上的端到端实测。
> ```
> ⚠️ 它不是现代 LLM 融合 kernel 的数字。按上面那笔账，融合实现下两者
>    【带宽时间相同】，差别只剩归约遍数，量级远小于 64%。
> ⚠️ 引用时必须带口径：这是【整个模型的训练/推理步时间】，不是【归一化算子本身】的加速。
> ⚠️ 而且"快 X%"本身就是含糊说法，一定要分清两件事：
>      时间 100 -> 60 ：  "时间减少 40%"，但"加速 1.67 倍"（★ 不是 1.4 倍）
>      时间 100 -> 50 ：  "时间减少 50%"，"加速 2.00 倍"
>    本教程一律只说【时间减少 X%】或【加速 X 倍】，不说裸的"快 X%"。
> ```

```
✅ 效果持平这一点是共识：五家【全部】用 RMSNorm，无一例外。这件事已经没有争议了。
```

> 📌 **一个写法上的小变体**：MiniMax M3 用的是"Gemma 式"的归一化写法（见 [../模型技术对比.md](../模型技术对比.md) 第二节"稳定性土办法"一行），即把可学习缩放写成 $(1+g)$ 而不是 $g$、$g$ 初始化为 0。
> ⚠️ **我的判断（M3 报告只写了"Gemma 式 norm"，没解释）**：这和 $g$ 初始化为 1 在数学上等价，好处是**初始时刻恰好是"纯归一化"**，而且 $g$ 上的权重衰减会把它拉向 0（即拉向"纯归一化"）而不是拉向 0 倍（即拉向"整层失效"）。

## 4.2 为什么必须有归一化

### 4.2.1 表面理由：防止数值失控

回忆 [03 章 §3.4](03-残差流.md)：残差流的范数会随层数增长。如果不归一化：

```
第 1 层输入  ||x|| ≈ 1
第 50 层输入 ||x|| ≈ 7    -> 送进 softmax 之前 QK 内积会大 7 x 7 = 49 倍
                         -> softmax 饱和（见 §4.5），梯度趋近 0
```

**归一化保证每个子层看到的输入尺度是固定的**，无论它在第 1 层还是第 50 层。这样：

```
(1) 每层可以用【同一套超参】（初始化、学习率）
(2) 激活值不会溢出低精度格式（BF16 的动态范围虽大，FP16/FP8 就很吃紧）
    -> 直接关系到 [14 量化](14-量化.md)
```

**为什么"内积大 49 倍"**：$q = W_Q x$、$k = W_K x$ 都正比于 $\|x\|$，所以内积 $q\cdot k$ 正比于 $\|x\|^2$。$\|x\|$ 从 1 长到 7，内积就涨 $7^2 = 49$ 倍。**而 [05 章 §5.3](05-注意力机制.md) 的表告诉我们：logit 从 ±1 涨到 ±49，softmax 就彻底变成 one-hot，导数为 0。**

### 4.2.2 更深的理由：它让损失曲面变平滑

早期的解释是"减少 internal covariate shift"（内部协变量偏移），**这个解释后来被实验推翻了**——人为往归一化后注入协变量偏移，训练依然稳定。

**目前更被接受的解释**（Santurkar et al. 2018，⚠️ 论文结论是"归一化改善了损失与梯度的 Lipschitz 性质"，本教程按这个口径转述）：**归一化让损失曲面的 Lipschitz 常数变小，梯度更可预测**。

```
无归一化的损失曲面：           有归一化：

     /\    /\                     /~~~\
    /  \__/  \                   /     \
   陡峭、多尖峰                   平滑、可用大学习率
   走一大步可能直接跳到           走一大步大概率还在下坡
   一个更糟的地方
```

**一个直观的机制**：归一化让权重的**尺度**变得无关紧要。

$$\text{RMSNorm}(\alpha \cdot x) = \text{RMSNorm}(x)\quad\text{对任意 } \alpha > 0$$

**用 §4.1.2 的数字验一下**：$x=[1,2,3,4]$ 乘 10 变成 $[10,20,30,40]$，`mean(x²)` 从 7.5 变成 750，`rms` 从 2.73861 变成 27.3861（正好 10 倍），除完之后**输出一模一样**。

所以如果把某层权重整体乘 10，归一化会把它除回来 —— **模型只能通过改变"方向"来学习，不能靠"变大"来作弊**。这消掉了一整个无用的自由度。

> 📌 **副作用**：这也意味着权重的模长会自由漂移（因为它不影响输出）。这正是**权重衰减在有归一化的网络里仍然重要**的原因——它把模长拉回来，从而间接控制有效学习率。这条线索会在 [13 优化器](13-优化器与Muon.md)里再出现。

## 4.3 放哪里：三种选择

这是本章真正有分量的部分。**同一个 RMSNorm，放的位置不同，训练行为天差地别。**

### 4.3.1 三种放法的结构图

三张图都只有**一列**主干，所有说明写在行尾——这样你不用数空格也能看清"Norm 卡在哪一步"。

```
【A】Post-Norm（2017 原始 Transformer）     x_{l+1} = Norm( x_l + F(x_l) )
     图里的 F 就是子层（Attention 或 FFN）

   x_l
   |
   |--> [ F ] --> delta            子层直接吃【原始的】x_l，前面没有 Norm
   |
  (+)                              残差相加：x_l 和 delta 在这里汇合
   |
  [ Norm ]                         <- 归一化压在【相加之后】
   |
   x_{l+1}                         => 恒等通路【穿过了】这个 Norm
```

```
【B】Pre-Norm（现在的主流）                 x_{l+1} = x_l + F( Norm(x_l) )

   x_l
   |
   |--> [ Norm ] --> [ F ] --> delta  <- 归一化只挡在【子层那条支路】上
   |
  (+)                                残差相加
   |
   x_{l+1}                           => 恒等通路上【什么都没有】
```

```
【C】Sandwich-Norm（两边都放）              x_{l+1} = x_l + Norm2( F( Norm1(x_l) ) )

   x_l
   |
   |--> [ Norm1 ] --> [ F ] --> [ Norm2 ] --> delta
   |                            ^
   |                            '-- 新增的就是这一个：控制【写回残差流的幅度】
  (+)
   |
   x_{l+1}                      => 恒等通路仍然干净
```

> 🔑 **三张图只有一处不同：那个 `|` 竖线（恒等通路）上有没有挡东西。** Post-Norm 挡了，Pre-Norm 和 Sandwich 都没挡。**整节的结论就这一句。**

### 4.3.2 ★ 同一组数值走一遍：三种放法的输出差在哪

继续用 §4.1.2 的 $x_l = [1, 2, 3, 4]$（$\|x_l\| = 5.47723$）。**子层 $F$ 取一个最简单的固定映射：把向量倒过来再除以 2**，即 $F(u) = 0.5\cdot[u_4, u_3, u_2, u_1]$。$g$ 全取 1。

先把要用的三个中间量算出来：

```
F(x_l)              = 0.5 x [4, 3, 2, 1]  = [2.00000, 1.50000, 1.00000, 0.50000]
Norm(x_l)           = [1,2,3,4] / 2.73861 = [0.36515, 0.73030, 1.09545, 1.46060]
F( Norm(x_l) )      = 0.5 x [1.46060, 1.09545, 0.73030, 0.36515]
                    = [0.73030, 0.54772, 0.36515, 0.18257]      范数正好 = 1.00000
```

四种放法逐行代进去：

| 放法 | 送进子层的东西 | 子层写出的增量 | 增量范数 | 相加后 $x_{l+1}$ | $\|x_{l+1}\|$ |
|---|---|---|---|---|---|
| **无归一化**（基线） | `[1, 2, 3, 4]` | `[2.000, 1.500, 1.000, 0.500]` | 2.73861 | `[3.000, 3.500, 4.000, 4.500]` | **7.58288** |
| **【A】Post-Norm** | `[1, 2, 3, 4]` | `[2.000, 1.500, 1.000, 0.500]` | 2.73861 | `[0.79126, 0.92314, 1.05501, 1.18688]` | **2.00000** |
| **【B】Pre-Norm** | `[0.365, 0.730, 1.095, 1.461]` | `[0.73030, 0.54772, 0.36515, 0.18257]` | **1.00000** | `[1.73030, 2.54772, 3.36515, 4.18257]` | **6.18902** |
| **【C】Sandwich** | `[0.365, 0.730, 1.095, 1.461]` | `[1.46060, 1.09545, 0.73030, 0.36515]` | **2.00000** | `[2.46060, 3.09545, 3.73030, 4.36515]` | **6.97180** |

**这张表能读出三条结论，每一条都对应后面一整段：**

```
(1) Post-Norm 的输出范数【恒等于 sqrt(d) = 2】，和输入是什么无关。
    -> 残差流的范数被【每层压回固定值】，永远不会增长。
    -> 代价：恒等通路上多了一个 1/rms 的缩放。§4.3.3 会把这个缩放的连乘算出来。

(2) Pre-Norm 的【增量范数恒等于 1.00000】，因为子层的输入被归一化了、
    F 又是固定映射，所以 F 的输出尺度被钉住了。
    但 ||x|| 从 5.47723 长到 6.18902 —— 这正是 [03 章 §3.4] 的 sqrt(N) 增长。

(3) ★ Sandwich 的增量范数是 2.00000，不是变小，是【变大了】（从 1.0 拉到 2.0）。
    因为 Norm2 做的事是"把幅度钉在 sqrt(d)"，而不是"把幅度压小"。
    -> 所以 Sandwich-Norm 的作用要准确地说成：让每层写入的幅度
       【受控、逐层可比、不随层深漂移】，而不是"自动变小"。
    -> 真正把这个值压到合适大小，靠的是可学习的 g（实践中初始化远小于 1）
       以及 openPangu 那种【块级后归一化】（§4.4）。
```

> 📌 **第 (3) 条是这张表最值得算一遍的地方。** 很多二手材料会说"Sandwich Norm 把子层输出压小了"——**在 $g=1$ 的情况下它其实是放大**。把数字算出来就不会记错方向。

### 4.3.3 分歧的关键：那条恒等通路有没有被打断

回到 [03 章 §3.2](03-残差流.md) 的核心——**梯度能不能沿一条"什么都不做"的路径直达浅层**。

```
Post-Norm:  x_{l+1} = Norm(x_l + F(x_l))
            -> 恒等路径【经过了 Norm】，梯度被 1/rms 反复缩放 N 次
            -> §3.2 的连乘问题【部分回来了】
            -> 深层网络必须靠【warmup】才能训起来，超过 ~20 层非常难训

Pre-Norm:   x_{l+1} = x_l + F(Norm(x_l))
            -> 恒等路径【完全干净】，d x_{l+1} / d x_l = I + (子层那一项)
            -> 可以不用 warmup、可以堆到 100 层
```

**把 Post-Norm 那个 $1/\text{rms}$ 的连乘算出来。** 设已经进入稳态（$\|x_l\|$ 已经被 Norm 钉在 $\sqrt{d}$ 上），每层的缩放因子是

$$\frac{\|x_l\|}{\|x_l + F(x_l)\|} = \frac{1}{\sqrt{1 + r^2}},\qquad r \equiv \frac{\|F\|}{\|x_l\|}\ \ (\text{假设 } F \perp x_l)$$

| 情形 | 每层缩放因子 | 连乘 20 层 | 连乘 50 层 | 连乘 93 层 |
|---|---|---|---|---|
| $r = 0.5$，$F \perp x$（$1/\sqrt{1.25}$） | 0.89443 | 0.1074 | **0.00378** | $3.1\times10^{-5}$ |
| $r = 0.5$，**本例的 $F$**（和 $x$ 不正交，实测比值 1.38444） | 0.72231 | 0.00150 | $8.6\times10^{-8}$ | $7.3\times10^{-14}$ |
| **Pre-Norm 的恒等项** | **1.00000** | **1** | **1** | **1** |

> 🔑 **这就是 Post-Norm 的病灶，而且是可以算出来的**：50 层之后，梯度沿恒等通路传回第 1 层时，**只剩千分之三点八到亿分之一**。而 Pre-Norm 那一项**恒等于 1，连乘多少层都是 1**。
>
> ⚠️ **口径提醒**：上表只算了"恒等通路被 Norm 缩放"这一项，**不是完整的梯度**（完整梯度还有子层那一项，以及 Norm 对方向的雅可比）。它说明的是**机制**和**量级**，不是可以直接去和实测对比的数字。
> ⚠️ **我的推断（不是论文结论）**：真实训练里 $F$ 会学着把自己的输出变小（让 $r$ 变小、缩放因子趋近 1）来抵消这个衰减，**而"学到这个状态之前的那段不稳定期"正是 Post-Norm 必须 warmup 的原因之一**。

### 4.3.4 三种放法的对照表

| | Post-Norm | Pre-Norm | Sandwich |
|---|---|---|---|
| 恒等通路 | ❌ 被 Norm 打断 | ✅ 干净 | ✅ 干净 |
| 训练稳定性 | 差，需要 warmup + 小学习率 | **好** | **更好** |
| 深度上限 | ~20 层就很吃力 | 100+ 层 OK | 100+ 层 OK |
| 最终效果 | **略好**（如果训得起来） | 略差 | 介于之间 |
| 残差范数 | 每层被压回 $\sqrt{d}$（§4.3.2 实测 2.00000） | **按 $\sqrt{N}$ 增长**（[§3.4](03-残差流.md)） | 增长被抑制（每层写入幅度受控） |
| 每层写入的增量幅度 | 不受控（§4.3.2 实测 2.73861） | 受控（实测 1.00000） | **钉死在 $\|g\|$ 决定的值**（实测 2.00000） |
| 额外开销 | 0 | 0 | 多一次 Norm（按 §4.1.3，即每元素多搬 4 字节） |

> 🔑 **Pre-Norm 用一点点最终效果，换到了"能训起来"。** 这个交易在 100B+ 规模上根本没得选——一次训练几千万美元，训崩了就全没了。
>
> **五家【全部】是 Pre-Norm 基础**（Sandwich 是在此之上的加固）。

### 4.3.5 Pre-Norm 的那个代价，具体是什么

$$x_{l+1} = x_l + F(\text{Norm}(x_l)),\qquad \|x_l\| \approx \sqrt{l}$$

因为 $F$ 的输入被归一化了，$\|F(\cdot)\|$ 大致是常数，而 $\|x_l\|$ 在长大：

$$\frac{\|F_l\|}{\|x_l\|} \approx \frac{1}{\sqrt{l}}$$

**逐层代出来**（这张表和 [03 章 §3.4](03-残差流.md) 的是同一张，从"稀释"这一侧读）：

| 层 $l$ | $\|x_l\| \approx \sqrt{l}$ | 本层子层的贡献占比 $1/\sqrt{l}$ | 等效学习率相对第 1 层 | 对应模型 |
|---|---|---|---|---|
| 1 | 1.000 | **100%** | 1.00 | — |
| 4 | 2.000 | 50.0% | 0.50 | — |
| 16 | 4.000 | 25.0% | 0.25 | — |
| 25 | 5.000 | 20.0% | 0.20 | — |
| **50** | **7.071** | **14.1%** | 0.141 | openPangu 的最后一层 |
| 61 | 7.810 | 12.8% | 0.128 | DeepSeek-V4 的最后一层 |
| 78 | 8.832 | 11.3% | 0.113 | GLM-5.2 的最后一层 |
| **93** | **9.644** | **10.4%** | 0.104 | Kimi K3 的最后一层 |

```
-> 深层的子层【实际上在做很小的修正】，表达力被浪费了
-> 这就是 Pre-Norm "最终效果略差" 的机制性解释
-> ★ 也解释了为什么【层数越多的模型越有动机去改残差】：
   K3 有 93 层，最后一层只剩 10.4% 的话语权，是五家里最严重的
   —— 它也确实是唯一做 AttnRes 的那一家（[03 章 §3.6]）
```

> 📌 **Sandwich-Norm 正是针对这一点的补丁**：给子层输出也加一个 Norm，让每层写入的幅度**受控且逐层可比**，缓解深层被稀释。
> ⚠️ 但按 §4.3.2 第 (3) 条，它**本身不会把幅度压小**，压小要靠可学习的 $g$。

> ⚠️ **上表的 $\sqrt{l}$ 是理论近似，不是实测。** 它依赖"每层写入的增量互相大致独立"这个假设（[03 章 §3.4](03-残差流.md) 有推导）。真实模型里增量之间有相关性，实测曲线会偏离 $\sqrt{l}$。**五家报告都没有公开逐层残差范数曲线**，所以这张表只能当量级参考。

## 4.4 openPangu 的门控塌陷：一个真实的故障与修复

这是本章唯一一个五家里有明确一手记录的故障案例，**值得完整看一遍**，因为它把 [03 章](03-残差流.md)和本章连在了一起。

### 4.4.1 背景

openPangu-2.0-Pro 用了 mHC（[§3.5](03-残差流.md)）。mHC 引入了 $A_l$（读门控）和 $C_l$（写门控）。

### 4.4.2 故障

> ✅ **华为报告明确记录**：训练早期，**早期层的 mHC 门控出现塌陷**——报告中记为 $H_{\text{pre}}$、$H_{\text{post}}$ 趋近于 0。

```
门控 -> 0 意味着什么：

    x_{l+1} = B_l x_l + C_l F_l(A_l x_l)
                        ^ 这一项被门控乘成了 0

    -> 子层【完全不起作用】，那一层退化成纯粹的 B_l x_l（只是流间混合）
    -> 参数白白浪费，而且是发生在【最该学基础特征的浅层】
```

**为什么它出不来：这是一个标准的"死单元"陷阱，把两个梯度并排写出来就看明白了。** 设写门控是一个标量 $c$，那一层是 $x_{l+1} = B x_l + c\cdot F(\cdot)$：

| $c$ 的取值 | 这一层的实际贡献 | $\partial \mathcal{L}/\partial c \propto F(\cdot)$ | $\partial \mathcal{L}/\partial W_F \propto c$ | 能不能爬出来 |
|---|---|---|---|---|
| 1.00 | 100% | 正常 | 正常 | — |
| 0.10 | 10% | 正常 | **×0.10** | 子层学得慢 |
| 0.01 | 1% | 正常 | **×0.01** | 子层几乎不动 |
| **0.00** | **0** | 正常但无用 | **×0 = 0** | ❌ **永远出不来** |

> 🔑 **看最后两列的乘法关系**：$c$ 越小，$F$ 里的权重收到的梯度就越小（正比于 $c$）；$F$ 越学不动，$c$ 就越没有理由被调大。**这是一个自锁的局部最优——门控一旦接近 0，就再也出不来了。**

### 4.4.3 为什么恰好在早期层

**⚠️ 以下是我的推断，华为报告没有给出机制解释。**

```
回忆 §4.3.5：Pre-Norm 下 ||x_l|| ~ sqrt(l)

    浅层 l 小  ->  ||x_l|| 小  ->  子层输出相对于残差流【偏大】
```

**用 §4.3.5 那张表直接读数字**（$\|F\| \approx 1$）：

| 层 $l$ | $\|x_l\| \approx \sqrt{l}$ | 子层输出 / 残差流 $= 1/\sqrt{l}$ | 优化器眼里 |
|---|---|---|---|
| 1 | 1.000 | **1.000**（和整条流一样大） | ⚠️ 子层一写就把流冲翻 |
| 2 | 1.414 | 0.707 | ⚠️ 还是很大 |
| 5 | 2.236 | 0.447 | 偏大 |
| 25 | 5.000 | 0.200 | 正常 |
| 50 | 7.071 | 0.141 | 偏小 |

```
    -> 早期层的子层输出【和整条残差流一个量级】，一写就是剧烈扰动
    -> 优化器为了稳定，最简单的办法就是【把门控关掉】
    -> 关到 0 之后撞上 §4.4.2 那个自锁陷阱，再也出不来
```

并且这和 [01 章 §1.3](01-鸟瞰全景.md) 的分层现象一致：**浅层做的事最简单**，所以"关掉也不太掉 loss"，优化器就真的关掉了。

### 4.4.4 修复

> ✅ **华为报告给出的两条措施**：
>
> **① Sandwich Norm** —— 给子层输出也加归一化，控制它写回残差流的幅度
> **② 块级后归一化** —— 在**第 1 层之后**、以及**每 5 层的块之后**，各加一次归一化

**50 层模型上，这些额外的归一化落在哪里**：

| 序号 | 位置 | 说明 |
|---|---|---|
| 1 | 第 **1** 层之后 | 单独一次——最容易塌陷的就是它 |
| 2 | 第 **5** 层之后 | 第一个 5 层块的末尾 |
| 3 | 第 **10** 层之后 | |
| 4–10 | 第 **15 / 20 / 25 / 30 / 35 / 40 / 45** 层之后 | 每 5 层一次 |
| 11 | 第 **50** 层之后 | 最后一个块的末尾 |

> ⚠️ **"一共 11 次"是我按 50 层数出来的**（1 次 + 50÷5 = 10 次），**报告只给了规则，没给总数**。

**为什么这管用**：

```
Sandwich Norm 保证子层输出【尺度受控、逐层可比】
    -> 它不会因为浅层 ||x|| 小就相对过大（对治 §4.4.3 那张表的第 1~2 行）
    -> 优化器不再有"必须关掉门控"的压力

块级后归一化【周期性地把残差流范数压回来】
    -> 直接对治 §3.4 的 sqrt(N) 增长
    -> 深层的相对话语权被恢复
    -> ★ 注意这一条【局部恢复了 Post-Norm 的做法】：每 5 层把恒等通路压一次。
      50 层里只压 11 次（而不是 50 次），所以 §4.3.3 那个连乘衰减只发生 11 次，
      按正交情形 0.89443^11 = 0.2931 —— 还能承受。
      => 这是一个很典型的【折中】：不是"Pre 还是 Post"，而是"多久压一次"。
```

自己验算：$0.89443^{11} = e^{11\times(-0.1115718)} = e^{-1.2273} = 0.2931$。再对比一下：如果 50 层每层都压（也就是纯 Post-Norm），那是 $0.89443^{50} = 0.00378$ —— **压 11 次和压 50 次差了 78 倍**，这就是「块级」这个词的全部分量。

> 🔑 **这个案例的价值**：它说明 [03 章](03-残差流.md)那些"改残差"的方案**不是免费午餐**。mHC 带来的不只是 +6.7% 墙钟（✅ 这个数字是 DeepSeek-V4 报告给的，openPangu 报告**未披露**墙钟），还带来了新的、需要额外补丁才能压住的训练不稳定性。**这是"三家改、两家不改"这个分歧的一条实证注脚。**

## 4.5 另一个位置：QK-Norm

除了残差前后，还有第三个常放归一化的地方——**注意力内部的 Q 和 K**。

$$\text{score} = \frac{\text{RMSNorm}(q)\cdot \text{RMSNorm}(k)^\top}{\sqrt{d_h}}$$

### 4.5.1 动机：softmax 饱和

[05 章 §5.3](05-注意力机制.md) 会详讲，这里只需要知道结论：

```
如果 q·k 的数值变得很大（比如 200），softmax 会变成【近乎 one-hot】：

    softmax([200, 5, 3]) ≈ [1.0, 0.0, 0.0]

    -> 梯度几乎全是 0（softmax 在饱和区导数趋近 0）
    -> 这个注意力头【卡死了】，再也学不动
    -> 训练日志上表现为【loss spike】或者干脆发散
```

**而 $q\cdot k$ 变大是很容易发生的**：$q$ 和 $k$ 都是无约束的线性投影输出，训练中它们的范数会自由漂移（§4.2 已经说过：归一化让权重模长变得"不影响输出"，于是它会自由漂移）。

### 4.5.2 QK-Norm 的修复，以及它的上界能算出来

**先把 $q$ 和 $k$ 归一化到固定长度，再算内积。** 这样内积被**限制在有界范围内**。

**上界是多少？两行柯西–施瓦茨就出来了**（取 $g$ 全为 1）：

```
||RMSNorm(q)|| = sqrt(d_h)      （§4.1.1：rms = 1  =>  范数 = sqrt(d_h)）
||RMSNorm(k)|| = sqrt(d_h)

柯西-施瓦茨： | q_hat . k_hat |  <=  ||q_hat|| x ||k_hat||  =  d_h

再除以 sqrt(d_h)：   | score |  <=  sqrt(d_h)
```

| $d_h$ | QK-Norm 后 logit 的上界 $\sqrt{d_h}$ | 无 QK-Norm 时 |
|---|---|---|
| 64 | 8.00 | 无界 |
| **128** | **11.31** | 无界 |
| 256 | 16.00 | 无界 |
| 512 | 22.63 | 无界 |

> 🔑 **这张表把 QK-Norm 的作用说准了：它给 logit 一个【上界】，不是把 logit 压到 ±1。**
>
> ```
> ✅ 它治的是【发散 / loss spike】：从"可以涨到几百"变成"最多 11.31"。
> ❌ 它【不】把注意力分布变平。11.31 这个上界本身已经足够尖：
>    softmax([11.31, 0, 0, ...]) 在 4096 个候选里，头名仍能拿到 ~95% 的权重。
> ```
>
> ⭐ **一个漂亮的跨章呼应**：[05 章 §5.5](05-注意力机制.md) 算过，要让 attention sink 稳定拿到 90% 的权重，需要的 logit 差是 $\ln(0.9\times4095/0.1) = 10.5$。**而 QK-Norm 的上界是 11.31 —— 刚好还够。** 所以 **QK-Norm 不会把 sink 机制砍掉**，两件事在数值上并不矛盾。这不太可能是巧合：$d_h$ 选 128 本来就有"$\sqrt{d_h}$ 够大"的考虑。⚠️ 这最后一句是我的推测，没有任何报告这么说。

> ⚠️ **严格说那个上界不是硬的**：$g$ 可学，真正的上界是 $\|g_q \odot \hat q\|\cdot\|g_k\odot \hat k\| / \sqrt{d_h}$，$g$ 学大了上界也跟着大。**QK-Norm 的真实价值是把"尺度"从【自由漂移的激活值】挪到了【一个 $d_h$ 维、能被权重衰减管住的小参数】上。**

> ✅ **DeepSeek-V4 明确使用 QK-RMSNorm**（报告有记）。
> ✅ **MiniMax M3 用的是 per-head QK-Norm**（见 [../模型技术对比.md](../模型技术对比.md) 第二节"位置编码"与"稳定性土办法"两行）。
> ⚠️ 其余几家报告中我没有找到明确记载，**不代表没用**——这是个很常规的稳定化手段。
> ✅ **另一条有意思的一手记录**：openPangu 报告说它的 attention logits **全程有界在 ≈20**、不需要任何 clipping，而它把这个归因于 **sandwich norm + 块级后归一化**（§4.4）而不是 QK-Norm。GLM-5.2 也说 logits 全程稳定，但归因于 **Muon Split**。⚠️ **同一个现象、三种互斥归因**，详见 [../模型技术对比.md](../模型技术对比.md) §3.8 与 [13 章 §13.8](13-优化器与Muon.md)。

> 📌 **这条"softmax 会饱和"的线索非常重要**，它在教程里出现三次：
> ```
> 这里（§4.5）         -> 训练不稳定的一个来源，用 QK-Norm 治
> [05 章 §5.5]        -> softmax 和必须为 1，模型没有"什么都不看"的选项
> [14 章 §14.6]       -> 上一条导致模型自造巨大激活当泄压阀 = 离群值
>                       这是低比特量化最大的敌人
> ```

## 4.7 本章小结

```
(1) RMSNorm = 除以 RMS 再乘可学习的 g。只改长度（拉到 sqrt(d)，不是 1），不改方向
    比 LayerNorm 少了减均值和平移。减均值的唯一功能是【对整体平移免疫】
    （§4.1.2 实测：x 加 10 之后 LayerNorm 输出一字不变，RMSNorm 全变）
    Transformer 不需要这个不变性，因为"整体平移"只占 5120 个方向里的 1 个
(2) ⚠️ RMSNorm 的算术强度是 1.0，比 LayerNorm 的 2.0 【更低】
    —— 省的是分子（FLOP 减半），分母（每元素 4 字节）一点没变
    两者都远在屋脊点 295 以下、都 Memory Bound => 屋顶线预测的时间【完全一样】
    真正省的是：少一遍归约（少一轮同步）+ 朴素实现下少读一遍 x + 少一个 b
    ⚠️ "快 7~64%" 是 RMSNorm 原论文在 RNN 系模型上的端到端数字，不是现代融合 kernel
    ⚠️ "快 X%" 含糊：时间减少 40% = 加速 1.67 倍，不是 1.4 倍
(3) 它有效的原因不是"减少协变量偏移"（已被推翻），
    而是【让损失曲面变平滑】+【消掉权重尺度这个无用自由度】
(4) Pre / Post / Sandwich 的分歧点只有一个：恒等通路有没有被 Norm 打断
    §4.3.2 用同一个 x=[1,2,3,4] 把三种放法算出来：
      Post ：输出范数恒为 sqrt(d)=2，但恒等通路每层被乘 ~0.894，50 层剩 0.0038
      Pre  ：增量范数恒为 1，恒等项恒为 1，但 ||x|| 按 sqrt(N) 增长
      ★ Sandwich：增量范数被【钉在 sqrt(d)=2】—— 是"受控"，不是"变小"，
        g=1 时它其实把增量从 1.0 放大到 2.0。压小要靠可学习的 g
    五家全部 Pre-Norm 基础，用一点最终效果换"能训起来"
(5) Pre-Norm 的代价：第 l 层的贡献被稀释成 1/sqrt(l)
    50 层剩 14.1%、93 层剩 10.4% -> ★ 层数越多越有动机改残差，K3 最深也最激进
(6) openPangu 的门控塌陷：mHC 的门控在早期层塌到 0，而且是【自锁】的
    （门控 -> 0 使子层梯度正比于门控也 -> 0，永远出不来）
    为什么在浅层：浅层 ||x|| 小，子层输出相对过大，优化器只好关门控
    修复 = Sandwich Norm + 第 1 层后及每 5 层的块级后归一化（50 层共 11 次）
    ★ 块级后归一化本质是"局部用回 Post-Norm"：50 层只压 11 次，衰减可承受
(7) QK-Norm：给 logit 一个上界 sqrt(d_h)（d_h=128 时是 11.31），治发散不治"太尖"
    ⭐ 而 05 章算出 attention sink 需要 logit 差 10.5 —— 11.31 刚好还够，两者不矛盾
    这条"softmax 饱和"的线索会一路通到量化章
```
