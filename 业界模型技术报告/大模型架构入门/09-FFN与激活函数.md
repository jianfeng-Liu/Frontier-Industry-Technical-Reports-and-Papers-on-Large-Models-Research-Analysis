# 09 · FFN 与激活函数：模型 2/3 的参数都在这里

> **这一章的目标**：讲清模型的另一半积木。

## 9.1 FFN 是什么

回忆 [01 章](01-鸟瞰全景.md)的二分法：**Attention 横向混合，FFN 纵向变换。**

**FFN（Feed-Forward Network）对每个 token 独立地做同一件事，位置之间毫无交流。**

$$\text{FFN}(x) = W_{\text{down}}\ \text{act}\!\left(W_{\text{up}}\,x\right)$$

```
    x  [5120]
      |
      |  W_up  [5120, 13824]       ★ 先【扩张】
      v
    h  [13824]
      |
      |  act(.) 非线性激活          ← 整个模型的非线性来源之一
      v
    h' [13824]
      |
      |  W_down  [13824, 5120]     ★ 再【压缩】回来
      v
    y  [5120]

    ★ 扩张倍数 d_ff/d 在 2.7 ~ 3.5 之间，为什么是这个范围见 §9.3
```

### 为什么要"先扩再缩"

```
① 如果不扩张，直接 [5120 → 5120] 两层线性，中间夹一个激活：
   表达力有限，而且参数量只有 2d²

② 扩张到 d_ff 之后，中间层有 13824 个神经元
   每个神经元可以检测一个【特征】：
       "这个 token 是不是一个人名？"
       "上下文是不是在讨论数学？"
       "这个位置需不需要一个动词？"

   然后 W_down 根据激活了哪些特征，决定往残差流写什么
```

> 🔑 **用 [03 章](03-残差流.md)的总线视角说得更准确**：
> ```
> W_up   的每一【行】  = 一个从残差流上【读取】的方向（"检测器"）
> W_down 的每一【列】  = 一个往残差流【写入】的方向（"结论"）
>
> FFN = 13824 个 [检测器 → 结论] 的规则，激活函数决定哪些规则被触发
> ```
> **这是一个非常有解释力的图景**：FFN 常被理解为**键值记忆**（key-value memory）——$W_{up}$ 是键，$W_{down}$ 是值，激活函数决定匹配度。可解释性研究确实找到了很多这样的"事实神经元"。

### ✅ 先把标题那个"2/3"算出来

**本章标题说"模型 2/3 的参数都在这里"，这不是形容词，是可以当场算的。** 一个 Transformer 层只有两块权重：注意力和 FFN。**拿掉 embedding，逐层数一遍：**

```
    注意力（标准 MHA = Multi-Head Attention，多头注意力，不用 GQA）：
                       W_q, W_k, W_v, W_o 各 d×d              → 4d²
    FFN（GLU 系，三个矩阵）：   W_gate, W_up, W_down        → 3·d·d_ff
```

| 模型 | $d$ | $d_{ff}$ | 注意力参数/层 | FFN 参数/层 | **FFN 占比** |
|---|---|---|---|---|---|
| LLaMA-2-7B（MHA） | 4096 | 11008 | 67.1 M | 135.3 M | **66.8%** |
| LLaMA-2-13B（MHA） | 5120 | 13824 | 104.9 M | 212.3 M | **66.9%** |
| LLaMA-3-8B（GQA 32:8） | 4096 | 14336 | 41.9 M | 176.2 M | **80.8%** |
| LLaMA-3-70B（GQA 64:8） | 8192 | 28672 | 151.0 M | 704.6 M | **82.4%** |

```
    ★ 两个读数：

    ① 标准 MHA 的年代，FFN 稳定占 【2/3】—— 标题的由来
    ② ★ 用了 GQA（Grouped-Query Attention，分组查询注意力 —— 让多个 Q 头
         共用一份 K/V，见 07 章）之后，注意力那块更瘦了
       → FFN 的占比反而【涨到 80% 以上】
       ⟹ 所以 [10 章](10-MoE.md) 要去拆的是 FFN，不是注意力：
          参数的大头一直在这里，而且越优化注意力，它的占比越高
```

## 9.2 激活函数的演化

| 年份 | 名字 | 公式 | ✅ 优点 | ❌ 缺点 |
|---|---|---|---|---|
| 2010 | **ReLU**（Rectified Linear Unit，修正线性单元） | $\max(0,x)$ | 极简、极快 | $x<0$ 时梯度**恒为 0** → 神经元"死亡"；在 0 处不可导 |
| 2016 | **GELU**（Gaussian Error Linear Unit，高斯误差线性单元） | $x\cdot\Phi(x)$，$\Phi$ = 标准正态的**累积分布函数** | 平滑可导；负半轴是软凹陷不是硬截断；GPT/BERT 时代的标准 | 要算 `erf`（误差函数），**慢** |
| 2017 | **SiLU**（Sigmoid Linear Unit）/ **Swish** | $x\cdot\sigma(x)=\dfrac{x}{1+e^{-x}}$ | 形状和 GELU 几乎重合，但**只需一个 sigmoid**，算得快；★ 现在的事实标准 | 同样无界（这是 §9.4 的祸根） |

### ★ 同一组输入，走一遍看差别

**光看公式感觉不出区别。把同一列 $x$ 灌进三个函数，差别一眼就出来了**（$\Phi$ 用精确值，不是 tanh 近似）：

| $x$ | ReLU | GELU | SiLU | GELU − SiLU |
|---|---|---|---|---|
| **−5** | 0 | −0.0000 | **−0.0335** | +0.033 |
| **−3** | 0 | −0.0041 | **−0.1423** | +0.138 |
| **−2** | 0 | −0.0455 | **−0.2384** | +0.193 |
| **−1.278** | 0 | −0.1286 | ★ **−0.2785**（SiLU 最小值） | +0.150 |
| **−1** | 0 | **−0.1587**（GELU 最小值附近） | −0.2689 | +0.110 |
| **−0.5** | 0 | −0.1543 | −0.1888 | +0.035 |
| **0** | 0 | 0 | 0 | 0 |
| **+0.5** | **0.5** | 0.3457 | 0.3112 | +0.035 |
| **+1** | **1** | 0.8413 | 0.7311 | +0.110 |
| **+2** | **2** | 1.9545 | 1.7616 | +0.193 |
| **+3** | **3** | 2.9960 | 2.8577 | +0.138 |
| **+5** | **5** | 5.0000 | 4.9665 | +0.033 |

```
    ★ 三个能直接读出来的结论：

    ① 正半轴 x ≥ 3 时，三个函数已经【几乎相同】，都 ≈ x
       ⟹ 差别全部发生在 |x| < 3 这个窄窗口里
       ⟹ ★★ 这也说明：三者在【大值区都是线性无界】的 —— 记住这一点，§9.4 要用

    ② 负半轴：ReLU 一刀切到 0，GELU 和 SiLU 留了一个【小凹陷】
       中等负值（x ≈ −1 到 −2）拿到一个小负输出，很负的值才趋近 0
       ⟹ 这是"软抑制"：ReLU 说"不要"，GELU/SiLU 说"少要一点，而且还能回头"
          （梯度不为 0 ⟹ 这个神经元还活着）

    ③ GELU 和 SiLU 的最大差距只有 【0.19】，出现在 x = ∓2
       ⟹ 形状几乎重合 ⟹ ★ 既然效果一样，就选【算得快】的那个 → SiLU 胜出
```

**SiLU 的形状**（横轴 x，纵轴 f(x)）：

```
      3 |                           _
      2 |                        _-
      1 |                    _-
      0 +---------------_---------------  x
     -1 |      \____/
        +----+----+----+----+----+
            -4   -2    0    2    4
                  |
                  +-- 最小值 = -0.2785，在 x = -1.278 处
```

> 📌 **注意负半轴那个小凹陷**：它意味着**中等负值的输入会得到一个小的负输出**，而**很负的输入趋近 0**。这给了模型一个"软的"抑制机制，比 ReLU 的硬截断信息量大。

## 9.3 GLU：加一个门

**GLU（Gated Linear Unit）是这一代 FFN 的标配。它的改动是：把 $x$ 投影两次，一份过激活当"门"，一份不过激活当"内容"，然后逐元素相乘。**

$$\text{SwiGLU}(x) = W_{\text{down}}\Big(\underbrace{\text{SiLU}(W_{\text{gate}}\,x)}_{\text{门：开多大}}\ \odot\ \underbrace{W_{\text{up}}\,x}_{\text{内容：传什么}}\Big)$$

```
    x [5120]
      |
      +-- W_gate [5120, 13824] --> g [13824] --> SiLU --> gate [13824]   "开多大"
      |                                                        |
      |                                                        * 逐元素相乘
      |                                                        |
      +-- W_up   [5120, 13824] ----------------> up   [13824] -+
                                                               |
                                                               v
                                                  h [13824]
                                                               |
                                            W_down [13824, 5120]
                                                               v
                                                          y [5120]
```

```
    第 j 个通道在干什么（j = 0 .. 13823）：

      gate[j] ≈ 0   ->  h[j] ≈ 0           这个通道被【关闭】，内容传不过去
      gate[j] ≈ 1   ->  h[j] ≈ up[j]       内容原样通过
      gate[j] <  0  ->  h[j] = -|..|·up[j] 内容被【反向】传递
```

### 为什么门控有用

```
① 标准 FFN：act(W·x) —— 一个神经元是否激活，只取决于【一个】线性投影
② GLU：     两个独立的投影，一个决定"传不传"，一个决定"传什么"
   → 【乘法交互】。乘法比加法的表达力强得多：
      加法只能叠加特征，乘法可以表达"条件"和"选择"

   这和 LSTM 的门控、[08 章](08-高效注意力.md) delta rule 的遗忘门是同一种思想
```

**实证上 SwiGLU 稳定优于 ReLU/GELU FFN**（Noam Shazeer 的原论文里做了完整的消融）。**五家全部用 GLU 系。**

### ★ 为什么是【三个】矩阵，不是两个

**这里有个很自然的疑问：门控不就是"多乘一下"吗，为什么要多一整个矩阵？**

```
    ① 用两个矩阵做不了门控：
       h = act(W_up x) ⊙ (W_up x)     ← 门和内容来自【同一个】投影
       = act(z) ⊙ z  = 这就是 SiLU(z) 本身，什么都没多出来 ★

    ② 想让"开多大"和"传什么"是两个【独立】的判断，
       就必须有两个【不同】的读取方向 → 两个矩阵 → 加上 W_down 共三个
```

| | 矩阵 | 形状 | 参数量 | 这个矩阵在回答什么 |
|---|---|---|---|---|
| 标准 FFN | $W_{up}$ | $d\times d_{ff}$ | $d\,d_{ff}$ | 这个通道的**读数**是多少 |
| | $W_{down}$ | $d_{ff}\times d$ | $d\,d_{ff}$ | 读数变成什么**结论**写回总线 |
| | **合计** | | $\mathbf{2\,d\,d_{ff}}$ | |
| GLU 系 | $W_{gate}$ | $d\times d_{ff}$ | $d\,d_{ff}$ | 这个通道该**开多大** |
| | $W_{up}$ | $d\times d_{ff}$ | $d\,d_{ff}$ | 开了之后**传什么** |
| | $W_{down}$ | $d_{ff}\times d$ | $d\,d_{ff}$ | 变成什么**结论**写回总线 |
| | **合计** | | $\mathbf{3\,d\,d_{ff}}$ | |

### ⚠️ 那个奇怪的 2/3 因子

**既然 GLU 每个通道贵了 50%，为了参数量公平对比，通道数就得少 1/3：**

$$3\,d\,d_{ff}^{\text{GLU}} = 2\,d\,d_{ff}^{\text{标准}}\quad\Longrightarrow\quad d_{ff}^{\text{GLU}} = \tfrac{2}{3}\,d_{ff}^{\text{标准}}$$

```
    标准 FFN 的惯例：d_ff = 4d
    GLU 版本：      d_ff = (2/3) × 4d = 8d/3 ≈ 2.67d

    d = 5120  →  8d/3 = 13653.3  →  向上对齐到 256 的倍数 → 13824 ✓
    d = 4096  →  8d/3 = 10922.7  →  向上对齐到 256 的倍数 → 11008 ✓
```

> 🔑 **这就是你在配置文件里看到 `intermediate_size: 13824` / `11008` 这种"奇怪"数字的原因。**
> 它不是随便定的，是 $\frac{8}{3}d$ 向上对齐到硬件友好的倍数。

### ⚠️ 但别把 8/3 当定律：真实模型的比值是散的

**上面那条推导只说明了"2/3 这个折算是怎么来的"，它没有说 $d_{ff}=4d$ 这个前提本身有多硬。事实上后来的模型普遍把中间维又往上抬了：**

| 模型 | $d$ | $d_{ff}$ | **$d_{ff}/d$** | 对应"折算前"的 $d_{ff}^{\text{标准}}/d$ |
|---|---|---|---|---|
| LLaMA-2-7B | 4096 | 11008 | **2.69** | 4.03 ← 教科书式的 $8d/3$ |
| LLaMA-2-13B | 5120 | 13824 | **2.70** | 4.05 ← 同上 |
| LLaMA-2-70B | 8192 | 28672 | ⚠️ **3.50** | 5.25 |
| **LLaMA-3-8B** | 4096 | ⚠️ **14336** | ⚠️ **3.50** | 5.25 |
| LLaMA-3-70B | 8192 | 28672 | ⚠️ **3.50** | 5.25 |
| Mistral-7B | 4096 | 14336 | **3.50** | 5.25 |

```
    ⚠️ 这里有个很常见的口径错误，值得单独标出来：

    ✗ 错："LLaMA-3-8B 的 intermediate 是 4h"
          4 × 4096 = 16384 ≠ 14336
    ✗ 错："所有 GLU 模型都是 8h/3"
          8/3 × 4096 = 10923 ≠ 14336
    ✅ 对：LLaMA-3-8B 是 h = 4096、intermediate = 14336，比值【3.5】

    ★ 从 2.69 涨到 3.50 是一个【主动的选择】，不是算错：
      LLaMA-3 用了 GQA（K/V 头数从 32 砍到 8），注意力那块省下了一大笔参数
      → 省下来的预算被【挪进了 FFN】（回看 §9.1 那张表：FFN 占比从 67% 涨到 81%）
```

> 🔑 **正确的说法是**：`8/3` 是**"给 GLU 做等参数折算"这个动作**的系数，不是中间维的最终答案。**实际取值 = (这一代认为 FFN 该拿多少预算) × 2/3，再向上对齐到 128/256 的倍数。** 见到 2.67、3.0、3.5 都不要惊讶，见到恰好 4.0 反而要怀疑它是不是没用 GLU。

## 9.4 ⚠️ SwiGLU 的一个大麻烦：它无界

**这一节是本章最重要的部分，它连着 [14 量化](14-量化.md)。**

### 问题

```
    SwiGLU(x) = SiLU(W_g x) ⊙ (W_u x)

    ① SiLU 在正半轴是【线性增长】的：SiLU(100) ≈ 100
    ② W_u x 也是【无界】的线性投影
    ③ 两个无界的东西【相乘】 → 输出可以到 【平方级别】的大

    输入 100 → 输出可能到 10,000
```

**再叠加 [05 章 §5.5](05-注意力机制.md) 那条链**（softmax 和为 1 → attention sink → 巨大激活），FFN 的输入本来就可能带着离群值进来，**经过 SwiGLU 的乘法会被平方放大**。

### 后果

```
① 训练不稳定：偶发的巨大激活 → loss spike → 甚至 NaN
② ★ 量化崩溃：一个 10,000 的离群值和一堆 0.1 的正常值在同一个量化组里
   → 量化区间被离群值撑满 → 正常值全部塌成 0
   → 详见 [14 章 §14.6](14-量化.md)
```

### 解法一：硬截断（clamp）

$$\text{clamp}(z, -c, +c) = \min(\max(z, -c), +c)$$

> ✅ **DeepSeek-V4：SwiGLU 输出 clamp 到 $[-10, 10]$**
> ✅ **MiniMax M3：clamp 到 $7.0$**

```
✅ 极简，几乎零开销
✅ 硬保证了上界 → 量化区间可控
❌ 截断处梯度为 0 → 被截断的通道"学不动"了
❌ 不平滑，理论上不优雅
```

### 解法二：软饱和 —— Kimi K3 的 SiTU-GLU

> ✅ **K3 报告给出的完整形式**：
> $$\text{SiTU-GLU}(x) = \Big[\beta_1\tanh\!\left(\tfrac{W_g x}{\beta_1}\right)\odot\sigma(W_g x)\Big]\ \odot\ \beta_2\tanh\!\left(\tfrac{W_u x}{\beta_2}\right)$$
> **参数：$\beta_1 = 4$，$\beta_2 = 25$。**

**逐块拆解**：

```
① β₁·tanh(z/β₁)     ← 把 z 【软性地】限制在 (−β₁, +β₁) = (−4, 4)
                       ★ 关键：|z| 很小时 tanh(z/β)·β ≈ z，几乎不改变
                                |z| 很大时饱和到 ±β₁

② ⊙ σ(W_g x)        ← 这就是 SiLU 的 sigmoid 部分（门）
   ①②合起来 ≈ 一个【有界版本的 SiLU】，上界 4

③ β₂·tanh(W_u x/β₂) ← 内容分支也软性限制在 (−25, 25)
```

$$\Rightarrow\quad |\text{SiTU-GLU}(x)| \le \beta_1\times\beta_2 = 4\times 25 = \boxed{100}$$

```
    ★★ 输出被【硬性数学保证】在 [−100, 100] 之内 ★★

    ✅ 处处平滑可导，没有梯度为 0 的死区（tanh 的导数处处 > 0）
    ✅ 小值区几乎恒等 —— 正常范围内的行为和 SwiGLU 一样
    ✅ 大值区软饱和 —— 离群值被自动压住，但仍保留大小顺序
```

### 对比

**先看形状**（横轴 = 输入 z，纵轴 = 输出；`|` 标出上界）：

```
    clamp(z, -c, c)                 beta * tanh(z / beta)

           _______  <- c                   ______   <- beta（渐近，永不到达）
          |                              _-
         /|                            _-
        / |                          _-
    ___/  |                     ____-
       ^                            ^
       |                            |
    在 z = c 处【折断】：           处处光滑：
    导数从 1 突变成 0               导数从 1 平滑衰减到 0，但【永远 > 0】
```

**再看数字**（这一列是 $\beta_1=4$ 的门分支：SiLU 对 SiTU 的 $\beta_1\tanh(z/\beta_1)\cdot\sigma(z)$）：

| 输入 $z$ | SiLU $=z\sigma(z)$ | SiTU 的门分支 | 差多少 |
|---|---|---|---|
| −4 | −0.072 | −0.055 | 几乎一样 |
| −1 | −0.269 | −0.264 | 几乎一样 |
| 0 | 0 | 0 | 相同 |
| **1** | 0.731 | **0.716** | ★ 正常区**基本恒等** |
| **2** | 1.762 | **1.628** | 开始压 |
| 4 | 3.928 | 2.992 | 压得明显 |
| 6 | 5.985 | 3.612 | |
| **10** | 10.00 | **3.946** | ★ 已经贴着上界 |
| **100** | **100.0** | **4.000** | ★★ SiLU 线性爆炸，SiTU 钉死在 4 |

| | **clamp**（V4 / M3） | **SiTU-GLU**（K3） |
|---|---|---|
| 怎么加界 | 硬截断 | $\beta\tanh(\cdot/\beta)$ 软饱和 |
| 小值区行为 | **完全恒等** | **近似恒等**（$\tanh z\approx z$） |
| 大值区行为 | 拍平成常数，**丢失大小顺序** | 仍单调递增，**保留大小顺序** |
| 截断处梯度 | ❌ **恒为 0**，这个通道学不动 | ✅ 处处 > 0 |
| 上界 | 精确等于 $c$ | 渐近到 $\beta_1\beta_2=100$（取不到） |
| 实现代价 | 一条 `min/max` | 两个 `tanh` + 两个标量 |
| 一句话 | 简单、够用 | 复杂、更优雅、上界更精确可控 |

> 🔑 **为什么 K3 值得做这么复杂的东西**：见下一节的因果链。

## 9.5 ★ 一条完整的因果链

**这条链把 09 章和 14 章连起来了，是全教程最有价值的推论之一。**

```
    ① 想把模型量化到 【4-bit】（省 4 倍显存和带宽）
             ↓
    ② 4-bit 只有 16 个量化档位，PTQ（训练后量化）在这个精度下必崩
       → 【必须用 QAT】（量化感知训练，训练时就模拟量化）
             ↓
    ③ QAT 期间，任何一个巨大的离群值都会毁掉整个量化组
       （详见 [14 章 §14.6](14-量化.md) 的手算例子）
             ↓
    ④ 而 SwiGLU 是【无界】的，且是两个无界量相乘（平方放大）
       → 它是离群值最大的产地
             ↓
    ⑤ ★ 所以：【必须给激活函数加界】
             ↓
    ⑥ 加界的两种方式：硬截断（简单）/ 软饱和（优雅）
```

### 反向验证：用这条链去看五家

| | 激活函数处理 | 量化目标 | 是否吻合 |
|---|---|---|---|
| **Kimi K3** | **SiTU-GLU**（软饱和，界 = 100） | **MXFP4 QAT**，贯穿 SFT 到 RL | ✅ 目标最激进 → 处理最讲究 |
| **DeepSeek-V4** | SwiGLU + **clamp [−10, 10]** | **FP4** 存 + FP8 算 | ✅ 目标激进 → 加了界 |
| **GLM-5.2** | SwiGLU | **INT4**（MoE）+ W8A8 QAT | ✅ 有 4-bit 目标 |
| **MiniMax M3** | SwiGLU + **clamp 7.0** | **MXFP8** | ✅ 只到 8-bit，但仍加了界 |
| **openPangu-2.0-Pro** | ❓ **报告中完全没提** | **W8A8**（疑似 PTQ） | ⚠️ 见下 |

### ⚠️ openPangu 那个空格

> **一个已核对的事实**：openPangu-2.0-Pro 技术报告中，`SwiGLU` / `GLU` / `SiLU` / `激活函数` 这几个关键词的命中次数是 **0**。

```
    这有两种可能的解读：

    ① 它就是用的标准 SwiGLU，因为太常规所以没写
    ② 它确实没做任何激活函数的加界处理
```

> ⚠️ **我倾向于第二种，但这只是推断，华为报告没有任何相关表述。** 理由是那条因果链的**反向**：
>
> ```
> openPangu 的量化目标只到 【W8A8】（8-bit），而且疑似是 PTQ 而非 QAT
>          ↓
> 8-bit 有 256 个档位，对离群值的容忍度比 4-bit 高【16 倍】
>          ↓
> ★ 所以它【不需要】给 SwiGLU 加界 —— 那个空格是自洽的
> ```
>
> **⚠️ 再次强调：这是一个自洽的解释，不是被验证的因果。** 也完全可能只是报告没写。

> 📌 但这个视角本身是有用的：**当你看到一份报告在某个位置什么都没做，去看它在下游的目标是什么，往往能解释得通。**

## 9.7 本章小结

```
① FFN = 先扩张到 2.7~3.5 倍，过激活，再压缩回 d。对每个 token 独立
   总线视角：W_up 的行是【检测器】，W_down 的列是【结论】
   → 常被理解为"键值记忆"
   ✅ 标题那个 2/3：MHA 时代 FFN 占每层参数 67%；
      用了 GQA 之后注意力更瘦，FFN 占比反而涨到 81%
      ⟹ 参数大头一直在 FFN，所以 10 章要拆的是它
② 激活函数演化：ReLU → GELU → SiLU（x·σ(x)，形状同 GELU 但更快）
   同一组输入走一遍：|x| ≥ 3 时三者几乎相同，差别只在窄窗口里
   GELU 与 SiLU 最大差 0.19（在 x = ∓2）→ 效果一样就选快的 → SiLU
   ★ 三者在大值区【都是线性无界】的 —— 这是 ④ 的祸根
③ GLU 门控：两个投影，一个当门一个当内容，逐元素相乘
   ★ 为什么必须是三个矩阵：门和内容若来自同一个投影，act(z)⊙z 就是 SiLU 本身，
     什么都没多出来 → 要两个【独立】方向 → 加 W_down 共三个
   乘法交互比加法表达力强 → 实证稳定优于普通 FFN，五家全用
   三个矩阵 → 每通道贵 50% → d_ff 要乘 2/3 才公平 → 8d/3 ≈ 13824、11008
   ⚠️ 但 8/3 只是【折算系数】，不是定律：
      LLaMA-2-7B/13B 是 2.69/2.70，而 LLaMA-3-8B 是 h=4096、
      intermediate=14336 → 比值【3.5】，既不是 4 也不是 8/3
④ ★ SwiGLU 是【无界】的，且两个无界量相乘 → 离群值的主要产地
   解法一：clamp（V4 [−10,10]，M3 7.0）—— 简单，但截断处梯度为 0
   解法二：SiTU-GLU（K3）—— β₁tanh(·/β₁)⊙σ ⊙ β₂tanh(·/β₂)
           β₁=4, β₂=25 → 数学保证 |输出| ≤ 100，且处处可导
⑤ ★ 因果链：想要 4-bit → 必须 QAT → 必须治离群值 → 必须给激活加界
   反向看，openPangu 只做 8-bit（容忍度高 16 倍），所以那个空格是自洽的
   ⚠️ 但这是我的推断，报告没这么说
```
