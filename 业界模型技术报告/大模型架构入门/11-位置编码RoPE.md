# 11 · 位置编码：RoPE 与长度外推

> **这一章的目标**：讲清模型怎么知道词的顺序，以及"4K 训练怎么推到 1M"这件事到底是怎么做到的。
> 读完你应该能回答：RoPE 为什么是旋转？那个漂亮的相对位置性质怎么证（§11.4 有一个 $d=4$ 的手算例子，所有数字都摆出来）？base 这个超参在控制什么？PI / NTK-aware / YaRN 各自改了公式里的**哪一项**？以及 **Kimi K3 为什么敢完全不用位置编码（NoPE, No Positional Encoding，不加位置编码）**？

---

## 11.1 为什么需要位置编码

**回到 [05 章](05-注意力机制.md)的公式**：

$$O_i = \sum_j \text{softmax}_j(q_i^\top k_j)\,v_j$$

```
    ★ 这个式子里【完全没有位置信息】

    "小明打了小红"  和  "小红打了小明"
    → 两句话的 token 集合完全一样
    → 如果不注入位置，注意力的输出【一模一样】
```

**注意力是"置换等变"的**：把输入顺序打乱，输出也只是跟着打乱，内容完全不变。**这对语言是灾难性的。**

> 📌 **对比一下**：RNN 天然有顺序（一步一步走），CNN 天然有局部位置（卷积核的相对位置）。**只有注意力是完全无序的**——这是它"任意两点一步可达"（[01 章](01-鸟瞰全景.md)）的代价。

---

## 11.2 三代方案

| | ① **绝对位置编码**（原始 Transformer, 2017） | ② **相对位置编码**（T5 等） | ③ **RoPE**（2021）★ 现在的绝对主流 |
|---|---|---|---|
| **在哪一步动手** | 在 embedding 上 | 在注意力分数上 | 在 $q$、$k$ 上 |
| **怎么做** | $x_i \leftarrow x_i + \text{PE}(i)$，**加**一个位置向量（学出来的或正弦函数） | 注意力分数上**加**一个偏置 $b(i-j)$ | 不加任何东西，把 $q$、$k$ **旋转**一个角度 |
| **模型学到的是** | ❌ "第 5 个位置" | ✅ "隔了 3 个词" | ✅ "隔了 3 个词"（效果上） |
| **长度上限** | ❌ 学出来的 PE 训练多长就只能用多长，**硬上限** | ✅ 无硬上限 | ✅ 无硬上限（但要处理外推，见 §11.5） |
| **能否活到深层** | ❌ 只在第 0 层注入，位置信息随层数**被冲淡** | ✅ **每层都重新注入** | ✅ **每层都重新注入** |
| **和 FlashAttention** | ✅ 兼容（根本没碰注意力） | ❌ 要显式构造 $[L,L]$ 的偏置矩阵，**冲突**，长序列开销大 | ✅ **完全兼容**（只改 $q$、$k$，不碰分数矩阵） |
| **泛化** | ❌ 差：训练时"隔 3 个词"这个模式，在位置 5 和位置 500 **要分别学两遍** | ✅ 好 | ✅ 好 |

```
    ★ 一句话串起这三代：
      ① 位置信息给对了地方（embedding），但给的是【绝对】的 → 泛化差
      ② 改成【相对】的，泛化好了，但它要一张 [L,L] 的表 → 和 FlashAttention 打架
      ③ RoPE 做到了【形式绝对、效果相对】：
         逐位置独立地转一下（好并行、不用建表），内积却只看相对距离

    五家全部用 RoPE 系（K3 除外，见 §11.7）
```

## 11.3 RoPE：把向量转个角度

### 二维的情形

**先只看两个维度**。位置 $m$ 处的向量 $(q_0, q_1)$，旋转角度 $m\theta$：

$$\begin{pmatrix}q_0'\\ q_1'\end{pmatrix} = \underbrace{\begin{pmatrix}\cos m\theta & -\sin m\theta\\ \sin m\theta & \cos m\theta\end{pmatrix}}_{R_m}\begin{pmatrix}q_0\\ q_1\end{pmatrix}$$

```
              位置 0            位置 1            位置 2
                ↑ q               ↗                →
                │              旋转 θ            旋转 2θ
                │             ╱                ╱
                ●            ●                ●

    ★ 向量的【长度不变】，只有【方向】随位置转动
```

### 那个漂亮的性质

$$\langle R_m q,\ R_n k\rangle = (R_m q)^\top(R_n k) = q^\top R_m^\top R_n\,k = q^\top R_{n-m}\,k$$

**因为旋转矩阵满足 $R_m^\top = R_{-m}$ 且 $R_a R_b = R_{a+b}$**（旋转是一个群）。

$$\boxed{\ \langle R_m q,\ R_n k\rangle = \langle q,\ R_{n-m}k\rangle\ }$$

```
    ★★★ 内积【只依赖 n − m】，与 m、n 的绝对值无关 ★★★

    "位置 5 和位置 8"  与  "位置 1005 和位置 1008"
    → 注意力分数完全相同

    这就是"形式绝对、效果相对"的含义
```

> 🔑 **这是 RoPE 全部魅力的来源**：它用一个**逐位置独立**的操作（好实现、好并行、和 FlashAttention 兼容），实现了**相对位置**的效果（泛化好）。

### 复数形式：更简洁

把 $(q_0,q_1)$ 看成复数 $q_0 + iq_1$，旋转就是**乘一个单位复数**：

$$\text{RoPE}(q, m) = q\cdot e^{im\theta},\qquad \langle q e^{im\theta},\ k e^{in\theta}\rangle = \text{Re}\!\left[q\bar{k}\,e^{i(n-m)\theta}\right]$$

**旋转 = 乘 $e^{i\theta}$，两次旋转 = 指数相加。** 群性质在复数形式下一目了然。

## 11.4 高维：多个频率

一个头有 $d_h$（比如 128）维，**两两配对成 $d_h/2$ 组，每组用不同的旋转频率**：

$$\theta_i = \text{base}^{-2i/d_h},\qquad i = 0, 1, \ldots, d_h/2 - 1$$

**base 通常是 10000（原始设定）。**

| $i$ | $\theta_i = 10000^{-2i/128}$ | 周期 $2\pi/\theta_i$（多少个 token 转一圈） | 它在分辨什么 |
|---|---|---|---|
| **0** | $10000^{0}=1$ | **6.3** | ★ 转得最快，分辨**相邻**的词 |
| 1 | $10000^{-2/128}\approx 0.87$ | 7.2 | |
| 32 | $10000^{-64/128}=0.01$ | 628 | 分辨段落级的距离 |
| **63** | $10000^{-126/128}\approx\mathbf{1.155\times10^{-4}}$ | ⚠️ **54,410** | ★ 转得最慢，在 4K 上下文里**连 1/13 圈都没转完** |

> ⚠️ **最后一格的周期是 54,410 个 token，不是 5.7 万这个量级的随口数**：$2\pi / 1.1548\times10^{-4} = 54{,}410$。**这个数后面会反复用到**——§11.5 的 NTK-aware 和 YaRN，本质上都是在问"哪些维度**转过了一圈**、哪些没有"。

```
    维度对 0-1    ●→●→●→●→●→●→●    高频：区分【相邻】的词
    维度对 2-3    ●─→●─→●─→●
    维度对 4-5    ●──→●──→●
        ⋮
    维度对 126-127 ●─────────→      低频：区分【很远】的词
                                    在整个上下文里可能还没转完一圈
```

> 🔑 **这就像时钟**：秒针（高频）分辨秒，时针（低频）分辨小时。**多个频率叠加，就能唯一地表示一个很大的位置范围。**

```python
def rope(x, pos, base=10000.0):
    d = x.shape[-1]
    i = np.arange(0, d, 2)
    theta = base ** (-i / d)                  # [d/2]
    ang = pos * theta                          # [d/2]
    x0, x1 = x[..., 0::2], x[..., 1::2]        # 偶数位、奇数位配对
    return np.stack([x0*np.cos(ang) - x1*np.sin(ang),
                     x0*np.sin(ang) + x1*np.cos(ang)], -1).reshape(x.shape)
```

### ★★ 最小例子：$d_h = 4$，两个频率，全部手算出来

**上面的公式都成立，但不动手算一遍，"内积只依赖相对位置"这句话是没有重量的。这一节把 $d_h$ 缩到 4，所有数字都列出来，可以拿计算器逐个核对。**

**设定**：

```
    d_h = 4  →  两两配对，只有【2 组】：(0,1) 和 (2,3)
    base = 10000

    θ_0 = 10000^(-2·0/4) = 10000^0    = 1.00      周期 2π/1.00 =   6.28 个 token
    θ_1 = 10000^(-2·1/4) = 10000^-0.5 = 0.01      周期 2π/0.01 = 628.3 个 token
                                    ↑ 一个"快针"，一个"慢针"

    取一个最好算的向量：  q = k = (1, 0, 1, 0)
    （也就是两组里都是"指向东边的单位向量"，角度 0）
```

**第一步：把 $q$ 转到位置 $m = 2$。** 第 0 组转 $m\theta_0 = 2$ 弧度，第 1 组转 $m\theta_1 = 0.02$ 弧度：

| 组 | 旋转角 | 公式 | 转之前 | **转之后** |
|---|---|---|---|---|
| 组 0 = 维度 (0,1) | $2\times1.00=\mathbf{2.00}$ rad | $(\cos\alpha,\ \sin\alpha)$ | $(1,\ 0)$ | $(\cos 2,\ \sin 2)=(\mathbf{-0.41615},\ \mathbf{0.90930})$ |
| 组 1 = 维度 (2,3) | $2\times0.01=\mathbf{0.02}$ rad | 同上 | $(1,\ 0)$ | $(\cos 0.02,\ \sin 0.02)=(\mathbf{0.99980},\ \mathbf{0.02000})$ |

$$\Rightarrow\quad R_2\,q = (-0.41615,\ \ 0.90930,\ \ 0.99980,\ \ 0.02000)$$

**第二步：把 $k$ 转到位置 $n = 5$。** 角度分别是 $5\times1.00=5$ 和 $5\times0.01=0.05$：

| 组 | 旋转角 | 转之后 |
|---|---|---|
| 组 0 | $\mathbf{5.00}$ rad | $(\cos 5,\ \sin 5)=(\mathbf{0.28366},\ \mathbf{-0.95892})$ |
| 组 1 | $\mathbf{0.05}$ rad | $(\cos 0.05,\ \sin 0.05)=(\mathbf{0.99875},\ \mathbf{0.04998})$ |

$$\Rightarrow\quad R_5\,k = (0.28366,\ \ -0.95892,\ \ 0.99875,\ \ 0.04998)$$

**第三步：做内积，逐项列出来。**

| 维度 | $R_2 q$ 的分量 | $R_5 k$ 的分量 | 乘积 |
|---|---|---|---|
| 0 | −0.41615 | 0.28366 | −0.118047 |
| 1 | 0.90930 | −0.95892 | −0.871945 |
| 2 | 0.99980 | 0.99875 | +0.998551 |
| 3 | 0.02000 | 0.04998 | +0.001000 |
| | | **合计** | **0.009558** |

**第四步：★ 见证时刻——换两个位置，只要距离不变，结果一模一样。**

| $m$（query 的位置） | $n$（key 的位置） | $n-m$ | $R_m q$ | $R_n k$ | **内积** |
|---|---|---|---|---|---|
| **2** | **5** | 3 | (−0.41615, 0.90930, 0.99980, 0.02000) | (0.28366, −0.95892, 0.99875, 0.04998) | **0.009558** |
| **100** | **103** | 3 | (0.86232, −0.50637, 0.54030, 0.84147) | (−0.78223, 0.62299, 0.51482, 0.85730) | **0.009558** |
| **0** | **3** | 3 | (1, 0, 1, 0) | (−0.98999, 0.14112, 0.99955, 0.02999) | **0.009558** |

```
    ★★ 三行的每一个分量都完全不同，内积却分毫不差 ★★
```

**第五步：为什么必然相等——不用矩阵，只用一条高中三角公式。**

```
    每一【组】都是一个二维平面里的旋转。两个单位向量的内积 = cos(夹角)：

      组 0 的贡献 = cos(nθ_0) · cos(mθ_0) + sin(nθ_0) · sin(mθ_0)
                  = cos( nθ_0 − mθ_0 )          ← 和差化积，★ 就是这一步
                  = cos( (n−m)·θ_0 )

      组 1 的贡献 = cos( (n−m)·θ_1 )            ← 同理

    ⟹ 总内积 = cos((n−m)·θ_0) + cos((n−m)·θ_1)
             = cos(3 × 1.00) + cos(3 × 0.01)
             = cos(3) + cos(0.03)
             = −0.989992 + 0.999550
             = 0.009558   ✓✓ 和第三步逐项加出来的完全一致

    ★ m 和 n 只以【差】的形式出现，绝对值被 cos 的和差公式【消掉了】
      —— 这就是 §11.3 那个 ⟨R_m q, R_n k⟩ = ⟨q, R_{n−m} k⟩ 的全部内容
```

> ⚠️ **一个必须说清楚的前提：消掉的条件是"$q$ 和 $k$ 用【同一套】$\theta$、每一组只转【自己那两维】"。** 只要这两条中任何一条被破坏，相对性就不成立了——**§11.9 里 DeepSeek-V4 那个"给输出补一次位置为 $-t$ 的 RoPE"，本质上就是在修复第二条被破坏之后的后果。**

> 📌 **顺手记两个对照数字**：不加 RoPE 时这个内积是 $q\cdot k = 1+1 = \mathbf{2}$；距离 3 时是 **0.0096**；距离 0 时是 $\cos 0+\cos 0=\mathbf{2}$。**也就是说 RoPE 把"完全相同的两个向量"的分数，从与距离无关变成了随距离震荡衰减。**

## 11.5 长度外推：4K 训练怎么用到 1M

### 问题

```
    模型在 4K 上训练 → 只见过 n−m ∈ [0, 4096] 的旋转角度
    直接用到 128K   → 出现了从未见过的角度
        ↓
    ★ 注意力分数完全失控，模型输出崩坏
```

**这是一个被反复验证的现象**：不做任何处理，超出训练长度后困惑度会指数爆炸。

**⚠️ 但"没见过的角度"这句话要说准，不然后面两个方法都讲不通。** 用 §11.4 那张周期表逐维度看一遍（$d_h=128$、base = 10000、训练长度 4096）：

| 维度对 $i$ | $\theta_i$ | 训练时最多转过几圈（$4096\,\theta_i/2\pi$） | 外推到 128K 时的处境 |
|---|---|---|---|
| **0** | 1.0 | **651.9 圈** | ✅ 整个圆周被走烂了，再转多少圈都是**老地方** |
| 16 | 0.1 | 65.2 圈 | ✅ 同上 |
| 32 | 0.01 | 6.5 圈 | ✅ 还行 |
| 48 | 0.001 | **0.65 圈** | ⚠️ **连一圈都没转完** |
| **63** | $1.155\times10^{-4}$ | **0.075 圈** | ❌ 只走过圆周的 **7.5%**，外推就是走进**全新的角度** |

```
    ★★ 关键结论：崩的不是"所有维度"，只有【低频那几十个维度】没见过世面 ★★

      高频维度：周期只有几个 token，训练时早就转了几百圈
                → 位置 128000 落在的角度，和某个 4K 内的位置【完全一样】
                → 它根本不知道自己在外推

      低频维度：周期是几万个 token，训练时连半圈都没走完
                → 位置 128000 对应的角度是【真正没见过的】

    ⟹ 这直接决定了后面三种方法的高下：
       谁能【只动低频、不动高频】，谁就赢
```

### 方法一：位置插值（PI, Position Interpolation）

**思路：把位置"压缩"回训练范围内。**

$$m \leftarrow m\cdot\frac{L_{\text{train}}}{L_{\text{target}}}$$

```
    训练 4K，目标 128K，缩放因子 = 1/32

    位置 128000 → 当作位置 4000 来算

    ✅ 所有角度都落回见过的范围，不会崩
    ❌ ★ 相邻 token 的角度差被压缩了 32 倍
       → 高频维度几乎【分辨不出相邻的词】
       → 局部精度严重损失，需要额外微调才能恢复
```

### 方法二：NTK-aware 缩放

> 📖 **NTK = Neural Tangent Kernel（神经正切核）**，是一套分析神经网络训练动力学的理论。**这个名字对理解方法本身几乎没有帮助**——它来自原作者的一个理论类比（高频信息难学、容易被网络当噪声丢掉）。**把它当成一个专有名词记住就行，下面的推导不需要任何 NTK 理论。**

**核心洞察：不该对所有频率一视同仁地压缩。**

```
    ★ 高频维度（区分相邻词）：训练时【见过完整的周期】，不需要压缩
    ★ 低频维度（区分远距离）：训练时【连一圈都没转完】，是它们在外推

    → 只压低频，不压高频
```

**实现上非常简单：不改位置，改 base。**

$$\text{base} \leftarrow \text{base}\times s^{\frac{d_h}{d_h-2}},\qquad s = \frac{L_{\text{target}}}{L_{\text{train}}}$$

**★ 这个指数 $\frac{d_h}{d_h-2}$ 看着莫名其妙，但只要把它代回 $\theta_i$，它在干什么就完全暴露了**：

$$\theta_i^{\text{new}} = \left(\text{base}\cdot s^{\frac{d_h}{d_h-2}}\right)^{-2i/d_h} = \text{base}^{-2i/d_h}\cdot s^{-\frac{2i}{d_h-2}} = \theta_i\cdot \underbrace{s^{-\frac{2i}{d_h-2}}}_{\text{每个维度各自的压缩率}}$$

```
    把两端代进去（d_h = 128，所以指数是 −2i/126）：

      i = 0    （最高频）： s^0      = 1       ★ 【完全不动】
      i = 63   （最低频）： s^(−126/126) = 1/s  ★ 【恰好等于 PI 的压缩量】

    ⟹ ★★ NTK-aware 不是"某种"折中，它是一个【端点被钉死的插值】：
         最高频那一维一点不改，最低频那一维和 PI 一模一样，
         中间的维度按指数平滑过渡
       —— 那个丑陋的 d_h/(d_h−2) 指数，唯一的作用就是把 i=63 这一端
          精确地钉在 1/s 上
```

**逐维度看压缩率**（$d_h=128$，$s=32$，base: 10000 → **338,097**）：

| 维度对 $i$ | $\theta_i$ 被乘上的系数 | 相当于压缩几倍 | 对照：PI 的做法 |
|---|---|---|---|
| **0** | $32^{0}=1.000$ | ★ **1×（不动）** | 32× |
| 16 | $32^{-32/126}=0.415$ | 2.4× | 32× |
| 32 | $32^{-64/126}=0.172$ | 5.8× | 32× |
| 48 | $32^{-96/126}=0.0713$ | 14.0× | 32× |
| **63** | $32^{-126/126}=0.03125$ | ★ **32×** | 32× |

> 🔑 **NTK-aware 的优雅之处：它不需要改任何代码，只需要改一个数字。** 在配置文件里就是 `rope_theta: 10000 → 338097`。

### 方法三：YaRN

> 📖 **YaRN = Yet another RoPE extensioN method**（又一个 RoPE 扩展方法）。**名字是作者的自嘲，不用深究。**

**NTK-aware 已经"高频轻压、低频重压"了，但它的分配方式是【纯指数的】——凭什么？YaRN 的回答是：不该凭指数，该凭"这一维在训练时到底转过几圈"。**

**★ 用 §11.5 开头那张表的口径，把每一维分类**（$d_h=128$、$L_{\text{train}}=4096$，YaRN 论文的默认门槛 $\alpha=1$、$\beta=32$）：

| 段 | 判据（训练时转过的圈数 $r_i = L_{\text{train}}\theta_i/2\pi$） | 落在哪些维度 | 怎么处理 |
|---|---|---|---|
| ① **高频段** | $r_i > \beta = 32$ 圈 | $i \lesssim 21$ | ✅ **完全不动**（它根本没在外推） |
| ③ **中间段** | $1 \le r_i \le 32$ | $21 \lesssim i \lesssim 45$ | **斜坡插值**：按 $r_i$ 在 1 和 32 之间的位置线性混合 ①②两种处理 |
| ② **低频段** | $r_i < \alpha = 1$ 圈 | $i \gtrsim 45$ | ❌ **按 PI 全量插值**（$\theta_i \to \theta_i/s$） |

```
    ⚠️ 注意 ①③② 的顺序：维度编号 i 越大频率越低，
       所以"不动"的是【小 i】那一头，"全压"的是【大 i】那一头

    ★ 和 NTK-aware 的区别就一句话：
      NTK：压缩率按 i 【指数】分配        ← 只看维度编号
      YaRN：压缩率按 r_i 【分段斜坡】分配  ← 看这一维在训练里【实际转了几圈】
            ⟹ 换一个训练长度，分界点就跟着挪，这是 NTK 做不到的
```

**★ 外加第二件 NTK 完全没做的事：注意力温度。**

```
    问题：序列从 4K 拉到 128K，softmax 要在【32 倍多】的 key 上分概率
          → 每个 key 分到的注意力被【摊薄】→ 分布变平 → 模型"注意不集中"

    ✅ YaRN 论文的解法：给注意力 logits 乘一个 1/t，经验式是
           √(1/t) = 0.1 · ln(s) + 1

       s = 32  →  √(1/t) = 0.1 × 3.466 + 1 = 1.35
               →  logits 被放大  1.35² ≈ 1.81 倍
       ★ 放大 logits = 降低 softmax 温度 = 让分布重新变【尖】

    ⚠️ 实现上通常不是真去改 softmax，而是把 cos/sin 查找表整体乘 1.35
       —— q 和 k 各被放大 1.35 倍，内积自然就是 1.81 倍，等价且零开销
```

**YaRN 通常效果最好，但超参最多**（$\alpha$、$\beta$、温度式子的那个 0.1）。

### ★ 三者对比：各自改了公式里的哪一项

**把 RoPE 的分数写成一个式子，三种方法各自只动了其中一处，一目了然**：

$$\text{score} \;=\; \underbrace{\lambda}_{\text{④ 温度}}\cdot\sum_{i=0}^{d_h/2-1}\Big(\cdots\Big)\cos\Big(\underbrace{(n-m)}_{\text{① 位置}}\cdot\underbrace{\gamma_i}_{\text{③ 逐维系数}}\cdot\underbrace{\text{base}^{-2i/d_h}}_{\text{② base}}\Big)$$

| | ① 位置 $(n-m)$ | ② base | ③ 逐维系数 $\gamma_i$ | ④ 温度 $\lambda$ | 高频维度 | 低频维度 | 需要微调 |
|---|---|---|---|---|---|---|---|
| **直接外推** | 不动 | 不动 | 1 | 1 | ✅ 无所谓 | ❌ **崩** | — |
| **PI**（位置插值） | ⭐ **除以 $s$** | 不动 | 1 | 1 | ❌ **一起被压 $s$ 倍**，分辨不出相邻词 | ✅ 压回见过的范围 | **需要**（必须微调才恢复局部精度） |
| **NTK-aware** | 不动 | ⭐ **乘 $s^{\frac{d_h}{d_h-2}}$** | 1 | 1 | ✅ **完全不动** | ✅ 被压 $s$ 倍 | 少量或不需要 |
| **YaRN** | 不动 | 不动 | ⭐ **按 $r_i$ 分三段：$1$ / 斜坡 / $1/s$** | ⭐ $(0.1\ln s+1)^2$ | ✅ 完全不动 | ✅ 被压 $s$ 倍 | 少量 |

```
    ★ 读这张表的正确方式：②③ 其实是【同一件事的两种写法】

      NTK 改 base，等价于给每一维乘上 γ_i = s^(−2i/(d_h−2))  ← 指数曲线
      YaRN 干脆直接给出 γ_i                                   ← 分段折线

    ⟹ YaRN ⊃ NTK ⊃ PI：
       PI 是"所有 γ_i 都等于 1/s"这个最粗暴的特例，
       NTK 把它改成一条指数曲线，
       YaRN 把曲线换成"按实际圈数决定"的折线，再补一个温度。

    ⚠️ 别把 ① 和 ② 同时改 —— 那是双重压缩，等于把 s 算了两遍。
```

## 11.6 ✅ openPangu 的 base 阶梯：实际工程是怎么做的

**真实的做法不是"训完再外推"，而是【边训边逐步拉长，每一档配一个 base】。**

> **openPangu-2.0-Pro 报告给出的完整阶梯**：

| 训练阶段的上下文长度 | RoPE base |
|---|---|
| 4K | **10,000** |
| 8K | **100,000** |
| 32K | **400,000** |
| 128K | **1,600,000** |
| 512K | **6,400,000** |

```
    观察这个数列：

    4K → 8K     长度 ×2      base ×10
    8K → 32K    长度 ×4      base ×4
    32K → 128K  长度 ×4      base ×4
    128K → 512K 长度 ×4      base ×4

    ★ 后三档是【严格的 base ∝ 长度】的线性关系
```

**★ "base ∝ 长度"正好就是 §11.5 那个 NTK-aware 公式**：$s^{\frac{d_h}{d_h-2}}$ 在 $d_h=128$ 时是 $s^{1.016}$，和 $s^1$ 只差 1.6%。**所以这不是另一套办法，就是 NTK-aware，只不过把指数上那点零头省掉了。**

> 🔑 **这就是 NTK-aware 思想的工程落地**：
> ```
> 不做一次性的大跨度外推（那样必崩），
> 而是【分 5 个阶段渐进拉长】，每一阶段：
>     ① 按新长度调大 base
>     ② 在新长度上【继续训练】一段，让模型适应新的角度范围
>         ↓
> ★ 每一步的外推倍数都很小（2~4×），模型有机会真正学会
> ```

> 📌 **注意第一跳 4K→8K 的 base 涨了 10 倍，明显超过长度的 2 倍。** ⚠️ 报告没有解释原因，我推测是为了给后续阶段留出更宽的低频覆盖余量，但这只是猜测。

## 11.7 ✅ Kimi K3 的 NoPE：干脆不要位置编码

> **K3 报告：不使用位置编码（NoPE, No Positional Encoding）。**

### 这怎么可能

**回忆 §11.1：注意力是置换等变的，没有位置编码应该完全无序。**

**但那个论证漏了两件事**：

```
① ★ 因果掩码本身就携带位置信息！
   位置 i 能看到 i 个 token，位置 i+1 能看到 i+1 个
   → 每个位置"能看到多少东西"是不同的
   → ★ 模型可以从"可见集合的大小"反推出自己的绝对位置

   已有理论工作证明：带因果掩码的 Transformer 【可以】学出位置信息

② ★ K3 是 KDA + MLA 【3:1 混合】的（[08 章](08-高效注意力.md)）
   KDA 是【线性注意力】，它是一个 RNN：S_t = f(S_{t−1}, k_t, v_t)
   → ★★ 递归结构【天然有顺序】，位置信息是内建的 ★★
```

> 🔑 **所以 K3 的 NoPE 不是"大胆"，是【它的架构本来就不需要】**：
> ```
> 3/4 的层是 KDA（RNN，自带顺序）
> 1/4 的层是 MLA（靠因果掩码隐式获得位置）
>         ↓
> ★ 位置信息已经从两个渠道进来了，再加 RoPE 是冗余的
> ```

### 白赚的好处

```
✅ 彻底没有长度外推问题 —— 没有 RoPE 就没有"没见过的角度"
   → 这是 K3 敢标 1M 上下文的一个底气
✅ 和 MLA 的矩阵吸收【完全兼容】
   → 回忆 [07 章 §7.5](07-MHA到MLA.md)：RoPE 破坏矩阵吸收，
     必须做 decoupled RoPE 这个补丁
   → ★ NoPE 直接把这个问题消灭了，MLA 的 1/4 层可以完整吸收
✅ 省掉 RoPE 的计算和那 64 维的解耦 KV
```

> 📌 **这是全教程里我最喜欢的一个设计**：**K3 在 [08 章](08-高效注意力.md)选了线性注意力，副作用是在本章白赚了一个"不需要位置编码"。架构决策之间是有耦合的，好的组合会产生额外收益。**

## 11.8 Partial RoPE：只给一部分维度加

**除 K3 外的四家都用 "Partial RoPE"：只对每个头的一部分维度施加 RoPE，其余维度保持不变。**

```
    q  [128 维]
    ├── 前 64 维：加 RoPE      ← 携带位置信息
    └── 后 64 维：不加         ← 纯内容信息，与位置无关
```

**为什么**：

```
① 有些语义匹配【本来就不该依赖位置】
   "这段话在讲数学" 这个判断，和它在第几个 token 无关
   → 强行给所有维度加位置旋转，会污染这类纯语义匹配

② ★ 和 MLA 的兼容性（[07 章 §7.5](07-MHA到MLA.md)）
   不加 RoPE 的部分 → 可以矩阵吸收
   加 RoPE 的部分   → 走 decoupled 通路，单独存
   → openPangu 的 512（压缩，无 RoPE）+ 64（解耦，有 RoPE）就是这个结构

③ 长度外推更容易：只有一部分维度需要处理
```

## 11.9 挂回五家

| | 位置编码 | 关键配置 |
|---|---|---|
| **DeepSeek-V4** | Partial RoPE | ★ 只转**最后 64 维**；⚠️ **和 MLA 无关**（V4 不用 MLA），是配合 CSA/HCA 的压缩 KV，见下方 ⭐ |
| **Kimi K3** | ⭐ **NoPE** | KDA 的递归 + 因果掩码提供位置 |
| **GLM-5.2** | Partial RoPE | — |
| **MiniMax M3** | Partial RoPE | — |
| **openPangu-2.0-Pro** | Partial RoPE | ⭐ **base 五级阶梯**：10K@4K → 100K@8K → 400K@32K → 1.6M@128K → 6.4M@512K |

> ⭐ **DeepSeek-V4 那一格值得单独讲一下，因为它有一个别家没有的动作。**
>
> ⚠️ 先纠正一个很容易犯的错（我自己先前就写错过）：**V4 已经不用 MLA 了**——它的报告全文没有出现过 "MLA"，注意力是 **CSA + HCA**，内核是**共享 KV 的 MQA**（见 [08 章](08-高效注意力.md)）。所以 V4 的 partial RoPE **不是**"配合 MLA 的 decoupled 结构"，它解决的是**另一个**问题。
>
> ```
> ✅ 报告原文（§2.3 Partial Rotary Positional Embedding）：
>    "for each query vector and KV entry vector used in CSA and HCA,
>     we apply RoPE to its last 64 dimensions"
>    → 只有最后 64 维被旋转，其余维度不带位置信息
>
> ★★ 真正特别的是下面这一步 —— 先看问题出在哪：
>
>    CSA / HCA 把每 ℓ 个 token 的 KV 压成【一条】KV entry，
>    而这一条 entry ★【同时充当 key 和 value】（共享 KV 的 MQA）。
>
>    key   那一路：q 和 k 做内积 → RoPE 的相对性成立 ✅
>    value 那一路：⚠️ 输出 o_t = Σ(权重 × KV entry)，是一堆
>                  【已经带了绝对位置旋转】的向量加权求和
>                  → ★ 于是输出里混进了【绝对位置】，而不是相对位置
>
>    ✅ 报告原话：the naive core attention outputs "will carry absolute
>       position embeddings, derived from the weighted sum of KV entries"
>
> ✅ V4 的解法：给【输出】再补一次【位置为 −t 的】RoPE，转回去
>    （t = 当前 query 的位置；⚠️ 提取版 PDF 里下标字符有乱码，
>      但 "apply RoPE with position −t on the last 64 dimensions of each o"
>      这句话本身是清楚的）
>
>    效果（报告原文）：输出也变成【相对】位置编码 ——
>    "the contribution of each KV entry to the core attention outputs
>     will also be related to the distance between the query and the KV entry"
> ```
>
> 🔑 **一句话理解**：`R_{−t}` 把 `R_位置` 抵消成 `R_位置−t`，也就是**距离**。
> 这和 §11.3 那个核心性质 $\langle R_m q, R_n k\rangle = \langle q, R_{n-m}k\rangle$ 是**同一个群性质**（$R_a R_b = R_{a+b}$），只不过 V4 把它从 **key 那一路**搬到了 **value 那一路**上用。
>
> ★ **为什么只有 V4 需要这一步**：因为只有它让**同一条压缩 entry 同时当 key 和 value**。别家的 value 是不带 RoPE 的，自然没有这个问题。

> 🔑 **这一格的分歧其实是【上一章分歧的下游后果】**：
> ```
> 谁用了线性注意力（K3）→ 谁就可以不用位置编码
> 谁用纯 softmax 注意力  → 谁就必须处理 RoPE + 长度外推
> ```
> **这再次说明：架构决策不是独立的旋钮，是一张互相约束的网。**

## 11.10 本章小结

```
① 注意力是【置换等变】的，不注入位置就分不清"小明打小红"和"小红打小明"
   （RNN/CNN 天然有位置，只有注意力没有 —— 这是它"任意两点一步可达"的代价）
② RoPE = 把 q、k 按位置【旋转】一个角度，不改长度只改方向
   ★ 核心性质：⟨R_m q, R_n k⟩ = ⟨q, R_{n−m}k⟩ —— 内积只依赖相对距离
     证明只需要旋转矩阵的群性质 R_mᵀ = R_{−m}、R_a R_b = R_{a+b}
   ✅ d=4 的手算例子（§11.4）：q=k=(1,0,1,0)，θ=(1, 0.01)
      (m,n) = (2,5) / (100,103) / (0,3) 三组向量分量【全不一样】，
      内积却都是 0.009558 = cos(3×1) + cos(3×0.01)
      本质只是和差化积：cos(nθ)cos(mθ)+sin(nθ)sin(mθ) = cos((n−m)θ)
      ★ m、n 只以【差】的形式出现，绝对值被消掉了
   → 形式绝对（好实现、兼容 FlashAttention），效果相对（泛化好）
③ 高维用多个频率 θ_i = base^{−2i/d_h}：高频分辨相邻，低频分辨远距离（像时钟）
   ⚠️ d_h=128 时最低频 θ_63 ≈ 1.155e−4，周期【54,410】个 token
④ ★ 外推为什么会崩，要说准：崩的只有【低频那几十维】
   4K 训练时，i=0 转了 651.9 圈（早就转烂了），i=63 只转了 0.075 圈
   ⟹ 高频维度根本不知道自己在外推，低频维度才是真的没见过
⑤ 长度外推三法 —— 各自改了公式里的哪一项：
   PI        ① 改位置 m ← m/s，所有维度一刀切 → 高频精度受损，必须微调
   NTK-aware ② 只改 base ← base·s^(d_h/(d_h−2))
             ★ 代回去看：等价于 θ_i ← θ_i·s^(−2i/(d_h−2))，
               i=0 系数恰为 1（不动）、i=d_h/2−1 系数恰为 1/s（等于 PI）
               那个丑指数的唯一作用就是把两端钉死 → 一个数字就搞定
   YaRN      ③ 直接给出逐维系数 γ_i，按"训练时转过几圈 r_i"分三段
               （r_i>32 不动 / r_i<1 全压 / 中间斜坡；d_h=128、4K 时
                分界点在 i≈21 和 i≈45）
             ④ 外加注意力温度：logits × (0.1·ln s + 1)²，s=32 时 ≈1.81
   ⟹ YaRN ⊃ NTK ⊃ PI，②③ 是同一件事的两种写法（指数曲线 vs 分段折线）
⑥ openPangu 的 base 五级阶梯就是 NTK-aware 的工程落地：
   分 5 段渐进拉长，每段外推倍数只有 2~4×，每段都继续训练适应
   ✅ 后三档 base ∝ 长度，正是 s^(d_h/(d_h−2)) = s^1.016 ≈ s
⑦ ★ K3 的 NoPE 不是冒险：
   因果掩码本身携带位置 + KDA 是 RNN 自带顺序
   → 白赚：没有外推问题 + 和 MLA 矩阵吸收完全兼容
⑧ Partial RoPE（其余四家）：只给一部分维度加，剩下的走矩阵吸收通路
   openPangu 的 512 + 64 就是这个结构
⑨ ⚠️ V4 的 partial RoPE 和 MLA 无关（V4 不用 MLA，用 CSA + HCA）：
   它的压缩 KV entry 同时当 key 和 value，value 那一路会把【绝对】位置
   带进输出 → 解法是给输出补一次位置为 −t 的 RoPE 转回去（§11.9）
```

**第三部分到此结束。** 到这里，一个完整的模型你已经全部看过了。**接下来三章讲的是"怎么让它跑得快、训得动"**——这是这一代技术报告里篇幅最大、也最工程的部分。
