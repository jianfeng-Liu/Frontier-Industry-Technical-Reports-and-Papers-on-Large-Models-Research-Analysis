⚠️ 先说清楚三件事

① 这份教程不预设你懂任何模型架构知识。

注意力、KV cache、MLA、MoE、RoPE、残差、归一化、量化——这些词你一个都不用提前知道。教程从"什么叫把一个词变成向量"开始讲起，每个名词第一次出现时都会先解释再使用。

② 对你的唯一要求：会写代码，看得懂循环、数组、矩阵乘法、softmax 这种函数、以及"用梯度下降调参数"这件事大概在干什么。只要这些就够了。

③ 怎么读：

第一遍  →  只看每章的【类比】【ASCII 图】【加粗句】，公式全部跳过
           目标：把整栋楼的样子看清楚

第二遍  →  回头看公式和伪代码
           目标：搞清每块砖的成分

第三遍  →  读每章末尾的「挂回五家」，然后去看真正的技术报告

第一遍看不懂公式是完全正常的，不影响你读懂后面的章节。 每章的结构都是固定的：

直觉类比  →  ASCII 图  →  数学公式  →  numpy 伪代码  →  挂回五家改了哪

📐 全教程通用的记号约定

B    = batch size（一次并行处理几条序列）
L    = sequence length（序列有多少个 token）    ← "长上下文"说的就是这个 L
d    = hidden dim / d_model（每个 token 的向量宽度，五家是 5120~7168）
H    = 注意力头数
d_h  = 每个头的维度，通常 d = H × d_h
d_ff = FFN 的中间维度
V    = 词表大小（vocabulary size，五家都是 15 万左右）
N    = 层数（五家是 50~93）

张量形状统一写成 [B, L, d] 这种方括号形式
向量默认是行向量，所以线性层写成 x @ W 而不是 W @ x
