A. 形状与记号

┌─ 形状 ─────────────────────────────────────────────────────┐
│ x            [B, L, d]        残差流（"总线"）              │
│ Q, K, V      [B, H, L, d_h]   注意力的三个角色              │
│ scores       [B, H, L, L]     ★ O(L²) 就在这里             │
│ KV cache     [B, L, H_kv, d_h] × 2 × 层数                  │
│ logits       [B, L, V]        每个位置对词表的打分          │
└────────────────────────────────────────────────────────────┘

B = batch    L = 序列长度    d = hidden 维    H = 头数
d_h = 每头维度   d_ff = FFN 中间维   V = 词表大小   N = 层数

约定：本教程用【行向量】，即 x @ W（x 在左）

B. 核心公式

┌─ 前向 ─────────────────────────────────────────────────────┐
│ RMSNorm(x)   = x / √(mean(x²)+ε) ⊙ g                       │
│ Attention    = softmax(QKᵀ/√d_h + M) V                     │
│ RoPE         θ_i = base^(−2i/d_h)，位置 m 转 m·θ_i          │
│   核心性质    ⟨R_m q, R_n k⟩ = ⟨q, R_{n−m} k⟩  只依赖相对距离 │
│   ★ V4 变体  KV entry 兼作 value，输出会带【绝对】位置       │
│               给输出再补一次位置 −t 的 RoPE 转回相对 [11.9]  │
│ SwiGLU(x)    = W_d( SiLU(W_g x) ⊙ W_u x )                  │
│   SiLU(x)    = x·σ(x)                                      │
│   d_ff       = 8d/3（GLU 三个矩阵 → 乘 2/3 才公平）          │
│ MoE(x)       = Σ_{i∈TopK} (s_i/Σs) · E_i(x)                │
│ 残差         x_{l+1} = x_l + F_l(x_l)                       │
│   mHC        x_{l+1} = B_l x_l + C_l F_l(A_l x_l)，B 双随机  │
│   AttnRes    x_l = Σ_{i<l} α_{i→l} · f_i(x_i)   ★【替换】累加│
│     源 k_i=v_i= f_i(x_i)【增量】，i=0 是 embedding；无 W_K/W_V│
│     α_{i→l}  = softmax_i( w_lᵀ · RMSNorm(k_i) )  无 1/√d     │
│     标准残差 = α ≡ 1 的特例；Σα=1 → √N 增长消失              │
│     K3 Block 版：93 层→8 块×12 层，块【内】求和、块【间】注意力│
└────────────────────────────────────────────────────────────┘

┌─ MLA ──────────────────────────────────────────────────────┐
│ 只缓存 c^KV = x W_DKV（低维），用时再升维                    │
│ 矩阵吸收     qᵀk = c^Q ᵀ(W^UQ ᵀ W^UK) c^KV                  │
│ ⚠️ RoPE 会插在两个矩阵中间 → 吸收失效 → decoupled RoPE       │
│ openPangu：512（压缩，无 RoPE）+ 64（解耦，有 RoPE）= 576    │
└────────────────────────────────────────────────────────────┘

┌─ 线性注意力 ────────────────────────────────────────────────┐
│ ★★ 全部来自结合律：(QKᵀ)V → Q(KᵀV)                          │
│    2L²d  →  2Ld²    省 L/d 倍（L=1M, d=128 → 8192×）        │
│    ↑ 中间那个 [d,d] 就是"全部历史"被压成的唯一容器           │
│ 前提   exp(qᵀk) 不可分解 → 换成 φ(q)ᵀφ(k) 才能挪括号         │
│ 因果掩码 → 上界随 i 变 → 滚动累加 → ★ 这就是 RNN 递推        │
│ S_t = S_{t−1} + φ(k_t) v_tᵀ,      o_t = φ(q_t)ᵀ S_t         │
│   φ(k)v ᵀ 是【外积】[d_k,d_v]；S 的形状里【没有 L】          │
│ delta rule  S_t = (I − β_t k_t k_tᵀ)·Diag(α_t)·S_{t−1}      │
│                   + β_t k_t v_tᵀ                            │
│   来历：对 ½‖Sᵀk_t − v_t‖² 走一步梯度下降（Widrow–Hoff）     │
│   α_t ∈ (0,1)^{d_k} 【逐通道】遗忘门 ← Kimi 的核心贡献       │
│   β_t ∈ (0,1) 是【标量】写入强度；‖k‖=1 时 β=1 即精确覆盖    │
│ ★ 状态大小恒定，与 L 无关 —— 但召回能力受限于状态容量        │
│   1M 上下文单头：KV cache 512 MB  vs  状态 32 KB（16384×）   │
└────────────────────────────────────────────────────────────┘

┌─ 训练 ─────────────────────────────────────────────────────┐
│ 训练目标      L = −(1/L) Σ log P(x_{t+1} | x_≤t)            │
│ AdamW        θ ← θ − η( m̂/(√v̂+ε) + λθ )   ★ λθ 不过 √v      │
│ Muon         G = UΣVᵀ → 用 UVᵀ 更新                        │
│   真正含义    谱范数球上的最速下降（不是"拉平奇异值"这个技巧）│
│   Newton-Schulz  X ← aX + b(XXᵀ)X + c(XXᵀ)²X               │
│                  (a,b,c) = (3.4445, −4.7750, 2.0315)       │
│   用/不用     矩阵形参数 ✅ ／ embedding、LM head、norm ❌   │
│   ★ 正交化谁  对象应是【逻辑上的一个线性映射】，不是显存里连续 │
│               的一块。融合张量要先切开：                     │
│               W_qkv → 按 Q/K/V、再按 head（GLM 的 Muon Split）│
│               W_gate_up → chunk(2) 各自正交化 ⚠️ 五家未披露    │
│               见 [13.7](13-优化器与Muon.md)                  │
│ MoE 均衡      b_i ← b_i − γ(F_i − Q_i)/RMS(F−Q)  积分控制器  │
└────────────────────────────────────────────────────────────┘

┌─ 投机解码 / MTP ────────────────────────────────────────────┐
│ 接受概率      min(1, p(x)/q(x))                             │
│ 残差分布      p' = max(0, p−q) / β                          │
│ 单步接受率    α = Σ_x min(p(x), q(x)) = 1 − TV(p, q)         │
│ 接受长度      E = (1 − α^(γ+1)) / (1 − α)                   │
│ 加速比        ≈ E / (1 + γc)     c = 草稿/主模型单步耗时比    │
│ MTP 模块      h'^k = M_k[RMSNorm(h^{k−1}); RMSNorm(Emb(t_{i+k}))] │
│ MTP 损失      L = L_main + (λ/D)·Σ_k L^k_MTP,  λ ≈ 0.1~0.3  │
│ ★ 输出分布严格等于不用投机解码时 —— 纯加速，不是近似          │
└────────────────────────────────────────────────────────────┘

┌─ 量化 ─────────────────────────────────────────────────────┐
│ 对称量化      s = max|x| / (2^(b−1) − 1),  x_q = round(x/s)  │
│ 误差方差      Var[ε] = s²/12                                │
│ ★★ 铁律      scale 必须在【求和维】上是常数，否则提不出求和号 │
│ MXFP4        32 个 FP4 共享一个 E8M0 scale → 4 + 8/32 = 4.25 位│
│ SmoothQuant   XW = (X·diag(s)⁻¹)(diag(s)·W)   结果不变       │
│               s_j = max|X_j|^α / max|W_j|^(1−α),  α≈0.5      │
│ 旋转量化      XW = (XQ)(Qᵀ W)，Q 正交         结果不变       │
│ QAT 的 STE    forward=xq, backward=1  写作 x + sg(xq − x)    │
│ 记号          W8A8 / W4A16 / W4A8 / KV8                     │
└────────────────────────────────────────────────────────────┘

C. 关键的量级感

┌─ 显存与带宽 ───────────────────────────────────────────────┐
│ H100：显存 80 GB，带宽 3.35 TB/s，ridge point ≈ 295 FLOP/字节│
│ 505B 权重：BF16 1010 GB / INT8 505 GB / FP4 253 GB          │
│ KV cache（GQA-8, 60 层, 1M, BF16）      ≈ 240 GB            │
│ KV cache（MLA-576, 50 层, 512K, BF16）  ≈  28 GB            │
│ MHA 500B 模型：约 1 MB / token                              │
└────────────────────────────────────────────────────────────┘

┌─ 计算 ─────────────────────────────────────────────────────┐
│ 单层 FLOPs（每 token）≈ 8d² + 6d·d_ff + 4Ld                 │
│   L=4K   时 4Ld 项占 ~12%                                  │
│   L=1M   时 4Ld 项占 ~97%   ← ★ 长上下文的全部麻烦在这一项   │
│ 长度 128K → 1M：长度 ×8，但 L² 项 ×64                       │
│ 参数量经验：MoE ≈ √(总参数 × 激活参数) 量级的稠密模型 ⚠️粗糙  │
└────────────────────────────────────────────────────────────┘

┌─ 两个阶段 ─────────────────────────────────────────────────┐
│ prefill：一次处理 L 个 token   → compute-bound  → 决定 TTFT │
│ decode ：一次处理 1 个 token   → memory-bound   → 决定 TPOT │
│   TTFT = Time To First Token   首字延迟，按回车到第一个字(s)│
│   TPOT = Time Per Output Token 每字延迟，之后每个字的间隔(ms)│
│          = 你看到的「打字速度」，10 ms → 每秒 100 字         │
│   TPS  = Tokens Per Second     吞吐量，一块卡每秒总产出      │
│          ★ TPS ≈ batch ÷ TPOT，两者互相打架（延迟↔吞吐取舍）│
│   ISL / OSL = 输入 / 输出序列长度（"8K+1K" = ISL 8K, OSL 1K）│
│   ★ decode 的算术强度 ≈ batch size                         │
│   ★★ 所以：省 KV cache 的字节数 ≈ 直接提吞吐                │
└────────────────────────────────────────────────────────────┘

D. ★ 三条因果链（全书骨架）

① softmax 每行和必须为 1
     → 模型自造巨大激活当泄压阀（attention sink）
     → 这些巨大激活就是离群值
     → 量化 scale 被绑架
     → ★ 低比特量化困难
   ⟹ 解释了：显式 sink 机制的兴起、稀疏化必须打 sink 补丁、4-bit 为何难

② 想要 4-bit → PTQ 不够 → 必须 QAT
     → QAT 下激活离群值会失稳 → 必须治离群值
     → SwiGLU 无界相乘是主要产地 → ★ 必须给激活加界
   反向：停在 8-bit → 容忍度高 16 倍 → 没有加界的动力
   ⟹ 解释了：V4 clamp / K3 SiTU-GLU / M3 clamp，以及 openPangu 那个空格

③ decode 访存受限（算术强度 ≈ batch size ≪ 295）
     → ① 省 KV cache ≈ 直接提速   ⟹ 解释了五家在注意力上的全部投入
     → ② 有免费算力可以拿来"猜"  ⟹ 解释了 MTP / 投机解码

G4. ★ 推理性能指标（报告"部署"一节几乎只报这几个）

缩写 全称 中文 一句话
TTFT Time To First Token 首字延迟 按下回车 → 看见第一个字，等了多久（秒）。由 Prefill 决定
TPOT Time Per Output Token 每字延迟 之后每多蹦一个字的间隔（毫秒）。由 Decode 决定。★ 就是你看到的"打字速度"，10 ms ≈ 每秒 100 字
ITL Inter-Token Latency 词间延迟 和 TPOT 是同一个东西，不同论文的不同叫法
TPS Tokens Per Second 吞吐量 一块卡每秒总共吐多少 token
ISL / OSL Input / Output Sequence Length 输入/输出长度 表头的 "8K+1K" = 输入 8192、输出 1024 
★★ TPOT 和 TPS 最容易混，务必分清：

   TPOT  「我这一个用户要等多久」   延迟   越小越好
   TPS   「这块卡一共干了多少活」   产能   越大越好

   两者的关系：  TPS ≈ batch ÷ TPOT
   ⚠️ 而且它们互相打架：batch 开大 → TPS 涨，但每个人的 TPOT 变差

   openPangu 实测就是一对活例子（同一个模型的两个取舍点）：
       超低延迟档： TPOT  9.53 ms                      ← 延迟优先
       高吞吐档：   TPOT 23.2 ms，batch 40，1727 TPS   ← 吞吐优先

   一次完整对话的耗时 ≈ TTFT + TPOT × 输出字数
