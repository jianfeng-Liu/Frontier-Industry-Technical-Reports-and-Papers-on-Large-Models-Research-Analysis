# 05 数据与评测：这个领域最脏的活

> 前四章讲的是「怎么做模型」。这一章讲一个更基础、也更容易被跳过的问题：
> **你怎么知道一个具身模型是好是坏？**
> ⟹ 剧透：**这个领域目前还没有 MMLU 那样公认的尺子。** 这件事的影响比想象中大得多。

---

## 5.0 ★ 先感受一下问题有多严重

```
    大语言模型：  「我在 MMLU 上 88.2 分」
                  ⟹ 你我他都能跑同一套题，分数直接可比。

    具身智能：    「我在真机上抓取成功率 78%」
                  ⟹ 哪台机器人？哪个桌子？什么光照？
                     物体是新的还是磨损的？摆在桌子哪个位置？
                     试了 20 次还是 200 次？失败了算不算重试？

    ★★ 结论：论文之间的真机数字，几乎【无法互相比较】。
       这不是研究者不严谨，是【真机实验本质上不可复现】。
```

> ⚠️ **我的判断**：这件事的后果是——**这个领域的进步速度很难被准确度量**。你看到的「成功率从 60% 到 85%」，可能一半来自模型，一半来自把桌子擦干净了。

---

## 5.1 数据侧：几个必须知道的名字

### ★★ Open X-Embodiment（也叫 RT-X）

```
    做了什么：把学术界几十个机器人数据集【合并成一个】
              🔎 覆盖 20 多种不同的机器人本体、约 100 万条轨迹

    ★★ 它证明的事比数据本身更重要：
        用【别的机器人】的数据一起训，
        能让【你这台机器人】变强。

    ⟹ 这就是具身智能版的「预训练假设」成立的第一个证据。
       在这之前，大家默认「换个机器人数据就没用了」。
```

> 📖 **本体（embodiment）**：机器人的物理形态——几个关节、多长的胳膊、什么夹爪。**跨本体（cross-embodiment）** 就是「换个身体还能用」。

### 其它几类数据来源

| 类型 | 代表 | 特点 | 致命缺陷 |
|---|---|---|---|
| **学术合并数据集** | Open X-Embodiment | 本体多样性最好 | 每种本体的数据都不多，场景单调（实验室桌面） |
| **大规模真机采集** | DROID、🔎 AgiBot World（智元） | 场景多样、动作标签精确 | ★ **贵**——靠人一条条遥操作 |
| **手持装置采集** | UMI | 便宜、能进真实厨房超市 | 没有机器人本体信息，力反馈缺失 |
| **人类第一视角视频** | Ego4D、EPIC-KITCHENS 类 | **量级碾压，几十万小时** | ★★ **没有动作标签**（见 §1.5 的潜动作解法） |
| **仿真生成** | RoboCasa 等 | 无限量、免费、标注完美 | 视觉和物理都和真实有差距 |
| **世界模型生成** | Cosmos、GigaWorld | 视觉真实、能造长尾 | ⚠️ 物理不保证正确（第 02 章） |

### ⚠️ 一个容易被忽略的坐标系

```
    评价一个具身数据集，其实要看三个独立的维度：

        ① 本体多样性 —— 有几种机器人？
        ② 场景多样性 —— 几个房间？几种光照？
        ③ 任务多样性 —— 几种动作技能？

    ★ 现实是：几乎所有数据集都只在【一个】维度上丰富。
      Open X-Embodiment 强在①，DROID 强在②，
      但没有任何一个数据集在三个维度上同时够用。

    ⟹ 这就是为什么「具身智能的 ImageNet 时刻还没到」。
```

## 5.2 策略评测：三层，各有各的问题

```
    ┌─ 第一层：纯仿真基准 ──────────────────────────┐
    │  LIBERO      —— 测「学了新任务会不会忘掉旧的」   │
    │  CALVIN      —— 测「听一长串指令能不能连续做完」 │
    │  Meta-World  —— 一批标准化的机械臂任务           │
    │  RoboCasa    —— 厨房场景，任务更接近真实家务     │
    │  🔎 RoboTwin —— 国内的双臂协作基准               │
    │  ✅ 优点：完全可复现，谁跑都一样                 │
    │  ⚠️ 缺点：仿真里 90 分，真机上可能 30 分         │
    └───────────────────────────────────────────────┘
                        ↓
    ┌─ 第二层：真机场景的仿真复刻 ───────────────────┐
    │  SimplerEnv —— 把真机实验场景在仿真里【照着搭】  │
    │  ★ 目标：让仿真分数和真机分数【排序一致】        │
    │     （不追求数值相同，只要好坏顺序对就行）       │
    │  ⟹ 这是个很务实的折中，值得记住                 │
    └───────────────────────────────────────────────┘
                        ↓
    ┌─ 第三层：真机 ────────────────────────────────┐
    │  ✅ 唯一真正算数的                              │
    │  ⚠️ 但不可复现、极慢、极贵                      │
    └───────────────────────────────────────────────┘
```

> 🔑 **记住第二层的思路**：当「绝对分数」注定不可信时，退而求其次去保证**排序可信**。⟹ 这个思路在第 5.3 节的世界模型评测里还会再出现一次。

## 5.3 世界模型评测：比上面还乱

一个世界模型好不好，其实要分开测**四件不同的事**：

```
    ① 画得像不像？   —— 视觉质量
       常用 FVD / FID 之类的分数
       ⚠️ 致命问题：这类指标只回答「像不像视频」，
          和「物理对不对」【完全无关】。
          一个把杯子穿过桌子的视频，可以拿到很高的画质分。

    ② 听不听动作？   —— 可控性 / 动作一致性
       我输入「向左推」，画面里手臂真的向左动了吗？动了多少？
       ★★ 这一项才是【世界模型区别于视频生成模型】的地方（见 §2.1）。

    ③ 物理对不对？   —— 物理合理性
       典型测法：给模型一段视频的前半截，让它续写，
       看它是否违反重力、守恒、刚体不可穿透等常识。
       🔎 这类研究（Physics-IQ / VideoPhy 一类工作）的结论高度一致：
          【生成模型的物理理解，远低于人类，甚至低于小孩】。

    ④ 滚久了还稳吗？ —— 长程一致性
       走出房间再走回来，桌子还在原位吗？杯子还是那个杯子吗？
       ★ 这一项直接决定了世界模型能不能当【训练环境】用：
         如果滚 50 步就崩，那就只能生成短视频当数据，
         没法在里面做强化学习（§3.2）。
```

> ⚠️ **我的判断——为什么世界模型的评测特别难**：
> 世界模型的**真正价值是「下游有没有用」**（训出来的策略更强吗？），
> 但下游评测又贵又不可复现（见 §5.2 第三层）。
> ⟹ 于是大家只好退回去测上面这四个**代理指标**，
> 而**代理指标高 ≠ 下游有用**——这是当前整个方向最大的方法论漏洞。

## 5.4 ⚠️ 泼冷水：基准过拟合

```
    ⚠️ 只要一个基准变成了「必刷榜」，它就开始失效。

    具身智能这边尤其危险，因为：
      ① 基准数量少 ⟹ 大家挤在同几个上刷
      ② 仿真基准的场景是固定的几十个 ⟹ 容易被记住
      ③ 真机评测无法复现 ⟹ 没人能验证你的真机数字

    ★ 一个实用的读论文姿势：
      看到真机成功率时，先找三件事：
        ▸ 试了多少次？（少于 20 次的数字，误差极大）
        ▸ 物体/位置是不是训练时见过的？
        ▸ 有没有和【同一台机器人上的】基线对比？
      三条都答不上来的，这个数字基本只能当 demo 看。
```

---

## 🔑 本章一句话

> **具身智能目前最缺的不是模型，是尺子。**
> 数据侧的关键突破是 Open X-Embodiment 证明了「**别的机器人的数据也有用**」；
> 评测侧的现状是——**仿真可复现但不算数，真机算数但不可复现**，中间层（SimplerEnv 这类）在试图用「排序一致」来救场。
> ⚠️ 而世界模型的评测更糟：**我们只会测代理指标，不会测它到底有没有用。**
