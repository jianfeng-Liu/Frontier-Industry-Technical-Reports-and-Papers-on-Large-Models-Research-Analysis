# 08 自动驾驶：世界模型真正跑通的地方

> 如果你想看「世界模型到底有没有用」的**已经落地的证据**，不要看机器人，看自动驾驶。
> 这个方向比人形机器人早了好几年，而且**已经进了量产公司的训练流水线**。
> 这一章讲：**为什么是它先跑通，以及这份成功能不能外推到机器人。**

---

## 8.1 ★★ 为什么自动驾驶比机器人先跑通？四个结构性优势

```
    ① 动作空间极低维
       自驾：方向盘转角 + 油门 + 刹车 ≈ 2~3 个数
       机器人：单臂 7 个关节，双臂 + 灵巧手能到 50 个数
       ⟹ 维度低意味着【动作条件】这件事容易学得多

    ②★★ 数据自带动作标签，而且免费
       车队每天在路上跑，方向盘转角本身【就是动作标签】，
       行车记录仪画面【就是观测】。
       ⟹ 天然的 (观测, 动作, 下一帧) 三元组，几百万小时，零采集成本。

       对比机器人：§1.5 讲过，动作标签要靠人一条条遥操作【摇出来】。
       ★★ 这一条是两个领域进度差距的【最主要原因】。

    ③ 长尾问题致命，且真实路测极贵
       「路口突然窜出一个孩子」这种场景，你不可能真的去制造。
       ⟹ 生成这类场景的商业价值【立刻就能算清楚】。

    ④ 场景结构性强
       路是平的、有车道线、参与者都是车和人、大家守规则。
       ⟹ 比「随便一个厨房长什么样」好建模得多。

    ★ 反过来看这四条，就是机器人为什么难：
      动作维度高、标签要花钱买、长尾场景说不清、环境毫无结构。
```

## 8.3 ★★ 自驾用世界模型，主要用两件事

回顾 §3.6 的五种用法，自驾**几乎只用①和⑤**——但把这两件做到了极致。

### 用法① 数据引擎（和机器人一样）

```
    生成罕见但致命的场景：
      ▸ 前车突然掉落货物
      ▸ 逆行车辆
      ▸ 暴雨夜间的施工路段
    ⟹ 这些场景在真实数据里可能几百万公里才出现一次。
```

### ★★ 用法⑤ 闭环评测——这才是自驾的杀手锏

```
    先讲清一个概念：

    📖 【日志回放 log replay】：
       把之前录的真实驾驶视频重放一遍，看模型会做什么决策。

    ⚠️ 日志回放的致命缺陷：
       模型说「我要向左打方向」，
       但录像里的画面【不会因此改变】——
       因为录像是死的，它不知道你打了方向。
       ⟹ 于是你只能评价【一步】，评价不了【一整段驾驶】。

    ★★ 世界模型解决的正是这个：
       模型说「向左打方向」⟹ 世界模型生成向左之后的画面
       ⟹ 模型基于新画面继续决策 ⟹ 一路滚下去
       ⟹ 你终于能评价【完整的一段驾驶】了。

       📖 这叫【闭环评测 closed-loop evaluation】，
          与之相对的日志回放叫【开环评测 open-loop】。

    ⟹ ★ 更进一步，它还能回答【反事实】问题：
       📖 反事实 counterfactual：「如果当时我做了另一个选择，会怎样？」
       这是事故复盘最想要、而日志回放【原理上给不了】的东西。
```

> 🔑 **这一段值得对照第 03 章重读**：机器人那边，世界模型的第⑤种用法（评测考场）我标为「最被低估」；而在自驾这边，**它已经是主力用法**。⟹ 差别不在技术，在于**自驾的评测痛点更尖锐、也更值钱**。

## 8.4 端到端 + 世界模型的组合

```
    自驾这几年的主线是【端到端】：
      画面 ⟹（一个大模型）⟹ 方向盘和油门
      —— 结构上和机器人的 VLA 几乎一样。

    ★ 世界模型在其中的位置有两种：
      ▸ 训练期：造数据 + 闭环评测（§8.3）
      ▸ 推理期：当【前瞻模块】，预测「我这么开，三秒后场景什么样」
        ⟹ 对应 §3.3，但自驾的实时预算比机器人还紧，
           所以推理期用法目前主要停留在研究阶段。
```

## 8.5 ⚠️ 泼冷水：这份成功能外推吗？

```
    ⚠️ 冷水一：安全认证不认「在生成的世界里测过了」。
       监管机构要的是真实路测里程和可追溯的证据链。
       ⟹ 世界模型能加速研发，但【替代不了合规环节】。

    ⚠️ 冷水二：自驾的成功高度依赖 §8.1 那四个结构性优势，
       而机器人【一条都不占】。
       ⟹ 所以不要因为「自驾跑通了」就推断「机器人也快了」。
          真正可以外推的，是【方法论】而不是【时间表】：
          ▸ 闭环评测比开环评测有用 —— 这条能外推
          ▸ 数据引擎是最先见效的用法 —— 这条能外推
          ▸ 「三年内可用」—— 这条不能外推

    ⚠️ 冷水三：驾驶世界模型的物理同样不保证正确。
       它学的是「路上通常会发生什么」，
       而不是「刹车距离该是多少米」。
       ⟹ 它擅长生成【看起来合理的交通流】，
          不擅长精确的动力学。
```

## 🔑 本章一句话

> 自驾之所以先跑通，是**结构性红利**：动作只有两三维、**数据自带动作标签且免费**、长尾场景值钱、环境有规则。
> ★★ 它最有价值的用法不是造数据，而是**闭环评测和反事实推演**——这是日志回放**原理上做不到**的事。
> ⚠️ 但这份成功**不能简单外推到机器人**：可以外推的是方法论，不是时间表。
