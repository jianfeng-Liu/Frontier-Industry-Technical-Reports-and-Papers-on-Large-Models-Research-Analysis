# 10 遥控、遥操作，还是自主？——看懂 demo 的正确姿势

> ★★ 这一章解决一个非常实际的困惑：
> **网上那些机器人视频，到底有多少是机器人自己干的？**
> 这个问题之所以难回答，是因为「遥」这个字被用来指**四种程度差很远的东西**。
> 先把这四种拆开，后面所有判断都会变得清楚。

---

**本章关键词**（每个词在正文第一次出现时还会再解释一遍）

**遥控**（remote control）—— 人给「去哪、多快」，怎么走是机器人自己算的。
**遥操作**（teleoperation）—— 人给「怎么动」，机器人的关节 1:1 跟着人动。
**预设播放**（motion playback）—— 提前编好一段轨迹，按时间轴回放。
**自主**（autonomous）—— 模型自己看、自己决策、自己出动作。
**主从臂**（leader-follower arm）—— 人手里握一条小一号的「主臂」，机器人的「从臂」跟着动，是目前最常见的遥操作采数据设备。
**动作分块**（action chunking）—— 策略一次输出一「块」动作再整体执行，块与块之间会有停顿。**这个词在本章很重要**：它会让自主策略看起来像有延迟的遥操作。
**影子模式**（shadow mode）—— 模型在后台跟着跑但不接管，只记录自己和人的决策差异。⚠️ 这个词常被借去指别的东西，§10.2 会说清楚。
**远程接管**（remote takeover）—— 机器人干不动时，由远端的人接手完成。
**分布内 / 分布外**（in-distribution / out-of-distribution）—— 测试时遇到的物体和位置，在不在训练数据覆盖的范围里。

## 10.1 ★★ 四种「遥」，先分清

| | 叫法 | **人在做什么** | **机器人自己在做什么** | 算自主吗 |
|---|---|---|---|---|
| **①** | **遥控**<br>(remote control) | 推摇杆，给方向、给速度 | ★ **平衡、迈步、避障，全自己算** | 算一半 |
| **②** | **遥操作**<br>(teleoperation) | 戴动捕设备，**手臂动作 1:1 映射**过去 | 基本只当执行机构 | ❌ 不算 |
| **④** | **预设播放**<br>(motion playback) | **提前编好一段动作，按下播放** | 只负责别摔倒 | ❌ 不算 |
| **③** | **自主**<br>(autonomous) | 说一句话，或者什么都不做 | 模型自己决策、自己出动作 | ✅ 算 |

> ★★ **第④类最容易被误读，也最少被提起。**
> 它**既不是遥控，也不是智能**——是在放一段编排好的轨迹。
> 跳舞、武术套路、开场表演，绝大多数属于这一类。
> ⟹ 机器人不是"听懂了音乐"，它只是在按时间轴回放，同时用**自主的平衡控制器**保证不摔。

> 📖 顺带说清 ① 和 ② 的界线：**① 给的是"去哪"，② 给的是"怎么动"。**
> 摇杆说"往前 1 米/秒"，怎么迈腿是机器人自己算的 ⟹ ①；
> 你抬一下胳膊、机器人跟着抬一下 ⟹ ②。

### 把这四种画成一个判别树：先问「此刻人在给什么」

```
    看一个片段，先问一个问题：这一刻，人在给机器人什么？
    ├── 什么都没给（或者只说了一句话）
    │     动作由模型现场算出来 ........................ ③ 自主
    ├── 给的是「去哪 / 多快」（摇杆、目标点、一句导航指令）
    │     怎么迈腿、怎么保持平衡，机器人自己算 .......... ① 遥控
    ├── 给的是「怎么动」（动捕服、VR 手柄、主从臂）
    │     机器人基本只当执行机构 ...................... ② 遥操作
    └── 什么都没给，但动作是提前编好的
          按时间轴回放，平衡控制器在底下自主兜底 ....... ④ 预设播放
```

> 📖 **主从臂**（leader-follower arm）—— 操作员手里握着一条小一号的「主臂」，机器人的「从臂」1:1 跟着动。这是目前采操作数据最常见的一种遥操作设备，成本比动捕服低得多。

### ★★ 「自主」不是一个开关，是一条光谱 —— 而且同一个视频里各部分不一样

这是读 demo 时最容易出错的地方：**一台机器人在同一段视频里，不同部位可以处在不同的类别上。**

```
    一个很常见的组合（而且完全不算造假）：
      走到桌子前    ①   人用摇杆给了方向，平衡和迈步是自主的
      伸手去抓      ②   操作员戴着设备，手臂 1:1 映射
      说的那句话    -    旁边的人念的，或者提前录好的
      最后挥个手    ④   一段预设动作

    ==> ★★ 所以「这个视频是不是遥操作的」这个问法本身就是错的。
        正确的问法是：【哪一部分、在哪一层，是自主的？】
```

⟹ 🔑 **这也是后面 §10.5 所有判据的前提**：你能判断的从来不是「真 / 假」，而是「**这一段里，哪些动作有自主的迹象，哪些没有**」。

## 10.2 分三层看：整个行业还是以「遥」为主吗？

### 第一层：训练数据 —— ✅ **是，仍以遥操作为主**

```
    这一层答案最确定。
    目前【高质量 + 带动作标签】的操作类数据，
    主力来源仍然是【人戴着设备一条条摇出来的】。
    ⟹ RT-1、DROID、🔎 AgiBot World 都是这个路子（见 §5.1）。

    ★★ 这正是【数据墙】（§1.5）和整个第 03 章存在的理由：
       世界模型现在最主要的商业价值，
       就是【替掉一部分遥操作的人力】。

    占比在被四条路稀释：
       UMI 手持夹爪 · 人类第一视角视频+潜动作 · 仿真 · 世界模型生成
    ⚠️ 但我没有可靠数据说现在遥操作占几成 —— 别信任何具体百分比。
```

### 第二层：产品演示 —— 🔎 **分领域，差别极大**

```
    ▸ 走跑跳、后空翻、平衡、越野
        ⟹ ✅【不是遥操作】。仿真里 RL 练出来的自主策略（§9.1），
           人最多用 ① 给个方向。这部分是真的。

    ▸ 抓取、递东西、干家务
        ⟹ ⚠️【要非常小心】。
        ✅ 已确认案例：特斯拉 2024-10 "We, Robot" 活动上，
           Optimus 调酒和与人对话是【遥操作】的（走路是自主的）。
        ⚠️ 各类展会上的人形机器人操作演示，
           相当比例是遥操作或预设播放 —— 这是我的观察，不是引用。
```

### 第三层：真实部署 —— ✅ **是，而且是明说的**

```
    ✅ 最有代表性的是 1X 的 NEO 家用机器人：
       公开说明【出厂就带远程人工接管】——
       机器人搞不定时由远端操作员接手完成，同时收集数据。
       ⟹ 这引发过隐私争议（意味着有陌生人能看到你家画面）。

    ★★ 但要强调：【这不是造假，是一种明说的商业策略】。
       逻辑很直白：
         先靠人接管把服务【交付】了
           ⟹ 同时把最贵的【真实场景数据】攒下来
             ⟹ 等模型够强了再逐步撤人
       📖 行业里有时把这类做法笼统叫【影子模式 shadow mode】。
       ⚠️ 但这个词是借来的，而且借得不太准：
          影子模式原本指【模型在后台跟着跑、不接管，只记录自己和人的决策差异】
          （自动驾驶的用法）—— 是【人在开车，机器在旁边看】。
          而 1X 这种是【机器在干活，干不动时人接手】—— 谁在操作是反过来的。
          ✅ 两者唯一的共同点是：都拿人类的动作当标签。
          ⟹ 说得准一点，这类做法更该叫【人工兜底 / 远程接管】。

    ⟹ ★ 换个角度看，这其实是把 §10.2 第一层（数据）
       和第三层（部署）合并成了一件事 —— 边挣钱边采数据。
```

## 10.3 案例拆解：宇树科技

> ⚠️ 本节基于公开信息整理，**未经一手来源核实**，2026 年最新情况请自行核对。

宇树是理解这套分类的最好例子，因为它**四类全占，但占的是不同场景**：

| 场景 | 属于哪一类 | 说明 |
|---|---|---|
| 行走、越野、机器人运动会竞速 | **① 遥控** | ✅ 平衡和迈步是自主策略，人只给方向 |
| 后空翻、侧空翻、被踹不摔 | **③ 自主**（运动层面） | ✅ 仿真 RL 练出来的，**没有水分** |
| 春晚秧歌、跳舞、武术套路 | **④ 预设播放** | ✅ 编排好的轨迹回放 |
| 格斗比赛 | **① / ②** | ✅ 场边有人拿手柄操控，**比赛规则本身如此，没有隐瞒** |
| 抓取、操作类任务 | **② 遥操作为主** | ✅ 宇树**自己开源了遥操作工具链**（如用 Apple Vision Pro 操控 G1/H1） |

> ★ **最后一行是最硬的证据**：一家公司把遥操作方案**作为官方配套发布**，本身就说明这是买家使用这台机器人的主要方式之一——研究者买回去，第一步往往就是遥操作采数据。

### ★★ 但真正的关键不是「遥控占几成」

| | 宇树 |
|---|---|
| **核心竞争力** | 本体 + 运动控制 + **成本控制** |
| **相对短板** | 「大脑」（VLA、操作智能） |
| **⟹ 由此决定的商业模式** | 把机器人当**平台**卖给高校 / 企业 / 表演方，**大脑由买家自己装** |

```
    ⚠️ 所以网上很多"宇树机器人做了 X"的视频，
       其实是【第三方用宇树的身体】做的，
       智能部分不是宇树的。

    🔎 宇树也在往模型层走（开源过世界模型+动作的模型），
       但这块的积累明显晚于也薄于智元 —— ⚠️ 此判断请自行验证。
```

## 10.4 ★★★ 一个通用判断框架：先问它在哪一层

这一节其实是**读 [04 章](04-玩家全景与产业现状.md)的正确姿势**：

| | **模型层**（做大脑） | **本体层**（做身体） |
|---|---|---|
| **代表** | DeepMind · PI · NVIDIA · 智元 | 宇树 · Figure · Tesla · 优必选 |
| **它在卖什么** | 一套能泛化的策略 | 一台能长期不坏、能量产的机器 |
| **评价标准** | 泛化、任务成功率、数据效率 | 可靠性、成本、运动性能、量产爬坡 |
| **用「自主程度」衡量它** | ✅ 合理 | ⚠️ **是错的** |
| **「做得好」长什么样** | 没见过的物体也能干成 | 一万台里坏的少、价格降得快 |

```
    ★★ 拿模型层的标准去衡量本体层公司，必然得出错误结论。
       🔎 宇树是国内首家全年盈利的整机企业 ——
          说明「卖身体」这条路在当下反而更赚钱。
       ⟹ 这不是谁高谁低，是【两门不同的生意】。
```

⚠️ **这个二分是一把尺子，不是一个事实分类。** 特斯拉、Figure、智元实际上两层都在投，只是**重心**不同。⟹ 所以判断一家公司时问的不是「它属于哪一层」，而是 ★ **它现在靠哪一层挣钱、哪一层是它愿意为之押上现金流的**。

## 10.5 ⚠️ 实用：怎么自己判断一个 demo

> ⚠️ 以下是经验法则，不是硬指标。

```
    ▸ 有没有标「1x speed」？
        没标的，默认被加速过。

    ▸ 镜头会不会刻意绕开某个方向？
        遥操作者通常就在几米外。

    ▸ 手部动作【像不像人】？
        ★ 反直觉：太像人反而可疑。
          自主策略的动作往往更「机械但高效」，
          而遥操作会带着人特有的犹豫和修正。

    ▸ 有没有一镜到底？
        频繁剪辑常常在掩盖失败重试。

    ▸ ★★ 最硬的一条：换个【没见过的物体 / 没见过的位置】还行不行？
        这才是自主的真正试金石 ——
        遥操作和预设播放都【必然】在这一关暴露。
```

### 把判据摊开：看到什么、它暗示什么、以及为什么它只是线索

⚠️⚠️ **先立一条纪律**：下面每一条都是**线索**（clue），不是**证据**（evidence）。线索能把你的置信度从 50% 挪到 70%，但**不足以让你写出「这个视频是遥控的」这种句子**。⟹ 这一章是全目录最容易把推断写成结论的地方，所以每条后面都列了「可能的无辜解释」—— **那一列才是真正要读的**。

| # | 观察到什么 | 它可能暗示 | ⚠️ 可能的无辜解释（为什么它只是线索） | 强度 |
|---|---|---|---|---|
| **1** | 动作走走停停，接近目标时「停一下再微调」，节奏在 0.2~0.5 秒量级 | 遥操作者在等画面回传，有**往返延迟** | ⚠️ 自主策略也这样：很多 VLA 一次输出一「块」动作（📖 **动作分块** action chunking），块与块之间天然有停顿 | 弱 |
| **2** | 末端有细微的高频抖动 | 人手的**生理性震颤**（⚠️ 公开生理学量级约 8~12 Hz）被 1:1 映射过去了 | ⚠️ 遥操作链路普遍带低通滤波，会把抖动滤掉；而扩散类策略的输出本身也可能抖 | 弱 |
| **3** | 动作**异常平滑**、匀速、没有一丝犹豫 | 策略网络输出经插值和滤波后的典型特征 | ⚠️ 倍速播放会把人类的抖动抹平，看起来就像策略输出 —— 和第 5 条**互相干扰** | 中（须先排除倍速） |
| **4** | 全程没有一次失败或重试 | 剪辑掉了失败，**成功率被隐藏** | ⚠️ 也可能真的是挑了成功的一条；而且「没有失败」本身**不区分**遥操作和自主 | 弱 |
| **5** | 没有标 `1x speed` | 默认被加速过 | ⚠️ 有些团队只是忘了标 | 中 |
| **6** | 镜头始终避开某一侧，或全程固定机位 | 操作员就在几米外的画外 | ⚠️ 正常的产品片本来就会固定机位、控制构图 | 弱 |
| **7** | 频繁剪辑、没有一镜到底 | 在掩盖失败重试或人工介入 | ⚠️ 也可能只是为了把十分钟剪成三十秒 | 中 |
| **8** | **没有给出成功率和试验次数** | 没有任何可核验的量化结果 | ⚠️ 宣传片本来就不是论文 —— 但这恰恰说明**它不能当证据用** | 强（反向） |
| **9** | **换没见过的物体 / 没见过的位置，仍然能做** | ★★ 真自主 | （几乎没有无辜解释 —— 遥操作和预设播放在这一关**必然**暴露） | 最强（正向） |
| **10** | 一镜到底的长时序多步骤任务，**中途失败了又自己恢复** | ★★ 强自主信号 | ⚠️ 遥操作者也会失败重试 —— 区别在恢复的**节奏**，但那又回到第 1 条的弱线索 | 强（正向） |
| **11** | 公开了权重 / 论文 / 第三方能复现 | ★★ 这是唯一能把线索变成**证据**的东西 | — | ✅ 这才叫证据 |

⟹ ★★ **注意第 9、10、11 条和前八条方向是反的**：前八条是「可疑信号」，强度都不高；真正有判断力的是后三条 —— 它们问的不是「有没有破绽」，而是 **「它有没有提供足以排除遥操作的信息」**。

#### ⚠️ 第 2、3 条和第 5 条会互相抵消，单独用哪一条都不行

```
    人类遥操作的典型特征：带抖动、有犹豫、会过冲再修正
    策略输出的典型特征：  平滑、匀速、该停就停

    ⚠️ 但倍速播放会【同时】做两件事：
       把抖动在时间上压缩掉   ==> 看起来更平滑
       把犹豫也压缩掉         ==> 看起来更果断

    ==> 结论：没标 1x 的视频，第 2、3 条判据【整个失效】。
        必须先确认播放速度，再谈动作特征。
```

⟹ ⚠️ 这也是为什么上面那条「太像人反而可疑」要**反过来再读一遍**：它成立的前提是**你看到的是原速**。一旦是倍速，「不像人」这个观察本身就没有信息量了。


> 🔑 顺带一提，这条判据和 [05 章](05-数据与评测.md)的读论文姿势是同一件事：**看它敢不敢在没训练过的条件下被测。**

## 10.6 ⚠️⚠️ 从线索到结论：这个领域最大的信息缺口，和一套不说过头的说法

这一章是本目录**最容易把推断写成结论**的一章 —— 看完一段视频，很容易脱口而出「这肯定是遥控的」。但上一节已经说明：**你手上全是线索，没有一条是证据。**

⟹ 而之所以只能靠线索，是因为这个行业有一块**结构性的信息缺口**：

```
    ① 没有统一的「自主度」标注规范
         自动驾驶好歹有一套分级的共同语言（L2/L3/L4 那套）；
         ⚠️ 人形机器人的 demo 没有任何对应的东西。
    ② 发布方没有披露义务
         宣传片不是论文，不必写清楚试验次数和自主级别。
    ③ 而自主度恰恰【直接决定】这段演示的技术含量
         同一个动作，②遥操作 和 ③自主 的难度差着整个 VLA 的全部难题。

    ==> ★★ 于是「一段 demo 里有多少遥操作成分」成了这个领域
        【最大的一块信息缺口】 —— 不是因为难测，是因为没人必须说。
```

### 先给手上的东西分级

| 档 | 是什么 | 例子 | 能支持什么结论 |
|---|---|---|---|
| **A ✅ 当事人明说** | 厂商自己披露 | 特斯拉 2024-10 "We, Robot" 上 Optimus 的调酒和对话是遥操作（走路自主）；1X 的 NEO 出厂就带远程接管 | ✅ 可以直接当结论写 |
| **B ✅ 官方技术材料** | 论文、技术博客、开源仓库、官方配套工具 | 宇树开源了自己的遥操作工具链 | ✅ 能支持「这是官方支持的使用方式」；⚠️ **推不出**「他们的 demo 都是遥操作的」 |
| **C 🔎 第三方可复现** | 别人买了同款、按公开方法复现 | 第三方复现报告 | 🔎 较强，但要看复现条件是否一致 |
| **D ⚠️ 视频里的可观察线索** | §10.5 那十一条 | 动作太平滑、没标 1x | ⚠️ **只能调整置信度，不能下结论** |
| **E ❌ 推测与氛围** | 「看着就像」「业内都知道」 | — | ❌ 什么都不能支持 |

⟹ ⚠️ **最容易越界的是 B 档。**「宇树开源了遥操作工具链」是一个 ✅ 事实，它能推出「**遥操作是买家使用这台机器的主要方式之一**」；但它**推不出**「宇树官方放出的那段抓取视频是遥操作的」—— 后者要 A 档的材料才行。⟹ §10.3 那句「最后一行是最硬的证据」，证的是前一句，不是后一句。

### 一个发布方本该给出的披露清单（六项）

```
    ① 自主级别            这段里哪些部分自主、哪些是 ①/②/④（见 §10.1）
    ② 播放速度            有没有变速？标 1x，还是标明倍率
    ③ 试验次数 n 与成功率 p   ★ 这一项最重要，也最常被省掉
    ④ 分布内还是分布外      物体、位置、光照在不在训练分布里
    ⑤ 剪辑情况            是否一镜到底；如有剪辑，剪掉了什么
    ⑥ 有无人工介入         全程有没有远程接管，接管了几次
```

⟹ 🔑 **把这六项当成一张检查表去读任何 demo**：缺得越多，这段视频能支持的结论就越少。⚠️ 注意这不是在指控谁 —— 大多数宣传片缺这六项只是因为它本来就是宣传片。**问题不在发布方缺德，在于读者容易把宣传片当成实验结果。**

### ⚠️ 就算给了成功率，也先过一遍噪声门槛

第 ③ 项最容易被当成「有数就是可信」。但机器人演示的试验次数普遍只有几十次，而成功率的噪声大到超出直觉：

```
    成功率的标准误      SE = sqrt( p(1-p) / n )

      n = 20,  p = 0.5  ==>  SE = sqrt(0.25/20)  =  11.2 个百分点  ★★
      n = 50,  p = 0.5  ==>  SE = sqrt(0.25/50)  =   7.1 个百分点
      n = 100, p = 0.5  ==>  SE = sqrt(0.25/100) =   5.0 个百分点

    ==> 「20 次成功 12 次」(60%) 和「20 次成功 10 次」(50%)
        差的 10 个百分点【小于单边的 11.2】 —— 说明不了任何问题。
```

> ⚠️ **比较两组时不要把两个 SE 相加** —— 那会把门槛抬得过高，反而漏掉真实差异。同一批任务、同一批初始条件下应当用 **McNemar 配对检验**（看的是两组结果**不一致**的那些试验）。完整版见 [附-速查表](附-速查表.md) §F2。
> ⚠️ 顺带两个口径坑：「成功率 50% → 60%」涨的是 **10 个百分点**，不是「提升 10%」；「任务时间减少 60%」不是「快了 60%」，而是 `1 / (1 − 0.6)` = **2.5 倍**（[附-速查表](附-速查表.md) §F4）。

### ★★ 最后：换一种句式，推断就不会被写成事实

| ❌ 不要这样写 | ✅ 改成这样写 | 为什么 |
|---|---|---|
| 「这个视频是遥操作的」 | 「这段视频没有提供足以排除遥操作的信息」 | 把举证责任放回发布方，而不是靠读者猜 |
| 「某家的 demo 都是假的」 | 「某家没有公开这段 demo 的自主级别和试验次数」 | 前者是指控，后者是可核验的事实 |
| 「动作太平滑，所以是策略输出」 | 「动作偏平滑，这是一条弱线索；但视频没标 1x，倍速会产生同样的效果」 | 把反例一起说出来 |
| 「遥操作占行业的七成」 | 「我没有可靠数据支持任何具体百分比」 | §10.2 第一层已经立了这条 |

⟹ 🔑 **这套句式不是为了礼貌，是为了准确。**「没有提供足以排除 X 的信息」是一个**你真的能验证的陈述**（把视频描述翻一遍就知道）；而「这就是 X」是一个**你验证不了的陈述**。⟹ 笔记里只写前一种，结论就永远不会被打脸。

## 🔑 本章一句话

> 「遥」有四种：**遥控（给方向）、遥操作（给动作）、预设播放（放录像）、自主（自己想）**。
> ★★ 行业现状是：**运动能力基本已经自主，操作能力还高度依赖人**——训练时靠遥操作采数据，部署时靠远程接管兜底，而后者是**明说的商业策略，不是造假**。
> ⚠️ 具体到某家公司，先问它在**本体层还是模型层**——宇树的运动是真自主、表演是预设播放、操作确实以遥操作为主，但这不算短板，**因为它本来就不是靠操作智能立身的**。
> ⚠️⚠️ 而具体到某一段视频，你手上**全是线索、没有证据**（§10.5）：唯一能把线索变成证据的是 **「换没见过的物体还能做」**、**一镜到底的长任务**、以及**公开的权重与论文**。⟹ 所以该写的句子是「**这段视频没有提供足以排除遥操作的信息**」，而不是「这段视频是遥操作的」（§10.6）。
