# 10 遥控、遥操作，还是自主？——看懂 demo 的正确姿势

> ★★ 这一章解决一个非常实际的困惑：
> **网上那些机器人视频，到底有多少是机器人自己干的？**
> 这个问题之所以难回答，是因为「遥」这个字被用来指**四种程度差很远的东西**。
> 先把这四种拆开，后面所有判断都会变得清楚。

---

## 10.1 ★★ 四种「遥」，先分清

| | 叫法 | **人在做什么** | **机器人自己在做什么** | 算自主吗 |
|---|---|---|---|---|
| **①** | **遥控**<br>(remote control) | 推摇杆，给方向、给速度 | ★ **平衡、迈步、避障，全自己算** | 算一半 |
| **②** | **遥操作**<br>(teleoperation) | 戴动捕设备，**手臂动作 1:1 映射**过去 | 基本只当执行机构 | ❌ 不算 |
| **④** | **预设播放**<br>(motion playback) | **提前编好一段动作，按下播放** | 只负责别摔倒 | ❌ 不算 |
| **③** | **自主**<br>(autonomous) | 说一句话，或者什么都不做 | 模型自己决策、自己出动作 | ✅ 算 |

> ★★ **第④类最容易被误读，也最少被提起。**
> 它**既不是遥控，也不是智能**——是在放一段编排好的轨迹。
> 跳舞、武术套路、开场表演，绝大多数属于这一类。
> ⟹ 机器人不是"听懂了音乐"，它只是在按时间轴回放，同时用**自主的平衡控制器**保证不摔。

> 📖 顺带说清 ① 和 ② 的界线：**① 给的是"去哪"，② 给的是"怎么动"。**
> 摇杆说"往前 1 米/秒"，怎么迈腿是机器人自己算的 ⟹ ①；
> 你抬一下胳膊、机器人跟着抬一下 ⟹ ②。

---

## 10.2 分三层看：整个行业还是以「遥」为主吗？

### 第一层：训练数据 —— ✅ **是，仍以遥操作为主**

```
    这一层答案最确定。
    目前【高质量 + 带动作标签】的操作类数据，
    主力来源仍然是【人戴着设备一条条摇出来的】。
    ⟹ RT-1、DROID、🔎 AgiBot World 都是这个路子（见 §5.1）。

    ★★ 这正是【数据墙】（§1.5）和整个第 03 章存在的理由：
       世界模型现在最主要的商业价值，
       就是【替掉一部分遥操作的人力】。

    占比在被四条路稀释：
       UMI 手持夹爪 · 人类第一视角视频+潜动作 · 仿真 · 世界模型生成
    ⚠️ 但我没有可靠数据说现在遥操作占几成 —— 别信任何具体百分比。
```

### 第二层：产品演示 —— 🔎 **分领域，差别极大**

```
    ▸ 走跑跳、后空翻、平衡、越野
        ⟹ ✅【不是遥操作】。仿真里 RL 练出来的自主策略（§9.1），
           人最多用 ① 给个方向。这部分是真的。

    ▸ 抓取、递东西、干家务
        ⟹ ⚠️【要非常小心】。
        ✅ 已确认案例：特斯拉 2024-10 "We, Robot" 活动上，
           Optimus 调酒和与人对话是【遥操作】的（走路是自主的）。
        ⚠️ 各类展会上的人形机器人操作演示，
           相当比例是遥操作或预设播放 —— 这是我的观察，不是引用。
```

### 第三层：真实部署 —— ✅ **是，而且是明说的**

```
    ✅ 最有代表性的是 1X 的 NEO 家用机器人：
       公开说明【出厂就带远程人工接管】——
       机器人搞不定时由远端操作员接手完成，同时收集数据。
       ⟹ 这引发过隐私争议（意味着有陌生人能看到你家画面）。

    ★★ 但要强调：【这不是造假，是一种明说的商业策略】。
       逻辑很直白：
         先靠人接管把服务【交付】了
           ⟹ 同时把最贵的【真实场景数据】攒下来
             ⟹ 等模型够强了再逐步撤人
       📖 行业里有时叫【影子模式】。

    ⟹ ★ 换个角度看，这其实是把 §10.2 第一层（数据）
       和第三层（部署）合并成了一件事 —— 边挣钱边采数据。
```

## 10.3 案例拆解：宇树科技

> ⚠️ 本节基于公开信息整理，**未经一手来源核实**，2026 年最新情况请自行核对。

宇树是理解这套分类的最好例子，因为它**四类全占，但占的是不同场景**：

| 场景 | 属于哪一类 | 说明 |
|---|---|---|
| 行走、越野、机器人运动会竞速 | **① 遥控** | ✅ 平衡和迈步是自主策略，人只给方向 |
| 后空翻、侧空翻、被踹不摔 | **③ 自主**（运动层面） | ✅ 仿真 RL 练出来的，**没有水分** |
| 春晚秧歌、跳舞、武术套路 | **④ 预设播放** | ✅ 编排好的轨迹回放 |
| 格斗比赛 | **① / ②** | ✅ 场边有人拿手柄操控，**比赛规则本身如此，没有隐瞒** |
| 抓取、操作类任务 | **② 遥操作为主** | ✅ 宇树**自己开源了遥操作工具链**（如用 Apple Vision Pro 操控 G1/H1） |

> ★ **最后一行是最硬的证据**：一家公司把遥操作方案**作为官方配套发布**，本身就说明这是买家使用这台机器人的主要方式之一——研究者买回去，第一步往往就是遥操作采数据。

### ★★ 但真正的关键不是「遥控占几成」

```
    ┌────────────────────────────────────────────────┐
    │  宇树的核心竞争力 = 本体 + 运动控制 + 成本控制    │
    │  宇树的相对短板   = 「大脑」（VLA、操作智能）     │
    │                                                  │
    │  ⟹ 商业模式：把机器人当【平台】卖给              │
    │     高校 / 企业 / 表演方，大脑由买家自己装。      │
    └────────────────────────────────────────────────┘

    ⚠️ 所以网上很多"宇树机器人做了 X"的视频，
       其实是【第三方用宇树的身体】做的，
       智能部分不是宇树的。

    🔎 宇树也在往模型层走（开源过世界模型+动作的模型），
       但这块的积累明显晚于也薄于智元 —— ⚠️ 此判断请自行验证。
```

## 10.4 ★★★ 一个通用判断框架：先问它在哪一层

这一节其实是**读 [04 章](04-玩家全景与产业现状.md)的正确姿势**：

```
    ┌── 模型层（做大脑）──┐   评价标准：泛化、任务成功率、数据效率
    │  DeepMind · PI      │   ⟹ 用「自主程度」衡量它，合理
    │  NVIDIA · 智元      │
    └────────────────────┘

    ┌── 本体层（做身体）──┐   评价标准：可靠性、成本、运动性能、量产
    │  宇树 · Figure      │   ⟹ ⚠️ 用「自主程度」衡量它，【是错的】
    │  Tesla · 优必选     │
    └────────────────────┘

    ★★ 拿模型层的标准去衡量本体层公司，必然得出错误结论。
       🔎 宇树是国内首家全年盈利的整机企业 ——
          说明「卖身体」这条路在当下反而更赚钱。
       ⟹ 这不是谁高谁低，是【两门不同的生意】。
```

## 10.5 ⚠️ 实用：怎么自己判断一个 demo

> ⚠️ 以下是经验法则，不是硬指标。

```
    ▸ 有没有标「1x speed」？
        没标的，默认被加速过。

    ▸ 镜头会不会刻意绕开某个方向？
        遥操作者通常就在几米外。

    ▸ 手部动作【像不像人】？
        ★ 反直觉：太像人反而可疑。
          自主策略的动作往往更「机械但高效」，
          而遥操作会带着人特有的犹豫和修正。

    ▸ 有没有一镜到底？
        频繁剪辑常常在掩盖失败重试。

    ▸ ★★ 最硬的一条：换个【没见过的物体 / 没见过的位置】还行不行？
        这才是自主的真正试金石 ——
        遥操作和预设播放都【必然】在这一关暴露。
```

> 🔑 顺带一提，这条判据和 [05 章](05-数据与评测.md)的读论文姿势是同一件事：**看它敢不敢在没训练过的条件下被测。**

## 🔑 本章一句话

> 「遥」有四种：**遥控（给方向）、遥操作（给动作）、预设播放（放录像）、自主（自己想）**。
> ★★ 行业现状是：**运动能力基本已经自主，操作能力还高度依赖人**——训练时靠遥操作采数据，部署时靠远程接管兜底，而后者是**明说的商业策略，不是造假**。
> ⚠️ 具体到某家公司，先问它在**本体层还是模型层**——宇树的运动是真自主、表演是预设播放、操作确实以遥操作为主，但这不算短板，**因为它本来就不是靠操作智能立身的**。
