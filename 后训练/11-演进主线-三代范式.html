11 · 演进主线：后训练的三代范式

如果你只读一章，读这一章。
前面十章讲的是"每个零件怎么工作"，这一章讲的是"这些零件为什么会按这个顺序被发明出来"。
读完你应该能回答：为什么 2023 年的技术报告在讲 DPO、2025 年在讲 GRPO、2026 年在讲"环境"？

11.1 ★★★ 先给结论：一条主线，四个台阶

整个后训练的历史，就是同一个问题被反复追问的历史：

「监督信号从哪来？」

┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  第一步  人写答案        → SFT                    2022          │
│          ⚠️ 瓶颈：人写不出"更好的答案"，只能写"一个答案"          │
│                │                                                │
│                ▼                                                │
│  第二步  人给偏好        → RLHF / DPO             2022–2023     │
│          ★ 突破：人只需要【比较】，不需要【创作】                 │
│          ⚠️ 瓶颈：人的比较也很贵，而且比不了博士级数学题          │
│                │                                                │
│                ▼                                                │
│  第三步  规则判对错      → RLVR                    2024–2025     │
│          ★ 突破：人彻底退出【单次评分】，判分器 0 成本无限次      │
│          ⚠️ 瓶颈：只有数学和代码能自动判分；且判分器会被作弊       │
│                │                                                │
│                ▼                                                │
│  第四步  环境给反馈      → Agentic RL              2026          │
│          ★ 突破：奖励不再是"判卷"，而是【世界的真实反应】         │
│             （代码跑没跑通、网页有没有点开、任务有没有完成）       │
│          ⚠️ 瓶颈：环境本身要人来造 —— 瓶颈从算法转移到了基建      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

★★★ 每一步都在做同一件事：把"人"从回路里往外挪一格。
    原因只有一个 —— 【人不 scale（不可规模化）】。
    模型能力涨了 100 倍，能雇的标注员没涨 100 倍。

🔑 这条线是理解全部后训练论文的钥匙。 你读到任何一篇新论文，先问它一句：
"它是在让人少做一点，还是在补上一个被移出去之后留下的窟窿？" 基本都能归到这两类之一。

11.2 第一代（2022–2023）：对齐时代 —— "让模型听话"

要解决的问题：base 模型不知道"被提问了要回答"（见 01.1）

标志性工作
  ✅ InstructGPT   arXiv:2203.02155   SFT → RM → PPO 三步走
  ✅ Constitutional AI  arXiv:2212.08073  ★ 人第一次从【打分】里退出
  ✅ LIMA          arXiv:2305.11206   1000 条数据就够 → 表层对齐假说
  ✅ DPO           arXiv:2305.18290   把 RLHF 化简成一个分类损失

这一代的核心信念：
   「模型在预训练时已经学会了几乎一切，
     后训练只是在教它【用哪种格式、哪种语气】把已有能力表达出来。」
   ⟵ 这就是【表层对齐假说】(Superficial Alignment Hypothesis)

评价标准：有用（helpful）/ 无害（harmless）/ 诚实（honest），俗称 3H
主要战场：对话质量、拒答边界、风格

这一代为什么会走到头：

① 人的偏好标注贵，而且【天花板是标注员的水平】
   ⚠️ 你没法让标注员去判断一道 IMO 题的证明对不对
② 表层对齐假说被证伪了一半 —— 见下一节
③ DPO 的数据会【过期】（off-policy 问题，见 04.5）

11.3 第二代（2024–2025）：推理时代 —— "让模型会想"

这一代的开场，是一个观念的翻转：

第一代：后训练只是【表达格式】的调整，能力都在预训练里
第二代：★★★ 后训练可以【长出新能力】 —— 具体说，长出"长时间思考"这件事

翻转的证据：o1 / R1 那条曲线 —— 让模型多想（生成更长的思维链），
           分数就涨。这不是格式问题，这是【推理时计算】(test-time compute)
           成为了一个新的 scaling 维度。

标志性工作
  ✅ o1（2024-09，OpenAI）  推理时计算成为新维度
  ✅ DeepSeek-R1  arXiv:2501.12948   ★ 把配方公开了
     · R1-Zero：完全跳过 SFT，纯 RL 也能自己长出反思与验证
     · GRPO：把 PPO 的 Critic（价值网络）扔掉，用【组内相对】算优势
  ✅ RLVR 范式确立：奖励 = 判分程序，不是奖励模型
  ✅ GRPO 的病与药：DAPO(2503.14476) / GSPO(2507.18071) / CISPO(2506.13585)
  ✅ RL 的 scaling law 开始被研究：ScaleRL(2510.13786)

这一代的核心信念：
   「只要奖励是【可验证】的，RL 就能规模化，
     模型就能自己搜索出人写不出来的解法。」

评价标准：AIME / Codeforces / GPQA —— 都是【有唯一正确答案】的
主要战场：数学、代码、逻辑

关键的技术分水岭：GRPO 让 RL 变便宜了

PPO：Actor + Critic + Reward Model + Reference = 4 个模型
GRPO：Actor + Reference = 2 个模型，优势靠"同一题采 8 次比大小"算

★★ 这不只是省显存 —— 它把 RL 从"只有大厂能跑"变成了
   "一个学术组也能跑"，直接导致 2025 年 RL 论文数量爆炸。

这一代为什么会走到头：

① 可验证的领域【就那么多】 —— 数学和代码之外怎么办？
② ★ 判分器会被作弊（见 06.5）
③ ★★ 争论：RL 到底是"教会了新东西"还是"只是把已会的排到前面"？
   （pass@k 争论，见 05.6 —— 到 2026 年仍未完全结论）
④ 单轮问答的形式，装不下"用 30 个工具调用修好一个 bug"这种任务

11.4 第三代（2026）：智能体时代 —— "让模型会做"

翻转点：奖励的来源从【判分程序】变成【真实世界的反应】

   RLVR：  模型写出 "42"  → 字符串比对 → 奖励 1
   Agentic：模型执行 30 步 → 测试真的跑了 → 真的绿了 → 奖励 1
                          ↑
              ★★ 这个奖励不是"人定义"的，是【世界给的】

标志性变化（五家 2026 报告的共同点）
  ✅ 一条训练样本 = 一个可运行的环境（沙箱 + 工具 + 成功判据）
  ✅ 瓶颈从算法转移到基建：环境的数量、多样性、稳定性、并发度
     GLM-5.3 直言：环境的构建与扩展是【核心瓶颈】
  ✅ 训推一致性成为一级问题
     （rollout 用推理引擎、训练用训练引擎，两边概率对不上 → RL 崩）
     五家各有解法：bitwise 确定性 / 全流程 QAT / INT4 一致核 / 根因剖析
  ✅ 异步 RL 成为标配：partial rollout、可抢占 rollout、动态过滤
     —— 全是为了对付"长尾轨迹"（99% 的卡在等 1% 的慢轨迹）
  ✅ ★ On-Policy 蒸馏（OPD）成为【收口】的标准手段：
     多个领域专家 → 一个统一模型，在函数空间合并（见 08 章）

这一代的核心信念：
   「能力的上限由【环境的丰富度】决定，不再由数据量决定。」

评价标准：SWE-bench、终端任务、真实工具链、长程任务成功率
主要战场：软件工程、计算机操作、深度检索、多轮工具使用

这一代现在卡在哪：

⚠️ ① 长程信用分配（credit assignment）
     30 步里只有第 7 步错了，但奖励只有最后一个 0/1
     —— 怎么把责任摊回去？【尚无公认解法】
⚠️ ② 环境的规模化生产
     造一个高质量环境的成本，接近造一个小型 CI 系统
⚠️ ③ 环境本身有 bug
     ✅ 已有审计发现代码 RL 环境的缺陷率可到 ~61.9%
     —— 模型学会的是"利用环境 bug"而不是"解决问题"
⚠️ ④ 评测失效（见 10.7）

11.6 ★★ 三代之间的三个"变量替换"

如果嫌上面太长，这三行是全部：

①  监督信号：  人写答案 → 人给偏好 → 规则判分 → 环境反馈
                （每一步都在把人往外挪，因为人不 scale）

②  一条数据：  一段对话 → 一个偏好对 → 一道带答案的题 → 一个可运行的环境
                （数据团队的技能从 NLP 变成了 DevOps）

③  真正的瓶颈：标注人力 → 奖励模型质量 → 判分器可靠性 → 环境基建
                （★ 后训练已经从一个【算法问题】变成了一个【系统问题】）

11.7 ⚠️ 一个必须澄清的误解：新范式没有淘汰旧范式

❌ 错误理解：有了 RLVR 就不用 SFT 了，有了 Agentic RL 就不用 RLHF 了

✅ 真实情况：它们是【叠起来的层】，2026 年的流水线里全都还在

   base → mid-training → SFT → RLVR → Agentic RL → 通用 RL/RLHF → OPD 收口
                          ↑      ↑         ↑            ↑
                       第一代  第二代    第三代      第一代（还在！）

★ 为什么 RLHF 没死：可验证奖励管不了"回答得好不好听"这件事，
  而这恰恰是用户每天都在感受的东西。
  ✅ 所以 2026 年的报告普遍把 RLHF 放在【最后一个 RL 阶段】，
     负责收拾前面几轮 RL 留下的"会做题但不会说人话"。

★ 为什么 SFT 没死：它是【最便宜的能力注入】方式，
  也是给 RL 提供一个"能采出正确答案"的起点的唯一实用办法。
  ⚠️ 但它的地位在下降 —— 有工作把 SFT 变成 RL 里的一个辅助损失项
     （CHORD），而不是一个独立阶段。

11.8 这一章的三句话总结

① 后训练的整部历史，是同一个问题的四次回答：
   「监督信号从哪来」—— 人写答案 → 人给偏好 → 规则判分 → 环境反馈。
   驱动力只有一个：人不 scale。

② 三代范式对应三个口号：
   让模型【听话】(2022–23) → 让模型【会想】(2024–25) → 让模型【会做】(2026)。

③ 新范式不淘汰旧范式，它们叠成了今天这条七段流水线；
   而瓶颈已经从算法转移到了【环境基建】—— 后训练现在是个系统工程。
