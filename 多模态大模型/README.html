多模态大模型 · 小白入门

这个目录讲什么：大模型怎么"看图、看视频、听声音"，以及这件事在 2026 年做到了哪一步。
假设你会什么：知道大模型是"预测下一个 token"的，其他不需要。
不假设你会：不需要懂 CNN、ViT、扩散模型、CLIP —— 用到的地方都会现场解释。

一句话地图

    图片/视频/语音   ──①切块──▶  向量  ──②视觉编码器──▶  语义向量
                                                            │
                                                          ③连接器（翻译）
                                                            │
                                                            ▼
    文字 ──▶ tokenizer ──▶ 向量  ──④拼在一起──▶  【同一个 LLM 主干】──▶ 文字
                                                            │
                                                    （少数模型还能 ──▶ 图片/语音）

全部难点就三个：怎么编码（02）、怎么翻译（03）、这堆向量要占多少 token 预算（04，最重要）。

🔑 全目录总结（读完你应该记住这五句）

  1. 多模态的全部难点，是在没有词典的情况下把图变成"像文字一样的向量"，然后管理它带来的 token 账。
  2. 三代范式：对齐（图≈一句话）→ 看清（图=一份预算）→ 使用（视觉=agent 的传感器与验证器）。
  3. ✅ 2026 年架构已经收敛（patch 14 + 2×2 合并 + 中等大小 ViT），差距在数据和训练；五家旗舰里仍有两家不做多模态，且都是推理导向。
  4. ⚠️ 两件事没解决：幻觉（语言先验压过视觉证据）、尺子（各家 benchmark 零重叠）。
  5. 🔮 最贵的开放问题：多模态到底能不能提升纯文本智能 —— 至今没有公开对照实验。
