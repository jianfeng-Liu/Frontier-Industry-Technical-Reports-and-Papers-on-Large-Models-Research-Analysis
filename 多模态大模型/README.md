## 一句话地图

```
    图片 / 视频 / 语音
      |
      |  ① 切块（patchify）：切成一堆 14×14 像素的小方格
      v
    一堆小方格
      |
      |  ② 视觉编码器（视觉塔）：让每块"看看邻居"，变成有语义的向量
      v
    视觉向量
      |
      |  ③ 连接器（翻译）：变成 LLM 认识的形状和风格
      v
    视觉 token
      |
      |  ④ 和文本 token 拼成一条序列
      |     （文字那边走 tokenizer，出来直接就是 token，不需要前三步）
      v
    【同一个 LLM 主干】
      |
      v
    文字（少数模型还能吐出图片 / 语音，见 09、10 章）
```

**全部难点就三个**：怎么编码（02）、怎么翻译（03）、**这堆向量要占多少 token 预算（04，最重要）**。

> 🔑 **为什么"token 预算"是最重要的那一环**：一张 1092×1092 的截图最后占 **1521 个 token**，约等于 **1100 个汉字**、一页半 A4。⟹ ★ 一张普通截图就是一篇短文的成本，这一句话解释了这个领域一大半的技术动作。

## 🔑 全目录总结（读完你应该记住这五句）

1. **多模态的全部难点，是在没有词典的情况下把图变成"像文字一样的向量"**，然后管理它带来的 token 账。
2. **三代范式**：对齐（图≈一句话）→ 看清（图=一份预算）→ **使用（视觉=agent 的传感器与验证器）**。
3. ✅ **2026 年架构的部件收敛了**（patch 14 + 2×2 合并 + 中等大小 ViT），⚠️ **但预算完全没收敛——一张图的视觉 token 从 256 到 16384，四家之间差 64 倍**。
4. ✅ **五家旗舰里只剩 openPangu 一家纯文本**；⚠️ 而**四家都只花一节篇幅写多模态** ⟹ 它已经从"战略选择"变成"默认的基础设施"。
5. ⚠️ **两件事没解决**：幻觉（语言先验压过视觉证据）、尺子（各家 benchmark 零重叠）。🔮 **最贵的开放问题**：多模态到底能不能提升纯文本智能 —— 至今没有公开对照实验。
