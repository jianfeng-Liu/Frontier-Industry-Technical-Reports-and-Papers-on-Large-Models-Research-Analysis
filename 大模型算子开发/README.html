大模型算子开发

系列定位：从零讲清"一行 torch.matmul 到底在 GPU 里发生了什么"，以及业界为什么能把同一个矩阵乘法优化到快 50 倍。
目标读者：看懂了大模型架构（注意力、MoE、量化）但不清楚它们是怎么跑在硬件上的工程师。
风格：通俗 + 彻底。每章先讲"为什么"，再讲"怎么做"，再给出实测数字。

章节地图

章节 主题 关键词
01 · GPU 硬件基础 SM、Warp、内存层级、bank conflict、occupancy 不懂硬件就看不懂后面所有章节
02 · 屋顶线与性能剖析 算术强度、Memory/Compute Bound、Nsight 工作流 诊断算子瓶颈的唯一正确姿势
03 · GEMM 深度剖析 分块三级、Tensor Core、CUTLASS 模板架构 大模型 90% 算力的来源
04 · FlashAttention 全系 FA1/2/3 算法推导、在线 Softmax、反向传播重计算 序列长度从 4K→128K 的关键
05 · 算子融合 融合模式分类、CUDA Graph、torch.compile/Inductor 消灭算子间的"搬运税"
06 · 量化算子 INT8/FP8/GPTQ、SmoothQuant、DeepSeek FP8 实践 带宽减半 = 速度翻倍
07 · Triton 编程 编程模型、写 kernel、调优、与 CUDA 对比 用 Python 写 GPU kernel 的正确方式
08 · MoE 算子与通信 All-to-All、Expert Parallel、Grouped GEMM MoE 为什么难、难在哪
09 · 推理侧算子 PagedAttention、连续批处理、投机采样、RadixAttention 从训练到服务，问题完全不同
附 · 速查表 硬件参数、关键公式、工具链对照 随时翻查
