# 大模型算子开发

> **系列定位**：从零讲清"一行 `torch.matmul` 到底在 GPU 里发生了什么"，以及业界为什么能把同一个矩阵乘法优化到快 50 倍。  
> 目标读者：看懂了大模型架构（注意力、MoE、量化）但不清楚它们是怎么跑在硬件上的工程师。  
> 风格：通俗 + 彻底。每章先讲"为什么"，再讲"怎么做"，再给出实测数字。
