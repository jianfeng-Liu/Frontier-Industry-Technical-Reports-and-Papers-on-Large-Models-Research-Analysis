一、最基础的几个

缩写 英文全称 中文 一句话 展开于
RL Reinforcement Learning 强化学习 模型自己生成答案、拿到打分、再据此调整参数的训练方式 全目录
RLHF Reinforcement Learning from Human Feedback 基于人类反馈的强化学习 打分来自「人类偏好训练出的奖励模型」的那一类 RL 01
RLVR Reinforcement Learning with Verifiable Rewards 可验证奖励强化学习 打分来自程序判定（代码跑没跑过、数学答案对不对），不需要奖励模型 01
rollout — 生成 / 采样 让模型针对一批题目生成答案的过程。RL 里 ~80% 的时间花在这 02
trajectory — 轨迹 一次 rollout 产出的完整序列（多轮对话里含工具调用和返回） 06
on-policy — 在策略 用来更新的样本，正是当前这版权重生成的 02
off-policy — 离策略 样本来自旧版权重。异步 RL 必然离策略 02
staleness — 陈旧度 样本生成时的权重版本，落后当前权重多少步 02

二、算法

缩写 英文全称 中文 一句话 展开于
PPO Proximal Policy Optimization 近端策略优化 RL 的基线算法。要额外训一个 critic（价值网络） 05
GRPO Group Relative Policy Optimization 分组相对策略优化 同一题生成 G 个答案，组内比较代替 critic。省掉一整个模型 05
GSPO Group Sequence Policy Optimization 分组序列策略优化 把 GRPO 的裁剪从 token 级抬到序列级 05
CISPO Clipped Importance Sampling Policy Optimization 裁剪重要性采样策略优化 裁剪重要性权重本身而非比值，MiniMax 用的就是这个 05
DAPO Decoupled clip and Dynamic sAmpling Policy Optimization 解耦裁剪与动态采样的策略优化 上下裁剪阈值分开，加动态过滤全对/全错的组 05
RLOO REINFORCE Leave-One-Out 留一法 REINFORCE 用「其他样本的平均分」当基线 05
REMAX — — 用贪心解码的分数当基线 05
GAE Generalized Advantage Estimation 广义优势估计 PPO 默认的优势计算方式，需要 critic 05
critic — 价值网络 / 评论家 预测「当前状态未来能拿多少分」的模型。和主模型同规模，很贵 05
IS Importance Sampling 重要性采样 用旧策略的样本估计新策略的梯度，需要乘一个修正比值 04
TIS Truncated Importance Sampling 截断重要性采样 给 IS 比值设上限，防止个别 token 权重爆炸 04
OPD On-Policy Distillation 在策略蒸馏 学生自己生成、老师给概率、按 KL 拉齐。用的是 RL 的管线 05
KL Kullback-Leibler divergence KL 散度 衡量两个概率分布差多远。RL 里用来防止模型跑偏 05

三、系统与架构

缩写 英文全称 中文 一句话 展开于
colocated — 同置 训练和推理挤在同一批 GPU 上，轮流用 02
disaggregated — 分离部署 训练一批 GPU、推理另一批，各跑各的 02
resharding — 重切分 训练态的并行切法和推理态不同，权重传过去要重新切 03
PD 分离 Prefill-Decode Disaggregation 预填充-解码分离 推理的两个阶段负载完全不同，拆到不同机器上各自优化 02
PCC Pearson Correlation Coefficient 皮尔逊相关系数 衡量两组数的线性相关程度，1 是完全一致。这里用来体检「推理算的概率」和「训练算的概率」对不对得上，<0.99 就该查 04 · 07
计数信号量 counting semaphore 计数信号量 一种「令牌池」：拿到令牌才能干活，干完还回去。用来把 rollout 队列的深度卡死在上界 OpenRLHF拆解
KV cache Key-Value cache 键值缓存 推理时缓存已算过的注意力中间结果，避免重复计算 06
partial rollout — 部分 rollout 长样本没生成完就先存下来，下一轮接着生成，避免拖慢整批 02
NCCL NVIDIA Collective Communications Library 英伟达集合通信库 GPU 之间高速传数据的标准库 03
HCCL Huawei Collective Communication Library 华为集合通信库 昇腾 NPU 上对应 NCCL 的那一套 03
CUDA IPC CUDA Inter-Process Communication CUDA 进程间通信 同一台机器上，不同进程直接共享显存指针，零拷贝 03
NIXL NVIDIA Inference Xfer Library 英伟达推理传输库 面向推理场景的点对点数据传输库 03
MTP Multi-Token Prediction 多 token 预测 一次预测多个 token，用来做投机解码加速生成 02
TITO Token-in-Token-out token 进 token 出 训练直接吃推理吐出的 token id，不经过「解码成文字再重新分词」 04
microVM micro Virtual Machine 微虚拟机 比容器更强隔离、比传统虚拟机更轻的沙箱 06

四、并行与训练后端

缩写 英文全称 中文 一句话 展开于
TP Tensor Parallelism 张量并行 把单个矩阵乘法切到多张卡上 03
PP Pipeline Parallelism 流水线并行 把模型按层切段，不同卡负责不同段 03
DP Data Parallelism 数据并行 每张卡一份完整模型，各喂不同数据 03
EP Expert Parallelism 专家并行 MoE 模型里，把不同专家放到不同卡上 04
FSDP Fully Sharded Data Parallel 完全分片数据并行 PyTorch 官方的显存分片方案 01
ZeRO Zero Redundancy Optimizer 零冗余优化器 DeepSpeed 的显存分片方案，FSDP 的思想来源 01
MoE Mixture of Experts 混合专家 每个 token 只激活一小部分参数，省算力 04
MLA Multi-head Latent Attention 多头潜在注意力 DeepSeek 提出的注意力变体，大幅压缩 KV cache 04
LoRA Low-Rank Adaptation 低秩适配 只训练一小组低秩矩阵，主权重冻结 03
AutoTP Automatic Tensor Parallelism 自动张量并行 DeepSpeed 自动推断该怎么切张量并行，不用手写切分策略 OpenRLHF拆解
RingAttention Ring Attention 环形注意力 把超长序列的注意力沿序列维切到多卡，卡之间环形传递 KV，用来撑长上下文 OpenRLHF拆解
QAT Quantization-Aware Training 量化感知训练 训练时就模拟量化误差，让模型适应低精度 04
FP8 / FP16 / BF16 Floating Point 8/16-bit, Brain Float 16 浮点精度格式 数值精度档位。位数越少越快越省，但误差越大 04
