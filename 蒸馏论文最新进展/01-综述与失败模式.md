# 01 · ⭐ 综述与失败模式：OPD 什么时候不work

## 本章关键词

每个缩写第一次出现都给中英文全称。读者自述「架构小白」，这一块不要跳。

**KD**（Knowledge Distillation，知识蒸馏）—— 用一个模型（**老师**）的输出去训练另一个模型（**学生**）。

**OPD**（**On-Policy Distillation**，在策略蒸馏）—— **学生自己采样**出句子，老师在学生写的每个 token（词元）上给方向。本章主角。

**off-policy 蒸馏**（离策略蒸馏）—— 传统做法：老师先把题做完存成数据，学生对着这些数据做 SFT。

**SFT**（Supervised Fine-Tuning，监督微调）—— 给定「输入 → 标准输出」对，用交叉熵训练。

**RL**（Reinforcement Learning，强化学习）；**RLVR**（Reinforcement Learning with Verifiable Rewards，带可验证奖励的强化学习）—— 答案能用程序判对错（数学答案、单元测试），就用这个对错当奖励。

**GRPO**（Group Relative Policy Optimization，组相对策略优化）—— 一种 RLVR 算法：同一道题采一组答案，用组内平均分当基线算优势值。

**KL 散度**（Kullback-Leibler divergence，库尔贝克–莱布勒散度）—— 衡量两个概率分布差多远的量，写作 `KL(P ‖ Q)`，**不对称**。

**正 KL / forward KL**（前向 KL）—— 指 `KL(老师 ‖ 学生)`。行为是 **mode-covering（覆盖模式）/ zero-avoiding（避零）**：老师在哪儿有概率，学生就被逼着在那儿也放概率。✅ 论文（综述）§2.3

**逆 KL / reverse KL**（反向 KL）—— 指 `KL(学生 ‖ 老师)`。行为是 **mode-seeking（寻峰）/ zero-forcing（强制归零）**：学生只挑老师的若干个峰死守，老师概率接近 0 的地方学生也压到 0。✅ 论文（综述）§2.3

**JSD**（Jensen-Shannon Divergence，詹森–香农散度）—— 正 KL 和逆 KL 的对称化折中，有界。

**f-散度**（f-divergence）—— 一个统括家族，换一个凸函数 `f` 就换出一种散度。正 KL / 逆 KL / JSD 都是它的特例。

**logits**（对数几率）—— 模型输出层给**词表里每个词**的原始分数，过 softmax 之后就是概率。白盒蒸馏要的就是这个。

**token-level / sequence-level 估计量** —— 同一个目标函数的两种梯度写法。1.3 节会讲清这两者的差别不是"精度"而是"偏差 vs 方差"。

**exposure bias**（曝光偏差）/ **compounding error**（复合误差）—— 训练时只见过完美前缀，自己写歪一次就进入没训练过的状态，误差逐步累积。

**epistemic verbalization**（认知性表述 / 把不确定性说出来）—— 模型在推理中显式写出"等等"、"嗯"、"或者说"这类标记不确定的词。1.4 节的主角。✅ 论文（退化篇）§1

**PI**（Privileged Information，特权信息）—— 老师能看到、学生看不到的东西（标准答案、运行报错、系统提示）。

**OPSD**（On-Policy Self-Distillation，在策略自蒸馏）—— 同一个模型，给它更丰富的上下文就当老师，不给就当学生。[02 章](02-自蒸馏.md)的主角。

**pass@1 / avg@k / pass@k** —— `pass@1` 采一次的正确率；`avg@k` 采 k 次取平均正确率；`pass@k` 采 k 次**至少一次对**的比例。⚠️ 三者数值差很远，**不能跨指标比**。

**pp**（percentage point，百分点）—— 「从 40% 涨到 55%」是涨了 **15 个百分点**，不是「涨了 15%」（那是 +37.5% 相对）。本章凡混淆处都会点出来。

## 1.2 综述篇：这个领域是怎么被切开的

### 1.2.1 三条轴

综述篇的核心贡献是**不按「方法长得像不像」分类，而按「这篇论文到底在优化哪个设计决策」分类**，一篇论文只进一个格子。✅ 论文（综述）§3.1

它给的三条轴，正好对应 OPD 训练流水线上的三个依次要做的决定：

```
On-Policy 蒸馏（综述篇的三条轴）
│
├── 轴 1：目标函数 —— 「用哪个散度去比老师和学生」（论文 §4）
│   ├── 固定散度：GKD、MiniLLM、DistiLLM
│   ├── 自适应散度：EOPD（按熵在正/逆 KL 之间混）、AOPD
│   └── RL 增强：G-OPD（证明 OPD ≡ 带 KL 约束的 RL）、RLKD、KDRL
│
├── 轴 2：信号来源 —— 「谁来当老师」（论文 §5）
│   ├── 外部老师
│   │   ├── 白盒：要老师的完整 logits —— DSKD、MAD-OPD
│   │   └── 黑盒：只有老师的文本或打分 —— Lion、GAD、OVD
│   └── 自蒸馏（★ 综述说这是最大且增长最快的一类）
│       ├── 特权信息（PI）：OPSD、HDPO、TT-OPD
│       ├── 纯自蒸馏：SDFT、UniSD
│       └── 外部反馈：SDPO、SD-ZERO、SRPO
│
└── 轴 3：训练动态 —— 「怎么把它训稳、训便宜」（论文 §6）
    ├── token / 样本加权：TIP、SCOPE
    ├── 课程与难度自适应：PACED、Stable-OPD、Uni-OPD
    └── 算力优化：FOPD、Lightning-OPD、Prune-OPD
```

**为什么「信号来源」这条轴是两级而不是平级的四类**（这是综述篇一个想清楚了的地方）：**「外部老师 vs 自己」是方法论选择，「白盒 vs 黑盒」是部署约束**。把它们摊成四个平级类别，就会出现"自蒸馏到底算白盒还是黑盒"这种无意义的归类争议 —— 自蒸馏天然是白盒，因为老师就是自己。✅ 论文（综述）§3.1

★ **三条轴不是完全独立的**，综述自己点出了两处耦合：①黑盒访问拿不到 token 级分布，所以**自动排除**了需要精确 token 级散度的目标函数（正 KL 的精确形式就要完整分布）；②RL 增强的目标天然配外部反馈（验证器、奖励模型）。所以"三轴"是用来**组织设计空间**的，不是说 3×3×3 种组合都能实现。✅ 论文（综述）§3.1

### 1.2.2 散度选哪个：一张表

这是 OPD 里最早被吵的问题，也是最容易被讲反的地方。

| | **正 KL `KL(老师‖学生)`** | **逆 KL `KL(学生‖老师)`** | **JSD** | **α-散度** |
|---|---|---|---|---|
| **f 的形式** | `f(u)=u·log u` | `f(u)=−log u` | `f(u)=u·log u−(u+1)·log((u+1)/2)` | 参数族 |
| **行为名字** | mode-covering（覆盖模式）<br>zero-avoiding（避零） | mode-seeking（寻峰）<br>zero-forcing（强制归零） | 对称、有界、在两者间平滑插值 | 连续插值：`α→1` 趋正 KL，`α→0` 趋逆 KL |
| **直观说法** | 老师在哪有概率，学生**都得跟着放一点** | 学生**只挑老师的几个峰**死守 | 折中 | 旋钮 |
| **代价** | 会在两个老师模式**之间的空隙里幻觉** | 会**忽略次优但也可接受**的输出 | ⚠️ 综述说它**没有理论最优性保证** | —— |
| **适合什么任务** | 答案**多样可接受**（开放写作、开放 QA）—— 保多样性 | 答案**唯一正确**（数学证明、代码正确性）—— 把质量集中到一条解法路径上 | 指令遵循这类中间地带 | 需要细调时 |

✅ 以上四行全部出自论文（综述）§2.3。

⚠️ **这张表有一个坑，必须提前说**：上面写着「数学/代码 → 用逆 KL」，这是综述对**外部老师**场景的总结。但 [02 章](02-自蒸馏.md)里 **Self-Distilled Reasoner 那篇在自蒸馏场景下实测出正 KL 最好、逆 KL 和 JSD 基本无效甚至变差**（✅ 该论文 Table 3）。两边**不是一个设定**（外部强老师 vs 同一模型带特权上下文），但**结论方向是相反的**。1.6 节会把这个矛盾单独立一行，**不要只记住综述那一行**。

### 1.2.3 曝光偏差：为什么 on-policy 从理论上就该更好

这件事 [后训练/08](../后训练/08-蒸馏与合并-OPD.md) 已经讲过机制，这里只补综述给的**量级**：

| | 训练数据来自 | 期望误差随长度 T 的增长 | 来源 |
|---|---|---|---|
| **off-policy 蒸馏** | 静态语料 / 老师生成的轨迹 | **`O(ε·T²)`** —— 平方 | ✅ 论文（综述）§1 引言 + §2.2，引 Ross et al. 2011（交互式模仿学习） |
| **on-policy（OPD / DAgger 式）** | 学生自己当前的策略 | **`O(ε·T)`** —— 线性 | ✅ 同上 |

⚠️ **怎么读这两个式子**（这是我的解释，不是论文原话）：`ε` 是"每一步犯错的概率"，`T` 是输出长度。`O(ε·T²)` 的平方项来自**一步走歪之后，后面所有步都处在没训练过的状态**；而 DAgger 式做法是"在学生自己会走到的状态上去问老师"，于是每一步的错只算一次，总量是线性的。**推理链越长，这个平方 vs 线性的差距越大** —— 这就是为什么长 CoT（Chain-of-Thought，思维链）时代 OPD 突然重要起来。

⚠️ 另一个必须说清的方向问题：**`O(ε·T²)` 是上界，不是"实测 off-policy 一定差"**。综述自己专门立了一节讲 **DeepSeek-R1 异常**：R1 用**纯 off-policy SFT**、约 80 万条 CoT 轨迹，蒸出来的 R1-Distill-Qwen-7B 在 AIME 2024 上 pass@1 **55.5%**、32B 达 **72.6%**，而在同规模直接做 RL（Qwen2.5-32B-Base 上跑 GRPO）只有 **47.0%**。✅ 论文（综述）§7.4

综述给的三条解释（✅ 论文 §7.4，⚠️ 它自己用的词是 "plausibly explain"，即**推测性解释**）：①671B MoE 老师强到能把问题空间覆盖得很密；②轨迹里本来就包含回溯和验证策略，多样性够；③学生模型**相对较小**，在 off-policy 学习下"有效条件复杂度"仍可控。⟹ **老师足够强 + 学生足够小的时候，off-policy 就够用了**。

## 1.3 ★★★ 失败模式篇：标准 OPD 实现到底脆在哪

**这一节是全章最有价值的部分。** 这篇论文做的事很具体：它拿当前工业界最常见的那种 OPD 实现（**sampled-token OPD**，只在"学生实际采到的那一个 token"上算老师-学生 log 概率差），问「这个实现为什么在长 rollout 上会崩」。

### 1.3.1 先把两个估计量摆清楚：这不是精度问题，是偏差 vs 方差

OPD 的目标是最小化**序列级逆 KL**：`J(θ) = E_x[ KL(π_θ(·|x) ‖ q(·|x)) ]`，其中 `π_θ` 是学生、`q` 是老师。✅ 论文（失败模式）§2.1

对每个解码位置 `t`，记 `s_t = ∇_θ log π_θ(y_t | c_t)`（当前 token 的得分函数梯度）、`r_t = log[π_θ(y_t|c_t) / q(y_t|c_t)]`（当前 token 的 log 比值，可以当"即时奖励"看）。于是有两种梯度写法：✅ 论文（失败模式）§2.1 式 (1)(2)

```
序列级估计量
   ĝ_seq = Σ_t ( Σ_{t'=t..T} r_t' ) · s_t
   └── 括号里的 Σ_{t'=t..T} r_t' 是【从 t 开始、后面所有步的奖励之和】
       ⟹ 每个 token 的更新都被后面所有步牵连

token 级估计量
   ĝ_tok = Σ_t r_t · s_t
   └── 这里只剩 r_t，也就是【当前这一步自己的奖励】
       ⟹ 每个 token 的更新只看自己这一步，未来被整个丢掉

折中：折扣回报估计量
   ĝ_γ = Σ_t ( Σ_{t'=t..T} γ^(t'−t) · r_t' ) · s_t ，  γ ∈ [0,1]
   ├── γ = 0  退回 token 级
   └── γ = 1  退回序列级
```

★ **关键结论，别讲反**：

| | **序列级** | **token 级** |
|---|---|---|
| **相对序列级逆 KL 是否有偏** | ✅ 无偏（它就是定义） | ⚠️ **有偏** |
| **最坏情况方差上界随长度 T** | **`O(T⁴)`** | **`O(T²)`** |
| **工业界实际在用的** | 少 | ★ 几乎全部 |
| **为什么** | —— | ★ **长序列上方差小得多，值得牺牲无偏性** |

✅ `O(T²)` vs `O(T⁴)`、「有界奖励与有界梯度假设下」这几句出自论文（失败模式）§2.1。⚠️ 完整推导在该论文 Appendix D，**我没读**，所以不能替它背书推导细节，只能说"这是它声称的结论"。

**它还做了一个玩具实验验证这个权衡**：在一个两任务合成环境里扫 `γ ∈ {0, 0.25, 0.5, 0.75, 1.0}`，`γ` 越大梯度方差越高、优化越不稳；`γ=1.0`（纯序列级）时策略在状态空间里**漂移**，不能稳定走向目标。✅ 论文（失败模式）Figure 1

⚠️ **这给长程训练一条设计原则**（✅ 论文原话 "keep supervision token-level to control variance"）：**监督要保持在 token 级来控方差**，然后**在 token 级内部去改善信号质量** —— 这正是它下面做的事。

### 1.3.2 ★★★ 三个失败模式：现象 / 机制 / fix / fix 的代价

这三个失败模式来自同一组实验：**学生 Qwen2.5-7B-Instruct，老师 OpenThinker3-7B**（一个在 Qwen2.5-7B-Instruct 上做了 SFT 的模型），任务是数学推理。✅ 论文（失败模式）§2.2

| | **失败模式 ①<br>单 token 信号严重失衡** | **失败模式 ②<br>老师在学生前缀上不可靠** | **失败模式 ③<br>tokenizer / 特殊 token 错配** |
|---|---|---|---|
| **分类** | 目标函数层面 | 目标函数层面 | ★ **实现层面**（不是理论问题） |
| **现象** | ✅ 第一轮迭代时，**大多数被采样的 token 拿到的是负奖励**（论文 Figure 2 的散点图：点大量落在 `y=x` 下方，即学生给的概率比老师高）。优化于是被**少数局部为正的 token**主导 | ✅ 学生掉进**重复循环**（反复输出 `### Final Answer:\boxed{-14}`），**老师在这些重复 token 上仍然给很高的概率**（论文 Figure 3 里老师概率 0.6–1.0），于是 OPD **不会惩罚这个行为** | ✅ 同一段文本在两个 tokenizer 下切法不同。论文举的例子：学生把 `<think>` 切成 `<`、`think`、`>`，老师期望的是 `<th`、`ink`、`>`，于是 `<` 这个 token 从老师那里拿到极低概率 —— 尽管两边**语义完全一样**。论文 Figure 5 给了一个具体对照：同一段输出学生 log 概率 −0.07 / −19.16，老师 −0.00 / −58.71 |
| **机制** | 负奖励的定义就是"学生给这个 token 的概率比老师高"。学生自己采出来的 token，**天然就是学生概率高的那些** ⟹ 结构上就偏向负 | sampled-token OPD 的**隐含假设**是「老师给学生某个 token 的概率 ≈ 这条轨迹的质量」。这个代理在**学生常去、老师不常去**的前缀上失效。论文给了两个放大因素：**老师分布很尖**（师生稍有不一致就产生巨大 log 比值）、**师生分歧随 rollout 变长而增大**（✅ Figure 4：越靠后的位置，log 概率差的下尾更宽、极值更多） | 单 token 比较**把"语义不一致"和"切词不一致"混成了一个数**。监督只落在一个 token 上，这种错配就直接扭曲奖励信号 |
| **它给的 fix** | ★ **老师 top-K 局部支撑集匹配**（teacher top-K local support matching）：不再只比那一个采样 token，而是在**老师概率最高的 K 个 token** 构成的集合 `S(c_t)` 上，把师生分布各自**重新归一化**，然后算**截断逆 KL** | 同上（同一个 fix 治两个病） + **top-p rollout 采样**：生成时用 top-p，避免采到极低概率 token 造成老师信号不可靠的前缀 | **特殊 token 掩码**（special-token masking）：把有问题的特殊 token 直接从损失里屏蔽掉 |
| **fix 的代价** | ⚠️ 每个位置要取老师的 top-K 并重算 softmax，比单 token 贵；但**比全词表 KL 便宜得多**。⚠️ **支撑集内必须重新归一化**，否则会**快速崩溃**（✅ 论文 Figure 6a：不归一化时策略熵直接飞到 10 以上，训练分数塌掉）。⚠️ K 太小会伤学习（K=16 不如 32/48） | ⚠️ top-p 会**限制探索**。✅ 论文消融里 `top_p=0.8/0.9` 优于 `1.0`（无约束），但这是在这一个设定下的结论 | ⚠️ 这是**模型相关的补丁**，不是通用方案。论文自己说还可以合并多 token 变体或在等价切词上取平均，但**它没做**，理由是掩码是"最简单的、与模型无关的修正"。⚠️ 换一对师生就得重新确认掩码哪些 token |

⚠️ **一个我必须点出来的内部张力**（论文自己没明说，这是我的观察）：它实验里的学生是 **Qwen2.5-7B-Instruct**，老师 **OpenThinker3-7B 是在 Qwen2.5-7B-Instruct 上 SFT 出来的** ⟹ **两边 tokenizer 本来就一致**。所以失败模式 ③ 在它自己的实验里**不可能来自真正的"跨 tokenizer 切词不一致"**，只可能来自**特殊 token 的约定差异**（`<think>` / EOS 标记这类）。而论文正文举的 `<` / `think` / `>` 例子是**泛化说明**。⟹ ★ **「掩码特殊 token 带来 +4.3 个百分点」这个巨大收益，是"约定错配"的收益，不是"跨 tokenizer"的收益**。把它当成"换 tokenizer 也能这么治"就讲反了。

## 1.4 ★★★ 退化篇：为什么自蒸馏有时会**损害**推理能力

### 1.4.1 现象先摆出来

这篇论文的起点是一个**具体的反常**：同一个自蒸馏算法（**SDPO**，[02 章](02-自蒸馏.md)的主角之一），在**化学**任务上大幅缩短输出同时快速提分；换到**数学**任务上，输出照样变短，**但分数显著下降**。✅ 论文（退化篇）§1 + Figure 1

它追到的机制是一句话：**自蒸馏抑制了 epistemic verbalization（把不确定性说出来）**，而数学推理恰恰**需要**这个东西。

**什么是 epistemic verbalization**：模型在推理中写出的"等等"、"嗯"、"或者说"这类标记不确定的词。论文定了一个**可数的 10 个词**的清单当代理指标：✅ 论文（退化篇）§3

```
epistemic token 清单（10 个）
├── wait          ├── actually        ├── seems      ├── likely
├── hmm           ├── alternatively   ├── might      └── check
├── perhaps       └── maybe
```

记一条回答 `y` 的 epistemic token 数为 `E(y) = Σ_{t∈T} count(t, y)`。✅ 论文（退化篇）§3

⚠️ **这个指标是代理，不是定义**。论文自己说这 10 个词是"不确定性外化可能发生的区域的**实用指示器**"，并在附录里验证它们和更长的不确定性表达共现。⟹ **别把"epistemic token 少了"直接等同于"模型不会表达不确定性了"**，中间隔了一层代理。

### 1.4.2 核心机制：信息量越大，不确定性表达越少

论文给的量化工具是**条件互信息**：

```
I(y*; c | x) = H(y* | x) − H(y* | x, c)
   ├── H(y* | x)     = 只给题目时，对正确答案的不确定性
   └── H(y* | x, c)  = 给了题目【加上额外上下文 c】之后，剩余的不确定性

⟹ I(y*; c | x) 就是「上下文 c 替你消掉了多少关于正确答案的不确定性」
```

✅ 论文（退化篇）§3 式 (2)。`y*` 是"理想正确回答"这个随机变量，`c` 是给老师的额外上下文。

**它设计了一个信息量阶梯**（4 个设定，信息量严格递增），在 **DeepSeek-R1-Distill-Qwen-7B** 上、**DAPO-Math-17k** 里挑出 **100 道**基座模型 8 次采样准确率在 **0.125–0.5** 之间的题（即"不太简单也不太难"）：✅ 论文（退化篇）§3

| 设定 | 给老师的上下文 `c` | `I(y*;c｜x)` 排序 | **准确率** | **平均长度（token）** | **epistemic token 数** |
|---|---|---|---|---|---|
| **(1) 无引导** | `c = ∅` | **= 0**（定义上） | 0.30 | **13,054** | **182.5** |
| **(3) 给解法但去掉 `<think>`** | `c = s\think` | 第 2 小 | 0.78 | 12,036 | 159.8 |
| **(4) 条件在"之前自己写对过的回答"上** | `c = y_r` | 第 2 大 | 0.95 | 2,808 | 24.1 |
| **(2) 给完整解法** | `c = s` | **最大** | **0.98** | **1,873** | **8.8** |

✅ 整张表是论文 Table 1 的原数据（我把行序按信息量重排了，论文原表顺序是 1/2/3/4）。

★ **这张表是全篇的地基，结论是一个单调关系**：`I(y*;c|x)` 越大 ⟹ 回答越短、epistemic token 越少、（当然）准确率越高。✅ 论文（退化篇）§3 式 (4)

⚠️ **几个可验算 / 要留意的点**：

- ✅ 论文明确说：设定 (3) 里 `s\think` 本身只有 **640 个 token**（对照设定 (1) 的回答平均 13,054 token）。⟹ 去掉 `<think>` 内容后信息量损失极大，所以长度和 epistemic token 数**几乎弹回无引导的水平**（12,036 ≈ 13,054；159.8 ≈ 182.5）。
- ⚠️ **我自己算的比例**：从无引导到全解法引导，长度压缩到 `1,873 / 13,054 = 14.3%`（约 **7.0 倍**压缩），epistemic token 压缩到 `8.8 / 182.5 = 4.8%`（约 **20.7 倍**压缩）。⟹ ★ **不确定性表达被压掉的幅度，比总长度被压掉的幅度大得多**（20.7× vs 7.0×）。**不是等比缩短，是选择性地把不确定性先删掉。** 这个倍数对比论文没算，是我算的。
- ⚠️ 设定 (4)（条件在自己之前写对的回答上）信息量按**数据处理不等式**必然 ≤ 设定 (2)（✅ 论文原话），实测确实落在 (3) 和 (2) 之间。

★★★ **这是整个目录里最该记住的一个数字对照**：**在 800 条全部答对的轨迹上做 SFT，可以把一个 7B 推理模型在 AIME24 上从 54.79 打到 20.21。** 而换成另外 800 条**同样全部答对**、只是"啰嗦且会表达犹疑"的轨迹，基本不掉（51.04，⚠️ 这 −3.75 pp 落在 30 题的噪声门槛内 —— `p≈0.55` 时 `SE ≈ √(0.55·0.45/30) ≈ 0.091` 即 **9.1 个百分点**，**所以不能当成"有退化"**）。

★ **机制（论文给的解释）**：solution-guided 的回答之所以简洁，**是因为生成时外部有 `s` 可看**。拿它们当 SFT 目标，等于**强迫模型模仿一种"预设了推理时拿不到的信息"的说话方式**，于是把支撑自主探索和自我纠错的 epistemic token 抹掉了。✅ 论文（退化篇）§4

⟹ ★ **「数据正确」不等于「数据可学」。** 这是本仓库里少见的、能把"数据质量"这件事讲到机制层的证据。

### 1.4.4 on-policy 场景：同样的机制，而且会自我放大

把场景换成 on-policy 自蒸馏（即 **SDPO**），对照 **GRPO**，数据集 DAPO-Math-17k：✅ 论文（退化篇）§5

| 模型 / 设定 | 方法 | 训练中长度趋势 | OOD 评测结果 |
|---|---|---|---|
| **DeepSeek-R1-Distill-Qwen-7B**<br>（基座本来就有约 180 个 epistemic token/回答） | GRPO | 略增 | ✅ AIME24 **54.7 → 56.0**；AMC23 **89.3 → 91.1** |
| 同上 | SDPO（`c = s` 全解法） | **急剧下降** | ⚠️ AIME24 掉约 **40%**（相对）；AMC23 掉约 **15%**（相对） |
| 同上 | SDPO（`c = s\think` 弱化条件） | 下降被缓和 | 跌幅减小，但**仍低于基座** |
| **Qwen3-8B（thinking 开）** | GRPO | 缓降 | 基本持平 |
| 同上 | SDPO | 降得更多 | **低于基座**，`c=s` 时尤甚；⚠️ 即使 `c=s\think` 的**训练分数**和 GRPO 接近，**OOD 仍随训练推进持续退化** |
| **Qwen3-8B（thinking 关）** | GRPO | **快速上升**（靠增加 epistemic 表达） | 训练分数快速上去 |
| 同上 | SDPO | 下降 | ✅ AIME24 **0.25 → 0.23**（⚠️ 这个差值很小，见下） |

✅ 以上全部出自论文（退化篇）§5.1–5.3。⚠️ 注意「掉约 40%」是**相对跌幅**，不是百分点：`54.7 × (1−0.40) ≈ 32.8`。摘要里那句 "performance drops of up to 40%" 指的就是这个，**是相对值**。

⚠️ **最后一行那个 0.25 → 0.23 不能当结论**：AIME24 共 30 题，论文用的是 `Acc@16`（16 次采样平均）。即使按最乐观的"16×30=480 次独立试验"算，`SE ≈ √(0.24·0.76/480) ≈ 0.019` → **1.9 个百分点**，而同一道题的 16 次采样**高度相关**，有效样本量远小于 480 ⟹ 实际 SE 更大。**0.02 的差值落在噪声里。** ⚠️ 这个验算是我做的；论文在这一处没给误差棒（它在别处的图里给了 shaded area，但这一句是正文文字）。⟹ 要用这篇论文，**用它的 SFT 表（1.4.3，跌 29.6 pp，远超任何噪声门槛）和机制论证，不要用这一行**。

★★ **一条额外的、很重要的机制：自蒸馏会自我放大。** 论文做了"固定老师 vs 移动老师"的消融（✅ 论文 §5.4 + Figure 6）：SDPO 原本用 EMA（Exponential Moving Average，指数移动平均）平滑的老师，EMA 率 0.05；而把 EMA 率设成 **0.0（即把老师钉死在初始策略）反而更好**。

```
为什么移动的老师更糟 —— 一个正反馈回路（论文自己的解释）

   学生被训得更自信、更简短
        ↓
   这个更自信的学生被拿去当老师
        ↓
   它生成的目标分布更自信
        ↓
   学生被训得【更】自信、【更】简短
        ↓
   …… 每一轮放大一次
```

✅ 论文原话：*"This can be interpreted as a feedback loop in self-distillation."* ⟹ ★ 这也是综述篇 §7.2 里叫 **self-play saturation / Ouroboros（衔尾蛇）问题** 的那个东西的一个具体实例。

### 1.4.5 ★ 决定"有增益还是退化"的第二个变量：任务覆盖面

论文接着问一个关键问题：**同一个机制（抑制不确定性表达），为什么在化学上提分、在数学上掉分？** 它的答案是**训练集和评测集的任务覆盖面不同**。

| | **ScienceQA（化学）** | **LiveCodeBench v6** | **DAPO-Math-17k（本文设定）** |
|---|---|---|---|
| **总题量** | ✅ 2,400 题 | ✅ **131 题** | ✅ 14,000 题用于训练 |
| **题型结构** | ✅ 只有 **6 类**主题型（配平反应 300、分子描述符计数 300、分子量计算 600、性质预测 500、前体/反应物选择 300、有机反应产物预测 400），**差异主要在表面细节** | ✅ 题型多样但**总量只有 131** | ✅ 题型**广、不重叠** |
| **训练/评测划分** | ✅ 90% 训练 / 10% 评测 | ⚠️ ★ **131 题全部既做训练又做评测**（训练时只用 50% 的 public 测试用例，评测用含隐藏用例的全集） | ✅ 评测在**训练数据之外**的标准基准（AIME24/25、AMC23、MATH500） |
| **⟹ 泛化要求** | 低（反复见到同构题） | **极低**（同一批题） | **高**（未见过的题型） |

✅ 整张表是论文 Table 3 + §6.1 的内容。

★ **这是一个很硬的方法论发现**：SDPO 原论文报的"在化学/工具调用/LiveCodeBench 上比 GRPO 更准且更短"，**其评测设定的泛化要求都很低**；而在高泛化要求的数学上，同一个方法掉分。

⚠️ **一处我没读懂的口径，诚实留白**：论文正文写 DAPO-Math-17k *"exposes the model to 14,000 distinct problems (78% of the 25,600 samples drawn over 100 steps, due to repeated sampling)"*。我试了几种读法：
- 若「78%」= `14,000 / 17,917`（DAPO-Math-17K 的实际题数）= **78.1%** ⟹ 口径自洽 ✅，但**分母 17,917 是我补的，论文没写**。
- 若「78%」= `14,000 / 25,600` = 54.7% ⟹ **对不上**。
- `25,600 = 100 步 × 256` ⟹ `256 = batch 32 × 8 rollouts`（⚠️ 这是我从 SDPO/SRPO 的超参推的，退化篇没给 batch 配置）。但若 25,600 是 **rollout 数**，则 100 步最多覆盖 `100 × 32 = 3,200` 个不同 prompt，**到不了 14,000**。

⟹ ⚠️ **这三个数（14,000 / 25,600 / 78%）我凑不出一个完全自洽的口径，不要在它们之上做进一步推算。** 可以放心用的只有定性结论：**DAPO-Math 的题型覆盖面比化学和 LCB v6 大一个量级，且评测题不在训练集里。**

**它还直接扫了覆盖面这个变量**：固定模型 Qwen3-8B（thinking 关），把训练题数（论文记作 `|D|`，本章为了不破坏表格改写成 `#D`）取 `{1, 8, 64, 128, 512}` 和全量 DAPO，分别跑 GRPO 和 SDPO。✅ 论文 §6.2 + Figure 7/8

| `#D` | **训练分数（SDPO vs GRPO）** | **OOD 表现（AIME24 / MATH500）** |
|---|---|---|
| ≤ 128 | ✅ SDPO **快速**拿到高分，长度最多压到 **1/8** | ⚠️ ★ **`#D` 越小，OOD 退化越严重** |
| = 512 | ✅ 长度继续压反而开始**拖累训练分数**，落后 GRPO | 同上趋势 |
| 全量 DAPO | —— | ⚠️ ★ **即使在最大 `#D`，SDPO 仍低于基座模型** |
| （对照）GRPO | ✅ 长度随 `#D` 增大而**逐渐变长** | ✅ **随 `#D` 单调变好**：`#D=1` 快速收敛后就停，越大的 `#D` 最终分数越高 |

★★ **这个反向趋势是全篇最漂亮的证据**：**GRPO 的 OOD 表现随训练题量变好，SDPO 的 OOD 表现随训练题量变差得更轻（但始终低于基座）** —— 两条曲线方向相反，说明这不是"训练量不够"，是**机制性的**。

✅ 论文自己的收口（Takeaway 4 原话转述）：**不确定性表达的价值随泛化要求上升** —— 对熟悉、重复的任务（小 `#D`）它基本是冗余的、删掉能换效率；任务多样性一涨，它就越来越重要。

## 1.5 综述篇自己整理的「失败模式总账」

1.3 和 1.4 是两篇一手论文的深挖。综述篇 §7.2 另外汇总了**十几种**失败模式，按**根因**而不是按**症状**归类（因为多种不同机制会产生同一种表面退化，比如"准确率崩塌"）。✅ 论文（综述）§7.2

⚠️ **这一节的证据等级最低**：下面每一行都是综述**转述别人论文**的结论，我**没有读那些原始论文**。所以这张表只能当**索引**用 —— 告诉你"有这么一类坑、叫什么名字、去哪篇找"，**不能当成已核实的结论**。

| 失败模式 | 根因 | 综述转述的关键证据 / 数字 |
|---|---|---|
| **flawed prefix trap**（坏前缀陷阱） | 学生生成错误前缀后，老师在这种 OOD 输入上的条件分布**校准很差** | 就是 1.3 节那篇（Fu et al. 2026b）的三个失败模式 |
| **extrapolation cliff**（外推悬崖） | 奖励外推 OPD（`λ>1`）在结构化输出任务上有**硬边界** | 存在一个闭式阈值 `λ*`，越过它训练就从"保格式"翻成"毁格式"。ListOPD 在阈值下方用 1.7B 学生打到 8B-SFT 的域内平手（参数量 1/5），⚠️ 但收益**主要来自格式遵循而非排序质量** |
| **Rock Tokens**（顽石 token） | 结构性/话语性残留（连接词、格式、模糊限定语）**学不进去也不必学** | 训练到表观饱和后，**高达 18%** 的 token 仍持续高损失，且因出现频率高而**占据超大比例的梯度范数**；因果干预显示它们对实际推理性能**贡献可忽略** |
| **gradient SNR collapse**（梯度信噪比崩塌） | 学生在某题上的通过率趋近 0 ⟹ 所有 rollout 都早早出错 ⟹ 老师信号被噪声主导 | 解释了**为什么难题在标准 OPD 下给不出学习信号** |
| **epistemic suppression**（认知抑制） | 就是 1.4 节那篇 | 缩短推理轨迹时**不成比例地**删掉模糊限定语和不确定性标记 |
| **local teachability collapse**（局部可教性崩塌） | ⚠️ 这个和 flawed prefix trap **不是一回事**：老师**仍然校准良好**，只是它在学生 top-K 候选集上的**区分边际变窄**到 KL 梯度没有判别信息 | 提出按老师的局部判别能力**在 BIC 式的变点处截断** OPD 监督，⟹ 最优截断点是**轨迹相关**的，不是固定位置 |
| **self-play saturation / Ouroboros**（衔尾蛇） | 自蒸馏里学生对着**和自己共享归纳偏置**的目标优化 ⟹ 假设空间逐步坍缩 | 一旦模型发现某个句法"hack"或高置信但有缺陷的启发式，**没有外部信号去惩罚它** ⟹ `p_θ(y_flawed｜x) → 1` ⟹ 梯度消失、探索停止。⚠️ 综述强调这**不同于**曝光偏差（后者是 off-policy 的训练-测试分布错配） |
| **precision-recall 权衡 / 多样性坍缩** | 学生把概率质量集中到高质量输出（precision ↑）就必然减少对老师完整分布的覆盖（recall ↓） | 激进的逆 KL 蒸馏 ⟹ **pass@1 高但 pass@k 灾难性差**，因为每题坍缩到单一推理策略。可用采样温度当旋钮 |
| **calibration-capability gap**（能力-校准落差） | 老师的监督是在**训练时才有的特权上下文**下形成的，部署时的模型只有部署上下文 | OPD 可靠地提准确率，却把模型留在**严重过度自信**的状态 ⟹ "**miscalibration 的 scaling law**"。⚠️ 综述的评语：一个分数更高但不可靠地指示自己何时出错的模型，**可以说比一个更弱但校准更好的基线更不安全** |
| **agentic collapse**（多轮 agentic 场景特有） | 三个子病：①**老师动态崩塌**：周期性硬拷贝老师导致 KL 从累积值**突降到接近 0**（综述给的例子：周期 T=30 时某次拷贝事件上 **2.637 → 0.343**），蒸馏梯度被抹掉；②**轨迹结构侵蚀**：稀疏终局奖励下，学生学会"冗长的单轮独白"比"协调的多轮工具调用"更容易拿分（每回合轮数 **7.65 → 5.52**，换 EMA 老师也仍从 **7.82 → 6.23**）；③**提示失控**：加入结果条件的老师提示而不控长度 ⟹ 回答爆长直到撑满上下文，准确率从 **54.5% → 49.0%** | ⟹ 综述的收口：**稳定的老师动态 + 对轨迹结构的显式正则 + 粒度匹配的信用分配，三者看起来是共同必要的** |
| **off-metric capability erosion**（指标外能力侵蚀） | **蒸馏评测本身结构性不完整**：只报学生保留了什么（任务分数），不报它丢了什么 | 把蒸馏重新表述为**有损投影**，并给了一个报告模板（Distillation Loss Statement：主指标 / 关键指标外能力 / 保留目标 / 压力分布 / 观测到的侵蚀） |

★ **这张表里对本目录最有用的两条**：**local teachability collapse**（老师没坏，只是"没什么可教了"——这是 1.3 节那篇没覆盖的第四种机制）和 **calibration-capability gap**（和 1.4 节的 epistemic suppression 指向同一件事：OPD 会让学生在任务分数上升的同时**丢掉元认知能力**）。

⚠️ **综述对成功条件也给了两条（Li et al. 2026j 的结论，综述 §7.1 转述，⚠️ 我没读原文）**：①**师生推理模式必须兼容**（操作化为 top-k token 分布的高重叠）—— 即使老师更强，如果**思考风格结构性不匹配**（例如用 non-thinking 老师去蒸 thinking 学生），知识也传不过去，因为**初始分布重叠太低是训练本身补不回来的**；②**老师必须能提供学生还没有的新能力** —— 同数据同配方训出来的师生在各自规模上会收敛到相似分布，反向蒸馏实验显示同族 1.5B 和 7B 老师**从学生视角看在分布上已不可区分**。

⟹ ★ **综述把这两条收成一句很好用的判据**：**OPD 的收益取决于"师生之间可被利用的落差"** —— 落差太小（同配方模型）老师没新信息；落差太大（思考模式错配）学生吸收不了。**有效区间在中间，而怎么识别这个区间仍是开放的诊断难题。** ✅ 论文（综述）§7.1

### 1.6.2 ★ 四处真正的矛盾（不和解，摆出来）

**矛盾 ①：散度方向该怎么选？三篇给了三个不同答案。**

| 来源 | 主张 | 设定 |
|---|---|---|
| 综述篇 §2.3 / §3.3 | **唯一正确答案的任务（数学、代码）用逆 KL** —— mode-seeking 把质量集中到一条解法路径上 | 外部强老师 |
| 失败模式篇 §3.1 | **截断逆 KL**（只在老师 top-K 支撑集上，且要重新归一化）—— 全词表逆 KL 太贵、单 token 逆 KL 太脆 | 外部老师（同底座 SFT 模型） |
| [02 章](02-自蒸馏.md) Self-Distilled Reasoner Table 3 | ★ **正 KL 最好**（AIME25 从 36.7 → 43.9）；**逆 KL（37.5）和 JSD（36.9）基本无效甚至变差** | **自**蒸馏：同一模型 + 特权上下文当老师 |

⚠️ **我能给出的调和，和不能给出的**：三者**不是一个设定**（外部强老师 vs 同模型带特权上下文），而"老师是不是真的比学生强"这件事会改变 mode-seeking 的意义 —— 如果"老师"只是"同一个模型多看了一眼答案"，那么去死守它的峰（逆 KL）可能恰好学到的是 1.4 节那种"被特权信息污染的自信风格"。⚠️ **这是我的推断，三篇都没有明说这个联系。** 不能据此说"自蒸馏一定该用正 KL" —— 02 章那篇的证据是**单模型（Qwen3-1.7B）单基准（AIME25）**，而 AIME25 只有 30 题。

**矛盾 ②：「输出变短」到底是好事还是坏事？**

```
SDPO 原论文（见 02 章）：  输出短 3 倍甚至 11 倍，同时准确率更高
                          ⟹ 把它当成【卖点】，叫「学会简洁推理」

退化篇（本章 1.4）：       同样的变短，在数学 OOD 上掉 40%（相对）
                          ⟹ 把它当成【病灶】，叫「epistemic suppression」

★ 这不是两篇在吵，是【同一个现象在不同任务覆盖面下的两种后果】。
   决定方向的变量是 1.4.5 节那个：训练集与评测集的任务覆盖面差多少。
```

★ **这个矛盾在文献里已经被接上了**：[02 章](02-自蒸馏.md)的 **SRPO** 那篇在讨论响应长度时**直接引用退化篇**，理由是「SDPO 过短的回答已被关联到因抑制 epistemic verbalization 而导致的推理退化」，并把"SRPO 的长度居中"当成一个好处。✅ SRPO 论文 §4.4 明确引 Kim et al. 2026 ⟹ **这两章不是我硬拉在一起的，是作者们自己接上的。**

**矛盾 ③：失败模式篇说"token 级比序列级好"，但综述说"多轮 agentic 任务需要序列级目标 + 轨迹感知的信用分配"。**

⚠️ 这两句**表面冲突、实际在说不同层面的事**（这是我的判断）：失败模式篇说的是**同一个 token 级损失的两种梯度估计量**（要不要把后续奖励耦合进来），结论是不要耦合、控方差；综述说的是**监督的语义粒度**（一个工具调用序列的成败不能摊到每个 token 上）。⚠️ 但我**没有读综述 §8**（agentic 那节的正文），所以**不能保证**这个调和是作者的原意。**不要把这条当定论。**

**矛盾 ④：OPSD 到底在干什么 —— 压缩，还是纠错？**

✅ 综述 §7.1 转述了 Kim & Lee (2026) 的一个很锋利的结果（⚠️ 原文我没读）：把 OPSD **分别**用在"只有做对的 rollout"和"只有做错的 rollout"上 ——

```
只对【做对的】rollout 做 OPSD  ⟹  准确率保住，推理轨迹显著变短
                                  = 这是【压缩】

只对【做错的】rollout 做 OPSD  ⟹  准确率【下降】
                                  = 这是【纠错失败】
```

并且三种替代解释（老师上下文更丰富、轨迹中途重新注入反馈、训练更久）**都被排除了**。⟹ ★ 综述的收口：**带后见之明的自老师能识别长思考轨迹里的冗余，但不能可靠地提供更好的替代推理步骤。** OPSD 的有效区间是"**让模型把已知的解法说得更省**"，不是"**让模型解出更难的题**"。

⚠️ 这条和 [02 章](02-自蒸馏.md)里 **SDPO 的测试时实验**看起来直接冲突：那篇报告 SDPO 在 LCBv6 的"very hard"题上 `discovery@2750` 达 53.2%，而 best-of-k 只有 41.5%，并且**有一道题只有 SDPO 解出来**；它还明确说**初始自老师在几乎所有这些题上准确率 `<1%`、78% 的题上正好 0%**。⟹ 即"老师自己解不出来，但它的信用分配仍然能把学生推到解出来"。**这看起来就是"纠错"而不是"压缩"。** ⚠️ 两者的设定差别（Kim & Lee 做的是数学 + 单次训练；SDPO 做的是代码 + 迭代式测试时自蒸馏 + 有真实环境反馈）足以解释吗？**我不知道，也没有足够证据判。02 章会把这条冲突再摆一次，不给结论。**

### 1.6.3 ⚠️ 本章的噪声门槛速查（通用纪律）

本仓库的规矩：`SE ≈ √(p(1−p)/n)`，**比这个小的差异不能当成结论**。

| n（题数） | p=0.2 | p=0.5 | p=0.8 | 本章里哪些数落在这个量级 |
|---|---|---|---|---|
| **30**（AIME24 / AIME25） | **7.3 pp** | **9.1 pp** | 7.3 pp | ★ 1.3.3 表 A 里 AIME 两列的**全部**差异 |
| **131**（LiveCodeBench v6） | 3.5 pp | **4.4 pp** | 3.5 pp | [02 章](02-自蒸馏.md)大量数字落在这里 |

## 1.7 小结：这一章能带走什么

```
① OPD 的分类坐标系是三条轴（综述篇）：
   目标函数（用哪个散度）/ 信号来源（谁当老师）/ 训练动态（怎么稳住）
   ★ 「外部 vs 自己」是方法论选择，「白盒 vs 黑盒」是部署约束 —— 两级，不平级

② 曝光偏差的量级差是【平方 vs 线性】：off-policy O(ε·T²) → on-policy O(ε·T)
   ⚠️ 但这是上界。DeepSeek-R1 纯 off-policy 蒸出 AIME24 55.5%（7B）
      ⟹ 老师足够强 + 学生足够小的时候，off-policy 就够用

③ 标准 sampled-token OPD 有三个具体的脆点（失败模式篇）：
   ① 单 token 信号结构性偏负  ② 老师在学生漂移后的前缀上失去可靠性
   ③ 特殊 token 约定错配
   ★ 最大的单项收益来自最土的补丁（掩码：36.4 → 40.7），不是来自新目标函数
   ★ 老师 top-K 单独上是【负收益】（20.4 → 17.7），必须配 top-p 才翻正
   ⚠️ 摘要那个「+19.8%」是【相对】，绝对只有 +6.9 个百分点

④ token 级 vs 序列级不是精度之争，是【偏差 vs 方差】之争：
   token 级有偏，但最坏方差 O(T²)；序列级无偏，但 O(T⁴)
   ⟹ 长程训练选 token 级控方差，然后【在 token 级内部】改善信号质量

⑤ ★★ 自蒸馏退化的机制是【老师的风格被它的特权上下文污染】：
   给老师的信息 I(y*;c|x) 越大 ⟹ 回答越短、不确定性表达越少
   （13,054 token / 182.5 个 epistemic token  →  1,873 / 8.8）
   ⟹ 用这种回答当 SFT 目标，等于让模型模仿一种
      【预设了推理时拿不到的信息】的说话方式
   ★★★ 800 条【全部答对】的轨迹，能把 7B 推理模型在 AIME24 上
        从 54.79 打到 20.21。换成另外 800 条同样全对但啰嗦的，基本不掉。
        ⟹ 「数据正确」≠「数据可学」

⑥ ★ 决定「有增益还是退化」的第二个变量是【任务覆盖面】：
   化学 2,400 题只有 6 类题型、LCB v6 的 131 题训练评测同一批
   ⟹ 泛化要求低 ⟹ 删掉不确定性表达换效率是赚的
   DAPO-Math 14,000 题、评测在训练集外 ⟹ 泛化要求高 ⟹ 同样的操作亏
   ★ GRPO 的 OOD 随训练题量【变好】，SDPO 始终【低于基座】—— 方向相反

⑦ 自蒸馏还会【自我放大】：移动的老师（EMA 0.05）比钉死的老师（EMA 0.0）更糟
   更自信的学生 → 当老师 → 目标更自信 → 学生更自信 …… 每轮放大一次
   ⟹ 这就是综述叫 self-play saturation / Ouroboros 的那个东西

⑧ ⚠️ 四处矛盾没有和解，也不该和解：
   散度方向（逆 KL / 截断逆 KL / 正 KL，三篇三答案）
   「输出变短」是卖点还是病灶（取决于任务覆盖面）
   token 级 vs 序列级（⚠️ 我的调和未经作者确认）
   OPSD 是压缩还是纠错（⚠️ 证据直接冲突，不给结论）
```
