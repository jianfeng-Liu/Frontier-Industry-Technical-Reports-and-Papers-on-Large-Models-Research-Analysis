03 · 特权信息蒸馏：用「老师看得见、学生看不见」的信息差来教

一句话：训练时给模型一份它在推理时拿不到的材料（标准答案、专家动作序列、解法前缀），让它先把题做对；然后想办法把「做对的那套本事」转移到没有这份材料的自己身上。

本章关键词

特权信息（privileged information，PI） —— 只在训练时提供、推理时一定不给的额外输入。可以是标准答案、专家的动作序列、解法的前半段。⚠️ 这个词来自 Vapnik & Vashist 2009 的 LUPI（Learning Using Privileged Information，利用特权信息学习）框架，三篇论文都引了同一个出处。

不对称（asymmetry） —— 本篇全部机制的来源：训练时给、推理时不给。如果推理时也给，那叫「加提示词」，不是特权信息。

OPD（On-Policy Distillation，在策略蒸馏）—— 学生自己采样、老师逐 token 打分。基础见 后训练/08。

OPSD（On-Policy Self-Distillation，在策略自蒸馏）—— OPD 的一个特例：老师和学生是同一份权重，只是输入不同（老师的输入里有特权信息）。⚠️ 2026 年至少有四组人各自独立提出了同一个目标函数，π-Distill 那篇在脚注 1 里点名了三组（✅ 论文 §3.1 脚注 1）。

KL 散度（Kullback-Leibler divergence）—— 衡量两个概率分布差多远。

逆 KL（reverse KL） —— 指 KL(学生 ‖ 老师)，寻峰（mode-seeking）：学生只要挑老师的一个高概率模式钻进去就能把它压小。

正 KL（forward KL） —— 指 KL(老师 ‖ 学生)，覆盖质量（mass-covering）：学生必须把老师所有有质量的地方都盖住。

JSD（Jensen-Shannon Divergence，JS 散度）—— 介于正逆 KL 之间的对称散度，偏覆盖。HDPO 用它而不是逆 KL，理由见 3.3。

sg[·]（stop-gradient，停止梯度）—— 只取数值、不回传梯度。

GRPO（Group Relative Policy Optimization，组相对策略优化）—— 三篇的 RL 底座都是它。细节见 后训练/05。

cliff prompt（悬崖提示） —— HDPO 的叫法：一道题采 G 次全错，GRPO 的优势全为 0，梯度精确为零。⚠️ 这就是 后训练/05 讲过的「优势归零 / 退化组」，只是换了个名字。

ray interference（射线干扰） —— POPE 的核心诊断：同一批训练里混了易题和难题时，on-policy RL 会优先在已经能拿到奖励的题上继续优化，反过来压住难题的进展。✅ 概念出自 Schaul 等人的多任务 RL 工作（POPE 论文 §3.2 引为文献 [32]）。

CoT（Chain-of-Thought，思维链）—— 模型的中间推理过程。

SFT（Supervised Fine-Tuning，监督微调）—— 对着标准答案做下一词预测训练。

pass@k —— 采 k 次里至少有一次对的概率。⚠️ 它有三种算法，其中插值估计量是有偏的，见 后训练/05。

realizability gap（可实现性差距） —— 学生的分布族里最好的那个离老师还有多远。HDPO 的命题 1 就是在说这个。

3.1 先把「特权」这个词钉死

定义：不对称才是关键

读这三篇之前必须先分清三件很像但完全不同的事：

做法 推理时还有吗 是不是特权信息
加提示词 / 系统提示 在输入里写「请一步步想」 ✅ 还在，推理时照样给 ✗ 不是。没有不对称
RAG 检索增强 检索到的文档拼进上下文 ✅ 还在，线上也要检索 ✗ 不是。线上成本更高而已
★ 特权信息（PI） 训练时把标准答案 / 专家动作 / 解法前缀拼进输入 ✗ ★ 一定没有。线上拿不到标准答案 ✅ 是

所以「特权」不是指信息有多好，而是指这份信息在训练和推理两个时刻的「有无」不一样。 整篇的全部技术难度都压在这一个落差上：一个在有答案时能做对的模型，怎么在没答案时也做对。

训练时（有特权）
├── 输入：题目 ＋ 标准答案 / 专家动作 / 解法前缀
└── 结果：模型能做对

推理时（无特权）
├── 输入：只有题目
└── 要求：模型【仍然】要能做对     ← ★ 全部难点在这里

⟹ 这三篇论文都在回答同一个问题：
   上面那一组里学到的本事，怎么搬到下面那一组？

为什么非要绕这一圈：直接用答案做 SFT 不行吗

这是最自然的质疑，而且三篇论文全部正面回答了，答案都是「不行」，这一点很重要，因为它是整条路线存在的理由：

谁说的 怎么说的 出处
POPE 对人写的标准解法做多轮 SFT 会背下来，得到一个低熵的初始化，后续 RL 探索不动；早停避免背诵，又得到一个高熵初始化，两边的风格都产不稳 ✅ 论文 §4「Limitations of training on oracle solutions」
POPE（数据） 「Full-oracle SFT」在难题集上把 pass@1 从 13.55 打到 2.00、pass@16 从 32.89 打到 12.37，AIME 2025 的 pass@1 从 49.58 掉到 33.89 ✅ 论文 Table 2
π-Distill 把特权条件化的策略先训好、再蒸馏给无条件策略的两段式流水线，存在「该蒸哪个 checkpoint」「从它的轨迹学是 off-policy、不稳」「分开训两个策略算力低效」三个问题 ✅ 论文 §3.1「Motivation」
HDPO 没有外部解法可用时，模型自己在看到答案后生成的轨迹就是最合适的目标，因为它和学生共享权重，分布差距有界 ✅ 论文 §3.1

⚠️ POPE 给出的那个 13.55 → 2.00 是全篇最刺眼的数字：拿标准答案直接做 SFT，比什么都不做（基座 0.57）只强一点点，比纯 RL（13.55）差了一个数量级。论文的解释是「标准解法的推理风格和模型自己的推理风格根本不同，克隆这种 off-policy 数据会破坏模型本来的推理能力」（✅ 论文 §6 Result 4）。

这条和基础篇是一脉相承的：后训练/08 讲过 off-policy 蒸馏的病根是曝光偏差——学生只在老师的正确前缀上被训练过。这里是同一个病，只是「老师」换成了人类写的标准解法，而人和模型的推理风格差得更远，所以病得更重。

3.3 三篇各自的机制，逐条拆开

① π-Distill：两个目标函数，一个 α 旋钮

核心设计：老师 π_T(o|s,I) 和学生 π_S(o|s) 是同一份参数 θ，区别只在输入里有没有特权信息 I。两者同时训。

老师目标（✅ 论文 §3.1 式 (2)）：

J_老师(θ) = E_{o~π_T(o|s,I)} [ R(o,s) ]  −  β · KL( π_T(o|s,I) ‖ sg[π_S(o|s)] )

├── 第一项  E_{o~π_T}[ R(o,s) ]        从【老师】采样，最大化奖励
└── 第二项  β · KL( π_T ‖ sg[π_S] )    逆 KL，把【老师】拉回【学生】够得着的地方

学生目标（✅ 论文 §3.1 式 (3)）：

J_学生(θ) = E_{o~π_T(o|s,I)} [ (π_S(o|s) / sg[π_T(o|s,I)]) · R(o,s) ]  −  β · KL( sg[π_T] ‖ π_S )

├── 轨迹由【老师】采，但被更新的是【学生】
├── 所以要除以 sg[π_T(o|s,I)] 做重要性修正
└── 第二项的 KL 方向：sg[π_T] 在前、π_S 在后

合起来（✅ 论文 §3.1 式 (4)）：J = α·J_老师 + (1−α)·J_学生，α ∈ [0,1]。

α 的三个档位在干什么（✅ 论文 §3.1）：

α 谁在被显式更新 另一边靠什么改善
1 只有老师 学生靠共享参数被动受益
0 只有学生 老师不被更新，就是个固定的数据源
0.5 两边都更新 ——

★ 老师目标里那个逆 KL 的方向值得单独说：它把老师往学生那边拉，不是反过来。论文给的两个理由（✅ 论文 §3.1）：(i) 让老师去拟合那些学生已经熟悉的高奖励模式，这样学生学起来容易；(ii) 共享参数本身就在促进知识转移。⚠️ 这和常规蒸馏的直觉是反的——常规蒸馏是把学生往老师那边拉。这里是主动给老师「降智」到学生够得着的范围，否则老师越强、学生越学不会。

OPSD（论文的第二个方法，✅ 论文 §3.2 式 (5)）：

J_OPSD(θ) = E_{o~π_S(o|s)} [ R(o,s) ]  −  β · KL( π_S(o|s) ‖ sg[π_T(o|s,I)] )

├── 第一项  从【学生】π_S 采样 ⟹ 这才是 on-policy
└── 第二项  逆 KL，当作逐 token 的密集奖励

⚠️ π-Distill 和 OPSD 的根本差别是「谁在采样」：π-Distill 从老师采样（所以是 off-policy，学生在学别人写的句子），OPSD 从学生采样（on-policy）。这正是 后训练/08 里那条分界线，只是这里的「老师」碰巧和学生同权重。

✅ 论文 §3.2 明说 OPSD 的逆 KL 项「acts as a dense per-token reward」——和基础篇里那个「老师当免费的逐 token 稠密奖励模型」是同一句话。

② HDPO：只在「悬崖」上开一盏灯

它要解决的问题极其具体：GRPO 下一道题采 G 次，三种结果——全对（优势全 0）、有对有错（正常学习）、全错（优势全 0，梯度精确为零）。第三种就是 cliff（✅ 论文 §2.3）。

⚠️ 这个问题在 后训练/05 里叫优势归零，那一章给过退化组概率 p^G + (1−p)^G。把 HDPO 的参数代进去可以自己验算一遍：

0.05 0.4401 ≈0 44.0%
0.10 0.1853 ≈0 18.5%
0.30 0.0033 ≈0 0.3%

⚠️ 这张表是我按 HDPO 的 G=16（✅ 论文 §4.1）自己算的，论文没有给这张表。读法：真正的悬崖是左上角那一块——p 低到 0.05 时，一道题有 44% 的概率整组全错，梯度直接是零。HDPO 要抢救的就是这一块。

HDPO 的三步（✅ 论文 §3.2、算法 1）：

每一步训练：
├── 跑标准 GRPO，拿到 L_GRPO
├── 挑出悬崖题          C = { x ∈ batch : Σ_k R(x, y^(k)) = 0 }
├── 对每道悬崖题
│   ├── 把标准答案拼进提示词，生成特权 rollout   ȳ ~ π_θ(· | x ⊕ y*)
│   └── 【只保留答对的】                          T = { (x, ȳ) : R(x, ȳ) = 1 }
├── 在 T 上算逐 token 的 JSD 蒸馏损失 L_JSD
└── 一起更新：  L_HDPO = L_GRPO + λ · L_JSD

★ 为什么用 JSD 而不是逆 KL：✅ 论文 §2.5 给了明确理由——引用 DPH-RL 发现的多样性坍缩问题，逆 KL 是寻峰的，会让策略集中到单个模式，pass@1 涨但 pass@k 掉；JSD 是覆盖质量的，能把学生的支撑集撑开。而 HDPO 的实验结果恰好验证了这一点：它涨的是 pass@4 / pass@8，pass@1 基本不动甚至下降（见 3.6）。⚠️ 这是一个目标和结果自洽的例子，但也意味着：如果你要的是 pass@1，HDPO 不是你要的东西。

工程细节（✅ 论文 §3.2）：JSD 用老师 top-k（k=64） 的 logits 重新归一化来近似；学生落在 top-k 之外的那部分质量有一个精确的尾部修正项 P_rest · ln2。⚠️ 为什么是 ln2：JSD 的取值上界就是 ln2（以 e 为底），把 top-k 之外的质量全部按最坏情况记上界——这是我的推断，论文只给了式子没给理由。

两条命题（✅ 论文 §3.4）：

命题 说了什么 ⚠️ 怎么读
命题 1（可实现性差距） 同一份权重的师生，KL(P_老师 ‖ P_学生) ≤ L_θ²·Δ(g)²/2，L_θ 是模型 logit 函数的局部 Lipschitz 常数，Δ(g) 是特权信息造成的输入空间距离。跨模型蒸馏的界多一项模型失配项 ‖f_φ(c_T) − f_θ(c_T)‖_∞ ⚠️ 论文自己说得很诚实：「贡献不是这个界本身，而是这个对比」（✅ 论文 §3.4 "Relation to prior work"）。界本身是 softmax 在 logit 扰动下的标准结论。⚠️ 而且 L_θ 和 Δ(g) 两个量论文没给任何数值估计，所以这个界没法用来算具体数
命题 2（R=1 过滤的意义） 对二值奖励，KL 正则化 RL 的最优解是 π* ∝ π_ref·exp(R/β)；当 β→0⁺，π* 收敛到 π_ref(·\|R=1)，而按 R=1 拒绝采样恰好就能得到它 ✅ 这一条站得住，是 DPO 那套推导的直接推论。⚠️ 但论文自己点明了两处偏离：代理参考分布 π_priv 替掉了 π_ref（差距由命题 1 兜）；难题上特权通过率远低于 1，引入采样噪声（✅ 论文 §3.4 末段）

★ HDPO 和 π-Distill 的关系，论文自己讲清楚了（✅ 论文 §3.4 末段）：π-Distill 的老师目标 E[R] − β·KL(π_T ‖ sg[π_S]) 和 HDPO 是同一个结构（取 π_ref = sg[π_S]）。差别是：π-Distill 在有限 β 下用梯度上升在所有题上优化它；HDPO 用硬性 R=1 过滤机械地实现 β→0 的极限，并且只在悬崖题上启动。这是两篇论文之间最干净的一条连接线，而且是 HDPO 自己写的，不是我推的。

③ POPE：不教答案，只教「从哪儿开始走」

POPE 的诊断部分比方法部分更有价值，先看它排除了什么（✅ 论文 §3）：

试过的办法 结果 论文给的机制解释
熵奖励 + KL 惩罚 ✗ 可解题比例和朴素 RL 几乎一样，而且熵在训练早期爆炸、之后恢复不了 ✅ 论文 §3.1 + 图 3
放大 ε_high（DAPO 式的 Clip-Higher） ✗ 熵同样上升（论文说这有点出乎意料），可解题比例没有实质改善 ✅ 论文 §3.1 + 附录 A：用重要性采样策略梯度去拟合罕见正样本，一步梯度既降低了基座偏好 token 的置信度、又没把正样本拟合好，不确定性反而上升，滚雪球式熵爆炸
混入易题指望迁移 ✗ 不但没帮上，混入「更易」的题反而让可解难题更少 ✅ 论文 §3.2：ray interference
直接优化 pass@k ✗ k 越大越差，pass@k（可解性）和平均 pass@1 都掉 ✅ 论文 §3.2：pass@k 是 per-problem pass@1 的单调函数，难题上 pass@1 近似为 0 时它没有任何可优化的东西；而且它会把奖励重新分配给错误轨迹以鼓励多样性，缩小正负样本的奖励差

⚠️ 「混入易题会害了难题」这条是反直觉的，而且 POPE 用一个只有两道题的玩具实验做了隔离（✅ 论文 §3.2 图 5）：一道易题 + 一道难题。混入一道语义不相关的易题（按基座模型文本嵌入的余弦相似度挑最低的），难题的收敛比只训难题还慢；混入相关的易题能部分缓解但仍然低效。⚠️ 关键控制：相关易题、不相关易题、引导变体三者在基座模型下的成功率是配平的，所以差异不是难度造成的。

POPE 的做法（✅ 论文 §4 式 (3)）：

给一道难题 x 和它的人写解法 z：
├── 取 z 的一段前缀  z_0:i
├── 配一条系统指令 I：「这是题目和一份部分解答，请研究它已经做了哪些推理，
│                      然后从它停下的地方接着往下解」
├── 构造引导变体     D_guided = { concat(x, z_0:i, I) | x ∈ D_hard }
└── 在 D_hard 和 D_guided 的 【1:1 混合】 上跑 GRPO

★ 前缀长度怎么定（✅ 论文 §4）：不是拍脑袋。对每道题，用粗粒度均匀间隔的若干候选前缀去试，挑能让基座模型采出至少一条成功轨迹的最短前缀。如果所有前缀都试不出成功轨迹，就随机取一个短于解法 1/4 的前缀。⚠️ 论文给的理由很实在：前缀太长就把题做掉了大半，学到的东西没法迁移到无引导的情形。

⚠️ 和 Amani 等人的工作对比，POPE 特意说明：对方（非推理模型、短回答）需要自适应调整前缀长度的课程，而 POPE 不需要，因为长 CoT 模型的回溯和复查行为天然提供了覆盖（✅ 论文 §7 "Most related prior works"）。

3.4 ★★★ 推理时拿不到特权信息，学生到底学到了什么

这是本篇唯一一个「必须问、而且三篇答得深浅差很多」的问题。 常见的糊弄答案是「学到了在没有特权信息时也该走的推理路径」——这句话不算错，但它什么机制都没说。下面按「论文自己说到什么程度」排序。

三篇的回答，按可信度排序

篇 它的回答 证据类型 ⚠️ 我的评价
★★★ POPE 缝合（stitching）：引导前缀把模型推进一组「从这儿出发能稳定拿到奖励」的状态 S_good；RL 在这些状态上学会了「续写策略」；而长 CoT 模型的回溯与自我复查会在引导 rollout 里回访到靠近题目开头的状态，于是有引导和无引导两套状态访问分布产生了重叠；学生剩下要做的只是「走到 S_good」，而不是「从零发现 S_good 并且还要会解」 ✅ 因果干预实验（见下） ✅ 三篇里唯一做了因果验证的。可信

★ POPE 的因果干预：本篇最有说服力的一个实验

✅ 论文 §5.2。做法是改一条系统指令，把原来的「研究这段部分解答，从它停下的地方接着写」改成：

你的任务是推断已经完成了哪些推理，并【不得重复、改写或引用】部分解答的任何内容

重要：静默地使用部分解答里的信息。不要复制、改写或明确提及其中任何内容。

结果（✅ 论文 §5.2 + 图 9）：

改指令之后：
├── 【有引导】那一侧的表现   ↑ 变好   ← 合理：禁止复述让条件化之后的 RL 问题更简单
└── 【无引导】那一侧的 pass@32 ↓ 变差  ← ★ 这才是关键

⚠️ 为什么这个结果是因果证据：如果学生学到的只是「一套和引导无关的通用解题能力」，那禁不禁止复述引导内容不该影响无引导侧的成绩。实际是有引导侧更好、无引导侧更差——说明转移这件事确实依赖于「模型在引导 rollout 里回头复述 / 重算引导内容」这个行为。论文把这个行为叫做制造「重叠」，干预把重叠掐掉，转移就跟着掉。

✅ 论文 §5.2 还给了定性证据（Table 1）：默认指令训出来的模型，在无引导的解答里会出现引导里才有的概念和中间步骤（用了不等式结构、用了循环下标、用了 λ = max S 这个想法）；修改指令训出来的那个，无引导解答走了一条完全不同的路，几乎不复用引导里的概念。

把三篇的答案合成一句话

⚠️ 下面这段是我的综合推断，不是任何一篇的原话：

三篇都没有真的「把特权信息压进权重」，它们做的是让模型在一个「本来采不到的状态分布」上获得经验，再利用这个状态分布和原始状态分布的重叠把经验接回去。

  • POPE 的重叠来自回溯行为（已验证）；
  • π-Distill 的重叠由初始 KL 直接度量——初始 KL 越大，重叠越小，转移越差（✅ 论文 §7.1 的主要发现之一就是「初始 KL 升高，最终表现普遍下降」）；
  • HDPO 则是用共享权重把重叠做到结构上：师生同参数，命题 1 说差距只剩特权信息本身造成的那一项。

⟹ 所以三篇的「特权」其实都不是在传递内容，而是在改变采样落点。

⚠️ 三篇都没回答的一个问题：答案泄漏

老师在看到标准答案之后写出来的推理链，有没有可能是「从答案倒推」的？ 比如 HDPO 把 y* 拼进提示词之后生成的轨迹，模型完全可能写出「我们验证一下 42 是否满足条件……成立，所以答案是 42」这种只有已知答案才写得出来的步骤。学生去拟合这种轨迹的逐 token 分布，学到的可能是一个在没有答案时根本走不通的模式。

篇 有没有防这一手
HDPO ⚠️ 正文没有讨论。R=1 过滤只保证答案对，不保证推理路径不依赖答案。命题 1 界的是分布距离，不是「路径可复现性」
π-Distill ⚠️ 部分地规避了：它的 PI 是前沿模型的动作序列，不是标准答案；而且任务是多轮工具调用，动作要在环境里真的执行才拿得到奖励
POPE ✅ 结构上躲开了：前缀只是解法的前半段，后半段仍要模型自己推；而且 POPE 从不把 oracle 内容当训练目标

⚠️ 以上是我的推断，三篇正文都没有专门做「答案泄漏」的消融。 如果要复现 HDPO，这是我会第一个去查的地方。

3.5 POPE 和 RLVR 那个死穴的连接

先把死穴摆出来

后训练/05 讲过：GRPO 一道题采 G 次，全对或全错时组内优势全为零，梯度精确是零。退化组概率是 p^G + (1−p)^G。难题上 p ≈ 0，于是 (1−p)^G ≈ 1——几乎必然退化。

这不是工程 bug，是组相对优势这个设计的直接推论：优势是「减去组内均值」，组内所有样本奖励相同时均值就等于每一个，差值当然是零。

工业界原来的三条路，和 POPE 的第四条

路线 代表 对难题做了什么 ⚠️ 代价
① 丢掉 DAPO 的动态采样、zero-variance 过滤 跳过退化组，补采到够 ✗ 难题被永久丢弃。POPE §1 直接点名：「常见的吞吐导向启发式，比如动态采样和零方差过滤，进一步把这些题显式丢掉」
② 指望迁移 易题到难题的课程 混入易题，希望能力外溢 ✗ POPE §3.2 的负面结论：ray interference，混易题后难题 pass@32 反而更早进入平台期、收敛到更低的渐近值
③ 强行探索 熵奖励、Clip-Higher、直接优化 pass@k 从分布层面推高多样性 ✗ POPE §3.1 三条全部试过，全部失败，而且熵爆炸
★ ④ 改采样落点 POPE（也包括 HDPO 的悬崖分支） 用特权信息把 rollout 的起点挪到能拿到奖励的地方 ⚠️ 需要数据集自带人写解法 / 标准答案

★ 第四条路的要害：前三条都在同一个状态分布里折腾（丢掉它、绕过它、把它摊平）；POPE 换的是状态分布本身。✅ 论文 §4 用经典 RL 的话讲得很准："learning from on-policy actions from off-policy states"——状态是离策略的（题目被人写的前缀污染过），但动作是在策略的（rollout 是模型自己写的）。这正是「Lightning OPD 那个 offline / on-policy 矛盾」的近亲，见 04。

★ 所以 POPE 真正被数据支撑的是什么：不是「刷榜涨了多少」，而是 ★ 「在混入大量易题之后，难题上的学习不塌」。看最后两组对比——混进 1000 道易题之后，无引导那一组的难题 pass@1 从 13.55 崩到 2.24（ray interference 把难题的学习彻底压死了），而带引导那一组仍然保持 13.98。11.74 个百分点、接近 4 倍噪声门槛、而且机制解释（ray interference）有独立的玩具实验支撑。这是本篇里证据链最完整的一条。

3.7 这一篇的五句话总结

① 「特权」= 训练时给、推理时不给。 不对称是全部机制的来源；推理时还在的东西（提示词、RAG）都不算特权信息。

② 直接拿标准答案做 SFT 是最差的一条路，而且有一手数据。 ✅ POPE Table 2：Full-oracle SFT 把难题 pass@1 从 13.55 打到 2.00，把 AIME pass@1 从 49.58 打到 33.89。病根和 后训练/08 讲的曝光偏差是同一个，只是「老师」换成了风格差异更大的人类解法。

③ 三篇对「学生学到了什么」答得深浅差很多，只有 POPE 做了因果验证。 ✅ 改一条禁止复述引导内容的系统指令，有引导侧变好、无引导侧变差——说明转移依赖「模型在引导 rollout 里回头复述、重算」这个具体行为。⚠️ π-Distill 回答的是「什么时候能转移」（初始 KL 要小、PI 效用要为正），不是「转移了什么」；HDPO 只有「pass@k 涨而 pass@1 不涨」这个间接自洽。⚠️ 三篇都没有做答案泄漏的消融，这是我会第一个去查的空白。

④ 三篇的「%」是三种口径，混读必错。 π-Distill 和 HDPO 写的「%」其实是百分点，POPE 写的是相对提升。POPE 那个 +524% 的绝对值只有 11.74 个百分点。

⑤ 按噪声门槛筛一遍，真正站得住的结论只剩三条。 ✅ Travel Planner 上 Qwen3-8B 做 π-Distill 后追平 671B 的 DeepSeek V3.1（44.1 vs 45.0，+11.8 pp 超基线）；✅ POPE 在混入 1000 道易题后仍把难题 pass@1 保在 13.98 而对照组崩到 2.24（+11.74 pp，≈3.8 倍门槛）；✅ 直接 SFT 标准答案会造成崩塌。⚠️ HDPO 的全部 pass@4 提升都在噪声门槛之下，只有 λ=0.1 的 pass@8（+1.4~1.7 pp）勉强越线——而且论文附录 D 自己承认了这一点。
