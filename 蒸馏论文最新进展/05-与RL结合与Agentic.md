**本章关键词**（每个缩写第一次出现给中英文全称，不靠上下文猜）

**RL**（Reinforcement Learning，强化学习）—— 模型自己生成，环境给一个分数，再按分数调整。

**KD**（Knowledge Distillation，知识蒸馏）—— 大模型（老师）教小模型（学生）。

**OPD**（On-Policy Distillation，在策略蒸馏）—— 学生自己采样，老师在**学生写出来的每个 token 上**给方向。基础见 [后训练/08](../后训练/08-蒸馏与合并-OPD.md)，本章不重复。

**MOPD**（Multi-teacher On-Policy Distillation，多教师在策略蒸馏）—— 多个老师依次（或混合）教同一个学生。

**KL 散度**（Kullback-Leibler divergence，KL 散度）—— 量两个概率分布差多远。

**逆 KL**（reverse KL）—— 指 `KL(学生 ‖ 老师)`。**三篇论文里的蒸馏项全都是逆 KL**，方向别搞反。

**RLVR**（Reinforcement Learning with Verifiable Rewards，可验证奖励强化学习）—— 奖励来自能机器判对错的检查器（数学答案、单元测试），不是来自打分模型。见 [后训练/05](../后训练/05-RLVR-可验证奖励.md)。

**GRPO**（Group Relative Policy Optimization，组相对策略优化）—— 对同一道题采 G 个答案，用**组内平均分**当基线算优势，省掉价值网络。三篇论文的共同基线。

**PPO**（Proximal Policy Optimization，近端策略优化）—— GRPO 的前身，核心是**重要性比值 + 裁剪（clip）**。

**trust region**（信赖域）—— 「这一步别迈太大」的约束。PPO/GRPO 用 clip 实现。

**importance ratio**（重要性比值）—— `新策略给这个 token 的概率 ÷ 旧策略给这个 token 的概率`。用旧策略采的样去估新策略的梯度，就要乘这个比值做修正。

**advantage**（优势，记作 A）—— 「这条轨迹比平均水平好多少」。正数表示该加强，负数表示该抑制。

**ORM**（Outcome Reward Model，结果奖励模型）—— 只看最终答案对不对，整条轨迹一个分。

**PRM**（Process Reward Model，过程奖励模型）—— 对中间每一步打分。

**credit assignment**（信用分配）—— **本章第三篇的主题**：一条 50 步的轨迹最后失败了，该怪哪一步？

**multi-turn**（多轮）/ **long-horizon**（长程）—— 多轮 = 模型和环境来回交互多次；长程 = 一个任务要很多步才能完成。两者常一起出现，但不是一回事。

**rollout**（采样轨迹）—— 模型自己跑一遍生成的完整序列。

**mode seeking**（寻峰）/ **mode covering**（覆盖）—— 逆 KL 让学生**挤到老师分布的一个峰上**（寻峰），正向 KL 让学生**摊开覆盖老师所有峰**。第三篇用这个解释 MOPD 的行为。

**pass@k / avg@k**（又写作 mean@k）—— 采 k 次，**至少一次对** = pass@k；**k 次的平均正确率** = avg@k（等价于 Pass@1 的无偏估计）。⚠️ 这两个指标在本章里会打架，5.6 节专讲。

PlanPhys 认为**在长程任务里 RL 的信用分配根本就是坏的**——与其修奖励，不如直接用老师的逐 token 分布当监督，接受「上限 = 老师」这个代价。

## 5.2 RLAD：「reinforcement-aware」到底 aware 了什么

### 5.2.1 先回答标题里那个问题

**「蒸馏时知道 RL 的什么信息？」—— 答案是：知道这个 token 的 advantage（优势）是正是负。** ✅ 论文 §4 开篇把这件事说得很直接：KDRL 那类方法的 KL 正则项「is independent of the estimated advantage」（与估计出的优势无关），所以老师的影响是**均匀施加**的，包括在老师的行为和高奖励轨迹不一致的地方。

把这件事摊开来看：

```
传统做法（论文称为 KDRL，Xu et al. 2025）：
  总目标 = GRPO 的奖励项  −  beta * KL(学生 || 老师)
                              ^^^^^^^^^^^^^^^^^^^^^
                              这一项不看 advantage。
                              不管这个 token 是好是坏，
                              都往老师那边拽同样的力。

  两个后果（论文 §1 列的）：
  ├── 后果一：两项打架。beta 调大了压死奖励，调小了蒸馏没用。
  │            超参敏感，要仔细配平。
  └── 后果二：学生自己写的轨迹，可能落在老师的低概率区。
               老师在那里本来就没什么意见，KL 的监督信号很弱。

RLAD 的做法：
  不加这一项。把老师塞进【重要性比值的分母】里。
  advantage 乘在外面 ==> 老师的影响自动被 advantage 调制。
```

### 5.2.2 ★★★ TRRD 的机制：一个公式，三种情形

**TRRD** = **Trust Region Ratio Distillation**（信赖域比值蒸馏），是 RLAD 的核心组件。✅ 论文 §4.1 式 (3)：

```text
r_TRRD(θ)  =  [ π_S(y_t) / π_S,old(y_t) ]^α  *  [ π_S(y_t) / π_T(y_t) ]^(1−α)

             \________ GRPO 原本的比值 ______/    \___ 对老师的比值 ___/
```

把它整理一下，就能看出它在干什么 ✅（论文 §4.1「TRRD as a Trust-Region Update」）：

```text
令  r_mix(y_t)  =  π_S,old(y_t)^α  *  π_T(y_t)^(1−α)      <== 混合锚点

则  r_TRRD      =  π_S(y_t) / r_mix(y_t)
```

**一句话：PPO 原本把信赖域的中心放在「上一版自己」，TRRD 把中心挪到「上一版自己和老师的几何加权平均」。** 其余一切（clip、advantage、梯度）原封不动。

**为什么这就叫 selective imitation（选择性模仿）？** ✅ 论文 §4.1 最后一段把梯度拆成三种情形。下面这张表是对那一段的逐条还原，**你可以对着 clip 的上下界 [1−ε, 1+ε] 自己验算**：

| advantage | 老师对这个 token 的态度 | 混合锚点 r_mix | 比值 `π_S/r_mix` 碰到 clip 边界的时机 | 实际效果 |
|---|---|---|---|---|
| **A > 0**（该加强） | 老师也觉得这个 token 好（π_T 大） | **变大** | 分母大了，比值涨得慢 → **更晚**碰到 1+ε | ✅ **允许学生把概率提得更多** |
| **A > 0**（该加强） | 老师觉得这个 token 不好（π_T 小） | **变小** | 分母小了，比值涨得快 → **更早**碰到 1+ε | ✅ 即使 advantage 是正的，**也只准小幅提升** |
| **A < 0**（该压制） | 老师觉得这个 token 好 | **变大** | 下界 1−ε 对应的 π_S 降幅**变小** | ✅ **不准学生猛砍老师喜欢的动作** |
| **A < 0**（该压制） | 老师觉得这个 token 不好 | **变小** | 下界对应的降幅**变大** | ✅ 奖励和老师都反对 → **准许大力压制** |
| **A ≈ 0** | 无所谓 | 无所谓 | 整项趋近于 0 | ✅ **老师的影响消失**（奖励信号没信息时不乱动） |

★ **这五行就是「reinforcement-aware」的全部含义**：老师不提供独立的梯度方向，它只改变「这一步最多能迈多大」。**方向永远由 advantage 决定。**

✅ 论文 §5.2.3 的弱老师消融正好验证了这个设计意图：用 Qwen3-0.6B 当 Qwen3-1.7B 的老师（老师比学生弱），RLAD 的逻辑推理 Avg 是 0.946，GRPO 是 0.950，**几乎没掉**；而 KDRL 掉到 0.910（论文 Table 5）。论文给的解释是：「the teacher shifts the trust-region center and clipping thresholds, but does not introduce an independent gradient term that can dominate the advantage direction」（老师挪动信赖域中心和裁剪阈值，但不引入一个能压过 advantage 方向的独立梯度项）。

### 5.2.3 ⚠️ 一处论文自己写反了：α 的方向

**这是本章我最想让你记住的一个「别抄错」。**

论文 §4.1 正文写着：「When α = 0, TRRD recovers standard GRPO; when α = 1, the trust region is fully teacher-anchored」（α=0 退化成标准 GRPO；α=1 完全锚定老师）。

**⚠️ 这句话和它自己的公式 (3) 相反。** 把 α=1 代入式 (3)：指数 `1−α = 0`，老师那一项整个变成 1，只剩 GRPO 的比值 —— 所以 **α=1 才是 GRPO**。

✅ 而论文**附录 C** 写的是正确的：「When α = 1, the anchor collapses to the student old policy and TRRD reduces to standard GRPO... as α→0, the anchor approaches the teacher」。附录 C 和公式一致。

| 来源 | α = 1 是什么 | α = 0 是什么 | 和公式 (3) 一致吗 |
|---|---|---|---|
| 论文 §4.1 正文 | 完全锚定老师 | 标准 GRPO | ✗ **不一致** |
| 论文 公式 (3) | 标准 GRPO | 完全锚定老师 | —— |
| 论文 附录 C | 标准 GRPO | 趋近 DPO 式的模仿 | ✅ 一致 |

⚠️ **结论（我的判断）：以公式 (3) 和附录 C 为准，§4.1 正文那一句是笔误。** 实验里固定用 α = 0.5（✅ 论文 §5 和附录 A），所以这个笔误不影响实验结果，但影响你复现时的理解方向。

**顺带一个实用细节** ✅ 论文附录 B：光靠 clip 还不够。训练早期老师和学生差太远，`π_S/π_T` 会炸出极端值，所以他们**额外**把 `log(π_S/π_T)` 硬截断到 `[−1, 1]`。⚠️ 这条在正文和伪代码里都没提，只在附录 B，复现时很容易漏。

```text
估计量  =  (1/30) * sum_i  p_i_hat          p_i_hat 是第 i 题 32 次采样的正确率

Var  ≈  Var(p_i) / 30

最坏情况（每题要么全对要么全错，p_i 取 0 或 1，整体均值 0.43）：
  Var(p_i)  ≤  0.43 * 0.57  =  0.245
  SE        ≤  sqrt(0.245 / 30)  =  sqrt(0.00817)  =  0.090   ==>  约 9.0 个百分点
```

⚠️ **也就是说：AIME24 上 Pass@1 从 37.7 涨到 47.8（+10.1 点），只有约 1.1 倍的单侧标准误上界。** 而论文**只跑了一次训练**——它报的 STD@32（Table 8）是**解码方差**，论文自己也写明「this is not multi-seed training variance」（这不是多种子训练方差）✅。所以 AIME 上的单点差距**不足以单独支撑结论**。

## 5.3 Text Feedback：把「为什么错」救回来

### 5.3.1 论文开场那句话值得抄下来

✅ 论文摘要第一句：「The success of RL for LLM post-training stems from an unreasonably uninformative source: **a single bit of information per rollout** as binary reward or preference label.」（RL 后训练的成功，来自一个**信息量少得不合理**的来源：每条轨迹只有一个比特。）

**这就是全篇的出发点。** 把它和蒸馏并排放，就看出中间那块空白：

```
信息密度从低到高：

标量奖励 / 偏好标签
├── 每条轨迹 1 bit
├── 便宜、可规模化
└── 丢掉了【为什么错】和【怎么改】

文本反馈                        <== 这篇论文占的位置
├── 一段自然语言批评
├── 能【定位错在哪一步】、【指出违反了哪条约束】、【建议怎么改】
└── 人类本来就在大量产生它（用户吐槽、单测报错、编译器错误、judge 的批注）

完整示范（蒸馏 / 模仿学习）
├── 一整条正确解法，逐 token 都有监督
├── 信息最密
└── 贵、难规模化，而且【前沿模型没有更强的老师可以模仿】
```

### 5.3.2 ⚠️ 先纠一个很容易写反的方向

**文本反馈不是用来「替代奖励函数」的。** 这篇论文里**标量奖励 R 从头到尾都在**，文本反馈是**叠加**在它之上的第二条信道。

✅ 证据有三处：(1) 论文 §2 的交互协议里，每一轮都既有 `r_h = R(x_0, y_h)` 又有 `c_h ~ M(·|x_h, y_h)`；(2) RLTF-SD 的优势估计 `A_i^(0) = R(x_0, y_1^i) − b^(0)`（论文 式 (7)）里，R 就是那个标量奖励；(3) RLTF-FM 的总目标是 `max J_MultiTurn(π) − λ * ℓ_FeeMol(π)`（论文 式 (10)），第一项就是普通的多轮 RL 奖励目标。

⚠️ 所以正确的说法是：**它没有换掉奖励函数，它是在稀疏奖励之外，额外开了一条稠密的监督通道。** 如果你在笔记里写成「用文本反馈替代奖励」，就把论文说反了。

### 5.3.3 ★★★ 核心难点：文字不可直接优化，那怎么办

**文字没法求导。** 你不能对一段中文/英文批评做梯度下降。论文给了两条把它「转成可优化信号」的路，而且两条路**转换方式完全不同**。

**另一个前提也要先说清** ✅（论文 §1 脚注 1 和 §2）：**训练时有反馈，测试时没有。** 论文明确选了更难的那一半——人类反馈类的、测试时拿不到的反馈（而不是单测报错那种测试时也能拿到的）。所以目标不是「学会在有反馈时改得好」，而是**把反馈内化进第一轮**。

✅ 论文 §1 和 §5.1 都验证了朴素做法行不通：直接做多轮 RL，第二轮确实变好了，但**第一轮几乎没涨**——因为目标函数里反馈完全可以被当成「多余的上下文」忽略掉，把反馈换成无意义 token 目标也仍然成立。

```
RLTF-SD（Self Distillation，自蒸馏）的转换路径：

  x0 (题目)
   |
   +--> 学生采样 y0 ----> 奖励 r0 ----> 用来当基线 b(0)
   |                 |
   |                 +--> judge 写批评 c0   <== 文字在这里
   |                                   |
   +--> x1 = concat(x0, y0, c0) -------+
         |
         +--> 学生【在 x1 条件下】采样 y1     <== 这就是「老师」
               |
               +--> 用 y1 去更新 π(· | x0)     <== 注意：更新的是【第一轮】的策略
                     权重 = R(x0, y1) − b(0)

  [!] 文字 c0 从来没有直接进入损失函数。
    它的作用是【改变了 y1 的分布】，而 y1 是可以求导的 token 序列。
    所以：文字 --> 更好的轨迹 --> 奖励加权的模仿。转了两道弯。
```

★ **这里的「老师」就是学生自己，只不过多看到了一条批评。** ✅ 论文 §3 原话：「we treat the policy acting under the post-feedback prompt as an implicit teacher, and distill it into the original one-shot policy」。⚠️ 这在结构上**就是特权信息自蒸馏**——老师 = 学生 + 一段学生在测试时看不到的上下文。和本目录 [03 特权信息章](03-特权信息蒸馏.md) 是同一个母题，只是特权信息的内容是「批评」而不是「标准答案」。

**第二条路 RLTF-FM（Feedback Modeling，反馈建模）更直接**：✅ 论文 §4 式 (9)，**把批评 c_h 本身当成要预测的文本**，做标准交叉熵：

```text
ℓ_FeeMol(π)  =  E[ sum_h  −log p_π(c_h | x_h, y_h) ]

总目标  =  J_MultiTurn(π)  −  λ * ℓ_FeeMol(π)          λ = 0.2  (论文 Table 2)
```

✅ 论文特别注明：`y_h` 按常数处理（不回传梯度），所以这一项是**纯监督学习**，不会引入额外的信用分配。

⚠️ FM 这条路比 SD 更「文字原生」：它**没有把文字转成轨迹再转成奖励**，而是直接把文字当成语言建模目标。代价是：它训练的是「会不会批评」，而**不是**「会不会做对」——论文 §4.1 自己承认「its benefit is not obvious a priori」（它为什么有用并不是一眼能看出来的），所以专门写了一整节表示学习的理论去解释。

### 5.3.4 ★ 第一轮基线 vs 第二轮基线：一个能算出来的坑

✅ 论文 §3.1 指出了一个非常具体的失效模式，叫 **gradient-signal collapse**（梯度信号坍缩）。

如果你按 GRPO 的习惯，用**第二轮**的组内平均当基线，那么只要组内 N 个样本的奖励**全一样**（全对或全错），中心化之后优势全是 0，**这一步完全没有梯度**。✅ 论文给的概率是 `p1^N + (1−p1)^N`，其中 p1 是第二轮的成功率。

**而反馈越有用，p1 就越接近 1，坍缩就越频繁。** 拿论文 Table 2 披露的组大小 **N = 8** ✅ 代入算一下（⚠️ 这张表是我按论文公式算的，论文没列）：

| 第二轮成功率 p1 | `p1^8` | `(1−p1)^8` | **这一步梯度为 0 的概率** |
|---|---|---|---|
| 0.5 | 0.0039 | 0.0039 | **0.78%** |
| 0.7 | 0.0576 | 0.0000656 | **5.8%** |
| 0.8 | 0.1678 | 0.0000026 | **16.8%** |
| 0.9 | 0.4305 | ~0 | ★ **43.0%** |
| 0.95 | 0.6634 | ~0 | ★ **66.3%** |
| 0.99 | 0.9227 | ~0 | ★ **92.3%** |

★ **读法：反馈质量越高，这个 bug 越严重。** 老师（= 带反馈的自己）几乎每次都做对，恰恰是你最想学的时候，而这时 93% 的 batch 给不出任何梯度。这是一个**反直觉但能用计算器验证**的失效模式。

✅ 论文的修法：基线改用**第一轮**的组内平均 `b(0) = (1/N) Σ R(x_0, y_0^j)`（式 (7)）。两个好处：(a) 它和 y_1 之间没有样本内耦合，期望上是 0，梯度仍然无偏；(b) 只要**学生自己还没做对**（`b(0) < 1`），优势就不为零——**只在学生已经会了的时候才归零**，这正是我们想要的。

### 5.3.5 ★ 重要性采样为什么被整个扔掉：一个 ✅ 实测数字

理论上，用第二轮的样本去估第一轮的梯度，要乘重要性比值 `π(y1|x0) / π(y1|x1)` 才无偏。✅ 论文 §3 式 (4) 证明了这一点。

但论文 §3.2 指出：**这个估计量的方差由二阶矩控制**，而二阶矩是**概率比值本身**的期望（`E_q[w²] = 1 + χ²`），不是对数比值。对长序列，逐 token 的偏移会**连乘累积**。

✅ 论文附录 D.5 Table 3 给了 AIME24 上的实测：

| 量 | 值 | 这意味着什么 |
|---|---|---|
| 轨迹级平均 log 重要性比值 | ★ **142.16** | ⚠️ 权重本身约等于 `exp(142)`，是一个 10 的 61 次方量级的数。**轨迹级重要性采样在这里完全不可用** |
| token 级平均 log 比值 | 0.1288 | 单 token 看着很小 |
| token 级标准差 | 0.5506 | ⚠️ 标准差是均值的 4.3 倍，长尾很重 |

⚠️ 我的验算：若一条回答约 1000 个 token，均值 0.1288/token，累计 log 比值约 129，和实测的 142 是同一个量级 —— ✅ 这和论文「this shift compounds across tokens」的说法一致。

✅ 论文的选择很干脆：**连裁剪都不要，直接把重要性权重整个丢掉**，令 `π_ref(·|x1) = π(·|x0)`，退化成 AWR（Advantage-Weighted Regression，优势加权回归）式的目标。论文 §3.2 原话：「we find that **variance dominates bias**」（方差压过偏差），并在 §5.2 的消融里显示：加了重要性权重（无论用 PPO 式还是 CISPO 式裁剪）训练都变得不稳。

⚠️ **这条经验的可迁移性**：它说的是「在第一轮策略和第二轮策略差距很大时，偏差比方差便宜」。和 [04 OPD 方法改进章](04-OPD方法改进.md) 讨论的那类 off-policy 修正是同一类权衡，但结论方向相反的场景也存在 —— 别当成普适定律。

### 5.4.2 ★★★ 信用分配：50 步失败了，该怪哪一步

**这是长程任务的核心难点，也是蒸馏在这里的真正作用。**

```
ORM（结果奖励模型）在长程任务里的困境：

  一条 50 步的轨迹
  step 1   step 2   step 3   ...   step 48   step 49   step 50
    OK       OK      WRONG    ...     OK        OK       FAIL
                      ^^^^^
                      真正的错因在这里

  环境最后只说一个字：失败。
  GRPO 的组相对优势是【整条轨迹一个数】，
  这个负优势会被平摊到【全部 50 步】上
  ==> 48 个对的动作被一起压低了概率。

  这就是【错误的信用分配】。
```

✅ 论文 §5.2.1 的原话：「In long-horizon tasks, when both non-optimal action ratio and RL task horizon increase, correct and incorrect actions are mixed in very long trajectories. **ORM based GRPO will assign rewards incorrectly**, failing to optimize long horizon agent tasks.」

**还有一个更狠的后果：长程 + 低质量时，GRPO 连梯度都没有。** ⚠️ 下面这张推演表是我算的（论文只给了现象，没给这个算法），但它能解释论文观察到的「梯度消失」：

```text
设每步正确的概率为 q，整条 T 步轨迹全对才算成功：P(成功) = q^T
GRPO 组大小 G，若组内 G 条【全部失败】，组内奖励全相同
==> 中心化后优势全为 0 ==> 这个 prompt 这一步【完全没有梯度】
P(组内全失败) = (1 − q^T)^G
```

| 单步正确率 q | 轨迹长度 T | **P(整条成功) = q^T** | G=8 时 **P(组内全败)** | 后果 |
|---|---|---|---|---|
| 0.95 | 5 | 0.774 | 0.0000 | 正常学习 |
| 0.95 | 10 | 0.599 | 0.0007 | 正常学习 |
| 0.95 | 20 | 0.358 | 0.029 | 开始有空转 |
| 0.95 | 50 | ★ **0.0769** | ★ **52.7%** | ⚠️ 一半的 batch 零梯度 |
| 0.90 | 50 | ★ **0.0052** | ★ **96.0%** | ⚠️ **几乎学不动** |
| 0.80 | 50 | 0.0000143 | 99.99% | ⚠️ 彻底卡死 |

✅ **论文确实观测到了这个现象**（§5.2.2 结果 (2)）：「specific GRPO curves **begin exactly at zero and remain completely flat** along the x-axis during the initial checkpoint steps... continuously increasing the number of non-optimal actions **triggers a vanishing gradient issue**」。⚠️ 上表是我给这个观测配的一个可验算解释，论文没写这个推导。

**那蒸馏是怎么绕开的？** ✅ 论文 §2.2 式 (2)：Agent-OPD 的损失在**每一轮的每一个 token** 上都有一项逆 KL：

```text
L_Agent-OPD(θ)  =  E[ sum_{k=1..K}  sum_{t=1..T_k}   D_KL( p_{k,t} || q_{k,t} ) ]
                       \__ 轮 __/     \__ token __/

  ==> 监督信号的数量 = 轮数 * 每轮 token 数，而不是【一条轨迹 1 个数】
  ==> 和【最终成没成功】完全无关
```

⚠️ **用论文 Figure 8 披露的量级估一下差距**（我的估算）：响应长度 150–350 token/轮，15 轮 ⇒ 一条轨迹约 `15 × 250 = 3,750` 个被监督的位置；而 ORM 只给 1 个数。**监督密度相差约 3 个数量级。**

★ **机制要点（本章最该记住的一句）：蒸馏在长程任务里不是「更好的奖励」，而是直接把信用分配这个问题取消掉了。** 老师在每一步都说「这里该怎么走」，所以根本不需要回答「是哪一步的错」。

★ **但这个取消是有代价的，而且代价很具体**：它把「找出哪一步错了」换成了「老师在每一步都是对的」。✅ 论文 §5.2.1 自己点明：「it is clear that **the correctness of the teacher planning pattern is extremely important**」。5.4.5 节会给出老师不对时会有多惨。

### 5.4.3 三个适用区域：OPD 的有效区比 GRPO 宽

✅ 论文 §5.2.1 把「什么时候 RL 有用」划成三个区域（Region A/B/C），两个维度是 **RL 任务长度** 和 **预训练数据质量**（用「非最优动作占比」衡量）。

| 区域 | 名字 | 判据 | 为什么 |
|---|---|---|---|
| **Region A** | **不必要区**（Unnecessary） | 不同规划模式表现差不多 | ✅ 预训练数据本来就是全最优的，没什么可选的。而且**高互信息的规划知识 RL 本来就注入不进去**，该用 SFT |
| **Region B** | **有效区**（Effective） | 不同规划模式差异明显，RL 能找到更好的 | ✅ 低互信息的**规划模式**能跨样本泛化，RL 擅长把它挑出来 |
| **Region C** | **不支持区**（Unsupported） | 更好的模式存在，但**取决于算法设计**，用错算法就激活不了 | ✅ 长程 + 低质量 ⇒ ORM 信用分配失效 |

**✅ 完整的实测网格**（论文 Figure 7 + Table 3，avg@8 的 S/M/L Mean 相对 Instruct 的差值，单位百分点）：

| 预训练数据质量 → | **4 最优**（全好） | **4 最优 : 4 次优** | **4 最优 : 8 次优**（最差） |
|---|---|---|---|
| **GRPO**，RL 用短程数据 | +0.1 | +10.0 | +7.4 |
| **GRPO**，RL 用中程数据 | −0.3 | +13.5 | ★ **−0.3** |
| **GRPO**，RL 用长程数据 | −0.1 | +12.3 | ★ **−1.6** |
| **OPD**，RL 用短程数据 | −1.7 | +16.6 | **+18.4** |
| **OPD**，RL 用中程数据 | −1.4 | +15.2 | **+18.9** |
| **OPD**，RL 用长程数据 | −1.1 | +15.1 | ★ **+18.6** |
| **区域归属** | Region A（两者都没用） | Region B（两者都有效） | ★ GRPO 落进 Region C；**OPD 仍在 Region B** |

★ **读表三句话：**

左列（数据本来就好）：**两个方法都没用，OPD 还略微有害**（−1.1 到 −1.7）。⚠️ 这一列很容易被忽略，但它说明 OPD 不是免费的。

中列（中等质量）：**两者都有效，GRPO 的 +13.5 和 OPD 的 +15.2 差距不大**（相差 1.7 点，SE≈1.3，勉强超噪声）。

右列（最差质量）：★ **分水岭。** GRPO 在中程和长程上变成**负的**，OPD 还稳定在 +18.4 到 +18.9。这就是论文标题里「OPD 有更宽的有效区」的全部实证内容。

### 5.4.4 ✅ 一个不靠准确率的旁证：梯度方向一致性

论文 §5.2.2 没有只看准确率，还直接量了**参数更新方向**：对每个 checkpoint 的权重增量 `ΔW = W(t) − W(base)` 做奇异值分解（SVD），取前 5 个左奇异向量，和**最终 checkpoint** 的对应向量算余弦相似度，再按层平均（✅ 论文 式 (11)–(16)，k=5，最多 75 个训练步）。

**意思是：训练早期的更新方向，和最后收敛的方向像不像？** 像 ⇒ 一路朝着一个目标走；不像 ⇒ 在原地打转。

| 观察 | 结论 | 出处 |
|---|---|---|
| 任务越长，GRPO 的方向一致性数值越低 | ✅ 粗粒度信用分配让 GRPO 的更新方向变得不一致 | 论文 §5.2.2 结果 (1) |
| 非最优动作越多，**GRPO 的曲线从 0 开始、完全平** | ✅ 梯度消失（和 5.4.2 的推演对上了） | 论文 §5.2.2 结果 (2) |
| **OPD 在所有配置下都维持较高的一致性** | ✅ OPD 的更新方向稳定得多 | 论文 §5.2.2 结果 (3) |

⚠️ **这个证据比准确率更有说服力的原因**：准确率可能被评测噪声、checkpoint 选择、超参运气影响；而「早期方向 ≈ 最终方向」是直接量在参数上的，和评测集无关。⚠️ 但它有自己的局限：它只说明**更一致**，不说明**更正确**——一个一直朝错方向走的优化器，一致性也会很高。论文的 takeaway 里加了「in ideal teacher condition」（在老师理想的条件下）这个限定 ✅，是对的。

### 5.4.5 ★ 老师满分，学生照样崩：知识不匹配

**这是整篇最值得单独记住的一个实验。**

✅ 论文 §5.3 的设计：同一个目标（造出「羊毛」），有**两条都合法的配方**。

```
配方 A：  水  +  草籽  --> 草     草 + 羔羊  --> 羊毛
配方 B：  水  +  棉籽  --> 棉     棉 + 纺纱  --> 羊毛

学生 A：预训练时学的是配方 A，世界模型里只有 A。
老师 A：按配方 A 训练，所有难度 100.00 分。
老师 B：按配方 B 训练，所有难度【也是 100.00 分】。

然后让学生 A 分别跟老师 A、老师 B 做 OPD。
```

✅ 结果（论文 Table 4，4 最优:4 次优，S/M/L Mean）：

| 模型 | avg@8 | 相对 Instruct | pass@8 | 相对 Instruct |
|---|---|---|---|---|
| Instruct（起点） | 26.13 | — | 44.03 | — |
| 老师 A | 100.00 | — | 100.00 | — |
| 老师 B | ★ **100.00** | — | ★ **100.00** | — |
| 学生 + 老师 A（知识匹配） | **41.37** | +15.24 | **46.74** | +2.71 |
| 学生 + 老师 B（知识不匹配） | **31.50** | +5.37 | ★ **36.60** | ★ **−7.43** |
| **差值（B − A）** | **−9.87** | | **−10.14** | |

★ **读法：老师 B 是满分老师，但跟它学完之后，学生的 pass@8 从 44.03 掉到 36.60——比不训练还差 7.4 点。**

✅ 更细的格子更惨（论文 §5.3 结果 (2)）：中等难度的 FA 领域，学生+老师B 比学生+老师A 的 avg@8 低 **36.09** 点、pass@8 低 **43.75** 点。⚠️ 我按 Table 4 复核过：中等 FA avg@8 是 42.19 vs 6.09（差 36.10），pass@8 是 51.25 vs 7.50（差 43.75），**和正文对得上** ✅。

✅ 论文给的机制（§5.3 结果 (3)，配合 Figure 12 的训练曲线）：

```
训练早期：学生在对齐【规划模式】  --> 性能上升
            （模式是低互信息的，跨样本共享，好学）

训练后期：优化方向转向对齐【规划知识】 --> 训练崩溃
            （学生脑子里是配方 A，老师逐 token 要求配方 B，
              两套世界模型直接打架，旧的被覆盖、新的没建起来）
```

✅ 论文还观察到一个重要的**局部性**：崩的主要是 **ID（in-distribution，同分布）** 的那个领域（FA），**OOD（out-of-distribution，分布外）的 LF 和 EA 只是轻微退化**——因为它们的世界模型没有被直接覆写。

★ **这条结论能直接反过来用**：如果你做 OPD 时**只有 ID 性能掉、OOD 没怎么掉**，那很可能不是「学生能力不够」，而是**老师和学生的程序性知识不是同一套**。✅ 论文 takeaway：「Successful distillation requires similar internal world modeling between the teacher and student.」

⚠️ **和本目录其他章的关系**：这和 [01 综述与失败模式章](01-综述与失败模式.md) 讨论的 OPD 失效模式是同一类问题的不同切面，但这篇给出的根因（**程序性知识冲突**，而不是能力差距或分布错配）在我读到的三篇里是独有的。

### 5.4.6 ★ 单老师 vs 多老师：落到可比较的口径上

**先把口径对齐，否则「多老师更好」这句话没有意义。**

| 口径 | 单老师 OPD | **多老师 OPD（MOPD）** |
|---|---|---|
| 老师数量 | 1 | ✅ 3 个领域专家（Fantasy Alchemy / Livestock Farming / Electronic Assembly） |
| 老师各自多强 | 本领域 100.00 | ★ ✅ **本领域 100.00，其他两个领域 0.00**（论文 Table 6）。是严格的偏科专家 |
| 组织形式 | —— | ✅ 论文选了 **cascaded（级联）** 而非 mixture（混合）：**一次只跟一个老师学**，顺序 FA → LF → EA。理由是混合式要同时部署多个老师，基础设施开销大 |
| 损失函数 | 式 (2) | ✅ 式 (20)：同一个逆 KL，只是老师下标从 m=1 迭代到 M |
| 评价维度 | 单领域准确率 | ✅ 跨领域泛化 / 持续学习 / 冲突遗忘 |
| 分类维度 | —— | ✅ 两维：**有没有共享的规划模式** × **模式之间兼不兼容** ⇒ Type I / II / III |

**✅ Type I（有共享 + 兼容）：跨领域泛化真的发生了。** 论文 §6.2 给的最硬的证据是——**只用 FA 一个老师蒸馏，LF 领域也涨了**：

| 4 最优:4 次优 (a)，中等难度 | FA（老师所在领域） | **LF（老师 0 分的领域）** |
|---|---|---|
| Instruct | 41.95 | 34.92 |
| **After FA**（只跟 FA 老师学过） | 61.64 | ★ **52.58** |

★ 老师 FA 在 LF 上是 **0.00 分**，学生跟它学完却在 LF 上涨了 17.7 点。✅ 论文的解释是：学到的是**跨领域共享的规划模式**，不是领域知识。

**⚠️ 但 Table 6 还有一件论文没有讨论的事：第 2、第 3 个老师几乎没有再带来收益，甚至是负的。** 下面这张表我是直接从论文 Table 6 的 avg@8「S/M/L Mean」列抄的，差值是我算的：

| 学生设置 | Instruct | After FA | After LF | After EA | ⚠️ 第 2 个老师 | ⚠️ 第 3 个老师 |
|---|---|---|---|---|---|---|
| 4 最优:4 次优 (a) | 42.77 | **56.50** | 57.93 | 53.64 | +1.43 | ★ **−4.29** |
| 4 最优:4 次优 (b) | 26.61 | **42.91** | 42.64 | 39.24 | −0.27 | ★ **−3.40** |
| 4 最优:8 次优 | 14.95 | **33.85** | 33.41 | 31.00 | −0.44 | ★ **−2.41** |

★ ⚠️ **三行都一样：第一个老师干完了几乎全部的活，第三个老师反而把分数拉下来 2.4–4.3 点。** 按 5.4.1 算出的噪声门槛（这一列 SE≈1.3 个百分点），**−2.4 到 −4.3 超过了两倍 SE，不太可能是噪声**。⚠️ 论文正文没有讨论这个下降，它的叙述重点在「跨领域泛化成立」。**这是我读表得到的，不是论文的结论**，但数字是论文自己的。

✅ **机制上论文其实已经解释了这个下降，只是没把它和准确率联系起来**（§6.2 图结果 (1)(2)）：MOPD 是 **mode seeking（寻峰）** 的——逆 KL 让学生**收缩到老师们的共同峰**，而不是覆盖所有老师的偏好。最极端的证据是：跟完最后一个老师（EA）之后，学生在**三个领域**的规划模式分布**同时坍缩到单一模板「T1 Goal」，比例 1.00**（✅ 论文 Figure 18、Figure 19）。

```
MOPD 的几何直觉（[推断] 我的概括，论文用的是 mode seeking 这个词）：

  多个老师的模式分布
  ├── 老师 FA 喜欢  {T1, T3, T4}
  ├── 老师 LF 喜欢  {T1, T2, T4}
  └── 老师 EA 喜欢  {T1, T2, T3}
                      ^^
                      交集只有 T1

  级联 OPD 的结果不是【并集】，是【交集】。
  学生最后只剩 T1，概率 1.00。

  ==> 老师越多，交集越小，多样性被挤得越狠。
  ==> 这既解释了跨领域泛化（共享的被放大），
      也解释了第三个老师为什么是负的（独有的被挤掉）。
```

✅ **另一个硬边界**：MOPD **无法凭空造出目标环境预训练里不存在的模式**。论文 §6.2 结果 (4)：在 FA 里 T3 Planning 模式从 0.27 提到了 0.47，但同样的训练信号**在 LF 里完全激活不了 T3**——因为 LF 的预训练数据里根本没有 T3。

✅ **Type II vs Type III：冲突时会发生灾难性遗忘。** 论文 §6.3 用两套 SFT 配置（Form c / Form d）做对照，差别只在「normal 模板 1 在不在三个领域里都出现」：

| 配置 | Instruct | After FA | After LF | **After EA** | FA 领域在 After EA 之后 |
|---|---|---|---|---|---|
| **Form c**（有共享、冲突可控 → 持续学习模式） | 17.86 | 36.00 | 44.99 | ★ **63.64** | 短 91.88 / 中 58.83 / 长 47.34 —— ✅ **保住了** |
| **Form d**（无共享 + 冲突 → 冲突模式） | 16.28 | 35.08 | 41.19 | ★ **39.28** | 短 **15.62** / 中 **0.00** / 长 **0.00** —— ⚠️ **归零** |

★ **Form d 的 FA 领域在学完第三个老师后，中程和长程直接变成 0.00。** 对比它在 After FA 时的 63.20 和 38.75。这就是灾难性遗忘（catastrophic forgetting）的教科书级证据——**而且两组配置的唯一差别只是 SFT 语料里一个模板的覆盖面**。

⚠️ **可操作的推论（我的归纳）**：做级联 MOPD 之前，**先检查各个老师的行为模式有没有交集**。有交集 ⇒ 级联安全，而且第一个老师就能带来大部分收益；没交集 ⇒ 后面的老师会把前面的擦掉，顺序决定了谁活下来。

**✅ 论文 Table 5 列了四家把 MOPD 用进真实流水线的报告**，⚠️ 但**我没有核对这四家的一手报告**，下面只是转述论文的说法：

| 模型 | 论文说的训练流程 | 学生是谁 | 老师是谁 | 动机 |
|---|---|---|---|---|
| MiMo-V2-Flash | 预训练 → 领域训练 → MOPD | SFT 模型 | 领域专家模型 | 跨领域能力整合 |
| GLM-5 | 预训练 → 中训 → 级联 RL → MOPD | 最后一个 RL checkpoint | 之前的 RL checkpoint | 跨阶段能力保留 |
| Nemotron-Cascade 2 | 预训练 → 多领域 RL → MOPD → 级联 RL | 中间 RL checkpoint | 之前的 RL checkpoint | 跨阶段能力保留 |

**最后一个 ✅ 参数空间旁证**（论文 §6.4）：MOPD 对权重的改动极小。Instruct 到 MOPD 第一阶段的 L2 距离只有 **4.82×10⁻¹**，而 Instruct 到老师模型的距离是 **7.10×10¹ 到 7.36×10¹**。⚠️ 我算了一下比值：`7.10e1 / 4.82e-1 ≈ 147 倍`。论文的解读是：这解释了**为什么 OPD 学不进大规模的、预训练里没有的任务知识**——它根本没怎么动权重。⚠️ 这和 5.4.5 的知识冲突实验、以及 Region A「规划知识该用 SFT 注入」是同一个结论的三个侧面。

## 5.5 ★ 算力账：这三种做法各自要多付多少

**「蒸馏 + RL」比纯 RL 贵在哪？取决于你让老师干什么。** 这里有一个量级上的分水岭：

```
老师的三种工作强度（从便宜到贵）：

(1) 只算【对数概率】
    老师对学生【已经写好】的 token 序列做一次前向，取出 log p。
    一次批量前向，序列维度可以并行。
    ==> RLAD 和 PlanPhys 的 OPD 属于这一档。

(2) 生成【一段文字】
    老师要自回归地逐 token 吐出来，不能并行。
    ==> RLTF 的 judge 属于这一档。贵一个档次。

(3) 生成【整条轨迹】
    老师把题从头做到尾。
    ==> 离线蒸馏（SFT on teacher traces）属于这一档。
        本章三篇都【没有】走这条路。
```

### 5.5.1 RLAD：✅ 唯一一篇给了实测的

✅ 论文 §5.2.4 + Table 9。设置：学生 Qwen3-8B-Base，老师 Qwen3-32B，**老师和学生同机部署**，32 张 H200，全局批 256 / 微批 16，开启动态微批。单位是「更新一个训练批的秒数」。

| 方法 | Updating Actor | Compute Log Probabilities | **Total** | ⚠️ 相对 GRPO |
|---|---|---|---|---|
| GRPO（无老师） | 28.9 | 24.5 | **491.2** | — |
| KDRL（显式 KL） | 61.2 | 57.0 | **568.1** | ⚠️ **+15.7%** |
| RLAD | 60.9 | 56.2 | **567.4** | ⚠️ **+15.5%** |

⚠️ **三件事要说清楚：**

**(1) 论文正文写的是「about 12% extra training latency」，但它自己的 Table 9 算出来是 +15.5%。** `(567.4 − 491.2) / 491.2 = 76.2 / 491.2 = 0.1551`。⚠️ 两者对不上，口径未说明。**我建议引用时用 Table 9 的数自己算，并注明正文给的是 12%。**

**(2) 为什么只贵 15% 而不是 4 倍（32B / 8B = 4）** ✅ 论文给的理由是对的：「the teacher is only used to compute response of student rollouts for log-probabilities **rather than generate additional trajectories**」——**RL 里真正的大头是学生的 rollout 生成**，老师只做一次打分前向。Table 9 里 491.2 秒的总量，学生自己算 log 概率只占 24.5 秒，剩下的绝大部分是生成和其他开销。

**(3) ⚠️ 但有两处 Table 9 自己解释不了的：** 一是老师打分的增量（56.2 − 24.5 = 31.7 秒）只有学生那一步的 1.29 倍，**而老师的参数量是学生的 4 倍**，对不上线性外推；二是 **Updating Actor 从 28.9 涨到 60.9**，可 actor 还是同一个 8B 学生，为什么更新变慢了，论文没说。⚠️ 另外注意 Table 9 测在 **32 卡**上，而数学主实验跑在 **64 卡**上（✅ 论文 §5.2.1），两者不是同一个规模。

✅ **一个确定的好消息**：推理时完全不需要老师，所以**部署成本和基线完全一样**（论文 §5.2.4）。

### 5.5.2 RLTF：⚠️ 没给算力，我按超参推

✅ 论文**没有披露任何 GPU 数量或 wall-clock 时间**，只说训练跑在 Tinker 上（附录 D.4 与致谢）。所以下面整段是我按 Table 2 披露的超参推的 ⚠️：

```text
[一手] 论文 Table 2：group size = 8，groups per batch = 32
    ==> 每个训练步有  8 * 32 = 256  条第一轮 rollout

[推断] 下面是推出来的：
    每条第一轮 rollout 都要 judge 写一段批评
      ==> 每步 256 次【大模型文本生成】
    评测曲线 x 轴到 500~600 步（[一手] 论文 Figure 2/3/5）
      ==> 全程约 128,000 ~ 150,000 次 judge 生成

    RLTF-SD 还要采第二轮
      ==> 学生自己的生成量【翻倍】：256 --> 512 条/步
```

⚠️ **贵在哪，一句话**：judge 是 **Qwen3-235B-A22B**（2350 亿总参 / 220 亿激活），学生是 **Llama-3.1-8B**。按激活参数粗估，judge 的单 token 前向成本约是学生的 `22 / 8 ≈ 2.75 倍` ⚠️，而且它是**自回归生成**，不是一次批量打分。**这比 RLAD 那种「老师只做一次前向」贵得多，不是一个档次。**

⚠️ **但这笔账也可能根本不用你付**：论文 §1 的论点是，文本反馈**本来就在真实世界里大量存在**（用户吐槽、单测报错、编译器输出、judge 批注）。如果反馈是现成的，这笔生成开销就是 0。✅ 论文选的是「测试时拿不到反馈」的那一半，而真实场景里有一部分反馈（如单测）测试时也拿得到。

### 5.5.3 Agentic 长程蒸馏：⚠️ 一笔必须自己算的账

✅ **PlanPhys 也没有给 wall-clock**（只知道用 2 张 GPU、模型 100M、RL 最多 75 步、OPD 用 top-k 且 k=100）。但 agentic 场景有一个**结构性的坑**，值得单独算：

```
多轮任务里，老师要打分的【上下文在每一轮都变长】：

  第 1 轮：老师读  [题目]                              然后打分 T 个 token
  第 2 轮：老师读  [题目 + 回答1 + 观察1]               然后打分 T 个 token
  第 3 轮：老师读  [题目 + 回答1 + 观察1 + 回答2 + 观察2] 然后打分 T 个 token
  ...
  ==> 如果每轮都重新 prefill（预填充）整个上下文，
      总开销是轮数的【平方】，不是线性。
```

⚠️ **可验算推演**（符号：P = 初始题目长度，T = 每轮学生输出长度，S = 每轮上下文增量 = 输出 + 观察）：

```text
不复用缓存：  Σ_{k=1..K} [ P + (k−1)*S + T ]  =  K*(P+T) + S*K*(K−1)/2
复用前缀缓存：Σ_{k=1..K} T                    =  K*T
```

⚠️ 代入 PlanPhys 的量级（P=400，T=250，S=300，均由论文 Figure 8 的 prompt/response 长度曲线估得）：

| 轮数 K | **不复用缓存**（老师前向 token 数） | **复用前缀缓存** | ⚠️ **倍数** |
|---|---|---|---|
| 5 | `5*650 + 300*10` = **6,250** | `5*250` = **1,250** | **5.0×** |
| 15（PlanPhys 的典型长度） | `15*650 + 300*105` = **41,250** | `15*250` = **3,750** | ★ **11.0×** |
| 50（真实 agent 的量级） | `50*650 + 300*1225` = **400,000** | `50*250` = **12,500** | ★ **32.0×** |

★ ⚠️ **结论（我的推断，三篇论文都没给这笔账）：agentic 蒸馏的老师开销，决定性因素不是老师多大，而是你有没有做跨轮的前缀 KV 缓存复用。** 50 轮的任务里，这一个工程决定就是 32 倍的差距。

⚠️ **这条属于工程，不属于算法** —— 具体怎么做（KV 缓存复用、训推权重同步、老师服务的部署形态）在 [强化学习训练框架目录](../强化学习训练框架/README.md) 里讲；环境侧的瓶颈在 [后训练/07 Agentic RL](../后训练/07-AgenticRL-环境成为瓶颈.md) 里讲。本章只负责把这笔账的量级算出来。

### 5.5.4 三篇算力账小结

| | **RLAD** | **RLTF** | **PlanPhys（OPD）** |
|---|---|---|---|
| 老师干的活 | ✅ 一次打分前向 | ⚠️ **自回归生成一段批评** | ✅ 一次打分前向（top-k=100） |
| 学生多采几次 | ✗ 不用 | ⚠️ **SD 要采第二轮，生成量翻倍** | ✗ 不用 |
| 论文给了实测吗 | ✅ 给了（Table 9） | ⚠️ **没给** | ⚠️ **没给** |
| 相对纯 RL 的开销 | ✅ 实测 **+15.5%**（正文写 12%，对不上） | ⚠️ 推断：**远高于 15%** | ⚠️ 取决于前缀缓存，5× 到 32× 之间浮动 |
| 推理时要老师吗 | ✅ 不要 | ✅ 不要（这是论文的核心设定） | ✅ 不要 |

## 5.6 ★ 三篇互相矛盾的地方

**把分歧列出来，比假装一致有用得多。**

### 分歧一：蒸馏到底抬的是 Pass@1 还是 pass@K

| 论文 | 说法 | 出处 |
|---|---|---|
| **RLAD** | ✅ **KL 式蒸馏（KDRL）抬的主要是 Pass@32，不是 Pass@1**；它的提升「driven primarily by stronger imitation of teacher solution modes」。而 RLAD 自己抬的是 Pass@1 | 论文 §5.2.2 |
| **PlanPhys** | ✅ **OPD 抬的主要是 pass@1（avg@8），GRPO 反而有更高的 pass@8 天花板**；因为「OPD suppresses diversity and directly follows the planning pattern of the teacher」 | 论文 §5.2.1 结果 (2) |

★ **方向正好相反。** RLAD 说「模仿 ⇒ 多样性更好 ⇒ 高 K 指标涨」；PlanPhys 说「模仿 ⇒ 寻峰 ⇒ 多样性被压 ⇒ 高 K 指标反而是 RL 更好」。

⚠️ **我的判断（请当成判断而非结论）**：PlanPhys 的机制解释更符合逆 KL 的标准性质（逆 KL 是 mode seeking，必然降熵），而且它有**熵的实测曲线**和**模式分布坍缩到 1.00** 两个直接证据支撑；RLAD 那一条是从 Pass@1 / Pass@32 的相对涨幅**反推**出来的，没有直接测多样性。⚠️ 但两者场景差太远（真实 Qwen3 做数学 vs 100M 模型做合成规划），**也完全可能两边都对，只是适用区间不同**。

✅ 两篇的实测数都在上面的表里，你可以自己核。PlanPhys 的「4 最优:4 次优」那一组，pass@8 是 GRPO 的 +9.44/+11.25/+10.69 对 OPD 的 +3.54/+2.71/+2.36，差距明确。

### 分歧二：pass@k 还能不能当「能力上限」

✅ **PlanPhys §5.2.1 结果 (3) 直接质疑了这个指标**：长程设定里 RL 前的 pass@k 几乎是 0，RL 后大幅上升，但这**不代表 RL 提升了能力上限**——「the necessary knowledge or solution patterns may exist in the pretrained model but are **rarely sampled**」。它的 takeaway 写得很硬：「we do **not** think that RL improves the model's capability ceiling... pass@k is **distorted** in this setting」。

✅ **RLAD 则沿用了相反方向的文献共识**（引 Yue et al. 2025a）：RL 主要提升 Pass@1 而不是大 K 指标，并用这一点来论证 RLAD「更像真正的 RL」。

⚠️ 这两者不是严格矛盾（一个在质疑指标本身，一个在用指标做论证），但**如果你接受 PlanPhys 的质疑，RLAD §5.2.2 那整段论证的前提就动摇了**。这一点值得记。

### 分歧三：重要性采样该留还是该扔

| 论文 | 做法 | 理由 |
|---|---|---|
| **RLAD** | ✅ **留着，而且重要性比值就是整个机制** | 比值的分母是 `π_S,old` 和老师的几何混合 |
| **RLTF** | ✅ **整个扔掉**，连裁剪版本都不如不要 | 「variance dominates bias」 |

⚠️ **这不是真矛盾，是分母离得远不远的差别**，值得写清楚：RLAD 的分母是**上一版的自己**（PPO 的标准设定，两者很近）；RLTF 的分母是**第二轮的自己**（看过批评之后，分布差很远——✅ 实测轨迹级 log 比值 **142.16**）。⚠️ 所以可提炼的规则是：**重要性采样能不能用，取决于两个分布的实际距离，不取决于理论上是否无偏。**

### 分歧四：老师更强 = 更好吗

| 论文 | 证据 | 结论 |
|---|---|---|
| **RLAD** | ✅ 弱老师消融（0.6B 教 1.7B）：RLAD 0.946 vs GRPO 0.950，几乎不掉；KDRL 掉到 0.910 | 老师弱不致命（**前提是机制设计对**） |
| **PlanPhys** | ✅ 满分老师（100.00）+ 程序性知识不匹配 ⇒ 学生 pass@8 从 44.03 掉到 **36.60**，**比不训练还差** | 老师强**完全不够**，知识要对得上 |

⚠️ **合起来的可操作结论（我的归纳）**：**「老师的 benchmark 分数」是选老师时最不重要的指标之一。** 真正决定成败的是 (a) 蒸馏信号有没有被 advantage 调制（RLAD 的答案），(b) 老师和学生的内部程序性知识是不是同一套（PlanPhys 的答案）。

### 分歧五：⚠️ 本章没有解决的一个空白

**数据质量本来就好的时候，蒸馏是不是有害？** ✅ PlanPhys 的 Region A 一列给出的是 OPD **−1.1 到 −1.7 点**（三个 RL 长度都是负的），而 RLAD **从来没在「数据已经很好」的条件下测过**。⚠️ 两篇没有冲突，是**没有交集**。如果你的预训练/SFT 数据质量很高，本章三篇都没有告诉你该不该上 OPD。

## 5.7 这一章我能确定的、和不能确定的

**✅ 能确定的（都有一手出处）：**

RLAD 的机制是把老师塞进 PPO 的重要性比值分母，老师只改信赖域中心和裁剪阈值，不提供独立梯度方向（论文 §4.1）。

RLAD 实测训练开销按 Table 9 自己算是 +15.5%，推理时零开销（论文 §5.2.4 + Table 9）。

RLTF 的文本反馈**不替代标量奖励**，是叠加的第二条信道（论文 §2 / 式 (7) / 式 (10)）。

RLTF 把文字转成梯度有两条路：SD 转成「带反馈的第二轮生成当示范」，FM 直接把批评当交叉熵目标（论文 §3 / §4）。

RLTF 的重要性采样在实测中不可用：AIME24 上轨迹级 log 比值 142.16（论文附录 D.5 Table 3）。

PlanPhys 的 OPD 在「低质量预训练 + 长程」里比 GRPO 宽一个区域：+18.6 vs −1.6（论文 Figure 7 + Table 3）。

PlanPhys 的满分老师 + 知识不匹配会让学生比不训练还差：pass@8 36.60 vs Instruct 44.03（论文 Table 4）。

MOPD 是 mode seeking 的，最终三个领域的模式分布同时坍缩到单一模板 1.00（论文 Figure 18 / 19）。

**⚠️ 属于我推断的（请自行复核）：**

5.2.4 里 AIME24 的 SE 上界约 9 个百分点（n=30 道题的推导）。

5.3.4 里 N=8 时梯度坍缩概率的整张表（论文只给了公式 `p1^N + (1−p1)^N`，表是我代的）。

5.4.6 里「第三个老师带来 −2.4 到 −4.3 点」——数字是论文 Table 6 的，**差值和解读是我的，论文正文没有讨论这个下降**。

5.5.3 里 agentic 老师开销的平方增长推演，以及 5× / 11× / 32× 那三个倍数。

**⚠️ 我读不到、或拿不准的：**
