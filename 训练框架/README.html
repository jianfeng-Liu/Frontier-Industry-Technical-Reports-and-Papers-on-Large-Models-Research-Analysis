⚠️ 先说清楚三件事

① 这份教程不预设你懂任何分布式知识。

② 对你的唯一要求：会写 Python，看得懂函数、循环、list、以及"一个矩阵乘以另一个矩阵"。只要这些就够了。

🧭 这个领域的一句话地图

分布式训练这件事，说穿了只有两个问题：

问题一：装不下   ——  「一张卡的显存放不下模型」
        → 把【某个东西】切开，分到多张卡上
        → 切什么？有五个可切的维度：
             切 batch     → 数据并行 DP        （04、05 章）
             切 矩阵      → 张量并行 TP        （06 章）
             切 层        → 流水线并行 PP      （07 章）
             切 序列      → 上下文并行 CP      （08 章）
             切 专家      → 专家并行 EP        （09 章）
        → 外加两个「不切，但省」的办法：
             省精度      → 混合精度           （10 章）
             省激活      → 重计算             （11 章）

问题二：太慢     ——  「切开之后，卡和卡之间要通信，通信会拖慢」
        → 通信量、通信能不能和计算重叠、气泡有多大
        → 03、07、12 章

★ 全教程的核心张力就一句话：
每一种并行都在"省显存"和"加通信"之间做交易。没有免费的午餐，只有适合你这台机器的配比。
12 章讲的就是这个配比怎么定。
