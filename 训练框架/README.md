## ⚠️ 先说清楚三件事

**① 这份教程不预设你懂任何分布式知识。**

all-reduce、NCCL、张量并行、流水线气泡、ZeRO 三个阶段、激活重计算、MFU——这些词你**一个都不用提前知道**。教程从"**为什么一张卡装不下一个模型**"这个最朴素的问题开始，每个名词第一次出现都会先给**英文全称 + 中文 + 一句话解释**，再使用。

**② 对你的唯一要求**：会写 Python，看得懂函数、循环、list、以及"一个矩阵乘以另一个矩阵"。**只要这些就够了。**

**③ 这个目录和隔壁两个目录的关系**：

```
  ../业界模型技术报告/大模型架构入门/   ← 「模型内部长什么样」
                        │
  ../数据格式和数据处理/               ← 「数据怎么进来」
                        │
                        ▼
  训练框架/  ← 你在这里。「几千张卡怎么把这个模型、用这些数据，训出来」
```

**三者互补，没有先后依赖。** 但如果你完全没看过前两个，也不影响读这一份——本教程需要用到模型知识的地方都会现场解释。

## 🧭 这个领域的一句话地图

**分布式训练这件事，说穿了只有两个问题**：

```
问题一：装不下   ——  「一张卡的显存放不下模型」
        → 把【某个东西】切开，分到多张卡上
        → 切什么？有五个可切的维度：
             切 batch     → 数据并行 DP        （04、05 章）
             切 矩阵      → 张量并行 TP        （06 章）
             切 层        → 流水线并行 PP      （07 章）
             切 序列      → 上下文并行 CP      （08 章）
             切 专家      → 专家并行 EP        （09 章）
        → 外加两个「不切，但省」的办法：
             省精度      → 混合精度           （10 章）
             省激活      → 重计算             （11 章）

问题二：太慢     ——  「切开之后，卡和卡之间要通信，通信会拖慢」
        → 通信量、通信能不能和计算重叠、气泡有多大
        → 03、07、12 章
```

> ★ **全教程的核心张力就一句话**：
> **每一种并行都在"省显存"和"加通信"之间做交易。没有免费的午餐，只有适合你这台机器的配比。**
> 12 章讲的就是这个配比怎么定。
