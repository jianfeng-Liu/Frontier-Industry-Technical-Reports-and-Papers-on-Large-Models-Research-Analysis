## 📐 全教程通用的记号约定

> ★ 本教程一律采用 **Megatron 系列论文的记号**（见 Megatron-3 / 2205.05198 正文），
> 这样你读论文和读本教程时不用在脑子里做一次翻译。

```
Ψ (Psi)  = 模型参数量（个），如 70B = 7×10^10
N        = 总 GPU 数

s        = sequence length（序列长度，一条样本多少 token），如 4096
b        = micro-batch size（一次前向喂几条）
B        = global batch size（一步优化器更新用了几条）
h        = hidden size（隐藏层宽度），如 8192
a        = number of attention heads（注意力头数）
L        = number of transformer layers（层数）
v        = vocabulary size（词表大小）
m        = micro-batch 个数（一个 global batch 切成几份）= B / (b × DP)

并行度记号（本教程和 Megatron 保持一致）：
  t 或 TP  = 张量并行度       p 或 PP  = 流水线并行度
  d 或 DP  = 数据并行度       cp 或 CP = 上下文并行度
  ep 或 EP = 专家并行度       vpp      = 虚拟流水线并行度（interleaving）

⚠️ 注意 d 有两个含义：论文里 d 一般指数据并行度，hidden size 用 h。
   本教程遵守这个约定 —— 看到 d 就想"数据并行"，看到 h 就想"宽度"。

铁律：  TP × PP × CP × DP  =  总 GPU 数 N        （EP 是从 DP 里"借"的，见 09 章）

单位：  1 GB = 10^9 字节（本教程一律用十进制，方便心算）
        1 TFLOP/s = 10^12 次浮点运算每秒
```
